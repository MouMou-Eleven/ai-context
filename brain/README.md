# 建委大脑

| 入口 | 负责什么 | 何时读 |
|---|---|---|
| [cognition](./cognition/README.md) | 建委的思维、判断与商业认知 | 需要参考建委判断时 |
| [ai-expression](./ai-expression/README.md) | 中文质量短卡与按需表达方法 | 生成/改写中文成品时 |

身份和经历在personal，项目事实在work。认知说明判断和理由，可执行方法进入工作领域并引用；表达不是模仿建委个人口吻。

一个主任务可组合必要能力。表达只读一次，先短卡，口语/书面、语法细则和来源按需要展开；纯位置/状态查询、代码和文件操作不加载完整表达规则。

新认知或表达经验先查同义规则，记录来源和范围；一次反馈可为候选，经重复验证或建委明确确认再提升为默认。见[写入流程](../repository/ingestion-workflow.md)。
