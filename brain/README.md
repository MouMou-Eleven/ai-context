# Brain — 建委大脑

> 这里是“杨建委这个人的数字化认知与表达层”，只记录建委稳定的思考方式、判断习惯和个人表达习惯。

## 目录结构

```text
brain/
├── README.md                   总入口、激活条件和写入边界
├── thinking-and-decisions.md  思考问题、判断和决策的稳定习惯
├── business-cognition.md      已沉淀的商业与增长认知
└── personal-expression.md     建委本人说话、写作和沟通的稳定习惯
```

## 与工作领域的区别

| 内容 | 正确位置 |
|---|---|
| 建委本人怎样思考、判断和表达 | 本目录 |
| AI 培训课程怎样讲、名词怎样解释、实操资料怎样写 | [`../work/ai/training/`](../work/ai/training/README.md) |
| 自媒体标题、文章、口播、直播销售和平台经验 | [`../work/ai/self-media/`](../work/ai/self-media/README.md) |
| 飞书书稿的出版表达和编辑规则 | [`../work/ai/publishing/`](../work/ai/publishing/README.md) |
| 某个具体项目的文案、事实和口径 | 对应项目目录 |

领域表达只在该领域任务中激活；它不是建委的通用个人语言。建委大脑也不能自动覆盖领域规则。

## 激活条件

只有出现以下意图时才读取本目录：

- “按照我的思考方式分析。”
- “按照建委的表达习惯写。”
- “参考我平时说话的口语习惯。”
- “把这个判断沉淀成我的个人认知。”
- “从建委本人的角度表达。”

只提到“AI 培训、自媒体、书稿、微课、AI 视频”等领域时，不自动读取建委大脑。需要组合时，建委必须明确说“同时参考我的个人表达/思考习惯”。

## 写入准则

- 只有跨多个任务长期稳定、并得到建委明确确认的个人习惯或认知才能写入。
- 某个领域独有的语言、模板、方法和经验必须留在该领域。
- 外部作者材料不能直接变成建委的个人风格；必须经过建委确认和长期实践验证。
- 同一认知只保留一个权威表述；旧口径被纠正后直接退出当前文件，由 Git 历史追溯。
- 不因一次临时要求就修改长期个人画像。
