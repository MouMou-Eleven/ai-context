# 建委大脑

保存建委对世界的理解、判断依据、认知变化与决策方式。认知应来自明确表达或认可，不由AI从一次经历推断为建委的个人信念。

| 主题 | 内容 |
|---|---|
| [商业认知](./business-cognition.md) | 需求、产品、商业价值与内容经营的判断 |
| [思考与决策](./thinking-and-decisions.md) | 学习、分析、行动与决策方式 |

成长、财务、价值观等在形成真实积累后按主题扩展，不提前搭建空目录。

个人身份、经历与背书在[个人信息](../personal/README.md)；可执行行业方法在[领域知识](../work/domains/README.md)；通用中文表达在[表达与成品标准](../system/expression/README.md)。观点变化注明来源、日期与替代关系，重大变化保留修订依据。

外部文章、视频或创作者观点先登记为来源，不按人物整体激活。进入当前认知前须有建委明确认可或实际采用，剥离夸大数字和未经核验的因果，写清适用条件、限制、反例与验证方法，与现有认知去重。别人的身份、故事与偏好不能变成建委事实；尚未验证的判断保持假设状态。
