# 书面化表达

> 面向书稿、正式文档、教程、项目说明、方案和需要留档的内容。书面化保留清楚和亲切，不等于堆砌官话。

## 适用特征

- 标题能够自解释，读者不看上下文也能知道本节内容。
- 先说明对象和背景，再写动作、原因、限制与结果。
- 使用完整句子和明确指代，避免只有熟悉工具的人才看得懂的省略。
- 用“例如”“因此”“需要注意的是”等准确连接词，减少随意口语连接。
- 操作步骤按真实界面和可验证结果编写，不把作者备课动作写成读者任务。

## 书面化检查

- 是否存在“点回来”“半个上午”“别人”这类依赖语境才能理解的说法。
- 是否把作者工作台、讲师提示、内部备注混入读者正文。
- 是否用长句隐藏了前提、例外和责任边界。
- 是否把没有核验的时间、效果、价格或功能写成确定事实。
- 是否让图表、截图和正文各自承担不同信息，而不是重复表达。
