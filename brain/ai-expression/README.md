# AI 中文表达：默认短卡

生成、改写、润色、翻译或组织中文成品时先读本页。纯查事实、文件位置、运行代码或整理文件不自动加载。这里负责中文质量，不替代专业事实，也不代表模仿建委个人口吻。

## 每次执行与交付前检查

1. 确认给谁、解决什么问题、交付形式和事实来源；项目身份不能从模板示例推断。
2. 主语、动作、对象、指代明确；一个句子承担一个主要判断，复杂因果拆开。
3. 事实、推测、示例和待确认分开；数字、产品功能与效果承诺必须有依据。
4. 先说具体内容，删掉空泛客套、机械排比、同义重复和翻译腔；不能因润色改变原意或增加经历。
5. 标题自解释，图文/旁白一致；表格用于横向比较，流程关系用图，顺序用步骤，不设固定视觉数量。
6. 按体裁选择自然口语或准确书面语；正文面向接收者，内部过程和制作提醒另放。
7. 交付前复核标点、拼写、搭配、成分、语序、结构、指代、逻辑、语境和意义漂移。发现问题查下面对应细则，不需要每次加载全部来源表。
