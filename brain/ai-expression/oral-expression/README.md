# 口语化表达

> 面向朗读、口播、直播、授课讲解和真实交流。口语化只改变表达形式，不降低事实与逻辑要求。

## 适用特征

- 句子短一些，先说人能听懂的动作和结果，再补概念。
- 可以有自然停顿和转折，但每次转折都要服务于理解。
- 使用“先说结论”“真正卡住的地方是”“你可以先这样判断”等自然连接。
- 允许保留真实的判断、失败过程和限制，不把内容写成完美宣传稿。
- 术语出现时先用场景解释，再给出术语名称。

## 不要这样写

- 不用连续语气词、感叹号、网络黑话制造“像真人”的假象。
- 不用“大家都知道”“一定可以”“轻松解决”替代证据。
- 不把书面长句直接切碎，也不把口语稿写成客服或广告腔。
- 不用“接住”“赋能”“闭环”等万能词掩盖具体动作。

## 口播检查

1. 第一段是否说明真实场景或判断，而不是空泛问候。
2. 每句话是否能自然朗读，主语和动作是否清楚。
3. 观众听完这一段后，是否知道下一步理解什么或做什么。
4. 画面文字是否只保留精华，旁白是否补充原因、场景和边界。
5. 结尾是否有一个明确行动，而不是多个互相竞争的 CTA。
