## 提炼规则

- 先保留来源和适用范围，再提炼成可执行规则。
- 只有在两个以上任务中重复验证，或建委明确确认长期有效，才上升为跨领域经验。
- 具体领域的表达模板不直接提升为通用规则。
- 规则被新证据修正时，更新当前文件并在仓库级修订中保留原因。
