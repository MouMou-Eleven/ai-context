# Cognition - 建委认知

> 本目录保存建委跨场景仍然稳定的思维、判断、决策和商业认知。它不是外部观点收藏夹，也不负责中文语言质量或具体领域的工作方法。

## 目录结构

```text
cognition/
├── README.md                  认知入口、读取路由与写入边界
├── thinking-and-decisions.md  思维习惯、判断方式、决策与学习方法
└── business-cognition.md      商业、增长、内容经营与经营判断
```

## 读取路由

| 用户要解决的问题 | 读取文件 |
|---|---|
| 建委通常怎样分析、判断、决策、拆解案例或学习能力 | [`thinking-and-decisions.md`](./thinking-and-decisions.md) |
| 建委怎样判断产品、营销、增长、渠道、内容经营和商业闭环 | [`business-cognition.md`](./business-cognition.md) |
| 用户明确要求综合建委的认知体系 | 先读本 README，再按问题读取一份或两份认知文件 |

正常生成中文内容时不自动读取本目录。中文质量统一由 [`../ai-expression/`](../ai-expression/README.md) 负责；只有用户明确要求结合建委的思考、判断或商业认知时，才叠加本目录。

## 与其他目录的边界

- `personal/` 保存建委是谁、经历、能力和背书，不保存认知方法。
- `brain/ai-expression/` 保存所有中文内容默认使用的表达质量规则，不代表建委个人观点。
- `work/` 保存设计、AI、商业化和项目中的可执行方法、工具和事实。
- [`../../work/other/commercial/`](../../work/other/commercial/README.md) 保存跨行业可执行的商业经验和对外交付规则；本目录保存建委长期采用的商业判断。
- 单个项目的策略和临时决策仍写入对应项目 README 或历史，不提升为跨场景认知。

## 外部材料进入认知的条件

外部视频、文章、课程和创作者观点先作为来源分析，不能按人物整体激活。只有同时满足以下条件，才可以写入当前认知：

1. 与建委当前明确确认的方向一致，或已经被建委实际采用。
2. 去掉夸张数字、个人经历、平台传说和无法验证的因果关系后仍然成立。
3. 能写清适用条件、限制、反例和验证方式。
4. 与现有认知去重后仍有明确增量。
5. 不把别人的身份、语气、故事和个人偏好写成建委事实。

原始材料只在需要追溯、重新提炼且来源与授权允许时读取；日常任务优先使用本目录中已经校正的当前认知。

## 写入规则

- 稳定认知写当前有效结论，重要变化由 Git 和仓库修订记录追溯。
- “有人这样说”不等于长期认知；未验证观点必须标记为假设或留在工作经验中测试。
- 思维文件回答“建委怎样看问题”，商业文件回答“建委怎样判断商业”，不能互相堆叠。
- 可直接转成选题、内容、营销、交付和复盘动作的方法，进入 `work/` 对应领域，本目录只保留上位判断。
