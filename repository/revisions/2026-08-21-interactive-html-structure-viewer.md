# 交互式 HTML 仓库结构查看器

## 修订日期

2026-08-21

## 修订原因

桌面上的 Markdown 目录树虽然完整，但深层结构需要连续滚动，无法逐级展开或关闭，不利于整体理解和重新规划。

## 新口径

- `STRUCTURE.md` 继续作为唯一权威结构源，负责记录完整层级和中文用途说明。
- 根目录 `STRUCTURE.html` 由维护脚本自动生成，作为人类浏览层，不允许单独修改。
- HTML 使用纵向树状思维导图，支持单节点展开与折叠、全部展开、全部折叠、仅显示一级、一级目录快速导航和全文搜索。
- 搜索匹配目录名、文件名和中文说明，并自动保留匹配项的完整上级路径。
- 桌面固定输出为 `F:\桌面文件\GitHub仓库完整结构.html`；旧 Markdown 桌面镜像停止使用并清理。

## 同步机制

1. 结构调整时先更新 `STRUCTURE.md`。
2. `pre-commit` 根据 Markdown 重建并暂存 `STRUCTURE.html`。
3. `post-commit` 和 `post-merge` 重新生成桌面 HTML。
4. 同步脚本核对仓库 HTML 与桌面 HTML 的 SHA-256，避免两个版本漂移。

## 边界

HTML 是离线单文件，不依赖网络、CDN 或第三方库。结构数据直接嵌入文件，双击即可浏览。任何内容调整仍应写入 `STRUCTURE.md`，不得直接编辑生成后的 HTML。
