# 桌面 HTML 同步稳定性加固

## 修订日期

2026-08-21

## 风险

原同步链路会在 F 盘、Windows 桌面目录或目标文件暂时不可用时返回错误。由于 `pre-commit` 把桌面镜像同步视为强制步骤，短暂的系统状态可能阻断仓库提交。

## 调整

- 仓库 `STRUCTURE.html` 仍必须在提交前成功生成并进入同一次提交。
- 桌面镜像改为可恢复的非阻断步骤；目标不可用时保留仓库正确状态并延后重试。
- 目标目录存在于可用磁盘但被删除时自动重建。
- 目标文件短暂占用时最多重试四次，写入继续采用临时文件加原子替换。
- 除提交和合并外，增加 checkout 与 rewrite 后的自愈触发。
- 校验脚本在桌面目录暂不可用时只给出警告，仓库结构错误仍继续严格报错。

## 重启边界

Git Hook 路径写入本地仓库配置，不依赖常驻后台进程，关机或 Windows 更新不会清除。重启本身不会产生结构变化；重启后第一次提交、合并、检出、amend、rebase 或手动同步会重新核对并补齐桌面 HTML。
