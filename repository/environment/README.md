# Environment - 电脑与运行环境

本目录只保存维护 AI 协作所需的设备、网络、本地工具和已验证排障边界，不属于建委的工作项目。

## 目录

| 入口 | 内容 | 激活条件 |
|---|---|---|
| [`computers/README.md`](./computers/README.md) | 按设备划分的电脑环境档案 | 明确涉及电脑、网络、VPN、Codex 或本地工具故障时 |

## 写入规则

- 先确认设备，再读取设备入口；不得把不同电脑的配置混用。
- 只记录长期有效的配置、故障结论和操作禁区。
- 密钥、Token、Cookie、完整认证文件、局域网地址等敏感数据不得入库。
- 临时日志与一次性命令不入库；有长期价值时先清洗为结论。
