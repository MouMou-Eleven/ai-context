# 项目入口模板

- ID：稳定且唯一，不用跨系列课号代替。
- 名称/主归属：
- 类型：会员社群 / 外部培训场次 / 商单 / 产品 / 出版等。
- 客户/组织者/受众：未知就待确认。
- 状态与截至日期：
- 当前目标与明确边界：
- 事实权威文件：进度、价格、权益等各指定一处。
- 已确认事实与来源：
- 待确认：
- 下一步：
- 案例/方法/产物索引：相对链接或可访问外部位置及版本。
- 相关能力：按用途链接，不复制正文。
- 写入方式：每次更新事实、README、上层索引、路由、结构与历史影响范围。

培训额外记录课程系列ID、教材资产ID和实际场次；章节额外记录当前章ID与旧章映射。
