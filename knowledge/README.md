## 写入判断

- 单个项目的事实、进度、案例和决策进入项目目录。
- 某个工作领域长期积累的方法进入对应 `projects/ai-*` 目录。
- 跨多个项目仍成立的认知、判断和商业方法进入本目录。
- 外部原始材料跟随调用它的领域保存，不建立脱离上下文的全局资料堆。
- 未验证观点可以记录，但必须标记“待验证”，不能写成稳定原则。
