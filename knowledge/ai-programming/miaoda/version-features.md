## 2026.05.13 — V3.0

里程碑版本：从"网页/小程序生成"扩展到"原生 APP 生成 + 通用任务执行"。

- **生成 APP**：自然语言生成原生 APP，支持 iOS 与 Android、Android 应用包打包、在线调试、APP 热更新
- **执行通用任务**：新增数据分析、深度研究、图片生成、PPT 生成、视频生成、网页解析等通用任务能力
- **上传多类型文件**：支持上传多类型文件作为任务或生成输入，扩展文件驱动的数据分析、解析与内容生成场景
- **集成 Skill**：插件体系全面升级为 Skill，支持在应用开发与通用任务场景调用
- **AI 自动质检**：非游戏类应用核心功能可用性检测，针对异常应用自动生成质检报告并提供一次免费修复
- **秒哒 APP**：移动端 APP 上线（安卓已上线，iOS 即将上线）
- **首页推荐问回放**：一键回放生成过程
- **发布流程优化**：按应用与小程序双类型区分配置项；支持 AI 生成封面
- **企业级 SLA**：高可用数据库资源保障
- **企业应用协作**：团队空间内多人共同创作同一应用
- **打通 Billing**：接入百度智能云标准计费系统，可记销售业绩、开发票

## 2026.04.01 — V2.5

里程碑版本：发布"秒哒 Skill"（**反向能力**——秒哒被 Agent 调用，详见 [skill-as-callable.md](./skill-as-callable.md)）。

- **PM Agent 升级**：需求文档从"功能罗列式"升级为"结构化产品方案"
- **发布秒哒 Skill**：秒哒打包为 Skill，可被 OpenClaw、Claude Code 等 Agent 调用，实现应用的智能化、批量化自动开发
- **小程序美观度优化**：解决间距、超出边界、对齐不规范问题
- **首页文件类型拓展**：新增 svg / gif / fbx / obj / glb / gltf / wav / mp3 / avi / mp4 / mov / ttf / woff，单文件 ≤ 20 MB
- **后端服务全新升级（邀请制）**：开发与生产环境数据库独立、数据库版本与应用版本绑定支持回滚
- **应用开发新增推荐问**：主动推荐应用优化 query
- **新增 15 个插件**：MiniMax 文本生成、视频生成（高级版）、图片生成与编辑、可灵图片扩展、百度 PC 关键词排名查询、汽车尾号限行、贵金属行情、驾考题库、彩票开奖、地点详情、行政区划、交通路况、天气、IP 位置识别
- **UI 增强器-自动模式**：根据 query 自动设计风格
- **执行失败返还秒点**：PRD/应用生成失败、修改失败、服务故障、主动中断对话等场景返还秒点
- **插件免费额度**：图片/视频生成类 20 次/天/用户；其他类 200 次/天/用户
- **后端函数运行可视化**：新增后端函数管理面板，查看插件、复杂业务逻辑的运行日志与代码
- **插件计费**：插件支持按调用次数消耗秒点
- **企业版 MVP**：企业-团队-成员三级权限体系
- **个人会员权益**：付费即享源码导出、专属域名绑定、应用去水印

## 如何扩展本文件

### 场景 A：新版本上线（最常见）

1. 在「2026.05.13 — V3.0」**上方**插入新章节，标题格式 `## YYYY.MM.DD — V<版本号>`
2. 用无序列表罗列重点能力，每条用粗体标题 + 简短解释（参考已有版本格式）
3. 如果是里程碑版本（如域名切换、架构重构、生成新形态），在该节首行加一句话说明里程碑性质
4. 写入前必须读取最新官方更新日志，并把新日志 URL 加到文件顶部「官方更新日志入口」
5. **不要修改历史版本章节**——历史是不可变的事实记录，只追加不修改

### 场景 B：旧版本细节补全

如果发现某个旧版本的能力描述需要补全（例如官方文档后来更新了），直接在对应章节追加项目符号；不要重排顺序。

### 场景 C：勘误

如果发现历史记录有事实错误，标注 `~~错误~~ → 正确（更正于 YYYY-MM-DD，依据：<官方 URL>）` 而不是直接覆盖，保留勘误轨迹。
