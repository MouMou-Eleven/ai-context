# Course Design — 课程开发与课件设计知识

> 状态：当前有效的知识入口
> 口径确认：2026-08-01
> 适用范围：建委作为 AI 讲师进行课程开发、课件设计、教学活动和讲师交付时的可复用知识。

## 这个目录解决什么

这里沉淀的是跨课程可复用的“怎样教”的规则，例如课程开发方法、课件设计规则、讲师课件与学员资料边界、教学活动设计和课程复盘。它服务付费社群课程，但不等于该项目的产品定位、招生话术或某一季课程大纲。

当前仓库尚未确认一套完整、可直接执行的课程开发或课件视觉规则。因此，AI 不能根据常见教学法自行补写成“建委的规则”；每次先遵循用户当次给出的课程要求，待建委确认后再将具体规则沉淀为专题文件。

## 当前调用规则

1. 设计课程大纲、单节课、讲师备课或课件时，先读本文件，再读所属项目的当前事实。
2. 产出学员正文时，同时读 `tutorial-writing/README.md`；不能把讲师提示、时间安排或内部制作备注直接给学员。
3. 课程中出现技术难点时，再按需调用 `writing-style/README.md`，借用解释逻辑而不照搬其口播节奏。
4. 需要招生、短视频或私聊转化时，回到付费社群项目的运营资料；课程设计知识不负责替代销售表达。

## 后续沉淀方向

后续有明确实践和确认后，可在本目录新增并索引以下专题：课程开发流程、单节课设计、课件版式与信息层级、讲师课件与学员资料规范、互动练习设计、作业与反馈、课程复盘。每份专题必须写清适用对象、适用场景、不可用边界和确认日期。
