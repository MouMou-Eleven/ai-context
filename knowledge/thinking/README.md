# Thinking — 思维、判断与经验

> 状态：当前有效的个人认知入口
> 作用：保存不绑定某个项目、但会长期影响建委判断和行动的方法。后续的第一性原理、复盘认知、头脑风暴方法和成功经验优先进入这里。

## 当前原则

| 原则 | 当前理解 | 使用方式 |
|---|---|---|
| 第一性原理 | 回到目标、约束和真实问题，不被表面现象或流行说法带着走 | 分析复杂问题前，先问“真正要解决什么” |
| 效率优先 | 能稳定自动化的重复工作，不长期依赖人工重复执行 | 先判断自动化成本、风险和维护成本 |
| 工具导向 | 好工具能够放大能力，但工具选择必须服务结果 | 不为追新工具而追工具 |
| 迭代思维 | 先形成可验证版本，再根据真实反馈优化 | 不追求未经验证的一步到位 |
| 落地为王 | 理论必须能转化为动作、结果或判断标准 | 输出建议时给出执行步骤和验收条件 |

## 后续适合进入的内容

- 第一性原理在真实项目中的应用。
- 一次成功或失败后的可复用判断。
- 头脑风暴、方案选择和决策复盘方法。
- 从不同人物、案例或书籍中提炼的认知，但必须注明来源和适用边界。

## 不放什么

- 单个项目的临时决策放项目目录。
- 写作表达方法放 `expression/`。
- 产品功能、版本和操作步骤放对应项目或工具目录。
- 只听过一次、尚未验证的观点先标记为“待验证”，不能写成个人稳定原则。
