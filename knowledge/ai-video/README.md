# AI Video — AI 视频制作知识库

> AI 视频创作、企业宣传片、电影/电视叙事画面、具体模型工作流、提示词、分镜、AE 包装和项目复盘经验库。
> 索引最后整理：2026-07-18

## 目录定位

本目录用于沉淀 AI 视频制作相关经验，不属于具体产品项目。

适合放在这里的内容：

- AI 企业宣传片制作经验
- AI 电影/电视叙事画面制作经验
- AI 视频提示词方法论
- 企业宣传片分镜与导演思维
- 电影感短片分镜、角色动作和剪辑经验
- AE 特效包装提示词
- 不同行业宣传片视觉风格
- 客户修改意见复盘
- AI 视频工具能力差异
- Seedance 等具体模型的实战工作流与版本复测记录

## 类型边界

AI 视频制作经验必须按片子类型区分，不要混用。

| 类型 | 核心目标 | 优先读取 |
|---|---|---|
| 企业宣传片 / 形象片 / 战略片 | 传递企业信息、数据、业务板块、荣誉和价值观 | `enterprise-promo-production.md` |
| 电影 / 电视叙事画面 / 短片 | 角色、场景、动作、道具、情绪、剪辑节奏和电影摄影质感 | `cinematic-narrative-production.md` |
| Seedance 2.0 生成执行 | 主体与场景资产、简洁提示词、声音策略、镜头编号和分辨率选择 | `seedance-2-practical-workflow.md`；需要可调用角色模板时再读 `seedance-2-prompt-templates.md` |

判断原则：

- 如果主要问题是“企业信息怎么高级表达”，走企业宣传片/AE 包装逻辑。
- 如果主要问题是“一个故事镜头怎么拍得像电影/电视画面”，走电影/电视叙事画面逻辑。
- 如果主要问题是“Seedance 2.0 的 Prompt 怎么写、素材怎么准备、选 720p 还是 1080p”，走 Seedance 工具级工作流。
- 如果后续出现动漫、旅游片、产品宣传片等新经验，继续在本目录下单独建文件，避免混进现有分类。

## 使用指南

对于 AI：

- 涉及 AI 视频制作、企业宣传片、电影/电视叙事画面、AE 包装、分镜规划时，优先读取本 README。
- 需要制作企业宣传片时，再读取 `enterprise-promo-production.md`。
- 需要制作电影感、电视感、剧情短片、角色动作或荒诞喜剧画面时，再读取 `cinematic-narrative-production.md`。
- 使用 Seedance 2.0 时，再读取 `seedance-2-practical-workflow.md`；其中时间戳、分辨率等结论属于当前版本经验，平台更新后应复测。
- 需要直接调用角色 Prompt 时，再读取 `seedance-2-prompt-templates.md`；不要同时加载三份本地原始模板。
- 需要学习完整实测 Prompt 时，再读取 `seedance-2-prompt-cases.md`；案例经验不能自动升级为平台通用规则。
- 不要把企业宣传片的 AE 包装逻辑直接套到电影/电视叙事画面里；也不要把电影短片的角色动作逻辑直接套到企业数据包装里。
- 不要把 Seedance 2.0 的“简短 Prompt、不依赖时间戳”无条件推广到所有视频模型；先判断任务类型和工具。
- 不要把本目录内容与 `history/archived-projects/videoai/` 混淆；后者是已归档的具体产品历史资料，本目录是可持续维护的 AI 视频制作知识库。

对于建委：

- 后续新的 AI 视频制作经验可以继续放在本目录下。
- 如果新增文件，请同步更新本 README 的文件索引。
- 如果某个企业宣传片项目形成大量独立资料，可在 `projects/` 下单独建项目目录，本目录只沉淀可复用方法论。
