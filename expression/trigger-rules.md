# Trigger Rules — 自然语言触发与组合调用规则

> 状态：当前有效
> 确认日期：2026-08-02
> 作用：让建委用自然说法触发仓库知识，不需要记作者姓名、目录名或固定口令。

## 一、基本原则

触发词按语义识别，不要求逐字一致，也不区分“GitHub”“仓库”“上下文仓库”等自然说法。AI 先识别任务领域，再叠加表达要求：

```text
领域触发词决定“读取哪些事实、规则和案例”
表达触发词决定“用什么方式组织和讲述”
用户当次明确要求决定最终交付
```

表达方法只能改变“怎样写、怎样讲”，不能改变项目事实、课程目标、产品承诺或微课规则。

## 二、表达类触发词

以下说法及其近义表达，均触发 `expression/`：

- 参考我 GitHub 仓库里的语言风格。
- 参考仓库里的语言表达习惯。
- 参考语言表达习惯。
- 参考语言类案例。
- 参考我收集的优秀文案或表达案例。
- 按我沉淀的表达逻辑、讲解方式来写。
- 写得自然一点，减少 AI 味。
- 把这个内容讲得更清楚、更容易吸收。

默认读取：

```text
expression/communication-preferences.md
→ expression/methods/README.md
→ 选择与任务匹配的方法
```

当用户明确说“参考语言类案例、参考优秀文案案例、看看原始表达”时，再读取 `expression/source-materials/README.md`，选择相关来源；不得无差别加载全部原文。

## 三、自媒体类触发词

以下语义触发自媒体内容路由：

- 自媒体文案、自媒体内容、自媒体写作。
- 短视频口播、口播文案、短视频脚本。
- 选题、账号内容、公众号文章、内容规划。
- 爆款拆解、完播率、内容节奏、评论区承接、资料引流。

当前默认读取：

```text
expression/README.md
→ projects/paid-community-course/README.md
→ media-growth.md 或 script-patterns.md
→ 涉及承接与转化时再读 conversion-path.md
```

涉及“成果展示、用户动机、观点和知识怎样结合、知识内容为什么没人看”时，增加读取 `self-media-outcome-and-motivation.md`。

如果用户明确指定了其他项目，自媒体内容优先服从该项目，不自动套用付费社群的产品事实和转化规则。

## 四、AI 培训类触发词

以下语义触发 AI 培训工作领域：

- AI 培训、企业培训、企业内训、公开课。
- 培训学员、学员资料、培训课程、培训大纲。
- 讲师备课、授课方案、培训课件、讲师稿、课程复盘。

默认读取：

```text
projects/ai-training/README.md
→ projects/ai-training/teaching-and-course-design.md
```

如果同时出现表达类触发词，再叠加 `expression/`。如果同时出现付费社群、会员、招生或社群课程，具体产品事实继续服从 `projects/paid-community-course/`。

## 五、微课类触发词

以下语义触发微课工作领域：

- 微课、精品课、参赛课、教师委托。
- 哞哞微课、教育案例、VR 交互课件、AI 视频微课。

默认读取 `projects/microcourse/README.md`。即使任务中出现“课程、课件、学员”等词，只要主要交付物是教师委托的参赛微课或教育课件，就不能转入 AI 培训。

## 六、组合触发示例

| 建委的自然说法 | AI 应组合读取 |
|---|---|
| “参考我 GitHub 仓库里的语言风格，把这段话写自然一点。” | `expression/` |
| “参考语言类案例，帮我写一段技术科普。” | `expression/methods/`；按需选择 `source-materials/` |
| “参考语言表达习惯，写一条自媒体口播。” | `expression/` + 当前自媒体项目 + `script-patterns.md` |
| “参考仓库里的语言风格，整理 AI 培训学员资料。” | `expression/` + `projects/ai-training/` |
| “参考语言表达习惯，写一个微课案例介绍。” | `expression/` + `projects/microcourse/` |
| “写付费社群的自媒体转化文案。” | 付费社群项目 + 自媒体文件；需要自然表达时叠加 `expression/` |

## 七、歧义处理

- 只有“课程、课件”时，先根据服务对象和交付物判断 AI 培训还是微课；无法判断再询问。
- 只有“文案、内容”时，结合当前项目判断；没有项目语境时先确认用途，不擅自套用销售、自媒体或培训规则。
- 提到具体作者姓名时，先使用已提炼的方法；只有用户明确要求研究该作者原文时，才进入对应来源目录。
- 用户当次明确说“不参考仓库风格”或指定其他写法时，以当次要求为准。
