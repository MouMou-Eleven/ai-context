## 调用规则

- 用户说“参考仓库里的语言表达习惯”时，先读本页，再选择最匹配的方法。
- 一篇内容可以组合多种方法，但每种方法必须解决不同问题，不能为了显得丰富而堆模板。
- 方法文件只控制“怎样讲”，不能改变事实、项目口径、课程目标或产品承诺。
- 新来源先进入 `../source-materials/`；经过提炼和验证后，才进入本目录。
