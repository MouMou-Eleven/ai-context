# History — 历史与追溯入口

> 历史文件只用于回答“什么时候发生了什么、为什么改成现在这样”，不能直接覆盖 `current.md` 或项目 README 的当前口径。

## 文件索引

| 文件 | 内容 | 何时读取 |
|---|---|---|
| [`timeline.md`](./timeline.md) | 建委跨项目的重要里程碑，按时间倒序记录 | 追溯个人发展、项目建立和重要方向变化时 |
| [`archived-projects/`](./archived-projects/README.md) | 已退出主线维护的项目资料，保留原始文件和可追溯入口 | 用户明确提到归档项目，或需要查询历史方案时 |

## 历史信息分工

- 跨项目、影响个人阶段的重要事件写入 `timeline.md`。
- 单个项目的方向变化写入该项目 `revisions/`。
- 已不再作为主线维护、但仍有追溯价值的完整项目移入 `archived-projects/`，并在目录 README 标明归档决定和读取边界。
- 普通 Git 提交、日常小改动和临时待办不进入时间线。
- 历史记录出现旧头衔、旧数字或旧项目名是允许的，但回答当前问题时必须回到当前入口核对。
