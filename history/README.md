# History - 历史与追溯

> 本目录只回答“什么时候发生了什么”和“过去是什么样”。回答当前事实时必须回到 `personal/`、`work/` 或 `repository/` 的当前 README。

## 文件索引

| 入口 | 内容 | 何时读取 |
|---|---|---|
| [`timeline.md`](./timeline.md) | 跨领域成长与重要里程碑 | 追溯个人成长、项目建立和重大方向变化时 |
| [`archived-projects/README.md`](./archived-projects/README.md) | 已退出当前主线的项目 | 用户明确提到归档项目时 |

## 写入规则

- 跨越多个领域、影响个人阶段的重要事件写入 `timeline.md`。
- 单个活跃项目的重大变化写入该项目 `history.md`。
- 日常修改、过程日志和格式调整只保留在 Git 提交历史中。
- 已不再维护但仍有独特资料的完整项目进入 `archived-projects/`。
- 历史记录允许保留当时口径，但必须明确标注“历史”；不得覆盖当前 README。
