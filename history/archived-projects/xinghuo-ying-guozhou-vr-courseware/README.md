## 项目概述

《星火映果州》是一套基于顺泸起义前夕“《起义宣言》失窃”情节设计的 VR 交互课件。项目目标不是做普通网页式剧本杀，而是做适合 Nibiru Creator 这类 VR 交互工具落地的“一个场景接一个场景”的课程流程。

核心表达方式：

- 开始场景：有“立即开始”等明确按钮。
- 任务导入：发布调查任务。
- 调查目录：作为主导航场景，承载不同模块入口。
- 分模块调查：背景档案、人物询问、师部现场、城中走访、推理研判。
- 内容场景：从目录进入具体场景，完成后回到目录。
- 投票复盘：通过证据链判断内奸，再进入真相复盘、知识测验、成绩报告。

## 使用指南

### 对 AI

当建委要求设计 Nibiru / VR 交互课件时，不要只输出故事设定、角色资料或散乱功能清单。优先按“场景ID、场景名称、画面内容、按钮/热点、点击后跳转”的方式表达。

客户外发文档与制作端文档必须分开：

- 客户外发文档：不出现“客户版”“演示版”“制作工具”“变量”“条件器”“提示词”等内部或技术表达。
- 制作端文档：可以写 Nibiru 逻辑、场景跳转、热点、按钮、生图提示词和制作注意事项。

### 对建委

本目录用于沉淀《星火映果州》项目和类似 VR 课件的表达模板。后续新增素材、交互脚本、客户确认稿或制作复盘时，可继续追加到本项目目录，并同步更新本 README 的文件索引。
