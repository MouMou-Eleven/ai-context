# AI 设计

> AI 参与创意与生产，项目仍按最终交付物选择一个主归属。

## 负责范围

AI 生图、视觉方案探索、风格测试；AI 与 Photoshop、Illustrator、Figma 等工具协作；人工筛选、修正、排版和交付；视觉提示词、失败反馈与验收经验。

## 根据交付目标调用

- 海报、KV、系列视觉 → [海报设计与 Skill 入口](../poster-fold-design/README.md)。
- 视频分镜中的视觉资产或生成镜头 → [AI 视频](../../ai/video/README.md)，需要包装和合成再读 [AE 设计](../ae-promo-video/README.md)。
- 教师微课、MG 与教育交互 → [微课](../microcourse-mg-animation/README.md)。
- 需要开发界面、交互工具或生产自动化 → [AI 编程](../../ai/programming/README.md)。
- 商单复盘与可复用经验 → [联合制作与沉淀流程](../production-workflow.md)。

跨域任务自动组合必要方法，既不把项目复制到每个目录，也不因主位置不同限制读取。中文设计文案先读 [表达短卡](../../../brain/ai-expression/README.md)。
