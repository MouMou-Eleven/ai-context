# 设计与 AI 视频联合制作、经验沉淀流程

> 性质：2026-09-12 建立的执行与维护规则；不是已完成项目或效果证明。
> 适用：AE 视频、MG 微课、AI 生成镜头、海报/PPT 等设计商单。入口：[设计](./README.md) · [AI 视频](../ai/video/README.md)。

## 一个主任务，按环节补必要依赖

项目归属由交付目标决定，工具名称不决定归属。委托教师微课进入微课；以 AE 信息包装为主的成片进入 AE 设计；以生成式镜头和生成工作流为主进入 AI 视频。已有项目继续保留原主位置，其他目录补链接。

| 环节 | AI 应做什么 | 按需要读取 |
|---|---|---|
| 需求与事实 | 从现有资料提取对象、用途、时长、比例、交付格式、品牌约束、素材与验收要求；只追问影响执行的缺口 | 主项目 README；[案例索引](./cases/README.md)；涉及生成镜头读 [视频通用经验](../ai/video/common/README.md) |
| 脚本与分镜 | 将已核验内容拆成信息点、镜头编号、时长、画面动作、口播/字幕和制作方式 | [表达短卡](../../brain/ai-expression/README.md)；微课读 [微课入口](./microcourse-mg-animation/README.md)；企业片读 [企业片流程](../ai/video/types/enterprise-promo/workflow.md) |
| 视觉与素材 | 明确哪些是实拍/客户资料、哪些手工设计、哪些 AI 生成；建立可复用资产与风格约束 | [AI 设计](./ai-design/README.md)；[海报与视觉 Skill 入口](./poster-fold-design/README.md) |
| AI 镜头与提示词 | 只给需要生成的镜头写工具可执行提示词，先验证关键镜头，再迭代失败点 | [AI 视频](../ai/video/README.md) → 相关片型与已选工具；不把企业片科技风套给儿童微课 |
| 动画、合成与后期 | 按目标选择 AE、手工动画、Remotion 或其他适用工具；整理字幕、图层、声音与镜头衔接 | [AE 入口](./ae-promo-video/README.md)；[Remotion 参数化动画能力](../ai/programming/experience/skill-repository/jianwei-ai-community-remotion-video/README.md)；交互/自动化读 [编程](../ai/programming/README.md) |
| 交付与复盘 | 按约定检查内容准确、文字可读、节奏、技术规格和可编辑源文件；记录反馈与最终状态 | 本项目验收清单、所选工具的验收规则；[案例模板](./cases/case-template.md) |

例如“做 MG 微课，AI 帮我拆脚本、设计分镜和出视频提示词”：主读微课，接着按镜头需要读视频通用经验与生成工具，需要 AE 合成再读 AE；不加载企业培训教学规则，不默认读取所有片型。

## 案例、方法与工具各存一处

- **案例**记录这次真实任务：输入、约束、过程、失败、结果、证据。跨领域标签让它能从多个入口找到。
- **方法**记录可重用做法：适用任务、前提、步骤、验收、失败边界和来源案例链接。单例提炼可标“待复用验证”，多次验证后记录证据；不等于所有项目都适用。
- **Skill/工具**记录执行能力和来源，其实体继续放在工具/Skill 主位置。设计与视频只链接到能力说明，不复制一份规则。
- **项目**记录长期客户/连续交付的当前状态与决策；同一事实变动先更新项目主文，再同步引用摘要。

## 沉淀时由 AI 自动完成

1. 搜索本方向索引、已有案例和项目；同一商单补原记录，不按每次对话新建一份。
2. 确定主位置与关联方向。短复盘可用 `cases/`，持续项目用 `projects/<slug>/README.md`；目录按需要创建，避免先堆空目录。
3. 使用 [案例模板](./cases/case-template.md)，保留用户原始证据位置、执行版本、结果状态；没有失败或验收资料就标待补，不推断成功。
4. 将可复用方法提炼到对应领域独立方法文件，回链来源案例；案例也链接方法。工具参数回到工具主位置，不在各案例重复维护成通用规则。
5. 更新主目录 README 的文件索引和 [设计案例索引](./cases/README.md)。若主位置在 AI 视频，同时更新 [AI 视频项目入口](../ai/video/projects/README.md)；主位置在设计的视频案例，也在该入口补带标签的链接。只链接相关项，不复制正文。
6. 新增能力、业务边界、当前事实或优先规则时，按根级维护规则检查是否还需同步上级路由、当前状态和修订记录；普通案例不会自动变成全局规则。
7. 检查链接可达、旧入口仍可定位、记录未重复，最新适用证据与当前README已同步；不能为匹配旧摘要而忽略新事实。交付说明路径、调用说法、方法状态及待补证据。

## 让下一次调用足够简单

案例索引同时写“任务类型”和“何时可复用”。用户说“做一个类似的企业荣誉动画”时，AI 先找对应任务，再检查该案例的前提、失败修正与验收证据；不需要用户知道目录名或 Skill 名。找到的只是候选经验，具体数字、客户身份、奖项、版权与工具能力仍要按本次资料核验。
