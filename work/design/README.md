## 调用原则

1. 先确定交付物与对象，选择一个主入口；再按制作环节读取必要依赖，无需建委另说“结合 AI”或指定每个目录。
2. AE 项目用到 AI 分镜或视频提示词，自动联动 AI 视频；AI 视频需要图形包装、排版或合成，自动联动设计。跨领域调用不会改变项目归属。
3. 中文标题、脚本、旁白、案例说明先读 [AI 表达短卡](../../brain/ai-expression/README.md)，详细规范按具体问题展开。
4. 具体案例正文只有一个主位置，其他方向用带适用说明的链接发现它。目录差异不能阻止必要调用，也不意味着加载所有目录全文。
5. 仓库保存能力资料不等于当前环境已安装该工具；选定能力后再检查其来源、执行入口与可用环境。

## 写入完成条件

建委只需说明“把这次经验沉淀到设计/微课/AE”等意图。AI 按 [写入闭环](./production-workflow.md#沉淀时由-ai-自动完成) 判断主归属，记录证据、适用条件与失败修正，更新本级索引及必要的跨领域入口，并检查链接。未知信息写“待补”；客户未公开信息先去识别化。新方法不能仅凭一个展示文案就标为实战验证。

本 README 保持短入口。具体商单进入案例或项目，通用方法进入独立文件，业务方向变化按仓库全局维护规则同步。
