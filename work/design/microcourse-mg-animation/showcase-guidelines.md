# 哞哞微课案例展示写作规范

> 从原微课 README 分离，保留已有写法；更新：2026-09-12。
> 只在撰写对外案例简介时读取。商单经验沉淀必须另按 [案例模板](../cases/case-template.md) 记录过程与证据，展示简介不能替代复盘。

### 案例描述写作规范（重要 - 每个新案例都按这套来）

平台上每个案例都需要一段**精简且精准**的案例简介。写作约定如下：

| 维度 | 要求 |
|---|---|
| 篇幅 | **一段话**，1-3 句，不要分点、不要小标题、不要 emoji 堆叠 |
| 标题格式 | `案例名称 —— 一句话定位（融合的核心技术或目标人群）` |
| 必须包含三要素 | ① **围绕什么主题/章节/痛点** ② **融合了哪些技术** ③ **实现了什么效果（对课堂/学习者/教师的价值）** |
| 语气 | 精准、专业、克制；不要营销话术堆砌，不要喊口号 |
| 技术列举 | 用粗体加重关键技术名（如 **AI 视频生成**、**MG 动画**、**实拍 + 标注剪辑**），让读者一眼看到融合了什么 |
| 禁止 | 不要写成"亮点列表 + 数个分点"形式；不要超过 200 字；不要把同一句话换种说法重复说 |

### 案例描述参考模板

```
{案例名称} —— {一句话定位}

本案例围绕{主题/章节/痛点}，融合 {技术 A、技术 B、技术 C}：
{用一两句话串起来描述这些技术分别承担什么角色、产生什么效果}，
让{教师/学生/课堂}{具体价值——更直观/更高效/更规范/更有趣}。
```
