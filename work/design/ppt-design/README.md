# PPT 设计

## 负责范围

- 商务汇报、企业演示和路演 PPT。
- 培训课件、课程视觉和教学演示。
- 信息层级、版式、图表、视觉统一和现场可读性。

## 不负责

- 课程内容、教学顺序和讲师经验进入 [`../../ai/training/`](../../ai/training/README.md)。
- 飞书书稿的出版事实进入 [`../../ai/publishing/`](../../ai/publishing/README.md)。

## 当前状态

已确认这是建委的核心设计能力；仓库尚未沉淀独立 PPT 方法或项目正文。新增内容必须来自真实项目或建委明确确认。
