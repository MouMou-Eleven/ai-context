## 使用规则

- 先从 `../../types/` 确认片型，再调用 Seedance。
- 实测经验只对记录时的平台版本和环境负责。
- 时间戳、参数、分辨率和模型能力在执行前必须重新验证。
- 案例不能自动升级为通用平台规则。
