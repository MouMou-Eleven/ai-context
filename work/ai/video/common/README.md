# AI 视频通用经验

## 负责范围

- 需求确认、受众、时长和交付平台。
- 主体、角色、场景、道具和视觉资产准备。
- 分镜编号、镜头连续性、生成测试和失败修正。
- 剪辑、声音、字幕、包装和最终验收。

## 通用工作顺序

1. 先确认片型和目标，不从模型开始。
2. 建立可重复使用的主体与场景资产。
3. 先用低成本镜头验证角色、风格和动作。
4. 按编号生成并记录成功与失败条件。
5. 在剪辑阶段检查连续性、节奏、声音和信息完整度。
6. 最终按发布平台检查比例、清晰度、字幕和版权。

某种片型的专属方法进入 `../types/`，某个工具的参数和提示词进入 `../tools/`。
