# 真人实拍故事与电影叙事

> 更新日期：2026-06-15
> 来源：建委提供的《丧尸清道夫》类 AI 视频创作经验拆解
> 定位：电影感、电视感、短片叙事、角色动作、荒诞喜剧、真人实景质感类 AI 视频经验。不要与企业宣传片/AE 包装经验混用。

## 一句话结论

AI 制作电影/电视叙事画面时，核心不是把提示词写得炫，而是先明确**角色与场景设定、影像风格、分镜动作**三件事，再用资产库保证统一性，用剪辑把素材组织成完整作品。

这类视频更像正常拍片：先定演员、服装、场景、道具和摄影风格，再拆分镜头逐条生成，最后靠剪辑完成节奏、笑点、反差和叙事。

## 与企业宣传片经验的边界

本文件适合：

- 电影感短片、电视画面、剧情片段、荒诞喜剧、角色动作戏。
- 有角色、场景、道具、动作、反应、声音和剪辑节奏的 AI 视频。
- 需要保持角色一致、镜头连续、画面有摄影设计的创作。

不适合直接套用到：

- 企业宣传片、城市形象片、战略片、招商片。
- 数据包装、荣誉展示、价值观包装、业务板块展示。
- AE 高级动效、HUD、粒子光轨、三维数据空间等包装片逻辑。

企业宣传片应优先读取 [`../enterprise-promo/README.md`](../enterprise-promo/README.md)。本文件的重点是**叙事镜头设计**，不是企业信息包装。

## 正确工作流

1. **先设定**
   - 明确主角是谁。
   - 明确配角/敌人/群演是什么。
   - 明确场景年代、空间、环境状态。
   - 明确声音策略：同期声、环境声、是否不要配乐。

2. **再做资产**
   - 先做角色图。
   - 再做场景图。
   - 再做道具图。
   - 常用角色和场景要形成资产库，避免每个镜头都重新赌一致性。

3. **再拆分镜**
   - 一个镜头只做一件事。
   - 一个镜头交代环境。
   - 一个镜头拍角色出现。
   - 一个镜头拍动作。
   - 一个镜头拍道具。
   - 一个镜头拍反应。
   - 最后靠剪辑连成作品。

4. **再写逐镜头提示词**
   - 每个镜头单独写景别、构图、机位、运镜、主体动作、声音和负面约束。
   - 不要把 15 秒内容写成一个大杂烩提示词。

5. **再批量生成、筛选、修正**
   - 生成失败后先判断失败位置，不要只会重抽。
   - 可用素材要保留，用于后续剪辑或资产复用。

6. **最后剪辑成片**
   - AI 生成出来的是素材，不是成片。
   - 成片完成度取决于剪辑节奏、镜头顺序、音效、字幕、调色和反差笑点。

## 提示词三要素

### 1. 基础设定

基础设定解决“这个故事里有什么”。

应包含：

- 主角：外形、服装、材质、身份、状态、表情方式。
- 配角或动物：品种、体态、表情、性格特征。
- 敌人或群体：数量、外形、动作速度、服装、腐败程度、危险感。
- 场景：年代、城市风格、环境状态、天气、地面物件、尸体/车辆/报纸等细节。
- 声音：是否需要配乐，是否只保留同期声，是否有角色发声。

关键原则：

- 角色 + 场景是根基，描述越精准，废片率越低。
- 不要只写“一个机器人在街上逃跑”，要写清楚机器人是什么风格、穿什么、脸怎么显示、街道是什么年代和状态。
- 如果角色有特殊表情限制，要明确写出，例如“面部显示屏表情保持静态，不要动态变化”。

### 2. 氛围和画质

氛围和画质解决“它看起来像什么片子”。

应包含：

- 风格核心：原子朋克、末日丧尸、荒诞喜剧、超写实、真人实景拍摄感。
- 质感要求：电影级、极致逼真、杜绝游戏 CG 感、杜绝动作僵硬。
- 摄影语言：宽银幕、IMAX 胶片摄影机、Panavision 镜头、动态模糊。
- 色彩影调：复古暖橙、海盐蓝、高对比、低饱和胶片滤镜、自然日光。
- 光影要求：高光不过曝、暗部有细节、光线通透、轻微胶片柔光。

关键原则：

- 电影/电视叙事类视频需要审美和摄影知识托底。
- “电影感”不能只靠一句“cinematic”，要拆成镜头、镜头质感、光线、色彩和画幅。
- 如果要荒诞喜剧感，要写清楚反差来源：例如闲适夏日街道与丧尸尸体形成强烈反差。

### 3. 分镜画面内容

分镜解决“每个镜头具体怎么拍”。

每个镜头至少写清：

- 时间段：例如 `00:00-00:07`。
- 景别：大全景、近景、特写等。
- 构图：中心构图、引导线构图、对角线构图等。
- 机位：高空俯拍、轻微仰拍、俯拍地面等。
- 运镜：固定机位、跟随、缓慢上摇、摇镜头跟随主体等。
- 画面内容：主体如何入画、做什么动作、背景发生什么、声音是什么。
- 情绪作用：交代环境、制造反差、推进动作、形成笑点。

关键原则：

- 一个镜头里不要同时塞太多任务。
- 动作越复杂，越要拆镜头。
- AI 当前更擅长完成小动作链，不擅长在一个长镜头里稳定完成一堆连续事件。

## 《丧尸清道夫》案例拆法

这个案例的核心不是某一句提示词，而是它把 15 秒拆成 3 个有功能差异的镜头。

| 镜头 | 功能 | 设计重点 |
|---|---|---|
| 00:00-00:07 | 建立世界和追逐关系 | 高空大全景、道路引导线、机器人骑鸵鸟入画、后方丧尸潮追赶 |
| 00:07-00:10 | 建立角色反差和喜剧效果 | 近景拍机器人被鸵鸟颠到失控，脸部仍保持冷酷表情，身体狼狈 |
| 00:10-00:15 | 用道具制造小笑点 | 报纸特写，鸵鸟踩中并粘脚，奔跑变成单脚跳，动作产生荒诞感 |

这个拆法值得复用：

- 第一个镜头先交代环境和规模。
- 第二个镜头把宏大的追逐变成角色近景笑点。
- 第三个镜头用一个小道具制造意外动作，让短片有记忆点。

## 单镜头提示词模板

> **时间字段边界**：下方“时间”用于人类分镜、剪辑和素材管理，不代表必须把逐秒时间戳写入所有视频模型。使用 Seedance 2.0 生成时，优先遵守 [`practical-workflow.md`](../../tools/seedance/practical-workflow.md)，用镜头编号组织 Prompt；只有经过当前版本实测确实有效时，才把时间约束加入生成指令。

```markdown
分镜：[编号]
时间：[00:00-00:00]
镜头功能：[交代环境 / 角色出现 / 动作推进 / 道具笑点 / 反应镜头]
景别：[大全景 / 全景 / 中景 / 近景 / 特写]
机位：[高空俯拍 / 平视 / 轻微仰拍 / 地面俯拍]
构图：[中心构图 / 引导线构图 / 对角线构图 / 前中后景层次]
运镜：[固定机位 / 跟随主体 / 缓慢上摇 / 横移 / 推进 / 摇镜头]
画面内容：[主体从哪里入画，做什么动作，背景发生什么]
动作约束：[只完成一个核心动作，不要同时做多个复杂动作]
声音：[同期声 / 环境声 / 角色台词 / 不需要配乐]
情绪：[紧张 / 滑稽 / 荒诞反差 / 死寂 / 速度感]
负面提示：[不要游戏 CG 感，不要动作僵硬，不要角色变形，不要多余动作]
```

## 失败后如何判断

不要生成失败就立刻重抽，先判断失败类型。

| 失败类型 | 处理方式 |
|---|---|
| 角色不准 | 补角色参考图，强化服装、体态、面部特征、材质描述 |
| 动作不准 | 把动作拆细，一个镜头只保留一个动作 |
| 构图不准 | 写清楚机位、主体位置、画面中心、前景/背景关系 |
| 场景好但剧情用不上 | 保留为素材或场景资产，不要直接丢掉 |
| 画面好看但镜头功能不对 | 可进入素材库，后续做转场、氛围镜头或备用镜头 |
| 完全偏题 | 丢弃，并重写提示词结构，不要只换形容词 |

核心判断：

- 会筛选、会修正、会复用，比单纯会生成更重要。
- 生成不是最后一步，筛片和剪辑才决定作品质量。

## 剪辑检查清单

成片前检查：

- 镜头顺序是否符合“环境 → 角色 → 动作 → 道具 → 反应”的基本逻辑。
- 每个镜头是否只承担一个核心任务。
- 动作是否能被观众看懂。
- 笑点和反差是否留出了停顿。
- 音效是否补足了动作重量、速度和喜剧节奏。
- 字幕是否必要，是否遮挡画面重点。
- 色调是否统一，角色是否前后基本一致。
- 是否存在明显 AI 崩坏、肢体错误、角色换脸、道具乱变。
- 是否有可复用镜头或资产需要沉淀到素材库。
