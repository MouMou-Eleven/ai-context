## 实战案例提示词

原文记录以下三个案例为反复迭代后的定稿提示词；复用前须核验本次素材、事实与工具能力，并测试生成结果。

### 案例一：荣誉奖项主画面 9 秒（鲁班奖 / 詹天佑奖 / 国优奖）

适用场景：企业荣誉殿堂、获奖展示、品牌实力收束。

核心节奏：0–2.5 秒完成蓝色科技城市生长、相机穿梭、粒子隧道转场、奖项画面成型；2.5–9 秒长时间停留在金色奖项主视觉上。

```
参考 @图片1 生成 9 秒高端 AE 企业荣誉宣传片。节奏必须是：0–2.5 秒完成蓝色科技城市生长、相机穿梭、粒子隧道转场和金色奖项画面生成；2.5–9 秒长时间停留在 @图片1 的金色奖项主视觉上。

开场是深蓝科技城市模型,建筑由线框和粒子快速生长,相机沿蓝金粒子线高速穿梭,随后进入蓝金粒子隧道,快速转到金色荣誉殿堂。第 2.5 秒时,圆形金色光环、月桂叶和三行金属立体文字"鲁班奖、詹天佑奖、国优奖"必须已经完整出现。

2.5 秒之后不要再切换场景,画面稳定停留在金色奖项主视觉,镜头只做轻微缓慢推进,金色粒子像星尘一样缓缓漂浮,文字和月桂环表面有柔和扫光、金属反射和高级光晕。整体庄重、辉煌、高级,像 AE 荣誉宣传片。不要频闪,不要文字乱码,不要让主画面只在结尾才出现。
```

### 案例二：核心数据展示 6 秒（管理面积超 750 万 m²）

适用场景：注册资金、资产总额、管理面积、年营收、服务户数等大数据展示。

核心节奏：0–0.8 秒科技背景启动；0.8–1.8 秒底部建筑生长；1.8–3 秒数字粒子汇聚成型；3–4 秒侧面文字飞入；4–5 秒背景与数字联动强化；5–6 秒最终定格。

数字成型公式：**粒子汇聚 → 三维描边 → 向内填充挤出厚度 → 金色扫光**。

```
参考 @图片1 生成一条约 6 秒的高端 AE 企业数据展示视频,画面比例 16:9,整体风格为蓝金科技地产宣传片,具有金色立体数字、科技 HUD 背景、城市沙盘建筑、粒子光效、数据光轨和电影级光影。保持参考图核心构图和文案内容,文字为"管理面积超 750 万 m²",不要改变文案。

0–0.8 秒：画面从深蓝色科技背景开始,不要一开始就完全静态展示整张图。背景中的蓝色数据线、粒子点阵、HUD 圆环和速度光轨逐渐亮起,左右两侧蓝色光轨向画面中心汇聚。

0.8–1.8 秒：底部城市建筑沙盘开始出现。建筑先以蓝色线框轮廓从地面生长出来,再由金色粒子和光点快速填充成实体建筑,楼体灯光逐渐点亮。镜头轻微向前推进,建筑有精致沙盘模型质感。

1.8–3 秒：中央核心数字"750 万 m²"以特效方式生成,不要直接淡入。先由大量金色粒子在画面中央汇聚,形成数字的三维描边轮廓,然后轮廓向内填充、生长、挤出厚度,最终变成厚重的金色金属立体数字,表面有高光反射和一道金色扫光划过。

3–4 秒：左侧文字"管理面积超"出现,从左侧带粒子拖尾飞入,落位后与中央数字风格统一,清晰稳定。文字下方有轻微倒影和金色光晕。

4–5 秒：画面整体强化。背景中的蓝色 HUD 圆环缓慢旋转,科技线条和速度光轨从四周向中央数字汇聚,数字后方出现半圆形科技光环。底部建筑群有一束柔和金色光线从中间向两侧扫过。

5–6 秒：镜头轻微拉远并稳定,最终定格到接近 @图片1 的完整构图。画面保留少量蓝色粒子和金色星尘缓慢漂浮,整体闪耀但不频闪,高级、稳重、震撼。

负面提示词：不要人物,不要卡通,不要文字乱码,不要把"750 万 m²"改错,不要改变"管理面积超"的文案,不要让建筑变得模糊,不要文字跳动,不要画面晃动,不要低清晰度,不要廉价质感。
```

### 案例三：多卡片入场展示 5 秒（五大业务板块）

适用场景：多个并列的业务板块、服务体系、产品线、合作伙伴展示。

核心节奏：0–0.5 秒只展示背景；0.5–2.6 秒五张卡片通过金色扫光显影快速依次出现；2.6–5 秒完整画面长时间停留。

原项目约束：卡片采用稳重蓝金科技风，因此避开“回弹/弹性/上下滑入”。改用"扫光显影 + 玻璃面板由暗到亮 + 边框描边 + 图标粒子凝聚 + 文字扫描显现"。

```
参考 @图片1 生成 5 秒高端 AE 企业服务展示视频。节奏必须是：0–0.5 秒只展示蓝色建筑背景和底部蓝金科技光轨;0.5–2.6 秒五张卡片通过金色扫光显影快速出现;2.6–5 秒完整五卡片画面长时间停留展示。

五张卡片不要回弹,不要弹跳,不要简单上下滑入。卡片出现方式为:金色扫光从左到右扫过,每扫到一个位置,就通过玻璃面板显影、金色边框描边、图标粒子凝聚、文字扫描显现的方式生成一张卡片。顺序为"福利服务、泉世界商管、森泰园林、置业担保、双安档案"。

每张卡片出现细节:先出现一条竖向金色光线,光线向两侧扩散形成半透明蓝色玻璃卡片;卡片边框被金色线条快速描边;图标由粒子点阵凝聚出现;中文标题被一道细光线扫描显现;卡片不回弹,不晃动,不做夸张位移。五张卡片之间约 0.25 秒间隔连续出现。

到第 2.6 秒时,五张卡片必须全部出现完成,形成接近 @图片1 的完整构图。2.6 秒之后不要再出现新卡片,不要再切换场景,只保留完整画面停留:卡片边框有轻微金色流光,底部波浪线缓慢流动,蓝金粒子漂浮,背景建筑轻微推进,一道细扫光从左到右经过五张卡片。

整体要像高端 AE 企业宣传片,蓝金商务科技风,干净高级,文字和图标清晰稳定。

负面提示词:不要人物,不要卡通,不要文字乱码,不要改错"福利服务、泉世界商管、森泰园林、置业担保、双安档案"任何一个,不要让卡片顺序错误,不要让卡片变形,不要回弹,不要弹跳,不要上下慢慢滑入,不要频闪,不要让卡片到最后才全部出现。

更强约束版补充词（加在最末）:特别强调:五张卡片不要拖到结尾才出现。0.5 秒开始出现第一张,2.6 秒前五张全部完整出现,2.6 到 5 秒必须是完整五卡片停留展示。卡片不要回弹,不要弹跳,不要上下滑动,用金色扫光显影和边框描边的方式出现。
```

## 原五分钟城市产业企业片的章节方案

原五分钟企业片采用章节结构；时长、章节与节奏应按本次传播目标和配音决定。

原项目参考结构（不作其他行业默认模板）：

| 段落 | 作用 | 画面策略 |
|---|---|---|
| 开篇 | 建立城市、企业、气质 | 城市地域符号 + 企业坐标 + 核心数据 |
| 理念 | 建立价值观和温度 | 真实人群 + 城市夜景 + AE 文化包装 |
| 党建 | 国企/组织属性 | 真实党建资料 + 庄重包装 |
| 战略 | 说明发展格局 | 数字孪生城市 + 全息沙盘 |
| 第一业务 | 建设能力 | 项目体量 + 工程品质 + 数据包装 |
| 第二业务 | 运营能力 | 五大业态拆开 + 服务网络 |
| 第三业务 | 未来产业 | 真实试点 + 产业可视化 |
| 结尾 | 品牌收束 | 城市夜景 + 万家灯火 + LOGO 落版 |

## 原项目的素材索要清单

向企业要资料时，不要只说“给项目素材”，要按分镜要：

- 企业 LOGO、VI、标准色、字体、落版规范。
- 办公楼、集团门头、员工、会议、沙盘、项目现场。
- 城市地标航拍、项目航拍、项目夜景。
- 注册资金、资产总额、信用评级、资质证书等证明材料。
- 住宅、商办、城市更新、安置房、公租房、获奖工程素材。
- 党建品牌、党建阵地、党员活动、党员先锋岗、党建荣誉。
- 运营业务素材：商管、物业、园林/城市运维、置业担保、档案管理。
- 新兴产业素材：康养、新能源、人工智能、数据标注、算力运营、创意设计、人才培养。
- 电台版或旧版宣传片原片及原始素材，尤其业务拆分镜头。
