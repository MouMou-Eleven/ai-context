# AI 视频类型

| 类型 | 入口 | 核心区别 |
|---|---|---|
| 漫剧 | [`motion-comic/`](./motion-comic/README.md) | 角色连续性、对白、镜头节奏和连续剧叙事 |
| 企业宣传片 | [`enterprise-promo/`](./enterprise-promo/README.md) | 企业信息、品牌、业务板块、数据和包装 |
| 真人实拍故事 | [`live-action-story/`](./live-action-story/README.md) | 真人质感、角色动作、场景、情绪和电影摄影 |

新片型必须有独立入口，不能继续把经验堆进 AI 视频总 README。

教师委托的微课与 MG 教育视频，其主入口在 [微课设计](../../../design/microcourse-mg-animation/README.md)；可按需要组合视频通用经验与生成工具。AE 宣传视频的包装与工程要求从 [AE 设计](../../../design/ae-promo-video/README.md) 进入。跨领域入口不等于重复建立片型或项目正文，也不等于建委作为讲师的培训课程。
