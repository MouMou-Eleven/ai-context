# 营销文案与推广文章

## 负责范围

- 不绑定单一平台的营销文章、活动推广文案、产品介绍和转化页面文字。
- 把人群、问题、证据、产品价值和下一步行动组织成完整的推广表达。
- 跨平台可复用的营销结构和复盘经验；具体渠道文案优先归入对应渠道目录。

## 分类边界

- 公众号知识文章和长图文进入 [`../articles/`](../articles/)。
- 朋友圈短文案进入 [`../moments-copy/`](../moments-copy/)。
- 社群内部文案进入 [`../community-copy/`](../community-copy/)。
- 直播销售和实时承接进入 [`../live-sales/`](../live-sales/)。

## 写入要求

- 先说明面向谁、解决什么问题、凭什么相信，再写产品或行动，不用空泛承诺代替证据。
- 明确区分已验证结果、创作者判断和待测试假设。
- 语言基础统一读取 [`../../../../brain/ai-expression/README.md`](../../../../brain/ai-expression/README.md)；口语化文本再读取 [`../../../../brain/ai-expression/oral-expression/README.md`](../../../../brain/ai-expression/oral-expression/README.md)。本目录只维护营销目标、证据组织和行动设计。

当前尚未收录独立营销文章案例库；后续新增内容必须注明渠道、目标、版本和验证状态。
