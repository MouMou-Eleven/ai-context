# 自媒体增长与复盘

## 自媒体在业务中的作用

自媒体是触达、解释、建立信任和承接行动的渠道之一，不是完整商业闭环。真实产品或服务、清楚表达、合适渠道、行动路径和真实交付必须共同成立。

## 内容任务

| 类型 | 主要作用 |
|---|---|
| 痛点型 | 让目标用户意识到问题与自己有关 |
| 过程型 | 展示真实解决过程和判断方法 |
| 教程型 | 给出可执行步骤或检查方式 |
| 案例型 | 用可核验结果证明方法能够落地 |
| 观点型 | 建立长期认知与专业判断 |
| 转化型 | 说明资料、直播、咨询或产品的下一步 |

一条内容先确定主要任务，不要求同时完成所有目标。

## 场景翻译

抽象工具和技术词要翻译成具体人群、动作和结果。例如不要只说“AI 编程”，而要说明它能帮助哪类人完成什么可见的小工具或工作结果。

## 测试原则

- 前期可以测试观点、案例、避坑、教程、轻松聊天和直播切片等不同形式。
- 每轮尽量只改变一个主要变量，例如标题、开头、结构或行动。
- 记录平台真实提供的数据，不只看播放量。
- 没有足够样本时只写阶段性判断，不写普遍规律。

## 复盘顺序

1. 内容是否找到正确人群和真实场景。
2. 开头承诺是否与正文一致。
3. 中间是否持续提供新信息。
4. 案例和数据是否真实可核验。
5. 唯一行动是否清楚。
6. 用户行动后是否被有效承接。
7. 下一轮只保留、修改或停止哪些变量。

需要商业分析时可按需读取 [`../../../../brain/business-cognition.md`](../../../../brain/business-cognition.md)；这不代表每个自媒体任务都自动激活建委大脑。
