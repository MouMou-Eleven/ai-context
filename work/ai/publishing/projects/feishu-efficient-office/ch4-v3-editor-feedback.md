## 一、编辑反馈总览

这轮 v3 修订稿反馈不再主要讨论章节大结构，而是集中在成书前的精修规范上：标题长度、语言书面化、术语一致、图表编号、图文匹配、截图可读性，以及正文是否真正面向读者。

一句话概括：**第4章已经进入“出版化打磨”阶段，重点不是再扩内容，而是让每一句话、每张图、每个图号都经得起印刷阅读。**

## 二、核心问题归类

| 类别 | 编辑关注点 | 后续处理原则 |
|------|------------|--------------|
| 章名与标题 | 章名过长，印刷后可能折成两行 | 后续参考其他章节标题长度，必要时压缩表达，避免标题承担过多解释功能 |
| 语言书面化 | “昨天答应别人的事又想不起来放在哪”“半个上午”“先点回来”等表达偏口语或不清楚 | 保留建委的亲切感，但改成出版书面语；每个说法必须语义明确 |
| 术语一致 | 截图显示“飞书 aily”，正文标题仍写“飞飞” | 图中产品名、章节标题、正文称呼保持一致；涉及产品名称时以当前截图和官方命名为准 |
| 图表编号 | 部分图片、流程图未按图4-1、图4-2顺序编号；表同理 | 第4章所有图片、流程图、截图、表格统一编号，流程图也按图处理 |
| 图文衔接 | “如图4-8所示”“如图4-14所示”不是完整句 | 每张图前必须有完整引导句，说明读者看图要看什么 |
| 图文匹配 | 图中圈1-4与正文内容对应关系不明确 | 图中标注必须能和正文步骤或说明逐一对应；不能出现图有标号、正文无解释 |

| 作者提示误入正文 | “写书时可以讲方法”这类话不适合正文 | 正文只写给读者；作者提醒、截图要求、待处理事项放素材清单或修改清单 |

## 四、对后续改稿的直接要求

1. **先做全章出版化语言通查**：重点查口语化、歧义、指代不清、内部工作话术。保留亲切感，但不要留下“点回来”“半个上午”“别人”这类需要猜的表达。
2. **统一术语和产品名**：如果截图显示“飞书 aily”，正文就不能只写“飞飞”。标题、正文、图题、素材清单要用同一套称呼。
3. **图表编号全量检查**：截图、流程图、表格都要进入编号体系。第4章图片按“图4-1、图4-2……”顺序；表格按“表4-1、表4-2……”顺序。
4. **所有“如图所示”改成完整引导句**：不能只写“如图4-8所示”。句子里要告诉读者看图的目的，例如看入口、看步骤、看效果、看对照关系。
5. **检查图中文字是否适合印刷**：截图应截核心区域，避免整屏截图导致字号过小。看不清的图宁可重截，不要勉强保留。
6. **图中标号必须与正文逐一对应**：如果图里有圈1-4，正文必须解释1-4分别对应什么；如果正文没有对应内容，就删掉圈号或重做图。
7. **正文只写给读者**：作者提示、截图制作要求、待截图说明、素材提醒放到素材清单，不进入正文。

## 六、改稿前检查清单

- [ ] 章名是否过长，是否需要与全书章名统一压缩。
- [ ] 全章“链路”是否都用得准确，是否有应改为“思路”的位置。
- [ ] 是否存在口语化但不清楚的表达，如“点回来”“半个上午”。
- [ ] 是否存在“别人”“这个”“那个”等指代不清的词。
- [ ] “飞飞”“飞书 aily”“智能伙伴”是否统一，是否与截图一致。
- [ ] 所有图片、流程图、表格是否都有编号和题名。
- [ ] 所有“如图X-X所示”是否都是完整句，并说明读者看图要看什么。
- [ ] 截图中文字是否足够大，是否只截了核心内容。
- [ ] 图中圈号、箭头、红框是否与正文逐一对应。
- [ ] 作者提示、截图要求、待处理说明是否已经移出正文，放入素材清单。
