# 动效导演策略

本文件负责“为什么这样动、哪一秒值得记住”。逐元素动作表和 Remotion 技术映射只能证明方案可执行，不能代替导演判断。

## 先分类，再导演

### 目标帧重建

适用于参考图、海报、标题卡、UI 或静态图表。除非用户明确要求改版，否则参考图就是目标最终帧：文字、品牌、视觉层级、元素相对位置和完整构图都要回到原图。只重建需要独立进入或可编辑的元素，不在重建层下长期叠放完整参考图。

### 概念文案

适用于一句观点或短文案。把抽象判断翻译成一个看得懂的状态变化或视觉隐喻，把最强动作留给关键词、反转或结果，不用角落说明文字解释一个本应由画面表达的概念。

### 流程与数据

适用于进度、排行、比较、管线和因果。使用真实形状、数值和状态，镜头或焦点跟随变化中的值；中间帧必须能核对数据映射，不能用装饰线代替内容。

### 脚本分场

适用于旁白或短视频脚本。先按语义合并为完整视觉单元，再按语速确定时长；每场只承担一个主张，转场延续上一场的主体、方向、形状、颜色或声音。

## 导演四问

进入逐元素拆解前，必须回答：

1. **目标最终帧是什么**：结果构图如何与参考图或文案目标对应。
2. **状态反差是什么**：开始与结束之间发生了什么可见变化，例如折叠到展开、混乱到有序、笨重到轻巧。
3. **最值得记住的一秒是什么**：明确动作、时间区间和观众注意对象，不能只写“整体很炫”。
4. **干净收尾是什么**：主动作完成后如何回扣、锁定或留下一个小惊喜，不靠继续堆装饰拖延结束。

答不出其中任一项，先改动作逻辑，不得用粒子、辉光、更多标签或持续运镜补空白。默认只推荐一个最强方向；只有两种视觉解读确实会改变结果时才给备选。

## 一个动作逻辑

主动作应像一句完整的动词短语，例如“指针沿边界搭出界面”“数据从拥挤中让出冠军位置”“标题被测量线切开并锁定”。其他动作只做三件事：触发主动作、解释主动作、确认主动作完成。

趣味性优先来自：

- 一处清楚的反差。
- 一个带角色感的小动作。
- 一次出乎意料但合乎因果的反应。
- 一个与开场呼应的收尾回扣。

不要把“有趣”翻译为增加元素数量。若画面同时需要说明和戏剧性，先让主动作成立，再把说明降为支撑层。

## 重叠节奏

短片头默认 4–5 秒。复杂流程或数据场景可用 5–8 秒；多场景再按信息和旁白扩展。阶段允许重叠，但不得失去因果：

| 阶段 | 建议范围 | 作用 |
|---|---:|---|
| 建立 | 0–12% | 给出画布、触发者或初始状态 |
| 主动作 | 8–38% | 绘制、选择、打开、组装或第一次状态改变 |
| 核心内容 | 28–68% | 标题、主体、数字或关键转换进入 |
| 次要细节 | 55–82% | 标签、图标、强调或收尾反应 |
| 定格微动 | 78–100% | 回到目标最终帧，保证阅读和记忆 |

时间轴可以有重叠区间，校验标准是“从 0 秒起无空档覆盖总时长”，不是每一段首尾相接。每个重叠必须写清前一动作达到哪个阈值后触发后一动作。

## 语言到导演判断

| 用户表达 | 优先翻译 |
|---|---|
| 有冲击力 | 短促决断的减速、一次受控超调、明确的前后尺度或位置反差 |
| 高级 | 更少的同时动作、克制距离、顺滑减速、清楚层级 |
| 科技感 | 精确网格、扫描或聚焦行为、有限辉光、数据式节拍 |
| 像设计软件搭出来 | 指针、拖拽、框选、控制柄、蒙版和逐层构建 |
| 镜头推进 | 有目标的景深视差和尺度变化，不是整页统一放大 |
| 有趣、有梗 | 一处反差、一个小意外、一个回扣，不增加无关装饰 |
| 更生动、更有戏 | 让主体发生一次状态变化，并以有性格的方式恢复或定格 |
| 轻松、俏皮 | 更快预备、更软落点、一次克制的调皮反应 |

## 目标帧核对

参考图任务在实施前和交付前都要核对：

- 最终帧是否保留精确文字、编号、品牌和信息层级。
- 主体占比、关键对齐、留白、相对位置和画幅是否与批准目标一致。
- 重建是为了独立动作和参数编辑，不是借机重新设计。
- 若用户批准改版，明确列出与参考图不同的项目；未列出的差异视为缺陷。

## 导演门槛

以下任一情况禁止进入实现：

- 没有一句话可说明的状态反差。
- 说不清最值得记住的一秒。
- 动作只有“依次出现”，没有阈值触发和干净收尾。
- 时间轴完全串行，而内容允许合理重叠。
- 参考图任务没有目标最终帧和差异清单。
- 为了显得丰富而增加不服务主题的装饰。
