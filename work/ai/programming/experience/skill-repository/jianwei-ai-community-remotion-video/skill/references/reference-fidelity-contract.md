# 参考图保真契约

参考图任务的默认解释是：参考图就是用户批准的目标最终帧。它提供的不只是色彩和气氛，也提供精确文案、品牌、排版层级、主体占比、留白、元素相对位置和画幅。除非用户明确批准改版，最终稳定帧必须回到这张图。

## 1. 先记录事实

在写动作前记录：

- 原图文件、像素尺寸、长宽比、色彩模式、透明通道和明显压缩情况。
- 可确认的精确文字、编号、Logo、品牌色和字体气质。看不清的内容标为“待验证”，不能靠猜测补写。
- 关键元素的归一化边界框 `[x, y, width, height]`，数值相对于原图宽高，范围为 `0..1`。
- 第一、第二、第三视觉层级，主体占比、主要对齐线和必须保留的留白。

规划中把 `preserve`、`mayChange`、`allowedDifferences` 分开。默认 `allowedDifferences` 为空；用户没有明确授权的改动都不是“合理发挥”。

背景同样属于受保护事实。按 [background-fidelity-contract.md](background-fidelity-contract.md) 记录至少三个安全采样区、平均 RGB、亮度、渐变/纹理结构和动态限制；不得只锁定前景排版而允许背景漂色。

## 2. 选择保真模式

### `layout-locked`（图片任务默认）

参考图是整段动画的几何目标，不是最后一秒才盖上去的素材。动画从第一帧起就使用同一套重建元素；每个可动/可编辑元素必须登记参考图边界框、层级、锚点和最终状态，运动终点直接落在这些目标上。生产 Composition 禁止加载、渲染或淡入整张参考图；参考图只能放在比较脚本、人工校准或 `reference/` 资料目录中。不能用“前面重新设计、最后整图渐显”换取像素相似。

若扁平图片无法同时可靠分离背景、保持精确排版并提供可编辑文字，必须在规划确认单中说明实际取舍并让用户选择：固定整图做受控的平面/视差运动，或接受有明确差异的可编辑重建。不得把整图终端叠加当作“既像素级一致又可编辑”的默认混合策略。

### `raster-motion`

仅当用户明确要求把整张图片作为一个平面进行推拉、旋转、视差或裁切时使用。它不提供图中文字的独立编辑，也不得在片尾再叠加第二张参考图；同一张图片从开场到收尾由同一个图层连续运动并收正。

### `approved-redesign`

只有用户明确接受最终画面与参考图存在差异，或原图本身只是风格板时才使用。规划必须先列出差异清单并获确认；未列出的文字、品牌、排版层级、主体占比、留白和相对位置仍视为缺陷。

## 3. 只重建必要元素

对每个候选图层回答三个问题：

1. 它是否需要独立运动，或是否是用户要求可编辑的文字、编号、颜色？
2. 它是否能从原图可靠分离或重建，不会暴露不存在的背景？
3. 它在最终帧的边界、层级和对齐如何被验证？

三个问题中任一答案是否定时，优先保持该区域为同一张连续的平面层，不为了“增加层次”强行拆分；但不得把整张参考图作为片尾覆盖层。禁止新增无关粒子、星点、标签、光晕、故障、装饰线或会改变视觉重量的发光。

### 3.1 生产路径硬禁令

- 单一扁平参考图只能用于分析和对比，不能出现在生产 `src/` 的 `Img`、`staticFile`、Canvas、SVG 或 Three 纹理路径中。
- 禁止 `FinalFrameLock`、`referenceOverlay`、`terminalReference`、`lockFinalFrame` 等“最后稳定区切换整图”的组件、Props 或条件渲染。
- 禁止为同一个文字、编号、Logo 或图标同时保留重建层和参考层；同一时刻只能有一个视觉所有者，除非规划明确批准局部拖影。
- 不能用最后 0.3–1 秒的全画布 opacity/crossfade 修正构图。最终稳定区应是前面动作的自然落点，而不是新场景。
- `reference.png` 可以存在于 `public/` 供离线比较，但必须通过 `scripts/audit_reference_render_path.py` 确认生产源码未引用它。

## 4. 最终帧验收

在同一宽高、同一裁切、同一像素密度下检查参考图与最终静帧：

- `layout-locked`：优先比较未压缩 PNG；要求文字和品牌逐字一致，关键边界框位置误差不超过画布宽高的 1%，尺寸误差不超过 3%，且默认值终帧像素差应接近零。除最终帧外，还必须检查最终稳定区的至少三个连续帧，确认没有全画布跳变或整图淡入。可使用 `scripts/compare_reference_frame.py --mode locked` 与 `scripts/check_settle_continuity.py`。
- 文字、编号、Logo、图标和主体的真实可见/墨迹边界必须完整；检查它们是否被画布、父级 `overflow`、`clip-path`、`mask`、过紧行盒、负偏移或 3D 变换裁切。按 `visibility-and-clipping-contract.md` 生成报告并运行 `scripts/check_visibility_report.py`，不能用容器框或最终帧像素总分掩盖局部缺字。
- `raster-motion`：同一个参考图平面从开场连续运动到收正；不承诺图中文字独立编辑，且不得存在第二个终端参考层。
- `approved-redesign`：按已批准差异清单验收，未列出的差异仍视为缺陷。

至少查看并排图、50% 透明叠加图和差异图。再从最终稳定区的开始、中间和结束各导出一帧，运行连续性检查；这一步专门拦截“最后一秒突然换成参考图”的伪还原。先修正尺寸、位置、字体、裁切和层级，再考虑任何微动；不要用辉光或镜头运动掩盖终帧偏差。最终稳定区最后 0.3 秒应保持构图不变；严格锁定时不添加会改变像素的微动。

## 5. 可审计记录

Blueprint 或实施报告必须写出：

- 原图尺寸和保真模式。
- 精确文案清单与参数化字段的绑定关系。
- 关键边界框和允许误差。
- 仅重建的独立运动/编辑元素。
- 禁止新增项和获批差异。
- 最终帧比较文件、指标、人工结论和待修复问题。
- 背景安全采样区、`compare_background_regions.py` 指标和是否发生未批准的亮度/色域漂移。
