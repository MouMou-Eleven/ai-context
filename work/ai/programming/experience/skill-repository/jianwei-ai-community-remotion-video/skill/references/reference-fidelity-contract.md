# 参考图保真契约

参考图任务的默认解释是：参考图就是用户批准的目标最终帧。它提供的不只是色彩和气氛，也提供精确文案、品牌、排版层级、主体占比、留白、元素相对位置和画幅。除非用户明确批准改版，最终稳定帧必须回到这张图。

## 1. 先记录事实

在写动作前记录：

- 原图文件、像素尺寸、长宽比、色彩模式、透明通道和明显压缩情况。
- 可确认的精确文字、编号、Logo、品牌色和字体气质。看不清的内容标为“待验证”，不能靠猜测补写。
- 关键元素的归一化边界框 `[x, y, width, height]`，数值相对于原图宽高，范围为 `0..1`。
- 第一、第二、第三视觉层级，主体占比、主要对齐线和必须保留的留白。

规划中把 `preserve`、`mayChange`、`allowedDifferences` 分开。默认 `allowedDifferences` 为空；用户没有明确授权的改动都不是“合理发挥”。

## 2. 选择保真模式

### `reference-locked`（图片任务默认）

最终稳定帧必须使用原图作为注册后的终端参考，或使用像素等价的合成结果。动画阶段只让获准的独立运动层离开终端状态；终点相机回到恒等状态。对扁平 JPG，若无法无损清除可编辑区域，不要同时承诺“像素级一致”和“任意文字可编辑”：应采用默认值锁定终帧、改值后切换到编辑层的混合策略，并在规划中说明。

### `editable-overlay`

适用于能得到干净底板、蒙版或明确可重建区域的图片。不可编辑背景和装饰保持原像素，只有用户批准的文字、编号、颜色或动作元素由 Props 重建。必须列出每个编辑区域及边界，禁止扩大重建范围。

### `rebuild`

只有用户明确接受最终画面会与参考图不同，或原图本身只是风格板时才使用。规划必须先列出差异清单，并让用户确认；不能把 `rebuild` 当作默认图片模式。

## 3. 只重建必要元素

对每个候选图层回答三个问题：

1. 它是否需要独立运动，或是否是用户要求可编辑的文字、编号、颜色？
2. 它是否能从原图可靠分离或重建，不会暴露不存在的背景？
3. 它在最终帧的边界、层级和对齐如何被验证？

三个问题中任一答案是否定时，优先保持该区域为平面参考，不为了“增加层次”强行拆分。禁止新增无关粒子、星点、标签、光晕、故障、装饰线或会改变视觉重量的发光。

## 4. 最终帧验收

在同一宽高、同一裁切、同一像素密度下检查参考图与最终静帧：

- `reference-locked`：优先比较未压缩 PNG；要求文字和品牌逐字一致，关键边界框位置误差不超过画布宽高的 1%，尺寸误差不超过 3%，且默认值终帧像素差应接近零。可使用 `scripts/compare_reference_frame.py --mode locked` 输出 MAE、RMSE、变化像素比例和叠加/差异图。
- `editable-overlay`：文字、编号、颜色按 Props 变化；未编辑区域仍应与参考图一致。关键边界框位置误差不超过 1%，尺寸误差不超过 3%，并人工检查排版层级、留白和主体占比。
- `rebuild`：按已批准差异清单验收，未列出的差异仍视为缺陷。

至少查看并排图、50% 透明叠加图和差异图。先修正尺寸、位置、字体、裁切和层级，再考虑任何微动；不要用辉光或镜头运动掩盖终帧偏差。最终稳定区最后 0.3 秒应保持构图不变；严格锁定时不添加会改变像素的微动。

## 5. 可审计记录

Blueprint 或实施报告必须写出：

- 原图尺寸和保真模式。
- 精确文案清单与参数化字段的绑定关系。
- 关键边界框和允许误差。
- 仅重建的独立运动/编辑元素。
- 禁止新增项和获批差异。
- 最终帧比较文件、指标、人工结论和待修复问题。
