# 动效导演规则

目标是让动作、镜头和节奏共同说明一件事。先确定视觉因果，再组合技术。

## 先导演，后拆表

逐元素动作表保证“每个东西怎么动”，但不能决定“这条动画为什么值得看”。拆表前先从 [director-strategy.md](director-strategy.md) 确定目标最终帧、状态反差、最值得记住的一秒和干净收尾。若只能描述一串入场动作，先重写主动作逻辑，不进入技术映射。

导演稿应先写成一条连续动作链，再把链中的关键元素拆成表格。表格服务动作链，不允许为了填满字段而把一个自然动作切成互不相干的小段。

## 反幻灯片原则

以下任一模式连续出现，都说明方案需要重做：

- 一个页面停住，然后整体淡出，下一页整体淡入。
- 所有元素使用同一方向、同一延迟和同一缓动。
- 只做标题飞入、正文飞入、图片飞入，元素之间没有作用关系。
- 每个镜头都在居中正视图，没有景别变化、遮挡或连续运动。
- 为了显得“高级”而随机增加粒子、发光、故障、旋转和镜头抖动。

至少使用两种连续性手段：运动方向延续、形状匹配、颜色延续、遮挡切换、相机穿越、共享主体或声音桥。

## 一场一主动作

每个场景只定义一个主动作，例如“压缩后展开”“从混乱汇聚为结构”“沿路径追踪并锁定”“从细节拉远显露全貌”。其他动作分为：

- 次动作：解释主动作的结构或层级。
- 微动效：增加触感和生命力，不改变信息状态。

主动作、次动作和微动效不要同时达到最大强度。

## 逐元素动作契约

规划中的每个关键元素必须拥有可实施的动作生命周期。至少写清：

1. **触发**：由谁或什么事件触发，例如鼠标到达角点、框体闭合、上一标签展开完成。
2. **起始状态**：元素从哪里、以什么尺寸、裁切、透明度、旋转或形变开始。
3. **动作与路径**：沿直线、曲线、顺时针边界、遮罩揭示、宽度展开、路径描边或空间跟随。
4. **时间与手感**：持续时间、加速段、减速段、超调、回弹或停顿；不得只写“丝滑”。
5. **因果关系**：说明为什么此时出现，以及它怎样触发下一元素。
6. **结束状态**：最终位置、构图角色、是否保持可读、是否进入微动。
7. **实现类别**：DOM/CSS、SVG 路径或蒙版、Canvas/effects、Three.js，及 Remotion 的帧驱动方式。

装饰性背景可按组描述；标题、框体、控制柄、Logo、标签、指针等识别元素不能用“其他元素依次出现”合并带过。

### 动作链而不是入场清单

不合格：`选择框出现，标签出现，标题出现，装饰出现，镜头轻推。`

合格：`指针从中心加速移向左上角 → 到达角点触发 SVG 路径沿顺时针绘制框体 → 每经过一个角点，该角点控制柄按预设的不同方向和幅度短促弹出 → 框体闭合触发紫色标签从左向右展开 → 标签竖线和圆点同步由下向上生长 → 标题被框内蒙版从下向上揭示，末段减速并收稳 → 装饰与作者标签在主信息完成后补入 → 最终只保留呼吸、光点和极轻视差。`

这里的“预设不同”用于实现视觉变化，不能调用未播种随机数。动作链可以互相重叠，但每个重叠都要说明前一动作达到什么节点后触发下一动作。

## 镜头服从动作

- 先设计元素动作链，再决定相机是否需要移动。不能用通用推拉掩盖元素动作不足。
- 开场动画的镜头优先跟随“触发者”或主动作，例如跟随指针、路径端点或展开边缘；主信息建立后再回到完整构图。
- 若元素动作本身已经建立方向和空间层级，相机可以克制甚至锁定。明显镜头运动不等于持续变焦。
- 规划必须说明镜头在每个时间段跟随谁、为什么移动、何时停止，以及停止后给文字多少阅读时间。

## 时间弧线

以单场景时长为 100%：

| 阶段 | 建议占比 | 作用 |
|---|---:|---|
| 预备 | 8–15% | 建立方向、压缩、蓄力或焦点 |
| 进入 | 15–25% | 主体快速进入或结构开始变化 |
| 展开 | 30–45% | 完成主要空间、层级或信息变化 |
| 定格 | 15–25% | 收稳相机，给观众阅读和记忆时间 |
| 转出 | 0–15% | 只有需要接下一场时使用 |

这是节奏骨架，不是固定模板。短冲击镜头可以省略转出；信息密集镜头需要更长定格。

这些阶段不是必须首尾相接。对短片头，主动作可在建立阶段后半段启动，核心内容可在主动作接近完成时进入，装饰可在标题减速时补入。重叠必须由路径进度、碰撞、闭合、点击、数值阈值或上一动作的减速点触发，不能只写“同时出现”。

时间轴校验采用“无空档覆盖”而非“严格串行”：第一段从 0 秒开始，后续区间可以重叠，但任何时刻都必须有明确画面状态，最后覆盖到总时长。

## 运镜选择

| 叙事目的 | 优先镜头 | 说明 |
|---|---|---|
| 从细节揭示全貌 | 后拉、升高、轻俯拍 | 先给局部触点，再建立结构 |
| 强调核心对象 | 推近、主体跟随、轻仰拍 | 推近时减少同时出现的新信息 |
| 展示顺序或排行 | 横移、纵向跟随、路径跟拍 | 相机运动方向与排序方向一致 |
| 展示层级与深度 | 斜向穿越、轻环绕、焦点转移 | 需要前中后景和遮挡依据 |
| 从混乱变清晰 | 先不稳定后收正 | 最终必须有明确正面或稳定构图 |
| 比较两侧信息 | 横向平移或对称推拉 | 避免无意义旋转 |
| 表达规模扩大 | 先近景后拉远 | 用景别变化说明规模，不堆复制元素 |

一场只设一条主相机路径。摇移、推拉、旋转和变焦叠加超过两种时，必须说明叙事原因。

## 2D 与 2.5D 镜头

- 2D 可通过不同速度的平移、缩放、遮罩、模糊、阴影和透视模拟景别变化。
- 2.5D 至少设置前、中、后三个速度层；相机与各层运动应共享同一方向逻辑。
- 轻微视差通常比大角度 Y 轴翻转更可信。
- 对文字和 Logo 保持可读正面，除非翻转本身是叙事动作。

## 真实 3D 镜头

3D 世界层会因透视、`translateZ`、`rotateX/Y` 和缩放让实际可见框超出局部布局框。除最外层画布外，中间相机层、世界层和承载文字/Logo 的元素层默认保持 `overflow: visible`；揭示扫光需要裁剪时使用独立临时层。进入稳定区后重新测量变换后的字形与主体边界，不能假设相机归零就自动消除元素自身的裁剪。

- 先确定相机目标点，再设计相机位置路径。
- 需要主体跟随时，让相机和目标点都有帧驱动轨迹，避免镜头只绕世界原点旋转。
- 使用实际前景遮挡、灯光或几何来证明 3D 的价值。
- 保留安全构图和结果定格；持续高速绕行会降低信息辨识度。

## 转场语言

优先选择与内容有关的转场：

- 主体越过镜头形成遮挡切换。
- 卡片、窗口或图形展开成下一场构图。
- 相同形状、颜色或位置做匹配剪辑。
- 镜头穿过屏幕、洞口、文字负形或数据节点。
- 速度峰值处用短促模糊、拖影或音效桥接。

普通淡化可用于呼吸和结束，不作为每场默认转场。

## 动作手感

- UI、卡片、标签：短预压 + 快速回弹 + 轻微余震，落点清楚。
- 大型标题、海报、重物：较慢加速、较大惯性、较少弹跳。
- 数据线、路径、排行榜：连续跟随，关键节点有短暂停顿。
- 科技空间：稳定相机、层级视差、局部扫描或焦点转移；少用无目的全屏发光。
- 轻松社群内容：允许小幅弹性和趣味节拍，但保持文字阅读区稳定。

### 自然感不是单调缓动

- 主体至少经过“预备或聚能 → 主变化 → 冲击/转折 → 回收”四个可辨阶段；阶段可很短，但速度曲线必须有重心。
- 支撑元素用事件响应建立丰富度：例如图标点燃触发相机短促后坐、徽章落位触发局部震荡环、标题集齐触发一次字面扫光。响应只发生一次并快速衰减。
- 相机路径优先用 3–6 个有目的的关键姿态组成连续曲线，不用一条从偏角到 0 的匀质插值撑满全片。
- 同一场只保留一个冲击峰值；标题、徽章、图标、相机和背景不能同时满强度。
- 元素语义决定建立方式：线条被描出，标签被展开或落位，文字被揭示/立起，图标被凝聚或点燃。不要让所有元素都使用同一淡入或侧滑。
- 所有相机震颤、拖影、扫光和背景反应都必须在定格前归零；微动不能改变目标边界框。

## 趣味与观赏性

- 每条短动效只设一个主要记忆点；明确它发生在哪一秒、观众看哪里。
- 先设计一处状态反差，再考虑装饰。反差可以是尺度、秩序、重量、速度、角色反应或信息地位变化。
- 主动作结束后给一个克制的回扣，例如主体短暂停顿后回应、起始元素重新出现、路径闭合触发一次确认。
- 趣味动作仍要保持确定性和可读性，不能依赖随机粒子、连续抖动或多次无意义回弹。
- 若增加的效果删掉后叙事完全不变，它通常不是导演动作，而是可删除装饰。

## 节奏与声音

- 微动作常在 0.15–0.6 秒内完成；主要变化常占 1–3 秒；结果画面至少保留 0.35 秒。
- 将动作峰值对齐鼓点、点击、撞击、whoosh 或语音重音。
- 声音负责确认动作和空间，不要每个元素都加音效。
- 没有授权音频素材时只写声音设计建议，不虚构已经加入的文件。

## 动效强度

### 1/3 克制

轻推拉、淡化、少量弹性和稳定构图，适合教程、品牌说明和高信息密度画面。

### 2/3 明显

一个清楚的主动作、分层视差、一次景别变化、少量强调效果。默认选择。

### 3/3 强冲击

快速空间穿越、真实 3D 相机、强速度变化或复杂遮挡。只用于短片头、高潮或用户明确要求；仍需保留可读停顿。

## 创意到实现的映射

每个设计描述都要写出实现类别：

- DOM/CSS：排版、卡片、界面、简单遮挡和 2D 透视。
- SVG：路径、线条、图标、蒙版和可控形变。
- Canvas/Remotion effects：像素级滤镜、拖影、失真和图像处理。
- Three.js/React Three Fiber：真实相机、灯光、几何、材质和空间粒子。
- Remotion 时间结构：Sequence、Series、TransitionSeries、音频和可参数化 Props。

如果无法指出实现类别，说明该创意仍然过于抽象。
