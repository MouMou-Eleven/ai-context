# 动效导演规则

目标是让动作、镜头和节奏共同说明一件事。先确定视觉因果，再组合技术。

## 反幻灯片原则

以下任一模式连续出现，都说明方案需要重做：

- 一个页面停住，然后整体淡出，下一页整体淡入。
- 所有元素使用同一方向、同一延迟和同一缓动。
- 只做标题飞入、正文飞入、图片飞入，元素之间没有作用关系。
- 每个镜头都在居中正视图，没有景别变化、遮挡或连续运动。
- 为了显得“高级”而随机增加粒子、发光、故障、旋转和镜头抖动。

至少使用两种连续性手段：运动方向延续、形状匹配、颜色延续、遮挡切换、相机穿越、共享主体或声音桥。

## 一场一主动作

每个场景只定义一个主动作，例如“压缩后展开”“从混乱汇聚为结构”“沿路径追踪并锁定”“从细节拉远显露全貌”。其他动作分为：

- 次动作：解释主动作的结构或层级。
- 微动效：增加触感和生命力，不改变信息状态。

主动作、次动作和微动效不要同时达到最大强度。

## 时间弧线

以单场景时长为 100%：

| 阶段 | 建议占比 | 作用 |
|---|---:|---|
| 预备 | 8–15% | 建立方向、压缩、蓄力或焦点 |
| 进入 | 15–25% | 主体快速进入或结构开始变化 |
| 展开 | 30–45% | 完成主要空间、层级或信息变化 |
| 定格 | 15–25% | 收稳相机，给观众阅读和记忆时间 |
| 转出 | 0–15% | 只有需要接下一场时使用 |

这是节奏骨架，不是固定模板。短冲击镜头可以省略转出；信息密集镜头需要更长定格。

## 运镜选择

| 叙事目的 | 优先镜头 | 说明 |
|---|---|---|
| 从细节揭示全貌 | 后拉、升高、轻俯拍 | 先给局部触点，再建立结构 |
| 强调核心对象 | 推近、主体跟随、轻仰拍 | 推近时减少同时出现的新信息 |
| 展示顺序或排行 | 横移、纵向跟随、路径跟拍 | 相机运动方向与排序方向一致 |
| 展示层级与深度 | 斜向穿越、轻环绕、焦点转移 | 需要前中后景和遮挡依据 |
| 从混乱变清晰 | 先不稳定后收正 | 最终必须有明确正面或稳定构图 |
| 比较两侧信息 | 横向平移或对称推拉 | 避免无意义旋转 |
| 表达规模扩大 | 先近景后拉远 | 用景别变化说明规模，不堆复制元素 |

一场只设一条主相机路径。摇移、推拉、旋转和变焦叠加超过两种时，必须说明叙事原因。

## 2D 与 2.5D 镜头

- 2D 可通过不同速度的平移、缩放、遮罩、模糊、阴影和透视模拟景别变化。
- 2.5D 至少设置前、中、后三个速度层；相机与各层运动应共享同一方向逻辑。
- 轻微视差通常比大角度 Y 轴翻转更可信。
- 对文字和 Logo 保持可读正面，除非翻转本身是叙事动作。

## 真实 3D 镜头

- 先确定相机目标点，再设计相机位置路径。
- 需要主体跟随时，让相机和目标点都有帧驱动轨迹，避免镜头只绕世界原点旋转。
- 使用实际前景遮挡、灯光或几何来证明 3D 的价值。
- 保留安全构图和结果定格；持续高速绕行会降低信息辨识度。

## 转场语言

优先选择与内容有关的转场：

- 主体越过镜头形成遮挡切换。
- 卡片、窗口或图形展开成下一场构图。
- 相同形状、颜色或位置做匹配剪辑。
- 镜头穿过屏幕、洞口、文字负形或数据节点。
- 速度峰值处用短促模糊、拖影或音效桥接。

普通淡化可用于呼吸和结束，不作为每场默认转场。

## 动作手感

- UI、卡片、标签：短预压 + 快速回弹 + 轻微余震，落点清楚。
- 大型标题、海报、重物：较慢加速、较大惯性、较少弹跳。
- 数据线、路径、排行榜：连续跟随，关键节点有短暂停顿。
- 科技空间：稳定相机、层级视差、局部扫描或焦点转移；少用无目的全屏发光。
- 轻松社群内容：允许小幅弹性和趣味节拍，但保持文字阅读区稳定。

## 节奏与声音

- 微动作常在 0.15–0.6 秒内完成；主要变化常占 1–3 秒；结果画面至少保留 0.35 秒。
- 将动作峰值对齐鼓点、点击、撞击、whoosh 或语音重音。
- 声音负责确认动作和空间，不要每个元素都加音效。
- 没有授权音频素材时只写声音设计建议，不虚构已经加入的文件。

## 动效强度

### 1/3 克制

轻推拉、淡化、少量弹性和稳定构图，适合教程、品牌说明和高信息密度画面。

### 2/3 明显

一个清楚的主动作、分层视差、一次景别变化、少量强调效果。默认选择。

### 3/3 强冲击

快速空间穿越、真实 3D 相机、强速度变化或复杂遮挡。只用于短片头、高潮或用户明确要求；仍需保留可读停顿。

## 创意到实现的映射

每个设计描述都要写出实现类别：

- DOM/CSS：排版、卡片、界面、简单遮挡和 2D 透视。
- SVG：路径、线条、图标、蒙版和可控形变。
- Canvas/Remotion effects：像素级滤镜、拖影、失真和图像处理。
- Three.js/React Three Fiber：真实相机、灯光、几何、材质和空间粒子。
- Remotion 时间结构：Sequence、Series、TransitionSeries、音频和可参数化 Props。

如果无法指出实现类别，说明该创意仍然过于抽象。
