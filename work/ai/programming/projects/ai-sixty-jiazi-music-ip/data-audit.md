### 已发现的音程问题

旧干支合音代码的注释、条件和音值存在不一致，例如部分组合的实际半音差与条件判断不相符。新 Demo 必须从统一音高表重新计算，并同时给出：

```text
rawDifference = abs(a - b)
shortestCircularDifference = min(rawDifference, 12 - rawDifference)
```

如果需要解释旋律方向，还要保留上行或下行的有向差值。旧代码结果不能直接作为真源。

## 三、六十甲子数据表

### 当前优先级

1. `60甲子总表_纵向版_拆开合并(1).xlsx`：当前六十甲子主表。
2. `古音律五行整合表_校勘完善版_重排版.xlsx`：五行古音律字段和校勘依据。
3. `codexBIAOGE (1).xlsx`：较早或较杂的对照表，不单独作为发布数据源。

### 主表可用字段

主表约 60 个字段，覆盖：

- 干支、纳音、阴阳、五行、调式、音阶、主音。
- 主辅乐器、BPM、四柱音符、气机方向。
- 意象、颜色、情绪、季节、方位。
- 脏腑、情志、六字诀、调节建议和疗愈意象。
- 太岁纪年、神名、干支、人物格局、生平、性格、守护属性和故事情绪。
- 理法、技法、心法等创作层字段。

字段丰富不等于可以全部直接对外发布。医疗、疗愈、人物生平和术数解释需要逐项标记来源、审核状态和展示边界。

### 已记录校勘

- 应为“五常”，不是“五伦”。
- 洪范五事对应：木为貌、金为言、火为视、水为听、土为思。
- 五礼需使用规范映射并补全军礼。
- 木鱼在不同分类视角下可能归属不同，需保留分类依据。
- 十神不能固定映射到五行；原表相关行被判为存疑，不纳入发布数据。
- 五刑条目已有纠正，后续应沿用校勘版。

## 四、创作资料

- 音乐创作素材：60 个甲子文档加 1 个模板文档。
- 音乐创作提示词：60 个甲子文档。
- 五行全流程：包含五行分类、生成框架和提示资料，以及 2 个内嵌 XLSX。
- 共检查 156 个 DOCX；六十份创作提示词的“旋律设计（Melody）”部分全部为空。

这一空缺应被转化为产品功能：依据主音、调式、音阶、速度、情绪、气机和乐器等已确认字段，生成可编辑且可追溯的旋律设计，不应继续保留空模板。

## 五、音频资产

- 文件数：20 个 WAV。
- 格式：48 kHz、立体声、16-bit。
- 体积：约 690 MB。
- 总时长：约 3,768.4 秒，即 62 分 48 秒。
- 内容：10 条五行生克关系音乐；10 条金木水火土的大调和小调音乐。

Demo 默认使用 Web Audio 合成更利于快速加载和规则验证。原始 WAV 的接入前置条件：

1. 确认版权、作者、授权范围和可否公开传播。
2. 决定是否剪辑预览段并转码为适合网页的格式。
3. 建立音频清单、内容 ID、时长、来源和版本字段。
4. 不把 690 MB 音频直接提交到 `ai-context`。

## 六、事实等级

建议数据导出时为每条内容增加：

| 字段 | 用途 |
|---|---|
| `source` | 原始文件、工作表或文档名 |
| `sourceLocation` | 工作表、行列或段落位置 |
| `status` | `confirmed`、`needs-review`、`excluded` |
| `reviewedBy` | 学术或内容审核人 |
| `reviewedAt` | 审核日期 |
| `interpretationType` | 计算事实、资料记载、创作转译或商业文案 |

产品界面应把“可重复计算的结果”“资料中的传统说法”“AI 创作转译”分开标识。

- 音频和人物形象的版权、肖像、商标与商用授权。
- 当前沟通中提到的合作团队、资金和学术背书是否存在可公开证明材料。
