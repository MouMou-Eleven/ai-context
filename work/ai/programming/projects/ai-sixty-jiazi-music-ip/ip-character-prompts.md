## 统一角色圣经

所有角色使用同一套视觉语言：原创中国潮流收藏级神祇形象，约 2.8 头身，年轻成年气质而非幼儿化；全身 3/4 视角，庄重、镇定、有守护神与将军气场；中国礼服与克制盔甲分层结合，哑光瓷感或树脂感主体，局部古铜金属；轮廓简洁但细节精致，适合实体手办和数字角色延展；同一镜头高度、比例、博物馆式圆形底座和柔和轮廓光；纯净背景，不出现文字、Logo、水印或边框。

统一负面要求：不要直接模仿任何现有潮玩品牌、现成 IP 或注册角色；不要真人写实、廉价 Q 版、婴儿比例、夸张大头、日漫校服、赛博朋克霓虹、欧美超级英雄盔甲、血腥、恐怖、宗教冒犯、过度繁复背景、可读文字、Logo、水印、多余肢体、手指错误。

## 使用建议

- 第一次生成时把“统一角色圣经”与单个角色提示词一起提交，固定画幅、镜头、底座和材质。
- 先各出角色正面 3/4 概念图，再做正、侧、背三视图；角色确认前不要直接制作 3D 模型。
- 五个角色并排评审时重点看轮廓、五行色彩、道具和神情是否一眼可分，不以堆砌传统符号为目标。
- 角色名和说明文字应在后期 UI 中排版，不要求图像模型生成汉字。
- 需要扩展到 60 角色时，先把已确认的冠、肩、甲、披风、道具、守护兽和底座拆成可复用部件库。
