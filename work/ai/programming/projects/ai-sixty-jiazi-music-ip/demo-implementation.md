## 实现结果

Demo 使用 React 19、TypeScript、Vite、`lunar-javascript`、Web Audio API 和原生 SVG 实现。首发形态为响应式 Web App，不依赖后端即可演示主流程。

| 模块 | 已实现能力 |
|---|---|
| 听命 | 公历日期时间输入、四柱与纳音、干支音位、可开关四分轨、Web Audio 合成音景、年柱档案 |
| 寻甲子 | 60 条数据检索、五行筛选、表格浏览、单条档案精读 |
| 合音 | 干支音位选择、A/B 试听、原始差值、上行/下行距离、十二律环形最短距离、五合六合预设 |
| 造曲 | 选择甲子、场景、情绪与时长，生成含完整 Melody、节奏、配器、意象和禁止项的可复制简报 |
| 神谱 | 甲子金辨、戊辰赵达、丙子郭嘉、丙寅耿章、庚午王济五个原型，神印、守护职责、气场、视觉锨点与档案联动 |

## 数据与算法口径

- 60 条数据从工作簿审计 JSON 机械导出，每条保留 Excel 源文件追溯信息；解读性字段统一标记 `needs-review`。
- 公历转四柱验收样例：`2005-12-23 08:37 → 乙酉 / 戊子 / 辛巳 / 壬辰`。
- 合音已修正旧工具只看线性差值的问题，同时返回上行、下行和 `min(上行, 下行)` 的十二律环形最短距离。
- 四柱 `40 / 30 / 20 / 10` 仅是 Demo 混音权重，界面已显示“待确认”。
- 不导入 690 MB 原始 WAV；首版用 Web Audio 实时合成，避免未确认授权和体积问题。
