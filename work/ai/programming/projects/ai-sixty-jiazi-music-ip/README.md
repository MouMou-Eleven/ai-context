> 当前口径确认：2026-08-24

## 项目定位

本项目以六十甲子、五行、纳音、古音律和相关文化资料为内容底座，当前分为两条相互独立的工作线：

1. **Web 产品 Demo**：把三套分散网页工具重构成“听命、寻甲子、合音、造曲”四个连贯模块。
2. **甲子神 IP 形象**：独立设计与生成五个潮玩卡通角色，不属于网站导航、页面或交互流程。

网站主路径为：输入出生时间或选择甲子 → 查看可追溯的干支、纳音与音律映射 → 试听与比较 → 生成音乐创作方案。不得再把独立 IP 图片工作误写成网站“神谱”模块。

## 当前确认事实

- 第一阶段产品形态：响应式 Web App，兼顾手机浏览器；App Store 与微信小程序仍只是后续方向。
- 当前已有三套相互分散的网页工具：本命五音推演、干支五音组合、六十甲子与干支关系查询。
- Web Demo 已完成四个模块、Web Audio 试听、60 条甲子检索、音程比较与非空 Melody 创作简报。
- 本地曾出现网页无法访问；实测原因是预览服务未运行，并非 React 白屏。已增加可双击启动脚本，自动安装依赖、构建、启动并打开网页。
- 五个甲子神 IP 是单独交付物，与网站无关；当前视觉口径为参考图所示的潮玩卡通、2.5–2.8 头身、超大头小身体、圆润 PVC/软胶手办质感、纯净影棚背景。
- 已生成五张当前潮玩版：甲子金辨、戊辰赵达、丙子郭嘉、丙寅耿章、庚午王济。早先 7–7.5 头身成熟神将方向已被否决，仅保留历史记录。
- 五个代表是产品阶段选样，仍需居老师与文化顾问确认人物史料、命名与正式商用口径。
- 当前六十份音乐提示词中的“旋律设计（Melody）”原为空；Web Demo 已用可复用规则补全，仍需作曲人与文化顾问复核。
- 当前沟通材料提到学术、软件、内容 IP、数字人、自媒体和商业化等方向；合作、资金和正式背书尚未取得可核验正式文件，不能对外写成既成事实。

## Web Demo 产品结构

| 模块 | 核心作用 | 首版闭环 |
|---|---|---|
| 听命 | 输入公历日期、时间，计算四柱并映射音律 | 四柱、纳音、音符、分轨开关、可试听组合 |
| 寻甲子 | 查询和筛选六十甲子 | 干支、纳音、调式、速度、乐器、意象、太岁原型 |
| 合音 | 比较天干地支及五合六合的音程关系 | 原始音值、循环最短音程、方向音程和 A/B 试听 |
| 造曲 | 依据甲子和使用场景生成音乐创作提示词 | 补齐旋律、调式、速度、乐器、意象和禁用项 |

详细方案见 [`product-demo-plan.md`](./product-demo-plan.md)。
