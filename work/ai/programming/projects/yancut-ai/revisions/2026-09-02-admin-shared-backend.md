# 2026-09-02 管理后台与共享后端闭环

## 修订背景

言剪 AI 的用户端已经具备剪辑、AI 计划、自动成片、包装渲染和商业化接口，但此前缺少运营管理入口，也没有一套能与秒哒共享后端衔接的管理员权限、服务配置和审计合同。本轮目标是在本地先完成前后端闭环，并把生产环境仍需接线的部分清楚隔离。

## 已完成内容

### 管理界面

- 新增 `/admin` 中文管理后台，并从工作台侧栏提供入口。
- 运行概览读取真实管理 API，展示用户、项目、订单、渲染任务和近期审计记录，不使用虚构统计数字。
- 用户管理支持搜索、查看积分及管理员状态，并可授予或撤销管理员权限；禁止管理员撤销自己的权限。
- 接口配置支持模型、声音、Remotion、HyperFrames、支付等 15 个允许项；敏感值只显示掩码，浏览器不会取回明文。
- 配置保存、管理员权限变化均写入审计记录。

### 共享后端与权限

- 新增 `admin_users`、`admin_settings`、`admin_audit_logs` 三张 Postgres 表、索引、迁移和行级安全策略。
- 管理 API 统一校验登录会话和管理员身份，支持数据库管理员记录，也支持用 `YANCUT_ADMIN_EMAILS` 初始化首批管理员。
- 本地开发可显式开启回环地址演示模式；该模式只用于本机验收，不会在非回环地址自动放行，也不伪造线上用户。
- 生产环境要求配置 32 字节 `YANCUT_ADMIN_ENCRYPTION_KEY`，接口密钥使用 AES-256-GCM 加密后入库。

### 运行时接线

后台配置不是只保存不生效。模型规划、自动成片、ElevenLabs、Remotion/HyperFrames 渲染队列、支付收银台和支付回调均已改为读取“后台覆盖值优先、环境变量兜底”的动态配置。保存后运行时缓存最长 5 秒刷新。

### 管理 API

| 接口 | 方法 | 作用 |
|---|---|---|
| `/api/yancut/admin/overview` | `GET` | 真实业务计数与近期审计 |
| `/api/yancut/admin/users` | `GET` | 用户、钱包与管理员状态查询 |
| `/api/yancut/admin/users` | `PATCH` | 授予或撤销管理员权限 |
| `/api/yancut/admin/settings` | `GET` / `PATCH` | 读取掩码配置、保存或删除覆盖值 |
| `/api/yancut/admin/audit` | `GET` | 审计记录查询 |

详细数据表、错误语义、配置键和秒哒迁移顺序见源码仓库 `docs/yancut/admin-backend.md`。

## 能力边界

- 本地演示模式可以验证管理页面、接口校验、配置生效和审计流程，但使用进程内存，服务重启后演示配置会清空。
- 接入真实 Auth 和 Postgres 后，用户列表、管理员授权、配置和审计才具备跨页面、跨设备持久化能力。
- 当前运行概览是业务状态监控，不等同于服务器 CPU、内存、请求耗时和告警平台；基础设施可观测性仍需由秒哒或独立监控服务提供。
- 支付、声音克隆和远程渲染虽已支持后台配置，但只有配置并验收正式供应商后才是生产能力。

## 秒哒上线接线顺序

1. 执行 `0001` 至 `0003` 数据库迁移，确认三张管理表和现有业务表均已建立。
2. 接入秒哒 Auth，并验证前端会话能够映射到 `users.id`。
3. 配置 `YANCUT_ADMIN_EMAILS` 初始化管理员，登录后再用后台授予其他管理员。
4. 配置独立的 `YANCUT_ADMIN_ENCRYPTION_KEY`，不得把密钥写进前端包或 GitHub。
5. 在后台录入生产模型、声音、渲染和支付配置，逐项执行真实调用验收。
6. 用普通用户和管理员两个账号验证越权、跨账号隔离、审计记录和密钥掩码。
