# Concat 评估、真实模板槽位与 AI 串行命令落地

> 日期：2026-09-01
> 结论：Concat 是有真实工程内容的早期 alpha，不是宣传空壳；言剪 AI 只吸收已经能解释和验证的架构经验，不把其桌面源码直接并入网页运行时。

## 一、Concat 成熟度判断

核验对象：<https://github.com/jub0t/Concat>

- 仓库创建于 2026-08-25，2026-08-31 仍有提交；截至核验时 GitHub API 返回约 980 stars、85 forks、10 个开放 issue。
- 当前有 155 个提交，主要由单一贡献者完成；发布版本全部为 alpha 预发布，最新为 `v0.2.0-alpha.16`。
- 最新发布同时提供 Windows、macOS、Linux 安装包；Windows setup 下载数已超过 500，说明不是只放截图或 README 的空仓库。
- 实际代码包含 React UI、Tauri 宿主、Rust 编辑引擎和 FFmpeg/ffprobe 子进程，文档描述了项目模型、撤销、自动保存、渲染和模板实例化边界。
- 当前 issue 仍有预览黑屏/灰屏、图片素材不渲染、多文件导入失败、字幕导出偏移、帧延迟和 Linux EGL 崩溃等问题。

因此成熟度应定义为“有真实工程能力的高活跃 alpha”，而不是“可直接商用的成熟底座”。高关注度和大量提交只能证明真实开发，不能替代多用户、长视频、跨平台和数据安全验证。

## 二、许可与架构边界

- Concat 主许可证是 MPL-2.0，属于文件级 copyleft；修改受覆盖文件并分发时需要保留通知并提供对应源码。
- `THIRD_PARTY_NOTICES.md` 记录了 FFmpeg GPL 构建和语音依赖组合带来的 GPL-3 风险，作者也指出后续需要进程隔离。
- 其 Tauri/Rust/桌面 FFmpeg 架构与言剪 AI 的 Next.js 浏览器架构不同，不能把桌面代码直接塞进网页端。
- 当前采取“吸收稳定 ID、模板文档、串行命令、事务回滚、任务状态”等公开设计经验，不复制 Concat 源码文件。

## 三、本轮落地

### 真实模板槽位

- 8 个内置创作包新增 4-6 个视频/图片槽位，按开场、主体、细节、证明、结尾排列。
- 用户必须为全部必填槽位选择真实素材，按钮才可创建项目；素材为空时不会生成只有标题的空壳工程。
- 实例化逻辑验证素材类型、存在性和有效时长；视频片段按源时长裁切，图片按模板目标时长进入连续时间线。
- 素材会复制到新项目，并使用独立 `blob:` 地址；模板页释放公共素材地址时不会破坏新项目预览。
- 创建过程中任一步失败会删除半成品项目，防止项目列表留下损坏数据。

### AI 串行编辑

- AI 计划执行加入页面级串行操作队列，后提交的操作等待前一操作结束。
- 单个操作失败不会使队列永久拒绝后续任务；现有项目指纹、执行回执和撤销/回滚继续负责状态安全。

### ducking 修复

- 修复人声窗口把 OpenCut 时间 ticks 当秒传给 ducking 的单位错误。
- 人声窗口现在先转换为秒，`buildDuckingKeyframes` 再输出正确的 attack/release 时间点。
- 新增测试覆盖 0-20 秒连续人声窗口与 `[0, 150, 19650, 20000]` 毫秒关键帧。

## 四、验证证据

- Biome 对 9 个相关文件检查通过。
- TypeScript `--noEmit` 通过。
- Next.js 16.1.3 生产构建通过，27/27 页面生成成功。
- 真实浏览器打开模板中心，弹窗显示 5 个必填槽位；未填时创建按钮禁用，填满后显示“待填 0 个槽位”并启用。
- 创建“美妆好物推荐”后进入真实编辑器：素材箱有实际图片，主视频轨有 5 段连续素材，文字轨有可编辑标题，总时长 25 秒；控制台错误和警告为 0。
- Bun 未安装，新增的 Bun 测试文件已通过 TypeScript 编译，但本机未执行 Bun test。

## 五、后续方向

1. 为模板增加可选槽位、镜头替换预览、字幕样式和配乐规则，不用静态卡片数量冒充模板丰富度。
2. AI 串行队列进入云端前，增加幂等键、取消、重试、租约和任务持久化。
3. 继续用真实长视频验证代理、波形、字幕、高光切片和内存占用。
4. 跟踪 Concat 新版本时只重新核验可迁移概念和稳定性，不随 alpha 代码同步。
