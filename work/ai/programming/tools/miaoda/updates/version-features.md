## 2026.07.16 — V3.5

> 来源：[秒哒官方微信公众号发布文章](https://mp.weixin.qq.com/s/y2_ip4MYlJQPpTJ2a_O26A?scene=1)。截至 2026-07-16，百度智能云 26 年更新日志尚未收录 V3.5，因此以该官方发布文章为准。

里程碑版本：从应用生成扩展到流量分发、多端交付、共享后端与生产环境管理。

- **SEO Agent**：逐页检查标题、描述、关键词等搜索要素；支持搜索结果预览、可理解的诊断建议、单项或一键修复及重新检查
- **iOS 打包与分发**：提供无需 Apple 开发者账号的 IPA 体验路径；拥有 Apple Developer Program 账号并配置 API Key 后，可完成证书申请、在线构建、签名打包，支持 Ad Hoc 真机测试、TestFlight 内测和 App Store 上架流程
- **多应用共享后端**：Web、APP、小程序、管理后台等多个终端可复用同一套数据库、接口、存储等后端能力，前端独立迭代、数据统一管理
- **自定义技能扩展**：支持首页“技能创建”、项目内对话创建或修改、`.zip` / `SKILL.md` 导入，以及粘贴 API 文档链接或 API 说明生成可调用技能；生成后的技能可保存到技能中心并通过 `@技能名` 在任意项目复用
- **数据库多环境隔离**：创建应用时可选单环境或开发/线上多环境；多环境支持标准发布、发布合入异常的免费 AI 修复、Schema 与数据快照回滚，以及从多环境切回单环境
- **后端资源分级**：提供基础版至超大容量的资源规格，覆盖并发、数据库存储、文件存储；支持按需升级和资源使用可视化提醒

## 如何扩展本文件

### 场景 A：新版本上线（最常见）

1. 在当前最新版本章节**上方**插入新章节，标题格式优先用 `## YYYY.MM.DD — V<版本号>`；如果只有发布速报、官方版本号尚未确认，用 `## YYYY.MM.DD — 更新速报（版本号待官方日志确认）`
2. 用无序列表罗列重点能力，每条用粗体标题 + 简短解释（参考已有版本格式）
3. 如果是里程碑版本（如域名切换、架构重构、生成新形态），在该节首行加一句话说明里程碑性质
4. 写入前必须读取最新官方更新日志；如果官方已收录，把新日志 URL 加到文件顶部「来源入口」；如果只有建委提供的速报，必须标注"官方日志尚未收录，版本号与官方 URL 待补"
5. **不要修改历史版本章节**——历史是不可变的事实记录，只追加不修改

### 场景 B：旧版本细节补全

如果发现某个旧版本的能力描述需要补全（例如官方文档后来更新了），直接在对应章节追加项目符号；不要重排顺序。
