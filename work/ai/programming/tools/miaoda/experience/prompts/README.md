## 写入与复用

新增模板先查现有主题和处方，补事实来源、适用前提、允许动作、验收与失败回传；同义模板合并。更新当前主题README、上层 [提示词入口](../prompt-patterns.md) 和相关处方链接。代码块中的路径是待核对的项目合同，不因文字移动而擅改供应商源码。

只有发现复现的旧上传限制时，才进入 [旧分片合同与专用提示词](../reference-materials/video-chunked-upload/legacy-contract.md)。套餐与平台功能以 [当前能力入口](../../basics/current-capabilities.md) 的日期和来源再核验；真实执行流程按本轮授权范围推进。
