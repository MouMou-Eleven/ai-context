# 秒哒当前能力与限制

> 状态：当前有效
> 核验日期：2026-08-29
> 当前版本节点：V3.7（官方文章发布于 2026-08-27）

本文件是回答“秒哒现在支持什么、当前限制是多少”的首读入口。计费、额度和界面仍会变化，执行付费或生产决策前必须再次查看秒哒当前购买页和项目控制台。

## 一、V3.7 当前新增能力

| 能力 | 当前口径 | 使用边界 |
|---|---|---|
| 设计智能体 | 首轮需求确认后可点击“先看看设计方案”，先生成 3 套不同方案；支持对话调整、组合后再生成应用 | 这是生成前的设计依据，不是只换颜色的预览图 |
| 素材库 | 图片、音频、视频、文档等可集中保存、搜索、下载并跨项目复用；项目内文件可“另存为素材” | 素材库容量与应用对象存储容量是两套额度 |
| 预览调试报错修复 | 预览调试页出现运行报错时，可点击“免费尝试修复” | 免费修复不等于已经完成真实设备和正式环境验收 |
| 预览视图偏好 | 重新打开编辑器时恢复上次选用的视图；手机应用在电脑编辑时优先显示手机视图 | 仍需分别验证真实手机和桌面端 |
| 应用回收站 | 删除应用后进入回收站，30 天内可恢复，也可以永久删除 | 回收站不是数据库备份或版本回滚的替代品 |
| 后端自定义套餐 | 存储与并发可按需调整，不再只按固定档位理解 | 具体可选值、价格和上限以当前控制台为准 |
| 自动扩容 | 业务增长时可开启自动扩容 | 开启前应同时设置费用与容量提醒，不能理解为无限免费资源 |
| 后端欠费缓冲 | 当天秒点不足时可临时出现负数抵扣，保障当日后端不中断 | 只解决当天连续运行，不代表免除后续补充秒点或结算 |
| 秒点加油包卡券 | 支持购买、赠送和兑换，多档位可选 | 实际档位、价格和有效期以购买页为准 |
| 对话内配置技能 | 调用未配置技能时可在对话中完成密钥或授权配置，再继续原任务 | 密钥仍不得写入前端、提示词正文或公开源码 |
| 图片体验 | 订阅用户查看、下载 AI 图片时可去除“秒哒AI生成”水印；多图可左右切换，静态图可点击“变视频” | 去水印权益按会员与当前页面为准 |

## 二、四种容易混淆的文件额度

### 1. 项目内应用的单文件上传

百度官方计费页在 2026-08-27 列出的当前权益是：

| 会员版本 | 项目内上传单文件上限 |
|---|---:|
| 免费版 | 50MB |
| 专业版 | 500MB |
| 旗舰版 | 500MB |
| 企业标准版 | 500MB |
| 企业定制版 | 包含企业标准版权益；最终以合同和控制台为准 |

官方同时给出配置提示：在项目对话中输入“上传大小改为 500MB，同步修改前后端限制”。因此，购买付费会员不应被理解为既有项目代码会自动完成所有修改；前端校验和后端限制必须同步，之后还要实际上传验收。

**当前结论**：过去仓库里的“50MB 已全面取消”不再作为当前口径。现在必须先判断会员版本：免费版仍是 50MB，专业版及以上才按 500MB 权益处理。

### 2. 素材库容量

| 会员版本 | 素材库容量 |
|---|---:|
| 免费版 | 100MB |
| 专业版 / 旗舰版 | 1GB |
| 企业标准版 | 基础 10GB，并按 5GB / 席位增加 |

素材库用于跨项目沉淀和复用文件。会员到期后容量会退回免费额度；已超出的已有素材不会立即丢失，但不能继续上传新素材。

### 3. 应用对象存储容量

应用对象存储用于保存应用运行中的图片、视频、音频和文档。免费基础后端仍是数据库 1GB、对象存储 200MB、并发 10。V3.7 已宣布后端资源改为自定义套餐并支持自动扩容，因此不再把旧固定档位中的“对象存储最高 10GB”当作当前上限；具体可选容量、并发和价格必须看当前项目控制台。

**500MB 单文件上传权不等于拥有 500MB 剩余对象存储。** 上传前必须同时确认当前对象存储剩余额度能容纳该文件及后续增长。

### 4. 首页或对话附件

2026-04-01 的历史更新记录曾写首页附件单文件最大 20MB。它描述的是向秒哒提交需求或素材的入口，不是生成应用内部给最终用户使用的上传功能，也不是素材库总容量。V3.7 没有在发布文章中宣布这个入口同步提升到 500MB，不能混用。

## 三、500MB 上传的当前开发决策

1. 先确认会员。免费版按 50MB；需要更大文件时先使用专业版或以上权益。
2. 在项目对话中明确要求“上传大小改为 500MB，同步修改前后端限制”。
3. 确认对象存储剩余容量大于待上传文件，并预留后续文件空间。
4. 用实际目标类型和大小做测试，至少验证上传、刷新后仍存在、播放或下载、删除及权限控制。
5. 当前原生上传稳定通过时，不部署旧的“永久分片 + Range 代理”架构。
6. 500MB 是产品上限，不是弱网可靠性保证。网络不稳定或需要断点续传时，可优先使用平台或云存储原生 multipart，最终仍保存为一个正常对象。
7. 只有旧项目仍可重复复现 CORS、413、函数取消或存储网关限制时，才读取 [`../experience/reference-materials/video-chunked-upload/`](../experience/reference-materials/video-chunked-upload/README.md) 的历史兼容实现。

## 四、已处理的旧口径冲突

| 旧记录 | 当前处理 |
|---|---|
| “取消 50MB 上限”被理解为所有用户都没有 50MB 限制 | 已替换为免费版 50MB、专业版及以上 500MB |
| 新项目默认用 5MB 永久分片上传 | 已降级为旧后端兼容资料；当前默认先配置并测试原生 500MB 能力 |
| 后端只有基础、小、中、大、超大固定档位，最高对象存储 10GB | V3.7 已宣布自定义套餐和自动扩容；旧档位只作历史追溯 |
| 源码下载 30 秒点/次 | 2026-08-27 官方计费页当前写“下载应用源码 300 秒点/次” |
| 素材库、项目上传、对象存储是同一额度 | 已拆分为三套不同用途和额度 |
