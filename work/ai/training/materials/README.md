## 写入规则

- 用户只说课程或课件时，默认制作口语化的课堂主文档：讲师现场使用、学员能够看见，不包含授课时长、讲课顺序和内部提示。
- 讲师备课稿可以包含备课、讲课顺序和演示提示；课后文章、作业和练习只在用户明确提出时生成。
- 正文在飞书时，本目录只保存标题、链接、受众、状态和最近核验时间。
