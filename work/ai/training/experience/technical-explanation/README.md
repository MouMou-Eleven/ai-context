## 使用边界

- 默认只读提炼后的方法；中文表达基础规则由 [`../../../../../brain/ai-expression/README.md`](../../../../../brain/ai-expression/README.md) 提供。
- 只有需要追溯来源时才读取中文数据集中的原始逐字稿。
- 平台版本、模型参数和技术事实必须重新核验。
- 只学习讲解逻辑，不模仿外部作者标志性措辞。
- 自媒体技术口播只有在建委明确要求组合“AI培训讲解方法”时才调用本目录。

## 多来源选择规则

- 本目录保存的是“怎样解释技术”的方法，不保存或激活某位创作者的完整个人风格。
- 新来源支持现有“问题驱动”链路时，补充证据或完善具体环节，不另建一套同义方法。
- 新来源提供不同但有效的解释路径时，必须写明适用受众、内容难度、课程形式和限制。
- 一次技术讲解只确定一条主链路。可以在主链路中加入兼容的演示或例子，但不能把多位作者的开头、节奏和句式拼接成混合风格。
- 建委真实授课复盘与当前课程目标优先于外部参考材料。
