## 多位讲师与创作者经验怎样合并

1. 先把资料拆成具体能力，例如课程开场、概念解释、案例展开、现场演示、互动、收束和复盘。
2. 每项经验写清适用受众、课程类型、使用条件和限制，不以作者姓名作为激活词。
3. 与现有方法一致时只补来源，不重复新增规则。
4. 可以前后分工的方法才组合，例如“问题驱动解释 + 演示验证”；多个互相替代的开头不得同时使用。
5. 发生冲突时按以下顺序选择：当前任务要求 → 当前项目事实 → 建委真实授课复盘 → 已验证培训方法 → 外部来源候选方法 → 原始逐字稿。
6. 无法确定哪种方法适用时，保留冲突并向建委确认，不把不同人的讲法平均混合。

## 写入规则

- 课程开始前形成的通用方法进入备课与课件设计。
- 真实授课后的反馈、失败和修正进入演示与复盘经验。
- 某个具体课程或社群的事实留在 `projects/`。
- 自媒体表达方法不写入本目录。
- 新来源必须先进入 `brain/ai-expression/chinese-datasets/` 登记来源、授权与用途，再提炼到本目录；原始资料不直接成为培训规则。
