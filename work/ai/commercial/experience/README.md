# 商业交付经验

> 这里记录建委在正式商业内容交付中确认可跨项目复用的经验。每项经验必须能直接转化为写作、审核或交付动作。

## 当前经验

| 经验 | 解决的问题 | 触发条件 |
|---|---|---|
| [`external-deliverable-language.md`](./external-deliverable-language.md) | 区分给建委看的内部工作稿与可直接对外发送的成品，清除“客户、建议、待确认”等内部措辞 | 给客户看、对外发送、正式交付、供外部审阅，或交付物显然代表建委或公司对外呈现 |

## 后续写入方式

- 一个文件只解决一类可复用问题，不把所有商业经验堆入总入口。
- 新经验必须写明触发词、默认行为、例外条件、正反例和检查清单。
- 具体项目名称、报价、排期、联系人和未经复用的临时要求留在项目文件，不提升为通用经验。
- 如果新经验改变了本目录的触发边界，必须同步更新上层 [`README.md`](../README.md)、根目录 `llms.txt` 和 `AGENTS.md`。
