# 2026-09-15：社群介绍页统一使用“你／大家”面对读者

## 触发背景

建委在手动检查并修改飞书《AI 超级个体陪跑社群｜介绍与报名》第02节时指出：自动改写虽然修正了内容逻辑和渠道语气，却把读者称为“成员”或“学员”。介绍页其他部分一直在直接对读者说话，主要代称是“你”，面向多人时使用“大家”。局部段落改成第三人称标签后，与全文表达方式不一致。

建委已经手动修正飞书。本次只更新 GitHub 长期规则，不再对飞书执行写入或回读，因此不记录手动修改后的 revision，也不根据 revision 240 推定当前正文。

## 当前确认

1. **介绍页正文以“你”为主要代称。** 回答“你能获得什么”“为什么这样安排课程”等问题时，直接面对正在阅读和判断是否加入的人。
2. **群体语境可以使用“大家”。** 当句子确实在说明共同学习、课程安排或多人参与时，用“大家”比“成员／学员”更符合这篇介绍页已有语气。
3. **“成员／学员”不是禁词，但有明确边界。** 它们可用于内部产品规则、受众分类、权益状态、资料索引或第三人称事实描述；不能在连续的读者直述正文里替代“你／大家”。
4. **局部改写必须服从全文。** 不能只判断目标段落本身是否通顺；写入前要读取相邻章节，确认称谓、叙述视角和语气，再沿用已有系统。

## 错误与修正

| 项目 | 错误做法 | 当前规则 |
|---|---|---|
| 直接回答读者 | “成员会接触……”“学员会逐步理解……” | “你会接触……”“你会逐步理解……” |
| 说明集体学习安排 | 反复使用“成员／学员”概括所有读者 | 语境需要时使用“大家” |
| 内部事实记录 | 为避免任何“成员／学员”而机械替换 | 保留准确的内部称谓，不把对外语气规则扩大到内部文档 |
| 局部改稿 | 只看当前小节，重新发明一套人称 | 先读相邻内容，沿用整篇文档的人称和叙述视角 |

## 适用范围

- 直接适用于当前飞书社群介绍与报名页及其后续局部改写。
- 可作为其他介绍页的检查方法，但不能预设所有项目都必须使用“你”；其他文档应先读取原文，再保持其既有人称一致。
- 不要求把 GitHub 内部项目文档、课程资料索引和历史记录中的“成员／学员”全部替换。
