# 2026-09-15：区分对外年度口径与内部持续交付设计

## 触发背景

建委提供了一段新成员入群前的真实交流。聊天中出现“499 两年”的临时回复，与项目 README 已维护的“499 元 / 年”口径不一致。建委随后明确说明，需要把社群最初的产品设计思路与当前对外宣传口径分开记录。

## 本次确认

1. **对外统一口径仍是 499 元 / 年。** 朋友圈、介绍页、私聊、海报和其他销售材料均不得写成“终身买断”“永久会员”或未经确认的“两年”。
2. **社群最初采用买断式的持续交付思路设计。** 建委希望成员一次付费后，仍可以跟随后续新增的 AI 课程、直播和知识库内容继续学习。
3. **内部设计背景不自动构成对外权益承诺。** 当前可公开承诺的会员周期仍是一年；不能因为内部希望长期交付，就把超过一年的权限写进宣传文案。

## 仍待对齐的执行问题

如果后续需要把内部持续交付设计变成正式会员规则，还要单独确认并同步以下事项：

- 一年后是否续费、如何续费。
- 一年后是否继续留群。
- 已发布历史课程、回放和知识库是否继续保留访问权限。
- 一年后新增课程、直播和知识库更新是否继续开放。
- 微信小店商品页、飞书介绍页、付款前说明和实际社群管理规则是否一致。

在这些事项明确前，所有对外内容只使用“499 元 / 年”及项目 README 已确认的一年内权益。

## 影响范围

- 项目 README 的当前产品口径日期更新为 2026-09-15，并新增对外口径与内部设计的区分。
- 历史摘要不再写“长期会员卡设想完全失效”，改为“不再作为对外口径”。
- 本次朋友圈文案不出现“两年”“终身买断”或超过一年后的权益承诺。
