# 实操课程从工具全景进入具体工作场景

日期：2026-09-18。来源：建委在本任务中的完整课程调整说明。性质：备课与方案设计反馈，不是讲后复盘或应用效果证明。

## 方向变化

此前方案围绕五类具体产品与AI整理公开材料的案例展开。建委本次明确要求：先系统梳理主流工作赋能方向，帮助学员形成整体认识、按自身场景选择与搭配工具，再进入实际工作任务。方案暂不列具体产品名称；上一轮DeepSeek、秘塔、ima等产品清单不再作为本轮外稿要求。

宏观科普至少覆盖文本、视频、设计、编程、搜索、知识库、浏览器、3D建模；提示词单独讲有效构成和优化工具；具体场景讲日常反复遇到的资料、格式、查询、数据和宣传任务。本轮把提示词安排在全景之后、场景之前，作为表达需求的连接环节。

## 用户提出的场景及保留要点

| 场景 | 需要保留的教学内容与价值 |
|---|---|
| 舆情监测、检索、溯源与管理 | 指定公开来源与主题，结合每日自动化任务，形成当日摘要和来源记录，持续跟踪公众关切 |
| Word规范排版 | 已有内容按现成规范调整格式，而非重新起草全文；保留可编辑成果 |
| 会议与培训资料 | 从录音/视频得到总结、逻辑框架或思维导图；本地工作台按日期/主题查阅，点击看重点，支持人工录入与导入 |
| Excel原表不上传 | 只描述抽象结构和计算需求，让AI生成公式或方法；真实数据留在本机处理 |
| 数据大屏 | 指标、趋势、分类对比及筛选查询形成直观展示，减少整理、制图和美化的重复劳动 |
| 公众号排版与发布 | 本地工作台串联内容准备、排版、预览审核、发布衔接与归档，重复步骤按预设流程处理 |

工作台价值还包括随需求迭代：增加分类、查询或导入功能，使工具适应持续变化的工作；不把固定系统说成一律不能修改，也不宣称所有功能都能无门槛立即完成。

## 事实校准与内部验证

- 本地保存/界面不等于模型处理不出网。音视频理解如调用远程模型仍会传输内容；需要不上传的资料须选符合要求的本地处理或单位批准环境。界面离线可用与完整数据流分别验收。
- Excel不上传原表还需避免在字段名、规则、截图、样例中暴露真实业务秘密；使用抽象描述和虚构小样例，在本机用已知结果核对公式。
- 公众号公开发布本身需要联网；本地化指素材管理与工作台，不把自动排版和自动发布等同。具体接口、账号权限和执行方式尚未选型或实测，方案不承诺无限制无人发布。
- 提示词优化工具可以提供结构化优化流程；“专业工具一定经过大量对比且必然优于普通模型”缺少本次具体产品与测试证据，不直接写成事实。备课比较同一任务、同一模型及评价标准下的结果。
- 舆情演示定位于公开信息检索、事实来源与聚合分析，不承诺覆盖全网，不包含个人画像或舆论操纵。

AI本轮核验参考：[Ollama官方FAQ](https://github.com/ollama/ollama/blob/main/docs/faq.mdx)明确区分本地和云模型处理，并有禁用云能力设置。该资料仅支持技术区别，不代表选用该产品授课，不改变国内工具要求。微信公众号官方发布接口页本轮无法成功读取，未据此写入任何具体接口能力。

## 通用化结论

1. **修订已有通用规则**：更新[演示驱动课程设计](../../../../domains/training/experience/demo-driven-course-design.md)第四节，在跨岗位应用入门课采用“全景帮助选择—任务表达—场景展示成果”；不把此顺序强加给单工具进阶课。
2. **修订已有通用规则**：更新[对外方案设计](../../../../domains/other/commercial/experience/external-proposal-design.md)，将“说明提示词教学主题”与“附上提示词操作脚本”分开；用工作任务、成果和收获表达场景，不以品牌数量代替内容。
3. **仅保留项目证据**：本次11类整理、六个场景、人员和时长不是所有AI培训的固定模板，也不登记成已授课成果。
4. **尚待实测**：具体工具效果、自动化可用性、工作台开发结果和提示词优化收益。
