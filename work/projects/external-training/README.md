# 外出培训

> 入口建立：2026-09-12。这里属于建委对外开展的培训，不使用会员社群的权益、定价、进度和课序。

建委确认其培训还包括企业、图书馆、夜校等场景。以上是业务类别，不代表仓库已掌握每个客户或场次。2026-09-16建委已明确[济南市图书馆培训](./jinan-city-library/README.md)包含网页美化、秒哒进阶及[《别让 Bug 打败你》](./lessons/bug-repair/README.md)。具体班次与日期未提供，已确认机构不再标为待确认。

## 新项目或场次怎样加入

确认客户或长期系列后，在本目录建立有独立 README 的项目目录，再按真实场次记录主办方、日期、受众、目标、资料版本、授课状态和反馈。一个资料用于多个场次时引用现有课程主文件；项目特有差异写在场次中。未知字段保留“待确认”，不造客户名、排期或已授课事实。

只查外训近况时读本页及具体项目；制作或修改课件时，按[培训总入口](../../domains/training/README.md)补充培训经验与所需依赖。
