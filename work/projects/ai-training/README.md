# AI 培训项目

建委持续推进的 AI 培训业务，包括外出培训的各场次、培训资料的积累，以及培训业务本身的规划。

**定位**：这是一个长期项目，不是领域知识。培训怎么写课件、怎么讲课的方法在 [training/experience](../../domains/training/experience/)；这里只记录培训业务的事实、各场次的情况、以及只适用于培训业务本身的经验。
