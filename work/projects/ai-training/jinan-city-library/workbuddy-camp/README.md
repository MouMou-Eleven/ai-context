WorkBuddy 这一版的操作细节（课上要提醒学员）：

- 回答它提出的问题时，点下最后一个选项就自动提交，右下角按钮此时已变成“停止”，再点会取消任务；取消后说一句“请接着做”能接上，之前的结果还在。
- 开计划模式：输入框左下角“＋”→“模式”→“计划 Plan”。开了以后它先出方案，点“开始执行”才动手。
- 右侧预览里的图表坐标轴文字不显示，第 1、2 课都遇到了，交出去前用 Excel 打开看。
- 它会在工作空间里留下 `.workbuddy` 等以点开头的文件夹和自己写的脚本文件。

WorkBuddy 这一版的操作细节（课上要提醒学员）：

- ima 连接器授权一次后，**每个对话还要单独打开**：输入框“＋”→“连接器”→ ima 开关。没开时它会说连接器在本对话未启用。
- ima 连接器**不能新建知识库**，要先在 ima 里自己建好，再让它传文件。
- 输入框里的“增强提示词”按钮只补通用结构（主题、参会人、待办……），不会补日期、“不许编”、冲突检查、篇幅；点后变成“恢复原文”可退回。
- 个性化指令：头像 → 设置 → 个性化 →“给 WorkBuddy 的指令”→ 编辑。截图只截这一框，下面的人设和记忆是建委私人内容。
- 方正小标宋简体、仿宋_GB2312、楷体_GB2312 不是 Windows 自带字体（本机是装在用户字体目录），学员电脑大概率缺，提示词里要让它先查字体。
- 上课前把 WorkBuddy 正常重启一次（制作截图时用了调试端口启动）。
