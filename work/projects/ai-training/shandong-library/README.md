## 山东省图书馆要的文档格式（建委给的参考）

参考山东省图书馆已有的《AI 视频培训课程详细大纲》（雅文、重光两位老师）：

1. 一份文件，**师资简介在前，课程在后**，不单独做讲师简介。
2. 简介要短：开头一句总述，每位老师一行身份加 4 句左右。
3. 简介之后依次是培训现场照片（两列，图注写老师和单位）、获奖经历（编号列表）。
4. 课程按“课程目标—课程安排表（时间｜课程内容｜学习重点）—学习成果”开头，再按部分展开，写到每个小节的分钟数；90 分钟和 180 分钟两版放在同一份文件里。
5. 这份文件直接发给图书馆，不放“精简版”“适用于海报”之类给讲师自己看的说明。

## 课程结构

- **90 分钟**：认识会干活的 AI 与 WorkBuddy（25）→ 把手上的办公文件交给它：表格汇总、Word 排版、文件整理（40）→ 说清需求、ima 知识库、定时任务与手机远程（25）。
- **180 分钟**：认识会干活的 AI 与 WorkBuddy（35）→ 四类文件处理：表格汇总、发票报销、文件整理、批量证书（55）→ 休息（10）→ 需求表达、公文排版、文件对比、汇报材料、知识库（45）→ 定时任务、技能、网页小工具、手机远程（35）。
- 内容来自[济南市图书馆 WorkBuddy 训练营](../jinan-city-library/workbuddy-camp/README.md)第 1–4 课的规划；例子按馆内工作改写（各部门借阅与活动数据汇总、读者活动证书、馆内制度查询）。两版文件对比、网页小工具还没在 WorkBuddy 上实测，讲之前要先跑一遍。
