## 对方原始需求（王海洋原话）

“我们想针对全员培训 workbuddy 的基础应用。包括连接器，skill，专家等方式，重点是 skill 的原理，如何把自己的工作能力写成一个 skill。基于 workbuddy 做工作台，数字员工。场景最好面向办公，设计方案编制，概预算，如果能有与 CAD 识图画图相关的实操就更好了。”

补充：多数人用 AutoCAD 2007 及以上，土建专业用天正；“如果 CAD 写进通知，估计大家关注度会提高”（所以副标题里写了 AI + CAD 识图画图）。对方推荐参考秋芝2046《手把手彻底学会 Agent Skills！【小白教程】》（B 站 BV1G3FNznEiS，19 分 19 秒）讲 Skill。

## 方案结构（120 分钟）

认识会干活的 AI 与技能/专家/连接器/定时任务（10）→ 设计咨询日常工作实操：清单汇总与概算比对、设计说明编制与版本对比、规范知识库（30）→ **Skill 原理与定制（35，重点）**：用“设计说明书预检”Skill 逐级升级四版（现场跑其中两版）讲渐进式加载，再讲五步法和问答式生成 → AI + CAD 两项：AI 与 CAD 结合的三种方式（看图、读图、画图改图）+ 案例演示电气接线图 DXF → 设备材料表 Excel（25；改图签、生成示意图按建委要求删掉，时间紧）→ 数字员工（专家、专家团）与工作台、安全使用（20）。

独立审稿后改的口径（以后同类单位照用）：AI 一侧不叫“校核”，叫“预检、初步检查、比对”，校核按院内校审流程由人签字；各专业写“电气一次、电气二次、线路、土建”，不写“变电、线路、配电”（那是业务类别）；不写“结果稳定一致”“确认无误”这类保证。

Skill 部分的“同一案例逐级升级、每级由一个新需求引出”借鉴自上面那条参考视频的讲法。

## 讲之前要做的

- CAD 案例：样图还没在真实 AutoCAD 里打开过；生成/修改文件一律用 2007 DXF（ezdxf 写 R2004 及更早格式中文会乱）；天正图要先导出 T3；最好向对方要一张脱敏的真实配电图提前跑。
- “AI 直接在 AutoCAD 里画图”的 MCP（如 daobataotie/CAD-MCP）都没写明支持 AutoCAD 2007，方案里只写了“介绍”，要演示得在讲师电脑装较新版 AutoCAD 先彩排；WorkBuddy 里配置 MCP 的入口还没实测。
- 材料表演示要稳：用自己做好的样图（设备都是带“型号”属性的块），把统计脚本做进一个“图纸材料表”Skill，现场一句话调用，结果每次一样；答案提前数好（断路器、隔离开关、电流互感器按型号的数量见样图脚本输出）。不现场让 AI 临时写脚本，也不用截图让多模态去认（论文准确率 70%—94%，会变）。对方的真实图纸只放截图讲“炸开的线条统计不了”，不现场跑。备一份做好的材料表，WorkBuddy 出问题时直接打开。
