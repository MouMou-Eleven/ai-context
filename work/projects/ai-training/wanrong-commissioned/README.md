## 植入原则：软广，不是硬广

- **让企业版作为学员自己冒出来的问题的答案出现**，不单独开“产品介绍”环节。政企学员最容易冒出的两个问题：
  1. “内部材料是不是永远不能用 AI？”——用来引出部署方式，即专属网络和内网私有化；
  2. “这个 Skill 好用，全单位每人都要自己装一遍吗？”——用来引出统一下发和集中管理。
- **一堂 2 小时的课植入三处，合计约 5 分钟**：
  1. 安全使用环节结尾埋一个钩子（30 秒，只说“单位层面有办法”）；
  2. Skill 或专家演示之后正式介绍企业版和万融的服务（约 3 分钟）；
  3. 收尾落地时留联系人（1 分钟）。
- **方案里**只写一小节“从个人用到全员用”（企业版能解决什么、三种部署方式），不写价格、不写联系人。方案是给主办方审的。
- **课件里**可以有一屏企业版介绍：三种部署方式和万融能提供的服务。联系人放在课后发的资料末尾，不放在课件正文。
- 讲师身份可以自然带出：建委是万融德天数智资深 AI 讲师、万融集团 OPC 社区超级达人，可以说“我们万融这边……”。
- 课上不报价、不讲活动、不催单。被问价格时只说“按席位年费，100 个席位以上有渠道优惠，具体会后商务一对一出报价单”，到此为止。

## 能对外讲的口径（来自万融《渠道价值宣传口径》V1.0，2026-11）

**一句话**：从腾讯买、从别的伙伴买、从万融买，产品、版本、账号、服务等级完全一样；区别在买完之后，万融交付的是这套工具在单位里真正落地跑起来的结果。

**讲的顺序**：先立信任，再讲服务，最后谈价格。

| 价值 | 课上可以这样说 |
|---|---|
| 国企身份 | 万融德天数智是万融集团下属全资国企子公司，不是渠道商；合同、专票、对公、账期都按国企流程走 |
| 现场部署工程师 | 别的服务是电话里指导，万融是工程师到单位现场，和同事坐在一起把系统跑起来。对体制内客户说“前置部署工程师”，少用 FDE 这个缩写，多数领导不熟 |
| 本地专家团队 | 团队就在济南，出问题本地到场；同城同类单位的案例可以约实地交流 |
| 定制 Skill 和智能体 | 把单位的公文格式、汇报模板、审批流程做成定制能力，做完是单位自己的资产；培训是固定课程、固定排期，全年计划提前给 |
| 官方伙伴通道 | 问题万融先接，需要腾讯层面的走官方伙伴便捷通道；腾讯官方活动、新品交流优先带客户参加 |
| 价格 | 按席位年费，100 个席位以上有渠道优惠，课上只说到这里 |
| 采购方式 | 可以代采（万融德天数智开发票），也可以直采（腾讯开发票）（2026-11-19 万融补充） |

**常见追问**（原文有完整应答，这里只留要点）：
- **直接找腾讯买不是更便宜？** 席位定价一致；腾讯不接单家单位的现场实施和业务定制。
- **别的伙伴折扣更低？** 核对三件事是否写进合同：续费价、是否含实施和培训、出问题谁上门。
- **你们会不会跑路？** 全资国企子公司，长期经营是制度安排。
- **就想直接跟腾讯签？** 可以，席位少、需求标准、内部有团队时直购确实省事。这句要照实说，说出来可信度反而上去。

**不能说的**：
- 不贬低腾讯和同行；
- 折扣数字只进报价单和合同，不进课件、公众号等公开物料；
- 不替腾讯承诺；“协助对接”和“包含实施”分开说；
- 不用“最、第一、唯一”这类绝对化用语，不承诺效果。

具体折扣数字和同行对照打法属于万融内部资料，不进本仓库，以万融原文件和当期报价单为准。

## 企业版产品事实（2026-11-19 核对腾讯云官网）

来源：[WorkBuddy 企业版定价页](https://cloud.tencent.com/product/workbuddy-enterprise)。价格和档位会变，每次用之前重新核对。

| | 旗舰版 | 专享版 | 企业私有化版 |
|---|---|---|---|
| 官网价 | 198 元/人/月 | 316 元/人/月 | 按需报价 |
| 起购 | 1 席位 | 100 席位 | 300 席位 |
| 部署 | 注册即用，多租户逻辑隔离 | 云端专属资源池，专属网络（VPC） | 自备算力与模型，企业内网，数据不出域 |
| 适合 | 中小团队快速启动 | 中大型企业、合规可控 | 金融政企、信创环境 |

- **三档都有**：企业 Skill、企业专家、企业智能体、企业模型配置、OpenAPI。
- **旗舰版、专享版**：集中管理成员用量与席位、企业安全与操作审计，并附带智能体办公套件，含腾讯文档、乐享、Ardot、腾讯网盘、安全与效能运营平台。
- **每坐席每月赠送** 2000 Credit。
- **说法边界**：“数据不出域”只能用在私有化版上；“数据会不会被拿去训练”“能不能试用”官网没查到，课上不答，交给商务。
