# 《小树叶》AI 教师音乐微课画面制作复盘

- ID：`little-leaf-ai-microcourse-mv`
- 日期：2026-09-10—2026-09-13
- 主要交付物：16:9 二维扁平儿童插画 / MG 风格的音乐微课分镜、场景图提示词、整段视频提示词、分段音频与交互式制作页面。
- 主领域：教师微课与教育视频设计
- 关联能力：音频分镜、AI场景图、即梦 / Seedance全能参考、多镜头视频生成、后期剪辑
- 记录状态：方案与制作流程已按建委反馈完成多轮修订，当前方向获建委确认；最终完整成片、客户验收与教学效果尚未归档。
- 公开范围：仅记方法和去识别化过程；不上传客户聊天截图、原始音频、角色图片、生成视频和本地路径。

## 任务与限制

任务是根据一首约 68 秒的幼儿歌曲制作音乐微课画面。画面必须与歌词、前奏、间奏和情绪高度一致，保持16:9二维扁平儿童插画与MG动画风格，并由建委在即梦 / Seedance中分段生成。

项目的主要难点不是单张画面是否好看，而是：同一角色能否保持一致；场景能否随剧情变化；每段起止状态能否衔接；树叶离枝、空中漂流、害怕、落地、发芽和重逢等动作能否出现在正确音频位置；没有歌词的音乐段能否承担新的转场作用。

| 段落 | 音频范围 | 本段作用 | 一次生成内部的镜头设计 |
|---|---:|---|---|

## 修订后确认有效的做法

### 1. 角色图复用，场景关键图按剧情新建

主角和树妈妈的角色图可以复用，以保持轮廓、五官和配色。场景图不能固定为少数几张反复使用；地点、机位、情绪、角色位置或季节状态变化时，要生成符合当前段落的新关键图。

### 2. 参考图只承担指定职责

提示词明确写出每张参考图负责角色、风格、场景、首帧或目标状态中的哪一项。剧情没有树妈妈的空中漂流段不上传树妈妈；参考图中不需要的元素不能因“保持一致”被强行带入。

### 3. 先保证关键图状态正确，再进入视频

P03原场景图的构图可用，但树妈妈和主角仍在微笑。最终处理不是在视频提示词中补一句“伤心”，而是先编辑成双方眉毛内侧抬起、视线互相追随、嘴角下弯的离别关键图，再用新图生成视频；视频阶段停用旧微笑版树妈妈参考。

### 4. 一次生成可以包含多个合理镜头

P04不再拆成多个很短的独立任务，而是在约11秒的一次生成内完成远景跟随、寻找方向和表情特写。参考图负责角色或某个画面，不要求整段都停留在参考图的原构图。

### 5. 无歌词段也必须有新叙事作用

P05是纯音乐衔接，因此没有重复前奏或上一段天空画面。最终改为俯视树叶与地面叶影，再匹配切到贴地低机位完成落地，同时为下一段“沙沙”动作准备位置。

### 6. 状态变化要写清起点、过程和终点

P03写明满树秋叶开始、所有叶片成片离枝、结尾完全光秃，避免只吹走主角一片。P08使用固定整棵树的连续生长动画，从完全光秃到芽点、嫩芽、绿叶和丰满树冠；P09直接使用长满绿叶的终态，不重复发芽。

## 主要问题与正确修复

| 发现的问题 | 不能继续采用的处理 | 最终修复 |
|---|---|---|
| 所有段落围绕固定几张图生成，画面僵硬、衔接不自然 | 每段都上传同一组角色和场景图 | 角色资产复用；每个新剧情状态重新设计场景关键图 |
| 把每个动作拆成过短独立片段 | 一句歌词或一个机位对应一次生成 | 将相邻镜头合并为不少于平台有效时长的一次生成，段内用镜头编号切换 |
| P03只吹走一片叶子 | 用“树叶离开”代替数量和终态 | 写清满树开始、所有叶片分批离枝、结尾完全光秃 |
| P03离别时树妈妈仍微笑 | 保留笑脸参考图，只在视频文字中写“伤心” | 先改关键图表情，停用旧微笑参考，并在各镜头保持下弯嘴角和追随视线 |
| P04带入不需要的树妈妈或让叶片提前落地 | 为了连续性保留前一场景所有元素 | 只显示天空与主角，持续漂流，最后推进到害怕特写但不落地 |
| P05纯音乐画面与前奏重复 | 用秋景全景填充没有歌词的时间 | 设计俯视叶影到贴地落下的新视角转场 |
| P08没有完整表现从光秃到长满绿叶 | 分散枝芽特写或直接切到绿树 | 固定同一整棵树和机位，连续表现芽点、舒展、变绿和树冠丰满 |
| P09再次重复长叶过程 | 每句“春天”都安排发芽 | P08完成生长，P09只展示完成状态和重逢收尾 |
| 本地HTML点击音频没有反应 | 直接以`file://`方式交付并假设浏览器兼容 | 使用本地HTTP服务预览，实际测试音频请求、播放状态和复制按钮 |

上表只把失败做法作为禁止项和修复依据；后续执行应直接调用“最终修复”，不能把早期方案与当前方法混用。

## 图片提示词结构

本项目最终采用以下顺序：

1. 说明这是生成新场景还是编辑现有构图。
2. 分别指定每张参考图的职责。
3. 写清必须保持的角色、构图和风格。
4. 写清本段必须变化的角色位置、情绪、数量或季节状态。
5. 用景别、视线、眉眼、嘴角和动作预备描述可见画面。
6. 列出不应出现的角色、状态、文字、水印和变形。
7. 写一条可观察的最高优先级验收条件。

P03的有效表达方式是“树妈妈嘴角必须为清楚的小幅向下弧线，眼神望向离开的主角，不能微笑”，而不是只写“悲伤氛围”。

## 视频提示词结构

最终视频提示词采用：生成规格、参考职责、音频用途、镜头01/02/03、声音和硬约束。每个镜头写清景别、动作、事件和结束状态；歌词时间码另放分镜表。

P04的有效结构是：远景持续飘动—中近景寻找方向—推进到害怕表情特写。P08的有效结构是同一固定机位中的连续生长阶段，不为了形式强行切镜。

通用模板和完整验收表见[AI教师微课画面生成与多镜头制作方法](../../domains/design/video/education/ai-generated-microcourse-video-workflow.md)。

## 实际验收与未验证部分

已检查：

- 9个生成段都不短于5秒，最短5.67秒。
- P03页面只列出纠正后的关键图和主角图，不再把旧微笑树妈妈图作为视频参考。
- 旧P03场景图没有进入新版制作包。
- 交互页面中的P03分段音频可播放，时长7秒。
- P03场景图提示词与视频提示词的复制按钮可以工作。

尚未归档：

- 所有场景关键图的最终生成版本与逐图验收。
