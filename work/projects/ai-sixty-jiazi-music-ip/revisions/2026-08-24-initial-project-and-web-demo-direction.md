# 2026-08-24：项目首次入库与 Web Demo 方向

## 背景

建委提供了项目讨论记录、三套分散网页工具、两份六十甲子表格、六十甲子音乐素材、音乐创作提示词、五行音乐全流程资料和 20 个 WAV 文件，并要求先完整理解项目，再完成产品 Demo 规划与整合开发。

项目名称确认为“AI 六十甲子古音律与 IP 孵化”。本次首次进入 `ai-context`，因此建立独立上下文目录、README、数据审计、产品规划和角色提示词，完整源码后续进入独立代码仓库。

## 本次确认的新口径

- 首版以响应式网页 Demo 为主，而非同时开发 App 和微信小程序。
- 三个旧工具不使用 iframe 拼装，而是重构为统一数据层、历法层、音律层和五个产品模块。
- 第一条体验主线为：日期时间 → 四柱与音律 → 试听 → 甲子档案 → 创作提示词。
- 六十甲子主数据以纵向总表结合校勘版五行表为准，早期 `codexBIAOGE` 只作对照。
- 旧工具中的音程判断和确定性健康、命理文案不可直接继承。
- 先以五个纳音五行代表验证 IP 风格，再扩展到 60 个甲子神。
- 当前商业、学术、资金与合作叙事属于沟通材料中的方向或陈述；未获得正式证明前，不对外写成已落地事实。

## 设计结果

以 Superdesign 建立 `玄金夜谱` 工作台设计方向：深墨黑、宣纸白、古铜金和少量朱砂；主界面把出生时间、四柱声部、十二音律圆盘、试听控制与甲子神档案放在一个连续工作台中。

- 项目画布：<https://superdesign.dev/teams/ea602598-6a14-4540-a451-f03579fb301c/projects/487e08d8-ca54-4287-aea6-bbbcdefe3898>
- v2 设计稿：<https://p.superdesign.dev/draft/0981ff19-0659-4af2-adaa-1bb6a65bc005>
- 历法演示固定样例：`2005-12-23 08:37 → 乙酉 戊子 辛巳 壬辰`。

前端源码在建委确认设计前不开始。ImageGen 概念图调用返回 404；后续需选择使用本机 API Key 的 CLI 方式，或由建委明确跳过 ImageGen、直接以已批准的 Superdesign 设计稿作为视觉规格。

## 影响

- 后续 AI 应先读取本项目 README 和最新修订记录，不得重新把项目缩减为三个工具的页面拼接。
- 任何历法、音律、健康和人物史料发布前，都需要来源与审核状态。
- Web Demo 通过后再依据真实使用数据决定 App Store 或微信小程序路径。
