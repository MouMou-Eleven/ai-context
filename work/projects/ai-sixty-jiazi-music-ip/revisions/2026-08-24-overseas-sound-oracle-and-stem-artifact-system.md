# 海外声音产品定位与甲子神天干法器系统

> 日期：2026-08-24
>
> 性质：产品方向与独立 IP 视觉规则的重要修订
>
> 取代范围：补充海外消费者产品方向；不取代 v4 专家工作台实现记录；不把甲子神 IP 接入网站。

## 一、本次问题

1. 六十甲子古音律网站面向海外时，国外用户是否接受“音乐算命”，产品应该提供什么功能。
2. 当前甲子神头饰已经体现生肖/地支后，天干如何获得统一、可识别的视觉表达。
3. 用户提出“地支做头饰、天干做兵器或法器”，要求判断并生成五张新图对照。

## 二、海外市场判断

### 已确认

- 占星、自我探索、个性化音频和冥想均有海外成熟产品与用户习惯。
- 美国皮尤研究中心 2025 年调查显示，30% 美国成年人至少每年接触一次占星、塔罗或算命，多数人用于娱乐或获得启发，而非依赖它做重大决定。
- 35 国数据说明市场差异很大，不能用一个“国外用户”概括所有国家。
- 英文 Four Pillars/BaZi 产品存在，但从公开商店评价规模看仍明显小于 Co–Star、CHANI 等主流西方占星产品。
- 海外已有 music + astrology 的小型产品，说明概念可被理解，但没有公开证据证明这一组合已形成大众级赛道。

### 不能确认

- 不能承诺产品上线后一定会火。
- 不能仅凭相邻市场规模推断“六十甲子古音律”一定有同等规模。
- 尚无真实海外用户数据证明哪个英文名称、功能组合和付费模式最有效。

## 三、最新产品口径

网站不再只被理解为“算命工具 + 音乐播放器”，而是：

> **一个根据出生时间生成中国五阶段出生节律、个性化古音色声音与每日聆听仪式的 Web 产品。**

英文类别可暂用：

> **Chinese Elemental Astrology × Personalized Sound**

英文消费者钩子优先测试：

> **Discover Your Chinese Birth Rhythm**
>
> **What Does Your Birth Time Sound Like?**

“Music Fortune Telling”保留为广告文案变量，不建议先作为长期品牌，因为它容易形成猎奇、骗局或确定性预测印象。

## 四、首版产品闭环

1. 用户看到可试听样例，30 秒内理解“出生时间会变成声音”。
2. 输入出生日期、当地时间和出生城市/时区；提供“不知道出生时间”路径。
3. 先展示一个可理解的 60 甲子 Archetype 和 Five Phases 图，再逐层解释 Four Pillars、Stems/Branches。
4. 立即播放 60–90 秒 Personal Birth Sound。
5. 用 Why This Sound 解释出生结构如何映射到主音、音色、速度、密度和情绪。
6. 给出三条轻量 reflection / listening intention，不输出凶吉恐吓。
7. 用户可选择保存、删除或分享带声音片段的结果卡。
8. 验证后增加 Daily Elemental Weather 和 3–5 分钟每日声音仪式。

当前“听命、寻甲子、合音、造曲”仍保留为专家/文化实验工作台；海外消费者版建议重组为：Home / My Rhythm / Today / 60 Archetypes / Library。合音后置为 Compatibility Duet，造曲后置为 Creator Studio。

## 五、首发与验证

- 第一阶段：英语 Web，优先测试美国、加拿大、英国、澳大利亚的占星、自我探索、冥想、世界音乐和东方文化兴趣用户。
- 第二阶段：日韩、新加坡本地化；不能用英文版直接机器翻译替代本地研究。
- 先做三个同内容、不同价值主张的落地页，招募 60–100 名英语测试者，完成 12–15 次深访。
- 核心观察：出生信息填写、声音播放与听完、结果理解、分享/保存、第二次回访。
- 在留存未得到证明前，不一次性投入完整原生 App、复杂社交和订阅系统。

## 六、健康与隐私边界

- “疗愈”对外写成 sound ritual、relaxation、reflection 或 listening intention。
- 不宣称诊断、治疗、缓解或预防焦虑、抑郁、失眠、器官疾病等。
- 默认只收集计算所需出生信息；保存必须明确授权；提供删除与导出；日志避免写入完整出生资料。
- 结果使用“may、suggests、invites”而不是确定性命运语言。

## 七、甲子神三层视觉语法

确认用户提出的方向成立，并增加纳音一层以避免天干与角色整体配色冲突：

> **地支定头饰和第一轮廓；天干定法器与能力；纳音定材质、配色和环境；太岁故事定性格与剧情。**

| 天干 | 法器家族 |
|---|---|
| 甲 | 建木杖 / 芽刃 / 青木建仪 |
| 乙 | 藤带 / 曲枝笔 / 花蔓钩 |
| 丙 | 八芒曜轮 / 日轮枪 |
| 丁 | 心灯 / 火针 / 烛印 |
| 戊 | 镇岳方碑 / 山盾 / 方天仪 |
| 己 | 田格印 / 育土钵 / 地环 |
| 庚 | 决断大刃 / 钺 / 开界刀 |
