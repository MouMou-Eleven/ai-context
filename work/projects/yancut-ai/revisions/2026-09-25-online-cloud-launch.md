## 已落地的云端边界

- Better Auth 注册、登录、退出；空库首个注册用户成为管理员，后续用户为普通用户。
- Neon PostgreSQL 迁移至 0007，包含账号、工程、素材、积分、充值码、AI 计划和豆包 ASR 任务。
- Vercel Blob 私有对象存储；上传配额预检、文件归属、签名访问、过期清理和工程/素材隔离。
- 云工程保存时间线与素材引用；浏览器 OPFS 只作缓存，云端数据库和 Blob 是权威来源。
- `/admin` 具备用户管理、运行模型/接口配置、审计和充值码生成/停用；敏感配置加密存储并掩码返回。
- AI 规划和豆包标准版 ASR 均需先报价、确认积分后执行；相同请求幂等，失败退款，余额不靠前端演示数字。
- 平台状态接口在固定域名返回 `cloudEnabled/databaseConfigured/storageConfigured: true`；未登录访问云工程接口返回 401。

## Vercel 部署注意

本地 Git 工作树直接创建 Preview 时，Vercel 因项目的 Git 提交作者未被团队识别而在构建前返回 `TEAM_ACCESS_REQUIRED`。使用不带 `.git` 元数据的干净源码包部署到同一项目后构建成功；这不是代码构建错误。后续本地更新应先在干净源码包上部署 Preview，验收后再提升固定域名，并保留上一生产部署用于回退。

## 用户使用边界

- 首次注册需要从本机私密文件读取建站口令；不要把口令、模型 Key、ASR Key 或加密密钥写入 GitHub。
- 视频预览、解码和当前 MP4 导出仍主要占用用户浏览器和设备性能；云端保存不等于云端渲染。
- 单文件和账号空间受服务端配额限制；大型素材首次打开会下载到浏览器缓存，清理缓存后仍可从云端恢复工程，但未完成上传或未保存的修改不在恢复保证内。
- Vercel 默认域名用于个人在线测试，不能据此承诺中国大陆所有运营商稳定访问；正式商业承载仍待百度秒哒能力核验。
- 未在生产环境代跑真实 GLM/豆包计费请求，避免污染用户余额；真人素材、长视频、上传速度和国内多运营商链路仍需用户继续验收。
