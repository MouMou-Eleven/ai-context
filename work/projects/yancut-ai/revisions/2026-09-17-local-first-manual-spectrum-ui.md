# 2026-09-17：本地优先手册与界面整理

## 已确认

- 言剪 AI 当前本地工作模式使用 IndexedDB 保存工程元数据、OPFS 保存导入文件；清理站点数据或更换浏览器用户配置会失去本地副本，不能把浏览器存储描述成云端备份。
- 新增面向用户的本地优先使用手册，说明首次使用、自动保存、大文件、AI 取样授权、导出边界和故障排查。
- 工作台素材工具改为单行横向标签，AI 快捷指令改为自动换行，侧栏按“创作 / 资源与任务 / 支持”分组，首页增加流程和存储提示。
- Spectrum UI 只按需参考源码和交互模式；MCP 作为开发期目录工具，不引入整套运行时依赖。
- 新增 `domain/capability-orchestrator.ts` 并接入模型计划：根据用户意图选择场景技能，检索有限镜头/动效候选，限制组合数量，并在执行前拒绝越界时间和过量动效；计划回执携带编排信息，便于用户核对 AI 为什么选择这些能力。
