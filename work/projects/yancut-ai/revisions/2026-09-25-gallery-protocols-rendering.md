# 作品发布、首页交互、模型协议与统一成片边界

日期：2026-09-25。接续[模式与组合技能](./2026-09-25-composable-skills-ui.md)，来源为建委本轮八张截图、渲染服务追问及最小闭环澄清。权威源码仍为 `F:\桌面文件\言剪AI`；本轮功能提交 `ef7f877c`。

## 用户目标与边界修正

建委明确需要“导入视频 → 输入指令 → 剪辑和动效包装 → 导出同一条完整 MP4”。不需要独立 Remotion 工作台，不接受让用户单独生成动画、手工导出后再拼接来代替统一流程。开发应优先完成这条最小闭环，再扩展复杂动效。

当前 `apply_packaging`、`compose_overlays` 等动作把已适配配方变成原生文字、图形及关键帧，跟原视频一起由浏览器导出。它们没有实际运行任意 Remotion React 组件，不能据此宣称所有参考仓库的动效已经可调用。Remotion Worker 是准备接入的内部服务：云端部署尚未完成，AI 自动提交、渲染结果回填、透明叠加和时间对齐仍需实现及整链验收，不能把购买主机说成唯一剩余事项。

## 这轮改造

- 导出窗口增加默认不勾选的“同步到广场”。导出成功后上传最终成片；失败保留下载并可重试，不重复编码。用户也可在广场或“我的 → 公开作品”本地上传 MP4/WebM（最大 512 MB），本人撤下；管理员保留审核及审计。
- 首页与广场读取同一份分页数据，以真实视频比例组成瀑布流，点击播放；移除宣传占位卡。公开作品会占云空间，但不连带上传原片和工程。上传权限、文件归属、并发重复提交和撤下后访问均在后端检查。
- 去掉重复的“智能风格”选择器；模式决定任务方向、技能组合能力、比例与时长约束输出，风格由技能和自然语言表达。历史 style 字段兼容保留，新建使用 auto。
- 视频和图片附件增加真实缩略图；输入 @ 引用技能或附件。候选为浮层，输入框、技能栏与附件栏高度固定，出现内容不把后续区域推下去；自定义时长放在对话框中。首页、工具箱、广场和我的页面拓宽并统一左右边线。
- 模型适配覆盖 OpenAI Chat Completions、Responses、Anthropic Messages、Gemini generateContent，GLM 沿用兼容协议。自动判断优先完整端点，其次官方域名，未知中转默认 Chat；特殊中转仍需手动指定。各协议共享计划校验与修复回合；截断、拒绝和未处理的工具调用不作为可执行计划。原生 Gemini 接收内联抽帧图片，不能把任意外链当作已上传文件。
- 客服二维码改为管理员本地选择/拖入 PNG/JPG/WebP，2 MB 上限，服务端解码、重编码，存入独立不可变私有 Blob。公开读取仅允许已配置的受管路径，避免测试与生产共用对象时覆盖原二维码。
- 后台显示渲染配置状态，区分未配置、无效地址、已配置但未实测；队列返回 completed 却没有实际成片地址时改为失败。

## Remotion 服务与费用

新增 `scripts/render-worker`：受限模板、Bearer鉴权、持久队列、单实例串行、签名下载与过期清理。本机 HTTP 调用已真实生成5秒1080×1920 MP4；Docker镜像、公网服务和Worker的远端Blob输出未验收。HyperFrames 独立 HTML Worker 尚未实现，不能填写同一个地址冒充接通。

Zeabur 连接实际返回 `ERROR_INVALID_TOKEN`。尚未购置服务器、未写入虚假地址或令牌。个人短包装测试建议2vCPU/4GB起、串行处理，4vCPU/8GB更有余量；需要HTTPS、持久磁盘及任务运行期间不休眠，不要求独显，具体性能仍须实测。

官方页面当日显示Dev平台套餐US$5/月，服务器另按地区及规格月付，并非5美元包全部资源；支持信用卡及支付宝充值。来源：[定价](https://zeabur.com/pricing)、[购买服务器](https://zeabur.com/docs/zh-CN/server/purchase)、[付款方式](https://zeabur.com/docs/zh-CN/subscription/payment-methods)。连接恢复不等于购买授权。最小闭环可先用已支持的原生动效，不必以买主机作为开始体验的前提。
