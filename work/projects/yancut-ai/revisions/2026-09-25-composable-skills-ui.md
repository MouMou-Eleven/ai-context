# 模式、组合技能与首页交互升级

日期：2026-09-25。来源：建委本轮七张截图、明确交互要求，以及源码和浏览器实测。本轮接续[统一入口与本机原片](./2026-09-25-unified-local-media-workspace.md)，不恢复云端上传全部原片，也不新建第二套工作台。

## 新旧差异

此前工具入口主要提供单条场景提示。现在首页、工具箱和模型规划器共用 `rust/resources/creation-skills.json`：11 个可选技能映射到现有执行合同，模式为智能编排、视频精剪、画面包装。每次最多选择 4 个技能，内部检索最多提供 6 个配方，避免整库塞进上下文。

选择技能会追加可编辑提示词与标签，保留原有文字和附件。工具箱“添加到对话”返回首页使用同一份草稿；支持搜索、分类、技能多选和 `@` 技能/附件。取消标签只移除未改写的建议，用户自行改写的文字保留。模式与技能 ID 随云端工程保存并传入实际模型请求，后续明确修改需求可以调整编排，初始模式不永久锁死工程。

组合“剪口播＋白板讲解”可安排原片与多段白板交替。结构剪切和白板包装分轮执行，避免旧时间点失效；本轮增加多段白板的越界、重叠和保留底层素材校验。修复否定配音仍占能力名额、默认提示条件句误触发口播、局部修改标题误判整个场景变化，以及深链同时提供技能和具体要求时丢失具体要求的问题。

首页与工具箱重做标题、正文、卡片层级和间距；我的空间、广场、帮助统一字阶。正文主要为 15–16px，大屏首页标题 60px，手机约 34px。字号作用域限制于线上页面，不整体放大密集时间线。修复手机技能弹层顶部裁切，提供可见关闭按钮、可用高度限制和可滚动列表。

登录注册保留左右布局，大屏卡片扩大并在主体中垂直居中；手机单列。注册按钮旁直接说明提交即同意使用条款、用户协议及隐私政策，不增加复选框；协议可在新标签打开。服务端要求当前协议版本 `2026-09-25` 并记录注册同意提交事件；这不表示用户授权任意扣费，模型与识别仍需单独报价确认。

- 本地真实模型首次请求超时；线上 Preview 重试成功，确认扣除测试账号 2 积分，生成 2–6 秒和 8–12 秒的两段白板，确认执行成功。新增中文超时/中断/网络提示，不向用户返回原始供应商错误。
- 浏览器下载实际 MP4，ffprobe：12.000 秒、H.264、480×270、24fps、418573 字节。抽查 1 秒原片、4.5 秒第一段白板、7 秒恢复原片、10.5 秒第二段白板，均与计划一致。此素材是无声合成短片，不是实际真人口播或 ASR 准确率验收。

## 边界

没有把截图里的批量切片、并发、视频生成等未实现能力包装成可用技能。白板是原生可编辑图文与逐项动画，不是逐笔手绘；测试没有证明真人长视频自动语义对齐、ASR 准确率或大工程性能。此前 Hypit、Shotcraft、Talkcraft、Spectrum UI 等参考的吸收与边界仍按前次修订执行，本轮重点是统一已有入口和调用合同，不声称新增执行了这些项目全部能力。Vercel 国内直连问题没有在本轮解决，浏览器线上验收使用本机已有代理。
