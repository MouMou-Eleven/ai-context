# 合音 v6 UI 审查与交互修订

> 日期：2026-09-02  
> 范围：Web Demo 合音页；甲子神潮玩 IP 仍为独立工作线，不接入网站。

## 触发问题

建委提供的桌面截图显示：合音页工作台在宽屏上显得稀疏，左右声音信息缺少明确层级；下拉选择和“试听应答”点击后缺少可见反馈，用户容易判断为按钮失效；文化关系预设密度高、选中态不明显。

## 已确认的新方案

- 工作台固定为“左侧起势卡 → 中央声音关系桥 → 右侧应答卡”的三栏结构。
- 每张声音卡同时展示五行、五音、公开配器质感、语义短句、试听按钮和进度提示。
- 文化预设使用选中态与“当前组合”标签；增加“恢复默认”和当前组合的起势/应答试听操作。
- 试听按钮在调用音频前立即切换为播放态，音频加载失败再回写错误状态，避免浏览器等待音频时呈现无响应。
- 中央装饰圆环的伪元素设置 `pointer-events: none`，不再覆盖声音卡的可交互层。
- 所有公开页面继续只显示五行、五音与乐器质感语义；不显示音级、半音、频率或内部映射。

## 浏览器交互证据

1. 下拉选择“火”后，起势卡更新为“徵音 / 高胡与点状打击质感”，关系更新为“火 → 土”。
2. 点击起势试听，状态立即变为“正在试听火行 · 徵音”，按钮切换为暂停态。
3. 点击“甲己合”预设，状态显示“已载入甲己合，可点击上方试听按钮”，预设获得选中态与 `aria-pressed`。
4. 点击“试听当前应答”，状态变为“正在试听土行 · 宫音”。
5. 点击“恢复默认”，停止当前声音，清除播放态并恢复“木 → 土”。
6. 桌面与移动端控制台均为 0 error、0 warning；移动端 `scrollWidth = clientWidth = 390px`。
