- 只有确认无法归入设计或 AI 时才进入本目录。
- 商业化入口只保存可执行的商业规范、内容经营方法、经验和注意事项；建委本人的商业判断仍属于 [`../../brain/cognition/business-cognition.md`](../../brain/cognition/business-cognition.md)。

- 领域或项目增加后，必须更新本索引。
- “AI 六十甲子古音律与 IP 孵化”的唯一上下文位置是 `work/other/ai-sixty-jiazi-music-ip/`；即使后续开发网站、App、AI 音乐或 AI 综艺，也不得在 `work/ai/programming/projects/` 重新建立同名项目。
