## 写入规则

- 只有确认无法归入设计或 AI 时才进入本目录。
- 商业化入口只保存可执行的商业规范、经验和注意事项；建委本人的商业判断仍属于 `brain/business-cognition.md`。
- 不建立“其他经验”杂物堆；每个独立领域或项目必须有 README。
- 领域或项目增加后，必须更新本索引。
