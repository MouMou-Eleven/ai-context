# 设计共用方法

平面、视频、教育作品都成立的方法。只在某一类里成立的，放到那一类的目录。

| 方法 | 解决什么 |
|---|---|
| [设计原则与审美](./design-principles/README.md) | 所有设计共用的审美底座：信息层级、构成、骨架、构图、留白、字体、配色、气质，以及把“好看”翻成具体做法的审美词库（光影、空间、材质） |
| [制作流程](./production-workflow.md) | 六个环节：判断交付物 → 事实与素材 → 拆内容 → 定分工 → 小样 → 验收 |
| [AI 生成原则](./ai-generation-principles.md) | 精确信息交给后期、参考图一图一职责、提示词≠成品 |
| [多轮反馈怎么改](./feedback-iteration.md) | 意见翻译成可见问题、每轮改一类、改坏就退回、只改授权范围 |
| [代码式视频设计经验](./code-driven-video/README.md) | AI 自己动手剪辑、包装、加效果、出成片时（实际都用代码完成，用户不必提）的字号、间距、对齐、容器、出场节奏、录屏讲解和逐帧验收；排版和审美判断用设计原则 |

视频专属的方法（Seedance 提示词、AE）在[视频共用](../video/common/README.md)。写进这里的规则，必须在平面、视频、教育至少两类里被验证过。
