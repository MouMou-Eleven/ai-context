# 设计制作流程

海报、PPT、宣传片、微课、故事片都适用的制作顺序。具体片型怎么做，进对应目录：[平面与演示](../graphic/README.md)、[视频](../video/README.md)。

> 来源：企业宣传片、创赛片、教师微课、精品课 PPT 等实际商单，2026-05～09。

## 六个环节

| 环节 | 要做什么 | 读什么 |
|---|---|---|
| 1. 判断交付物 | 先弄清客户要的到底是什么：提示词、风格参考、AE 工程文件，还是成片。这几种差别很大，做错了整个方向就错 | 本页"交付物判断" |
| 2. 事实与素材 | 从客户资料里提取对象、用途、时长、比例、格式、品牌要求、素材、验收标准；只问影响执行的缺口 | 客户资料、项目 README |
| 3. 拆内容、分镜 | 把内容拆成信息点、页面或镜头编号、时长、画面动作、字幕或口播，并标明每一块用什么做 | 片型方法：[宣传片](../video/promo/workflow.md)、[微课](../video/education/README.md)、[故事片](../video/story/README.md)、[PPT](../graphic/ppt/README.md) |
| 4. 定分工 | 每一块标清：客户实拍或原有资料、手工设计、AI 生成、AE 模板、后期合成 | [AI 生成原则](./ai-generation-principles.md) |
| 5. 先做小样 | 用成本最低的一两个关键镜头或页面先验证风格、角色、动作，建委或客户认可后再批量做 | [多轮反馈怎么改](./feedback-iteration.md) |
| 6. 交付与验收 | 看实际导出的成品：内容对不对、文字清不清楚、节奏、规格、可编辑源文件 | 片型方法里的验收项 |

## 交付物判断（红线）

动手前先确认客户要的是哪一种，拿不准就问：

| 客户说 | 可能要的是 | 交付什么 |
|---|---|---|
| "帮我写一下提示词" | AI 生成用的提示词 | 可复制的提示词 + 参考图对应关系 |
| "给我个风格参考" | 视觉方向 | 风格图、配色、字体，不是成片 |
| "AE 工程" | 可修改的源文件 | .aep 工程 + 素材 + 字体说明 |
| "做个视频""出片" | 成片 | 导出的视频文件 |

反例：创赛片项目里，客户要的是提示词，AI 却直接用代码渲染了一段照片动画交上去，白做了。（来源：2026-09-21 创赛片复盘）

## 写入

一次商单做完，按这个顺序沉淀：

- 这一单的事实（客户、输入、过程、失败、结果）写成案例文件（文件名以 `case-` 开头），直接放在它证明的那个方法所在的目录里，不另建案例文件夹。
- 能用到别的项目的做法，改对应片型方法的原文。
- 只有在平面、视频、教育都成立的做法，才写进 `design/common/`。
- 写入规则见[仓库写入规范](../../../../system/repository/ingestion-workflow.md)。
