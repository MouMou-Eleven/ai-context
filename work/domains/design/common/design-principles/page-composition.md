# 构图：图和字怎么摆

图片最容易抓住视线，所以图片的位置和大小基本决定了构图。先数这一版有几张图，再选构图。

## 只有一张图时（默认）

图通常放大处理。七种常用构图：

| 构图 | 怎么摆 | 什么时候用，注意什么 |
|---|---|---|
| 上下 | 图在上文在下，或反过来 | 最简单、最稳。文字面积可以和图一样大，也可以分主次；文字区小一些更好排 |
| 左右 | 图和文各占一边 | 竖版里文字被挤进又窄又高的区域，难排，常要竖排文字；横版更合适 |
| 上中下 | 分三段，图居中或占两段 | 第三段可以是另一块文字，也可以是留白；留白通常放在文字组和图片之间 |
| 左中右 | 横向分三段 | 竖版少用，对编排要求高；多用在横向更宽的版面，比如横版 PPT、展板 |
| 半包围 | 图放在版面一角，文字在剩下的两侧围着它 | 版面更有个性、有趣 |
| 全包围 | 图居中，文字围在四周 | 留白也是元素，四周不必填满 |
| 满版 | 图铺满整个版面，文字压在图上 | 文字位置由图的内容决定：图里有主体，文字必须避开主体，放在图的“留白”处 |

选择的依据：

- 版面比例：竖版优先上下、上中下、满版；横版（PPT、展板、横幅）优先左右、左中右。
- 图的质量：图够好、主体明确，用满版或大比例；图一般，缩小并靠留白撑气质。
- 文字多少：文字多用上下或左右分区；文字少可以满版或全包围。

## 有多张图时（默认）

先分主次：一张主图加几张辅图，不要几张图一样大地平铺，除非它们本来就是并列关系。

| 构图 | 怎么摆 | 适合 |
|---|---|---|
| 上中下 | 图和文交替成三段 | 步骤、前后变化、几组并列内容 |
| 对角线 | 两张或几张图沿对角方向摆，文字在另一条对角 | 版面有动感，又能保持平衡 |
| 错位 | 图片上下或左右错开，不在一条线上 | 打破呆板，适合时尚、活动类 |
| 模块 | 用网格把版面分成若干格，每格放一张图或一段字 | 图多、信息多：产品合集、作品集、团队介绍 |

并列的图：裁成同样的比例和大小，等距排列，视角和色调尽量统一。要突出其中一张，就只放大这一张。

## 排法按素材定，元素变了就整页重排（默认）

- **排法不止上下、左右两种。** 图多图少、有没有主图、字多字少，排法都不一样（主图加小图、网格、错落、环绕、分栏……），按这一版素材的数量和形状去想，不套固定的几种，也不一上来就沿用旧版或模板样例的方向。每版至少排两种并排比过再定，两种是下限不是全部；选块面更整、两边更不空的那版，交付时说一句为什么。例：同样几张图加几行字，可以上图下字，也可以左图右字；字组和旁边的图组对齐，可以两端对齐（第一行顶边对齐图组顶边、最后一行底边对齐图组底边，中间等分），也可以整组居中（上下边距一样）。建委原话：“不只是上下排版或者左右排版这两种……具体还是得根据素材来确定……不要写的那么死板”“排版上你一定要灵活一些”。
- **元素的数量或种类变了，整页重新划分版面，不在旧版面上缩小再塞。** 3 张图和 4 张图、有没有文件、有没有指标，排版逻辑都不一样。加了素材，先按新的全部元素重新划区（标题区、主图区、辅助区、指标区各占多少），再动手；不要保留旧版、整体缩小、再在空出来的一边加几张图。
- **容器的形状跟着空间改，不只缩放。** 一张方形卡放在图表旁边会剩一块不规则的空；改成横跨图表上方的长条（左标签、分隔线、右大数字），空白被填满，也和下面的图同宽。

例（视频画面，驰热固芯创赛片）：1.5 电池页沿用“上 4 图、下 3 标签”，左右大片空，建委说“很死板”，改成左 2×2 图、右侧 3 个标签竖排两端对齐才铺开；3.2 温度页把旧柱状图缩小、左边硬塞 4 张照片，建委说“跟乱放一样”，重新分成左 2×2 照片、右侧对比面板才稳；良品率页方形数据卡偏右上、左侧空，建委说“极其的不协调……把它做成一个长方形”。

为什么：排法是从这一版的素材里长出来的；套旧版或固定几种，素材一变就会空一块、挤一块。

## 多图展示页：排满版心，不让一块区域突然空着（默认）

适用：作品集、案例展示、自我介绍、产品合集这类“一版放几张图或几段视频”的页面。主角是作品，但页面一空，第一眼看到的是“没排完”。

1. **整套先定一个版心，每页都排到同一条底线。** 图、图注、说明块一起排到版心下沿，不是排完图就结束。
2. **图的大小由版心反推，不先定图再看剩多少。** 两张图并排时，图下用“编号＋名称＋两行说明＋一排标签”接住下半区；四张用 2×2，行高按版心高度算。
3. **多图网格不要居中悬在中间。** 网格靠版心一侧对齐，剩下的一栏放一块说明栏（这一类讲什么、代表作品或成绩、几个标签），两块同高、同上下沿。居中的网格两边各空一条，看着像没排完。
4. **大小图混排时边缘和图注都要对上。** 一大两小：大图高度＝两张小图高度＋中间那段图注高度，大图底边和下面那张小图底边在同一条线，几段图注在同一水平线。
5. **并列的短信息别只排成一列字。** 身份、合作单位这类并列短信息，做成等大的小卡片或标签，和旁边区块底边对齐；一列字下面留一大块空，就显得简单。
6. **深色底给一点变化。** 整套纯黑容易闷，可以铺一道压暗的主色大弧形或渐变（不抢内容）。

正反例：建委的自我介绍 PPT，第二版视频 2×2 居中、两图页图下只有一行字，建委说“下面全是黑的，某一块区域突然空出来很大一块，看起来很奇怪”；第三版改成网格靠左＋右侧说明栏、两图页加编号说明块，评价“干净、直观、信息都能凸显”。具体版式见[自我介绍 PPT 案例](../../graphic/ppt/ai-assisted-design/case-self-intro-share-deck.md)。

## 按内容关系选版式（默认）

先看这一版的内容是什么关系，再从下表挑第一个尝试的版式：

| 内容关系 | 先尝试的版式 | 不合适时怎样改 |
|---|---|---|
| 一句核心话（问题、主张、诗句） | 中心主文＋边缘氛围；必要说明另成小组 | 长句改两行，不把全部字挤成细小一行 |
| 两组图或两个方案比较 | 两栏等宽，同级标题同位置、图像同尺度 | 不用一边大一边小暗示材料没支持的优劣 |
| 顺序、过程 | 横向或纵向步骤，方向与阅读一致 | 步骤多到看不清时分阶段，不把箭头缩成装饰 |
| 多项同类内容 | 网格卡片，列对齐、同行净空一致 | 数量和格子不匹配时换行列，不留无意义空卡 |
| 操作或讨论任务 | 问题、要求、作答空间分区 | 不让边框和插画侵占实际作答区 |
| 真实图表、数据 | 图表占主区，结论与单位紧邻 | 数据过密时拆指标或放附录，不生成虚构图形 |

## 平衡和重心（默认）

- **怎么判断**：每个元素都有“分量”，由面积和深浅决定。面积越大、颜色越深、笔画越粗越密，分量越重；大面积的浅色可以和小面积的深色互相平衡。检查时把版面转成灰度，看深色块是否都压在一边；重心一般放在水平方向的中间。
- 主体不一定居中，但整体重量要平衡：一侧放了大图，另一侧用标题、色块或足够的留白呼应。
- 留白的位置也参与平衡。版面的一头信息明显过少，会显得往一边倒，文字全堆在上方、下方空着就头重脚轻：把一部分文字挪到空的那一侧。例：标题和说明全挤在上方，下方只有图，就把副题和说明移到底部。
- 四个角是稳定版面的位置：把次要信息压在四角或底边，中间留给主体。
- **上下按空白相当来定高度。** 下方有必须空着的区域（字幕区、页脚、底部色带）时，内容放多高按上下平衡定：内容上方的空白和内容下沿到保留区的空白看起来相当，不把“底边压到某个位置”当目标去凑。内容挤在上半部、下方大片空着，就把整组下移并放大。例（视频画面，驰热固芯创赛片第 1 幕）：为了让标签框贴近字幕区把整组下推，图片上方空出约 260 像素，建委说“上面其实还有大量的空白空间”，整组上移后才均衡；精尺匠造时间轴内容挤在上半部，整组放大约 16% 并下移后铺开。

## 视线怎么走（默认）

横排版面，视线从左上到右下走“Z”字；竖排文字从上到下、从右到左。

- 把最重要的放在起点或版面的视觉中心（比几何中心略偏上），把行动信息（电话、二维码、结论）放在终点。
- 用大小、方向性的图形、人物的视线来引导，不让视线在版面里来回跳。读的人不该一边读一边想“下面该看哪”。
- 把文字想成河水，图片是河里的石头：图片放在文字流经的路上，阅读就被打断；放在两侧或段落之间，水才流得顺。

## 一套作品里的构图（默认）

一份 PPT、一本画册、一组海报，统一的是版心、字体、颜色和间距，**不是每页同一种构图**。按内容换构图：封面和章节页可以满版或居中，内容页按图文多少在上下、左右、模块之间切换。同类内容重复同一种版式能帮读者认出“这是同一类”，但连续好几页都是左文右图、全套都是同样的背景加文字，会让人疲劳，也看不出内容的差别。

## 怎么检查

- 把图和文字块各涂成一个色块，看色块的摆法是否属于上面某一种构图，而不是随手放的。
- 满版图上的文字有没有压到主体。
- 遮住版面的一半，另一半是否明显更重；转成灰度看深色块是否压在一边。
- 多图页的图、图注、说明块是否都排到了版心底线，有没有一块区域突然空着。
