# 图片与图表

## 选图（默认）

- 图片是版面里最抓视线的元素，一张好图顶得上很多装饰。先把图选对，再谈排版。
- 主体明确、背景干净的图最好用：有地方放字，也方便裁切。
- 一组图的视角、光线、色调要接近；差别大就统一调色，或裁成同样的比例。
- 要高级感时的四种选图方向：仰视角度、不常见的特殊角度、画面里只有主体清晰、用光影聚焦主体（见[情感与氛围](mood.md)）。

## 裁切和大小（默认）

- 图片等比缩放，不拉伸变形。框的比例不合适，就裁图或换框，不硬拉。
- 裁切是为了突出主体：裁掉无关的背景，让主体更大；人物不要裁在关节处。
- 并列的图裁成同样的比例和大小。
- 图片的大小差别（跳跃率）决定版面的活泼程度：一张特别大、其余很小，版面有冲击力；都差不多大，版面平稳。

- 图片的外形也有气质：方图稳定、规矩；沿轮廓抠出来的图活泼；裁成圆形柔和，裁成多边形硬朗；沿物体外围粗略留一圈边裁下来，显得粗犷、有手工感。
- 矩形的长宽比有两个常用基准：约 1:1.618（黄金比例）和 1:1.414（A4 这类纸张的比例）。比黄金比例更接近方形显得稳定，更细长显得新鲜。这是参考，不是规定。

## 多张图怎么组织（默认）

- 先分类再摆：按内容类别归组，或按色调归组（明亮的放一起，深暗的放一起）。归了组，图再多也有秩序。
- 同比例、同大小的图整齐排列，图与图之间留一致的间隔，旁边留一块空白缓解拥挤。
- 图片比例不一时，把大小相近的图放在对角的位置互相呼应，版面仍然平衡。
- 把形状相近的图叠在一起，表示它们是一组、有关联。
- 用大小分主次：主图放大，其余缩小围着它。

## 人物图的朝向（默认）

- 人物视线或动作朝向的那一侧，要留出空间；把人贴着他面朝的那条边放，画面会显得憋闷。
- 文字放在人物视线看过去的方向，读的人会顺着看过去。
- 两个人物相向摆放，像在对话；背向摆放，显得对立。跨页时人物朝向内侧，版面更聚拢。

## 图和文字的关系（默认）

- 文字压在图上时，放在图的留白处，不遮主体；文字的形状配合留白的形状。见[留白 · 在图片上放文字](whitespace.md#在图片上放文字默认)。
- 图太花、压不住字：在图上盖一层半透明的深色或浅色蒙版，或者把图调暗、虚化，再放文字。
- 图片和它的说明文字靠近，和无关的内容拉开。
- 图和字可以叠压在一起做主体（字压图、图压字），比各放各的更有整体感，但被压住的部分仍要认得出来。
- 抠出来的图（去掉背景）比方图更灵活，可以破出版心、和文字穿插，适合做主视觉。

## 什么时候用图表（默认）

遇到大量信息或数据，先考虑能不能画出来。图表的好处：简化信息、传达快、吸引注意、突出重点、对比直观。

| 内容 | 用什么 |
|---|---|
| 数量比较 | 柱状图、条形图 |
| 随时间变化 | 折线图 |
| 占比 | 饼图、环形图（项目不超过五六个） |
| 步骤、流程 | 流程图、时间轴 |
| 关系、结构 | 结构图、对比表 |
| 单个关键数字 | 把数字放大，旁边配一句说明 |

## 图表怎么做好看（默认）

- 一张图表只说一个结论，把结论写成图表标题。
- 要强调的那根柱子、那条线单独用点缀色，其余用灰色或主色的浅色。
- 条形图按大小排序；去掉多余的网格线、边框、阴影和立体效果。
- 图表里的字体、字号、颜色和整个版面一致。
- 数据、单位、来源必须准确，用真实数据做成可编辑的图表，不让 AI 凭空画一张图表。
- 表格去掉默认底纹和竖线，只留必要的横线；要强调的行列用线的粗细或一处底色区分。

## 怎么检查

- 图有没有变形、模糊、带水印。
- 图上的字是否清晰，主体有没有被挡。
- 图表去掉标题后，结论是否仍然一眼能看出来。
