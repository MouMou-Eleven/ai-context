# 审美词库：把“好看”翻译成能执行的设计决定

用户说“做好看点”“高级一点”“要有设计感”，AI 往往不知道具体指什么，于是要么套一个自己熟悉的风格，要么到处加装饰。好看不是一种风格，而是一组判断都做对了。本页把抽象的感觉拆成设计师之间沟通用的专业词，每个词对应画面上能做、能检查的动作。

所有设计都用这一套：PPT、海报、书、视频画面和动画、网页和 App 界面、Word 版式和流程图、AI 生图和生视频的提示词。

## “好看”由四层组成（默认）

按顺序看，前一层不成立，后一层再漂亮也不算好看：

1. **信息传达不受阻**：一眼看到主角，层级清楚，字读得清。见[信息层级](information-hierarchy.md)、[配色 · 先保证辨识度](color.md#先保证辨识度默认)。
2. **气质对得上内容**：给幼儿园的要温暖，给工厂的要冷静理性。见[情感与氛围](mood.md)。
3. **有秩序**：对齐、重复、统一间距；变化只出现在要强调的那一处。见[构成法则](composition.md)、[版面骨架](layout-skeleton.md)、[留白](whitespace.md)。
4. **细节没有破绽**：没有差一点没对上的边、被裁的字、压住文字的元素、发脏的颜色。

人说“有设计感”，多半是第 3 层做足了、再加一处有意的打破；说“高级”，多半是第 2 层里的克制。

## 接到“做好看点”时怎么做（默认）

1. **从内容和读者推气质，不从自己的喜好推。** 先回答三件事：给谁看、在哪看、希望看完有什么感觉。
2. **从情绪类词汇里选 1 个主词，最多再配 2 个辅词。** 主词决定方向，辅词只微调。例：小学语文阅读智能体的演示视频，主词“温暖”，辅词“信任”“轻松”。
3. **按主词，在空间、构图、版式、字体、色彩、光影、材质七类里各挑手段，写成一句设计简报。**
   - 例（温暖＋信任，1080p 演示视频）：“大留白、左对齐两栏、圆润黑体、米白底加琥珀色点缀、柔光不用硬阴影、淡纸张纹理；字号三档全片统一。”
   - 例（科技感＋冷静，工厂实拍包装）：“深色半透明面板压暗背景、细线框和角标、等宽数字、冷蓝单色相加一个强调色、只给当前目标发光。”
4. **先把这句简报告诉用户，再动手。** 用户给了参考图，就先说清从参考里借哪几个词、不借哪几个。
5. **做完对照[交付前检查表](README.md#交付前检查表)，再对照简报自问**：每一类手段是不是都朝主词用力，有没有哪一处在拆台（例：要冷静，却用了高饱和撞色）。
6. **用户说“不好看”时，先用本页的词把意见翻译成是哪一类出了问题**，再按[多轮反馈怎么改](../feedback-iteration.md)一次改一类：
   - “太乱”：通常是秩序问题，先查对齐和间距。
   - “不高级”：通常是太满、颜色太纯、字体太多。
   - “没冲击力”：通常是主角不够大、对比不够强。
   - “太闷”“太素”：通常是背景太暗或太灰、没有一处亮点、留白没有形状。

## 防止生搬硬套（红线）

- **词是用来选的，不是用来堆的。** 一个作品只有一个主气质，七类手段都朝同一个方向，不在每一类里各挑最炫的。
- **同一个词，在不同内容里长得不一样。** “科技感”放在儿童教育里，是干净的几何线条和明快的蓝；放在工业包装里，是深色面板和细线发光。照内容去找对应的东西取形取色（见[配色 · 颜色的气质](color.md#颜色的气质可灵活)）。
- **不把上一单的外观当默认。** 建委认可某个作品，认可的是它的判断：主角够大、留白有依据、颜色有主次，不是那套颜色和卡片样式。下一单重新走上面六步。
- **客户有品牌规范、指定模板、明确参考时，以客户为准。** 词库只用来把客户的要求说清楚、做到位。

## 八类词汇（默认）

已经在别的专题写透的，这里只给一句话和链接；光影、空间、材质三类在本页写全。

### 版式与构图

| 词 | 画面上怎么做 | 详见 |
|---|---|---|
| 居中、中轴 | 主体落在中轴、左右对称：稳定、正式、聚焦；长段正文不居中 | [构图](page-composition.md)、[字体](typography.md) |
| 左对齐、右对齐 | 左对齐读起来最顺，用于大段文字；右对齐只给数字列、短文案 | [构成法则 · 对齐的细节](composition.md#对齐的细节默认) |
| 两栏式、网格 | 先画格子再放内容：多图、多卡片、录屏加说明栏 | [版面骨架](layout-skeleton.md) |
| 对齐轴线 | 多个元素共用看不见的线，每个元素都说得出和谁对齐 | [版面骨架](layout-skeleton.md) |
| 阵列、重复 | 同类元素同样式、等距排列，形成统一和节奏 | [构成法则](composition.md) |
| 渐变 | 大小、明暗、颜色逐步变化，表现过程和纵深 | [构成法则](composition.md) |
| 对比、聚焦 | 大小、明暗、粗细、疏密拉开，只给要强调的一处 | [构成法则 · 无对比不设计](composition.md#无对比不设计默认) |
| 层次、虚实 | 前后遮挡、清晰与虚化、实体与留白的对比，制造呼吸和张力 | 本页“空间” |
| 构成 | 把内容看成点、线、面再组合，检查整体结构 | [构成法则 · 用点线面看版面](composition.md#用点线面看版面默认) |
| 动态版式 | 倾斜、错位、出血、打破网格：年轻、活动、创意。先有网格再打破，要读的正文仍然正排 | [构成法则 · 稳定和动感](composition.md#稳定和动感可灵活) |

### 字体

字重、字距、行距、对齐、层级、对比、风格（无衬线、衬线、手写、艺术字）、可读性、中英搭配、情绪表达，都在[字体与文字](typography.md)。一句话：字体一到两款，先定正文字号再推其他层级，同层统一，字的气质和内容一致。

### 色彩

色相、明度、饱和度、冷暖、对比色、邻近色、同类色、色彩比例、色彩情绪、品牌色，都在[配色](color.md)。一句话：先保证文字和背景的明度差，再定主色、辅助色、点缀色，面积依次减小。

### 光影

光决定氛围、质感和视线的落点。平面和 PPT 里，光体现在选什么样的图、渐变和投影；视频、3D 和 AI 生成的画面里，是真实的打光；界面里，是阴影层级和发光状态。

| 词 | 给人的感觉 | 怎么做 |
|---|---|---|
| 自然光 | 真实、有生命力 | 选晴天、窗光下的实拍；生图写“午后窗光”“自然日光” |
| 柔光 | 柔和、舒适、有温度 | 大范围柔和渐变；投影模糊大、不透明度低；生图写“柔光、漫射光” |
| 硬光 | 强烈、明确、有力量 | 边缘清楚的投影、高反差；适合运动、工业、促销 |
| 逆光 | 轮廓鲜明、梦幻 | 主体边缘一圈亮边，背景偏暗；人物剪影、片头主视觉 |
| 侧光 | 突出体积和质感 | 产品、建筑、雕塑，强调表面纹理 |
| 顶光 | 戏剧感、聚焦主体 | 舞台聚光：主体亮，四周压暗；揭晓时刻、片头 |
| 光斑 | 细节、情绪、自然感 | 前景虚化的小光点，少量点缀，不压主体 |
| 阴影 | 层次、空间感 | 界面里用阴影表示前后层级，越靠上的阴影越大越淡；平面里给主体一个落地的影子 |
| 光晕 | 氛围、浪漫、治愈 | 主角背后一圈柔光；代码视频里的发光效果 |
| 光影对比 | 突出重点和情绪 | 亮处放主角，暗处收配角 |

光影的规则：

- **光先回答“看哪里”。** 画面里最亮、对比最强的地方，就是视线第一落点，必须是主角。别处比主角亮，视线就被抢走。
- **一个画面一个主光方向。** 投影、高光、渐变的方向一致。反例：卡片阴影朝右下，图标阴影朝左下。
- **发光是最贵的手段，只给主角。** 一屏最多一处；视频里的具体分寸见[动效与验收 · 特效的分寸](../code-driven-video/motion-and-verification.md#特效的分寸默认)。发光不能把图片和文字冲白。
- **写生图、生视频提示词时写清光的方向、软硬、色温**，不只写“光影好看”。例：“左后方暖色逆光，主体轮廓有亮边，背景压暗，柔和投影。”

### 空间

空间是视觉的骨架，负责引导视线、建立层次、营造氛围。

| 词 | 怎么做 |
|---|---|
| 留白 | 有意空出的、有呼吸感的空间，让信息聚焦。见[留白](whitespace.md) |
| 层次 | 前景、中景、背景分开：平面靠遮挡、大小、虚实；视频靠视差（前景移得快、背景移得慢）；界面靠阴影和模糊（弹窗在最上层） |
| 纵深 | 让视线往远处延伸：道路、走廊、透视线、越远越暗的背景；场景镜头、片头常用 |
| 透视 | 近大远小，造出真实空间；要被读的文字不放在大角度透视里，读不清 |
| 比例 | 元素和画面、元素之间的大小关系；放一个人或熟悉的物体当参照，尺度就清楚了 |
| 引导 | 用路径、线条、光、人物视线、箭头把眼睛带到主角；人物看向哪边，哪边就多留空间 |
| 包围 | 四周围合、中间是主角：安全感、沉浸感。见[构图](page-composition.md) |
| 开放 | 元素少、边界通透、背景一直延伸到画外：自由、轻盈。见[留白 · 留白要能延伸](whitespace.md#留白要能延伸默认) |
| 节奏 | 疏密交替：密一组、空一段；视频里镜头的快慢交替 |
| 虚实 | 主体清楚、背景虚化，或实体与空白对比，制造张力 |

空间的规则：

- **空间先服务阅读。** 做层次是为了让主角跳出来，不是为了炫景深；要读的文字所在的那一层永远最清楚。
- **视频里空间是动的。** 推镜时贴在场景上的元素跟着缩放，屏幕上的界面元素不动（见[动效与验收 · 跟着画面走](../code-driven-video/motion-and-verification.md#跟着画面走默认)）。

### 材质

不同材质自带不同的气质，是质感和调性的重要来源。

| 材质 | 给人的感觉 | 在设计里的常见做法 |
|---|---|---|
| 金属 | 坚固、精致、现代、科技 | 拉丝渐变、冷色高光、细亮边 |
| 玻璃 | 通透、纯净、轻盈、高级 | 半透明面板，背后模糊，加一条细亮边 |
| 塑料 | 轻便、亲和、实用 | 纯色圆角块、柔和高光 |
| 木材 | 自然、温暖、质朴 | 浅木纹做底或做局部 |
| 石材 | 厚重、稳定、有品质 | 大理石、水泥纹理，哑光 |
| 皮革 | 细腻、高级、经典 | 深色哑光加细缝线 |
| 织物 | 柔和、舒适、有生活感 | 布纹、毛毡纹理，暖色 |
| 纸张 | 文化、书卷、亲切 | 米白底、淡纸纹、手写或印章点缀 |
| 混合材质 | 对比、层次、创新 | 一种主材质加一种对比材质（例：石材底配金属字） |
| 特殊材质 | 独特纹理、强记忆点 | 品牌专属纹理，只用在一两处 |

（原词库第 9 项“可持续材料”指再生纸、竹、原木这类环保材料，表达环保和社会责任；数字设计里少用，做环保主题时用对应的纹理和色彩。“纸张”一行是本仓补的，教育类作品最常用。）

材质的规则：

- **材质和气质要同一方向。** 教育、温暖：纸张、木、织物；科技：玻璃、金属；高端：石材、皮革、哑光。
- **一个作品一种主材质，最多再配一种做对比。**
- **材质只做背景和容器的质感，不能抢文字。** 纹理压到很淡，文字底下保证干净；玻璃面板背后要模糊或压暗到字读得清。
- **质感要靠光才成立。** 玻璃要有亮边和高光，金属要有渐变反光；平涂的灰色不叫金属。

### 情绪

高级、温暖、冷静、活力、轻松、科技感、自然、浪漫、信任、愉悦，每种气质对应的版面、字体、配色、光影、材质和动效，都在[情感与氛围](mood.md)。情绪是七类手段的总方向，第一个定。

## 用到不同的成品上（默认）

同一套判断，换了媒介只多出几件要注意的事：

| 成品 | 额外注意 |
|---|---|
| PPT、海报、折页、书 | 按观看距离定字号（见[字体与文字](typography.md)）；PPT 落地操作见 [PPT 拆页与版式](../../graphic/ppt/ai-assisted-design/layout-and-pagination.md) |
| 视频画面、动画、包装 | 多了时间：出场顺序、停留、运镜；字号按画面高度换算。见[代码式视频设计经验](../code-driven-video/README.md) |
| 网页、App 界面 | 多了状态和交互：按钮主次、悬停和按下、空状态、各种屏宽。见[前端 UI 质量标准](../../../development/experience/frontend-ui-quality-standards.md) |
| Word 文档、申报书、流程图 | 常有模板约束，以模板为准；层级、对齐、间距照样适用。流程图方框等大、对齐成行，两三种浅色 |
| AI 生图、生视频提示词 | 把选好的词和对应手段写进提示词，见[设计原则 · 用在 AI 生图和设计图上](README.md#用在-ai-生图和设计图上默认)；视频提示词见 [Seedance](../../video/common/seedance/README.md) |
