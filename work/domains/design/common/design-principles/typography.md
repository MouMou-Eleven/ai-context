# 字体与文字

## 字体数量（默认）

一个版面用一到两款字体，然后重复使用。字体种类一多，版面立刻显乱。一款字体如果有多个字重，标题用粗的、正文用细的，只用这一款就够。

反例：标题用书法体、副题用圆体、正文用宋体、数字再换一款。正确做法：标题一款有性格的，其余全部用同一个字体家族。

## 中文和西文怎么配（默认）

中西文同时出现时，选笔画结构相近的一对，气质才统一：

| 中文 | 配西文 | 气质 |
|---|---|---|
| 宋体（笔画有粗细变化、有装饰角） | 衬线体 | 文化、典雅、正式 |
| 黑体（笔画粗细均匀） | 无衬线体 | 现代、简洁、科技 |

- 不要宋体配无衬线、黑体配衬线，除非是有意做对比。
- 中西文并排时，西文的字重、大小要调到和中文看起来一样重：同样的字号，西文通常显小、显细，需要略放大或选粗一档。
- 英文副标和中文主标是一组：英文居中在中文正下方、宽度接近中文，或者两行整组一起居中；中文改宽、挪了位置，英文要跟着走，不留在原来的位置。
- 西文作装饰时（大号英文垫在中文标题后面），可以放开对比，但全篇只用这一种装饰方式。

## 字号（默认）

- **先定正文字号，再定其他。** 正文定了，才能按比例推出小标题、大标题和注释的字号。
- 字号按层级定，不按“放得下”定。相邻层级要差多少、同层怎么统一，见[信息层级 · 用什么拉开层级](information-hierarchy.md#用什么拉开层级默认)。
- **按观看距离定字号**：投影的 PPT 要让最后一排看清，海报按远看的距离，书和折页按手持阅读。视频画面同样适用，换算成画面高度的比例，具体档位见[视频排版与尺寸 · 字号按画面高度定](../../video/common/video-craft/layout-and-sizing.md#字号按画面高度定默认)。

## 行距、字距和行长（默认）

- 间距有固定的大小顺序：**字里面的空白 < 字和字之间 < 行和行之间 < 段和段之间 < 栏和栏之间**。顺序一乱，文字就难读。例：行距比字距还小，横排的字会被看成竖排。
- 正文的行高（上一行基线到下一行基线）大约是字号的两倍，也就是行与行之间空出将近一个字高。笔画细、字面小的宋体类行高可以略大，黑体类略小。字越小、行越长，行距越要放宽。
- 标题字大，行距和字距可以收紧，显得紧凑有力；正文字小，适当放松，增加呼吸感。
- 一行不要太长也不要太短：太长，换行时找不到下一行的开头；太短，读起来断断续续。合适的行长是眼睛不用转头就能读完一行。读得快的内容（新闻、说明）行短一些，需要沉下心读的长文行可以长一些。
- 行长靠分栏来控制。各栏宽度保持一致。
- 同样的字号，不同字体看起来大小不一样：字面大的黑体显大，可以用小半号；字面小的宋体显小，要用大半号。英文同字号比中文显小。
- 中文正文优先左对齐或两端对齐；居中只用于标题和短句，长段居中每行开头参差，很难读。

## 断行，以及放不下时怎么办（默认）

没有“标题永远一行”“正文最多四行”的通用答案，按下面的顺序定：

1. **先守语义。** 在句子最自然的停顿处分行；不把人名、专名、数字和单位、一个词拆在两行；标点不放在行首。诗句、歌词遵守原有分行，不按现代段落重排。不为凑整齐改原文。
2. **再看主次。** 一句主问题、主张适合一到两行；几个独立条件分成条目或分组，不伪装成同一长句。
3. **用目标字体实排。** 在真实字形、目标画幅、文字区有效宽度下试排，不按字符数估算；标点落点、中英混排、字体替换都会改变宽度。
4. **超出时依次调整：** 优化断行 → 扩大文字区域或净空 → 收减无关装饰、调整布局 → 经确认精简上屏文字（原话留在备注或讲稿）→ 拆页。**最后才考虑缩字**，而且同级一起缩；同级标题不为某一页的长标题单独换一套字号，可以改两行或经确认缩写。

文案比预留位置长一倍以上时，拆行而不是硬缩。例（视频画面，精尺匠造）：“面向智慧工厂的多目标协同高精度实时定位系统”21 个字，模板样例只有 8 个字；缩成一行会小到读不清，拆成 12 字＋9 字两行，第一行宽度对齐上方标题组的总宽，整组居中，字号仍有约 100 像素（1080 画面）。

例：“把你最想留住的画面／用一两句话写下来”按语义分两行，比把所有字压成一条更易读；“小组合作：借助注释，读懂诗意”与“说清画面，再说说起名理由”是两个任务，各成一组，讨论时间另作辅助信息。不是“两行才好”，而是任务和阅读顺序支持这样分。

为什么：缩字最省事，但会把层级打乱、让远处的人读不清；先动断行和布局，字号才守得住。

## 灰度和粗细（默认）

把一段文字眯眼看成一块灰色，用深浅拉开层级、让同组匀称。做法见[信息层级 · 同层统一，灰度匀称](information-hierarchy.md#同层统一灰度匀称默认)。

## 字体的气质（可灵活）

| 想要的感觉 | 字体选择 |
|---|---|
| 高级、经典 | 衬线体、宋体，或简洁的黑体；字重偏细到中等 |
| 力量、冲击 | 笔画粗壮、外形硬朗的黑体，放大到撑满版面 |
| 纤细、优雅 | 字重轻、笔画细的字体，配更大的留白 |
| 柔和、亲切 | 圆角、轮廓圆润的字体 |
| 传统、国风 | 宋体、楷体、书法体；书法体只用在标题 |

带棱角的外形让人想到坚硬，圆的轮廓让人想到柔软轻盈。选字体就是选这种联想。详见[情感与氛围](mood.md)。

## 怎么检查

- 数字体：超过两款就删。
- 数字号：是否和层级数一致。
- 最小的字在实际尺寸和观看距离下能否读清。
- 有没有孤字成行、标点在行首、专名被拆开。
- 有缩过字的地方：是不是先试过断行、布局和拆页，同级是不是一起缩的。
