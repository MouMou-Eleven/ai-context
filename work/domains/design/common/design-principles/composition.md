# 构成法则：秩序、对比与变化

分析或设计一个版面，按这个顺序看：造型要素（点线面）→ 关系要素（怎么组合）→ 具体的图形和文字。

## 用点线面看版面（默认）

把版面里的内容都抽象成色块来看，细节先不管：

- 一个字、一个符号、一个小图标是**点**；一行字、一条分隔线是**线**；一张图、一段文字块、一块底色是**面**。
- 点线面可以互相转换：点密集排列成线，线密集排列成面；点放大成面，线加宽、平移、旋转也成面。
- 面有实有虚：实心色块是实面；一片点、一组线、一个线框围出来的是虚面。
- 线有三种变化：路径（直线、折线、曲线）、样式（细、粗、虚）、方向（横、斜、竖）。
- 一个画面同时有点、线、面，会显得丰富；只有一种，容易单调。

用法：做完后把版面眯眼看成色块，检查大块（面）是否稳、线是否把视线引向主角、点是否起到点缀而不是添乱。

## 先看四种基本关系（默认）

关系要素包括方向、位置、空间、比例、重心。设计时先从这四种构成考虑：

| 构成 | 做什么 | 怎么做 |
|---|---|---|
| **对齐** | 建立秩序最基本的办法 | 每个元素都和另一个元素共用一条线；文字、图片、整个版面用同一套对齐规则 |
| **对比** | 拉开主次，制造节奏 | 大小、色彩、空间（疏密、远近）三种最常用 |
| **重复** | 让版面统一 | 同类元素用同样的字体、颜色、形状、间距 |
| **平衡** | 让版面稳 | 左右、上下、四角的视觉重量大致相当，重的一侧用留白或小元素在另一侧呼应 |

**平衡怎么判断**：每个元素都有“分量”，分量由面积和深浅决定。面积越大、颜色越深、笔画越粗越密，分量越重。大面积的浅色可以和小面积的深色互相平衡。检查时把版面转成灰度，看深色块是否都压在一边；重心一般放在水平方向的中间。

其余构成按需要选用：

| 构成 | 特点 | 适合 |
|---|---|---|
| 密集 | 元素向某处聚拢，疏密对比 | 营造热闹、聚焦某一点 |
| 特异（变异） | 整齐队列里有一个不一样 | 强调单个重点 |
| 渐变 | 大小、颜色、方向逐步变化 | 表现过程、纵深、动感 |
| 分割 | 用线或色块把版面切成几块 | 信息分区、多内容并置 |
| 发射 | 元素从一点向外或向内 | 聚焦中心、表现冲击力 |
| 近似 | 形状相似但不完全相同 | 统一里带一点变化 |
| 空间 | 利用遮挡、大小、虚实做前后层次 | 需要纵深感的主视觉 |

## 秩序靠重复，变化要先有秩序（默认）

- 重复使用同一种模式，就有了秩序。等距排列的东西比随意摆放的有秩序；即使单个元素很乱，数量够多并重复排列，整体也有秩序。
- 变化就是打破规则。**要先建立规则，再打破，才叫对比。** 没有规则只求变化，得到的是混乱；只有规则没有变化，版面呆板。
- 做法：先让一组元素整齐，再让其中一个不同，这就是特异对比。对比的地方太多，等于没有重点。

## 无对比不设计（默认）

版面平淡，多半是两个毛病：层级模糊、缺少节奏。节奏就是有意营造对立关系。可以制造对比的十个维度：

形状、大小、位置、方向、肌理、色彩、空间（前后遮挡）、疏密、数量、虚实。

用法：

- 一次只从**一个属性**下手做特异，效果最干净。例：黑白版面里只给要强调的内容加一种彩色；整齐的方块里只把一个转个角度；横排文字里只有一行竖排。
- 文字的对比最常用字号：标题和正文差距拉大，层级立刻清楚。例：把主图和主标题放大到原来的一倍多，同样的内容马上有了主次。
- 改一个平淡的版面时，先问“哪里可以再大一点、哪里可以再小一点”。
- 明暗的反差最抓眼：深底配亮字，或亮底配深字。其次是大小、粗细、疏密。
- **反差只给要强调的地方。** 同时强调很多项，结果是互相抵消，谁也不突出。先把整体排得好读，再给一两处加反差。

## 稳定和动感（可灵活）

水平线、垂直线、整齐的对齐，给人稳定感；稳定也意味着没有动感。想要版面有动感：

- 用本身有动势的图：动作进行到一半的人或物，有方向的视线。
- 有意打破一部分对齐：让某个元素倾斜、错位、大小不一。
- 加入斜线、曲线，或箭头这类有方向的元素。
- 文字的方向跟着图片的运动方向走，不要一个向左一个向右。
- 需要细读的正文仍然水平排，只让标题和图动起来。动得太多，版面就散了。

## 对齐的细节（默认）

- 文字对齐有八种：左对齐、居中、右对齐、左右两端对齐；竖排时对应顶部、中间、底部、上下两端对齐。一段文字只选一种并坚持用。
- 对齐同样用在图片上：图片的边和文字块的边、和版心的边对上。
- **视觉对齐**：元素边缘不规则时，按眼睛看到的重心对齐，不按软件的外框。例：带把手的啤酒杯要居中，应该让杯身居中，而不是让“杯身加把手”的外框居中。
- 字体也要重复：一个版面选一到两款好字体，反复使用；一款字体既能做标题又能做正文，就只用这一款。

## 怎么检查

- 能不能指出这个版面的规则是什么（对齐线、重复的样式、统一的间距）。
- 能不能指出唯一被打破的地方，以及它是不是想强调的内容。
- 把主角缩小一半，版面是否变得平淡：是，说明原来的对比有效。
