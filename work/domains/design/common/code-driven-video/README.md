# 代码式视频设计经验

AI 自己动手做出来的视频：剪辑、加包装、加特效、加字幕标题、画标注、做动画，最后渲染出成片。AI 编程工具（Claude Code、Codex 等）做这些事时，实际都是写代码完成的：ffmpeg 剪接，Python（OpenCV、PIL）逐帧绘制，HTML/CSS/JS 录制，HyperFrames、Remotion、p5.js、three.js、Manim 等等。所以“代码式视频”说的是**做法**，用户不会这么说。

这里沉淀的是**设计经验**，不是一套风格。AI 写代码、做动效已经很强，缺的是设计判断：字该多大、元素之间空多少、谁和谁对齐、容器怎么包住内容。这些判断不管做科技风、国风、极简还是热闹的综艺风都成立；风格每次按内容重新定。

## 什么时候读（红线）

**按“谁来出画面”判断，不按用户怎么说判断。** 只要这次是 AI 自己动手处理视频、最后交出视频文件，开工前就读完本目录，不管用户有没有提“代码”。

用户通常这样说：

- “帮我剪一下这个视频”“把这几个镜头剪成 30 秒宣传片”“把录屏剪辑一下”
- “在这个视频上给我做个科技感的效果”“按分镜给这段视频做包装”
- “给视频加字幕 / 加标题 / 加标注 / 做个片头和转场”
- “这个 AI 生成的视频字糊了，你帮我重新做一下文字”
- 明确说用 Python、HTML、Remotion、HyperFrames 做视频或动画

宣传片、创赛、微课这些片型照常走各自的目录定内容和结构；本目录叠加在上面，管画面上的排版、尺寸、动效和验收。

不读的情况：只写 AI 视频模型的提示词（读 [Seedance](../../video/common/seedance/README.md)）；只写脚本、分镜、口播稿，不动手出片；给人用的 AE 手工工程（读 [AE 制作](../../video/common/ae-production.md)，其中的排版判断仍可参考本目录）。纯剪接、画面上什么都不加时，读[动效与验收](motion-and-verification.md)里的节奏和验收部分即可。

## 和平面设计原则的关系（默认）

视频包装本质上就是动起来的版面：文字排版、UI 排版、图片信息排版。所以**排版判断直接用[平面设计原则与规范](../../graphic/design-principles/README.md)**（信息层级、字体、留白、构成、配色），本目录不重抄，只写三类平面原则里没有的东西：

1. 画面是固定尺寸、远距离、只看几秒的版面，字号和间距怎么换算（见[排版与尺寸](layout-and-sizing.md)）。
2. 版面在动：出场顺序、停留时间、哪些东西跟着镜头走（见[动效与验收](motion-and-verification.md)）。
3. 代码实现的常见坑：图层顺序、写死的容器尺寸、出画、发光把内容冲白（见[动效与验收](motion-and-verification.md)）。

不要过拟合：平面里只对纸张、印刷、长文阅读成立的规则（比如正文行长、两端对齐、出血）不要硬搬进视频；视频里只对某一条片子成立的做法（比如某个颜色、某种面板外框）不要当成通用规则。复用的是判断方法，不是样式。

## 做一条代码式视频的顺序（默认）

1. **读需求和分镜**：每一段要说什么、几秒、哪句是主角。分镜给了时间轴就按时间轴排。
2. **看素材**：分辨率、帧率、时长、镜头动不动、画面里哪里是主体、哪里是可以放字的留白（天空、地面、墙、虚化区）。
3. **定版面骨架**：安全区、边距单位、信息放哪几块区域；按[排版与尺寸](layout-and-sizing.md)定字号和间距。
4. **先出关键静帧**：每个阶段结束时各出一张、最终状态一张，按检查表自查后再渲染全片。
5. **渲染全片，抽帧复查**：从成片里抽帧看，不只看渲染前的静帧。
6. **返修只改被指出的那一类**，按[多轮反馈怎么改](../feedback-iteration.md)。

## 交付前检查表

- [ ] 缩到手机屏幕大小看，最重要的那句话一眼能读清。
- [ ] 正文字号、标签字号、标题字号符合[排版与尺寸 · 字号](layout-and-sizing.md#字号按画面高度定默认)，同层级同字号。
- [ ] 每个容器（面板、卡片、字幕条）都被内容撑满：没有大块空着的底板，内容也没贴边。
- [ ] 每组文字在自己的容器里居中或明确对齐；所有面板顶边、底边能说出和谁对齐。
- [ ] 组内间距 < 组间间距；没有元素互相压住，也没有元素出画或贴到画面边缘。
- [ ] 标注、连线、文字没有挡住画面主体的关键部位。
- [ ] 发光、调色没有把画中画和文字冲白或压暗。
- [ ] 每段文字完整出现后有足够的停留时间读完。
