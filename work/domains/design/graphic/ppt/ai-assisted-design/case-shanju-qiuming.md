## 关键过程与人机分工

- **内容与初稿**：按教学设计保留策展主线，组织解题、朗读、诗句赏析、AI图像比较、王维自述与背诵。建委要求不留教师出镜位，不能每页左文右图，不能太写实老气，也不能把水墨插画理解成幼稚卡通。初稿已有图文，但装饰层级、版式丰富度与审美未达要求。
- **人先确定画面目标**：建委在网页端生图，先定首页，再反复上传同一首页和当前页内容截图。首页锁定风格，当前页提供文字与任务；生成时重新安排背景、题签、文字承载区和构图。截图显示对双图比较页、策展手记页做过多轮修改，具体问题包括画面不通透、底部排版、答题区过紧、选项颜色不一致。
- **从参考图转为可编辑样稿**：先提供前3张设计参考，要求Codex通过生图重新生成背景、标题框、卡片和徽章，文本框还原教学文字，逐页并排对比。3页样稿交付后建委明确继续，其后提供全26张参考。
- **整套与动态**：要求统一标题尺度与少量题签样式，去掉页码；书法只需相近字体；人物与前景独立分层。按教学顺序配置问题、回答、圈画、选项、背诵和媒体。最初禁止使用他人素材，后明确允许使用指定参考课件中需要的音视频；这是本单的使用指令变化，不等于确认第三方媒体可以公开再分发。
- **返修与交付分工**：建委指出观看视频被做成听音频、圈画和动画单一、讨论页文字溢框、底部文字不清、选项框拉伸等问题。后来要求自己做放映检查，尽量不用Computer Use。接续聊天确认交付“课堂优化版”，继续保留这个验收边界。

## 问题、修正与证据边界

| 问题 | 可复用判断 | 本次处理与已知结果 |
|---|---|---|
| 教学设计原文有不准确处 | 拆页阶段先核内容，设计不能掩盖错误 | AI拆页时主动校正：“月夜采莲”改为符合诗意的渔舟画面；“AI永远画不出声音与动作”改为针对当前静态图的观察；“空山”先解释山林空旷再引到心境；王维生平核对755年战乱与756年被俘，不混为一谈 |
| 首轮画面太写实老气，改后又成了儿童卡通 | 风格用真实参考图定，不靠“插画”“水墨”这类词 | 建委给出两张满意参考，AI分析其层次（外框、纸纹、前后景、题签与内容框）后改为青绿工笔，再进入首页定调 |
| 首轮按精品课流程给老师留了出镜位 | 教师委托的课件先看有没有模板和录课约束，没有就是自由视觉PPT | 建委纠正“整份不需要老师出镜”；后来单独设立自由视觉板块，路由也把“给老师做课件美化”与精品课分开 |
| AI直接做整套，画风和文字关系不合意 | 先用实际首页/代表页校准，不靠“精美”形容词 | 先样稿再扩展，后来采用逐页设计图作重建目标 |
| 图2即使要求不照搬，也会影响新图布局 | 基础图文稿先做合理排版；双图职责写清 | 建委在本轮明确要求把此项前移至拆页阶段 |
| 标题和题签单页好看，整套不一致 | 统一视觉系统，不盲目复制各页波动 | 本例选两套题签、统一标题尺度；不推广成所有项目只能两套 |
| 文字在框内仍显挤/背景不清 | 文本边界检查之外，还要检查实际字形、装饰净空和对比 | 讨论页、底部提示、短题签和复习页文字区已做修订，留有渲染记录 |
| 长框缩为短选项导致变形 | 目标比例不对时重生成，不强拉素材 | 补短题签及适配卡片，独立图层保存 |
| 所有动画都用出现；圈画不准 | 按语义选择轮子、擦除、框选、变色与适当进入 | 使用说明记录组合方案；正确选项B及释义变红有放映确认，不能据此认定全套动态通过 |
| “观看”页放音频 | 用途、按钮、实际媒体三者一致 | 说明记录改为视频及取消该页歌曲音频入口；最终播放实测交由建委 |
| 嵌入媒体后该页动画受影响 | 追加媒体后复核整页序列，不只检查文件存在 | 原聊天发现并修订；不能推广为所有PowerPoint版本必然如此 |
| 生图并非原生可编辑设计文件 | 图像层可替换，正文必须原生文本 | 背景、人物、装饰与文字分层；不能宣称图片内部所有像素均可编辑 |

## 已提炼的方法

- [完整流程](workflow.md)：内容图文稿→报价确认→首页定调→双图逐页设计→生图重建分层→原生文字→可选动态→人工终审。
- [拆页与版式判断](layout-and-pagination.md)：按场景任务拆分，先做好基础排版，检查实际字形、比例、内边距与背景对比。
- [分阶段提示词](prompt-playbook.md)：AI主动索要当前缺少的图，为本页构思提示词并说明下一步；不把截图里的国风提示当成通用唯一模板。

本例专属：26张设计参考、语文策展主题、青绿工笔、无教师出镜区、无页码、两款题签、王维第一人称与课堂互动。可迁移的是分工和检查方法，不是这些表面元素。没有保存聊天逐字记录、客户私有文稿或第三方媒体到仓库；证据定位与方法足以支持复用，避免体积膨胀和来源混淆。
