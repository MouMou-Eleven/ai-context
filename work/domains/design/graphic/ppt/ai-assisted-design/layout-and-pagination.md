# 内容拆页与版式判断：先把页面做对，再把它画美

## 一、先按使用动作拆页，不按字数平均分（默认）

每页写一个“看完/讲完这页要完成什么”。它可以是一个论点、一组比较、一个操作、一个讨论任务，不等于每页只能有一句话。

1. 通读材料，先区分上屏正文、讲述备注、证据图表、互动指令与答案。逐字稿里的每句话都要有归属，但不必每句话上屏；不得自行删掉必须呈现的内容。
2. 找不可割裂的关系：双图比较须同屏或在相同位置可切换；选项须能同时比较；图表与单位/关键结论相邻。概念还没出现，不先出结论。
3. 内容任务变了、阅读负荷过高或展示时机必须分开时才拆页；同一任务的必要上下文先保留在同页。问题与答案如果仅是出现先后不同，优先考虑同页点击揭示，不为了凑页数再拆一页。
4. 拆完输出映射表并对源稿逐段复核：每段在哪一页/备注、每页为何独立、素材和媒体是否有来源、需要谁确认。

正例：把“小组讨论：读懂诗意，给画面起名，并解释理由”放在一个可驻留的任务页，预留阅读和回答空间；反例：按每50字切开，问题在上一页、判断条件在下一页，课堂来回翻找。企业页同理：比较产品方案时把同口径指标保留在一起，不逐项拆成不能对照的散页。

## 二、先定信息层级，再选版式（默认）

给每页标三种角色：主问题/结论、支持内容、辅助说明。主角必须在缩略图中仍清楚；支持层围绕主角组织；辅助层减轻视觉重量但仍可读。不要每个词都放大、加框或标红，否则没有重点。

| 内容关系 | 先尝试的版式 | 不合适时怎样改 |
|---|---|---|
| 一句核心问题/一句诗 | 中心主文＋边缘氛围；必要说明另成小组 | 长问题改两行，不把全部字挤成细小一行 |
| 两组图或两个方案比较 | 两栏等宽，同级标题同位置、图像同尺度 | 不用一边大一边小暗示未经材料支持的优劣 |
| 顺序/过程 | 横向或纵向步骤，方向与阅读一致 | 步骤多到看不清时分阶段，不把箭头缩成装饰 |
| 多项同类任务 | 网格卡片，列对齐、同行净空一致 | 项目数量不匹配时换行列，不留无意义空卡 |
| 操作或讨论 | 问题、要求、操作/回答空间分区 | 不让边框和插画侵占实际写答区 |
| 真实图表/数据 | 图表占主区，结论与单位紧邻 | 数据过密时拆指标或保留附录，不生成虚构图形 |

一套视觉系统中允许多种构图：统一配色、字体层级与边距，不等于每页左文右图。重复可帮助认知同类内容，但把全部页面做成同样的背景加文字会失去内容差异。

## 三、网格、对齐与疏密怎样落到页面（默认）

先确定画布与安全边距，再设标题带、内容区、底部辅助区。按需要选两栏、三栏或中心主区，使用同一组参考线；不凭感觉给每个对象一个独立起点。

- **对齐**：同组标题和正文对同一条线；卡片内部的文本对内部净空，不仅对外框。并列图片区分大小时要有语义原因。
- **邻近**：图注靠近对应图，组内间距小于组间间距。两张图各有解释时，不把两段说明挤成同一条底部细字。
- **疏密**：把信息聚成可识别的组，组间留白；不要把“通透”做成四周巨大空白而文字仍拥挤，也不要为了“丰富”塞满云纹、叶片和小标签。
- **对比**：先保证文字与背景的明度差，再处理颜色和装饰；复杂背景下加稳定的浅色文字承载区或重生成低细节背景，而不是只给文字加阴影。
- **视觉重量**：插画主角、深色大块与大标题都在抢注意力，要让它们服务同一阅读顺序。缩小看第一眼若只看到装饰，重新分配面积。

这些是判断原则，不是规定每个项目用同一网格。微软的网格、参考线和对齐功能提供实施手段；是否清晰还要看实际文字和输出画面。

## 四、一行、两行还是四行：按意思与实排决定（默认）

没有“标题永远一行”或“正文最多四行”的通用答案。按以下顺序处理：

1. **先守语义**：句子在哪个停顿处分行最自然？不把人名、专名、数值与单位随意拆开。不能只为凑整齐而改变原文。
2. **再看主次**：一句主问题适合一至两行；多个独立条件应用条目或分组，不伪装成同一长句。诗句遵守原有诗行，不按现代段落随意重排。
3. **在目标字体下实排**：用真实字形、目标画幅、文本框有效宽度测试，不靠字符数估算。标点落点、英文混排和字体替换都会改变宽度。
4. **超出时依次调整**：优化断行→扩大文字净空→收减无关装饰/调整布局→经确认精简上屏文字并保留备注→确需时重新拆页。不要第一步就缩小字号。
5. **看全套层级**：同级标题不要为一页长标题就随意缩成另一套字号；可改两行题签或合理缩写，但需确认内容。字体大小按投影距离、画幅和层级验证，不搬用精品课固定字号。

例：“把你最想留住的画面／用一两句话写下来”按语义分两行，比把所有字压成一条更易读；“小组合作：借助注释，读懂诗意”与“说清画面，再说说起名理由”应各成一组，讨论时间另作辅助信息。并非“只有两行才好”，而是任务和阅读顺序支持这个选择。

## 五、先选合适的框，不把素材拉成需要的形状（红线＋默认）

生成前说明目标宽高比、文字净空、内边距、装饰所在边缘。长题签缩成短选项框会让两端花纹挤满内部，文字虽然在矩形边界内，也可能贴住花纹。需要短框就重新生成短框，不强拉长框；使用时等比缩放，必要时调整布局。

文本框边界≠装饰框有效区域。必须把字形与真实可用净空对照，同时检查透明PNG边缘、人物脚手完整度和遮挡关系。页面截图只能证明当前状态；编辑后换一段字也应试一次，确认仍能合理换行。

## 六、从内容图文稿到最终PPT，都检查三种视图（默认）

- **全套缩略图**：层级、色调、标题位置与视觉节奏是否统一；有没有连续多页同一构图。
- **逐页实际渲染**：全页看阅读路线，放大看字形、间距、边框、图注和底部文字。
- **实际使用状态**：现场投影或目标显示尺寸看可读性；有动画则看初始状态、每次点击与媒体返回，不能只看最终静态画面。

反例：自动检查没有文本框溢出，就宣布排版合格。正确做法：继续检查内容框净空、文字与底景的对比，以及选项框是否被拉伸；本例这三种问题都曾被建委实际指出。
