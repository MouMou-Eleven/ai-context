# PPT 设计：AI 全流程协作

适用于所有 PPT 的制作和美化：教学课件、企业介绍、汇报与其他演示（建委2026-10-09要求在PPT设计下独立设立）。没有模板就自由设计；有教学模板、企业模板等指定模板时，模板代替“首页定调”，其余流程照用。精品课另有录课合成和教师出镜的要求，由[精品课流程](../premium-course/README.md)主导，但页面美化、AI 生成元素同样借用本流程。

## 什么时候主动进入（默认）

出现“PPT美化”“从文稿拆页”“首页定调”“双图参考”“按设计图还原可编辑PPT”“背景题签重新生图”等需求，先读本页和[完整流程](workflow.md)。用户仅说“做一份PPT”也进入本流程，不要求用户记住板块名称或说出工具名。

已经有确认稿就从相应环节接续，不强制重做。每一阶段的排版判断都按[设计原则与规范](../../design-principles/README.md)。

**操作主线：先把每页讲什么定好，再把长什么样定好，最后把好看的设计图做成能修改、能使用的文件。** AI在每一阶段说明本轮输入、产物、检查点、下一步动作；需要首页图或当前页截图时主动索要，不假装已经看过。

## 维护边界（默认）

流程只在workflow维护；版式判断只在layout维护；可复制交互只在prompt维护；项目数量、路径、费用、版本与反馈只在案例维护。后续同类实践修订对应原段落，不按日期另建SOP副本。26页、青绿工笔、无页码、两款题签是本例选择，不是所有PPT必须遵守的规范。未来工具变更保留方法，按实际可用能力核验，不锁死模型名。
