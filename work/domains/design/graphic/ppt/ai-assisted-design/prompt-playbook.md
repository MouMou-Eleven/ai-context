# 分阶段提示词：AI负责写本轮指令，人负责确认关键结果

> 配套[完整流程](workflow.md)。默认使用：先判断阶段和真实输入，再把方括号替换为本项目内容；不要原样把空占位符甩给建委。提示词是可调整的协作脚手架，不是唯一句式。

## 先问哪张图，而不是泛泛问“你想要什么”（默认）

需要定调时索要已满意的首页；没有就用首页内容先定调。需要做第N页时索要第N页内容截图及可核对文字；需要重建时索要确认设计图文件夹与当前PPT。已经提供的内容直接使用，不重复要。图片中的旧提示词是历史证据，不自动覆盖本次要求。

AI先观察首页的配色、画风、明暗、装饰尺度、标题和留白，再提供本轮完整提示词以及“上传哪两张图、先看什么、通过后做什么”。不只说“请生成高级PPT”。

## A. 文稿拆页与内容图文稿

输入：客户文稿/教学设计/逐字稿及明确约束。

```text
请完整阅读附件，为[受众]在[使用场景]使用的PPT做内容拆页，最终要交可编辑的基础PPT。
先核对文稿结构、主要任务、必要图表与媒体，区分必须上屏、放入备注、需要核实的内容。按实际讲述/教学/决策顺序拆页，不平均按字数切分，不为了凑页数拆开同一比较或任务。
先交逐页规划：页号、本页目的、原文对应、上屏文字、备注、配图/媒体、呈现先后、建议版式。说明页数及拆分理由，核查遗漏和重复。
确认后制作有图有文字的内容图文稿：完成基础字体层级、对齐、断行、间距和适当配图；需要原创插图时调用生图。此时可以不做复杂装饰，但不能交只有文字的大纲。不要照搬他人课件素材。
存在事实疑点或新增内容时先标出，不擅自编造。完成后导出预览，让我先检查内容与版式，再据此确认报价和制作范围。
```

检查：页面能实际用于当前场景，文字与配图分工明确。下一步：核对报价与范围，未确认前不批量精修。

## B. 首页定调

输入：首页内容图文稿、受众、用途、已知风格偏好。

```text
请为[主题]设计一张[比例]PPT首页视觉稿，用于[场景/受众]。
必须保留的文字：[核对后的标题、署名、必要信息]。
我希望的气质是[具体气质]，参考[真实上传图的职责/无图时文字描述]。请让标题、必要信息和画面形成明确层级，保留可阅读的文字空间；不要把页面做成文字淹没在插画中的海报。
视觉方向：[配色、图像风格、材质、光线、装饰程度]；不希望出现：[已明确的禁区]。
本次先定首页的整体视觉，不批量生成后续页。结果确认后，我会用同一首页作为后续页面的风格参考。
```

AI拿到结果后提炼“保留什么、允许变化什么”。再挑一页正文试排；不能只因首页漂亮就认定正文适配。

## C. 固定首页＋当前页：双图生成通用版

输入：图1＝已确认首页；图2＝当前页内容图文稿截图。每轮重新附上两图并明确顺序。

```text
生成一张[比例]的单页PPT设计图，用于[主题、受众和具体场景]，当前是第[N]页，本页要让观众[完成的理解/动作]。

两张图分工：
图1只作为全套视觉风格依据：沿用[从首页提取的配色、画风、材质、标题气质、装饰密度]，不照搬首页的文字和全部构图。
图2提供本页全部内容及信息关系。核对文字清单：[准确文字]。保留事实、数字、专名、图表含义和必要视觉对象；不要照搬图2的背景、装饰及存在问题的排版，不擅自删改或扩写文字。

重新按本页内容设计：[AI针对当前页确定的版式、阅读顺序和图文关系]。
一级重点为[主问题/标题]，支持信息为[正文分组]，辅助信息为[图注/提示]。按语义断行，避免专名和数值单位被拆开。文字处要有稳定、清晰的承载区，背景和装饰降到次要层，留足组间距与框内净空。
[有讨论/书写时：为每个问题预留真实可用的回答空间。]
[有比较时：比较项同尺度同层级，说明文字分别靠近对应对象。]
画面必须干净通透，符合演示阅读，不是海报长图。主题所需景物随当前内容变化，不强制每页重复同一元素。保持与首页一致的视觉语言，但允许不同页面采用不同构图。
输出一张完整页面设计图；本轮不拆素材，也不把它当作最终可编辑PPT。
```

**可灵活：本例国风变量**：淡雅低饱和，墨绿与淡米色、少量柔和赭金，细笔国风山水、轻纸感、轻量云纹题签；标题书法气质，正文清晰端正。不要把这些变量带入企业科技发布、医学报告等不适配的任务。截图原提示“图2只提文字”须结合任务补足真实图表/必要对象，避免把证据当装饰删掉。

生成后核对文字和整套风格，选定版本命名保存。下一页仍用同一首页，不用上一页替代风格源。提示词不保证模型完全遵守，错误必须回查修正。

## D. 把确认设计图重建为可编辑PPT

输入：设计图文件夹、确认内容稿、最新PPT及交付要求。

```text
请读取[设计图目录]、[确认文字稿]及[当前PPT，如有]，先确认实际文件、页数、对应关系和最新版本。保留我的已有修改，不按旧文件覆盖。
这些图片是已经确认的逐页设计稿。请尽量还原其构图、位置、比例、留白和层级，同时修正整套标题/题签/字号不一致的问题。[具体整套规则]

重建方式：
1. 先列每页素材与图层清单，明确背景、标题装饰、内容框、人物、前景、文字及互动对象。
2. 背景、题签、内容框、人物、前景等以参考为依据调用生图，重绘为完整独立素材；不得从整页参考图裁碎、拼补作为交付素材。被遮挡的部分需要补全；无字背景和无字装饰不保留参考图文字。需要透明的素材提供真实透明背景。
3. 所有需要编辑的标题、正文、选项、作者、数字和说明使用PPT原生文本框，允许修改和换字体；书法用相近字体，不要求逐笔一致。需要移动/替换/动画的人物与前景分层。精确数据和真实Logo保留原始依据，不由生图伪造。
4. 先做[少量代表页]并导出与参考图的并排对照，检查实际文字、比例、内边距、背景对比与素材完整度。确认后再完成全套。
5. 我需要[静态/有动画]成品；先完成静态质量，再按内容安排动画和媒体。不要在没有生图能力时偷偷改成裁图，遇到能力缺口明确告诉我。
6. 交付PPTX、静态预览、分层素材、字体与使用说明。区分已经配置、已经验证和仍待我检查的项目；图片层可移动/替换不等于其内部像素全可编辑。
```

## E. 单个素材的生成指令

```text
以附件中[明确对象]为参考，重新生成一份完整的[背景/题签/内容框/人物/前景]，用于第[N]页[具体位置与用途]。
保留[造型、配色、质感与朝向]。目标比例为[按实际页面测量]，文字净空位于[位置与大致面积]。不含任何文字、数字、水印及无关对象。
[背景：去掉全部文字、人物和独立装饰框，重绘原遮挡位置，输出连续完整背景。]
[题签/人物/前景：主体完整，边缘不得缺失，框外或主体外真实透明；装饰不侵占文字区。]
不要截图裁片，不要保留矩形背景块。输出后需要检查透明度、残留文字和主体完整性。
```

## F. 动画与媒体

```text
根据[教学设计/讲述逻辑]，为当前PPT列逐页点击计划，再配置PowerPoint实际支持的动画。
区分初始可见内容、问题、回答、归纳和媒体。按目的组合淡化、擦除、轮子、框选与变色强调，不要全篇只用出现，也不要为丰富而堆特效。
相关图框和文字同一次点击出现；问题先出、答案由我点击后揭示。关键词或正确选项需要更醒目时采用变色并保留非颜色提示；圈画范围与方向准确，不压字。
媒体页明确是听音频还是看视频，嵌入[已确认可用素材]，检查点击播放、暂停、全屏/返回与既有动画序列。新增媒体后再复核该页。
请分别报告静态检查、动画结构检查、实际放映和媒体播放的验证状态。[本次若明确由我验收：不使用Computer Use反复测试，列出我需要检查的动作。]
```

## G. 有效返修：指出对象、问题、原因与目标

```text
第[N]页的[对象/区域]有[可见问题]：例如文字压到花纹，或底部提示与背景混在一起。
保留[已确认内容和区域]，把[目标对象]调整到[具体目标：净空、断行、层级、对比、比例]。
如果装饰比例不适配，重新生成合适素材，不拉伸现有边框。请同时检查其余页面是否存在同类问题，修改后给真实PPT导出的前后对照，并列出仍未验证项。
```

正例：“第9页讨论时间挤在底景上，请移入清晰的辅助信息区，并检查全套底部提示。”反例：“都不好看，再高级一点。”前者能形成可复核的改动，后者缺少对象与通过标准。
