# 案例：《揠苗助长》22页排版返修与生字笔顺动画

- 日期：2026-10-11 三轮返修；2026-10-13 插入客户视频并两轮调整。
- 受众：小学语文精品课教师委托（逐字稿署名为岳阳楼区八字门小学余恬老师）。
- 输入：指定精品课模板制作的22页课件（上一版由AI批量美化）、两版逐字稿（第3版只改了台词，页数不变）、客户发的生字教学参考视频（“看一看，说一说 / 看一看，学一学 / 描一描，写一写”）。
- 状态：建委收到第一轮成品后指出笔顺方向错误、最后一页没留教师位；第二轮已修正，并用导出视频抽帧核对了笔顺方向和全稿动画播放。真人录制与后期合成尚未进行。

## 建委指出的问题

| 问题 | 根因 | 改法 |
|---|---|---|
| 标题和下划线叠在一起，元素遮字、跑出底板 | 上一版按固定坐标批量画装饰线，插图卡片比底板高，装饰图压在文字行上 | 每页重排：装饰线放到文字下方、宽度跟随字宽；所有对象收进模板白区，用程序检查越界 |
| 课题“揠苗助长”字小，重点字不突出 | 只是四个 28 pt 字排一行 | 四个田字格配 72 pt 字，“揠”“长”用红字、金色格框加拼音 |
| 写字页田字格里的字太小、比例失调 | 184 pt 的格子放 43 pt 的字 | 字面占格子约 90%，用笔画数据绘制 |
| “一看结构、二看占格、三看关键笔画”配错 | 把三个观察角度分别配给三个字 | 改为一条横排要点，三个字各自写出结构、占格和关键笔画 |
| 笔顺动画方向全反 | 擦除效果 `presetSubtype` 与 `filter` 方向词不一致；静态逐点击截图看不出方向 | 修正方向参数；折笔按转角切段；导出 MP4 抽帧逐笔核对 |
| 第22页没留教师位 | 第一轮把作业页当全屏页 | 改为左侧三行作业卡，右侧约 1/3 留空 |
| 第5页拼音挤在一起、和字对不上，字在卡片里显小 | 整串拼音居中放在整个词上方 | 每字一格，音节逐个居中在字上方，拉开字距 |
| 第16页大片空白 | 一张图加两行字铺满整宽 | 改为出镜页：左侧图文，右侧留给老师 |
| 第14页标签居中、说明左对齐 | 同一组用了两种对齐 | 标签和说明共用居中线；同时查出第3、12、19页同类问题一并改 |

## 2026-10-13 插入客户视频

客户提供 39 秒种田人求助视频、9 秒懊悔数字人视频，以建委改过的《揠苗助长2.0(3)》为底插入第 2、16 页，不增页。旧版课件统一移入“旧版课件归档”文件夹，只留一版带时间戳的正式文件。

| 问题 | 根因 | 改法 |
|---|---|---|
| 插视频后第 2 页淡入全变“出现”、触发方式变了 | PowerPoint 保存时重写了已有动画页的时间线 | COM 删除重建原效果，前后签名逐页比对 |
| 第 16 页视频下又写了一遍种田人的话 | 没先核对视频自带的配音和字幕 | 删掉引语，视频放大占满左侧 |
| 第 11、12、18 页右侧空出 90～200 pt | 文字组按左边贴图片排，没按栏居中 | 文字组整体移到栏中间，提示条和文字等宽 |

## 对照两版逐字稿查出的内容问题

- 第3版删掉了作业段，但第22页作业沿用旧稿，已在备注中写明，待客户确认是否保留。
- 上一版有台词里没有的内容：自拟的“学生讲述”示范段、“如果再来一次，你会怎样劝他？”“你准备怎样做好身边的一件事？”。已换成稿中原有的评价标准原文和“那我们应该怎么做？”。
- 稿中“筋疲力尽”的释义和“长”的多音读法原先没上画面，已补上。

## 交付与验证

- 正式文件：本机 `F:\桌面文件\精品课-小学-语文-揠苗助长\揠苗助长_精品课_22页_10月13日0046.pptx`；每轮改完换新时间戳，旧版移入同目录“旧版课件归档”。
- 动画：15页有动画，共42次点击，每页备注写了对应台词和点击时机；第21页三个字共30段笔画擦除。
- 已验证：PowerPoint 渲染22页、越界检查、COM 读取动画绑定、整套导出 MP4 播放；第21页按 0.1 秒抽帧核对笔顺方向。
- 未验证：真人出镜合成后的整体效果、老师现场按备注操作的节奏。

## 制作中遇到的环境问题

用 PowerPoint COM 批量渲染时，某次打开失败会留下一个后台进程，之后每次 `Presentations.Open` 都报错，看起来像文件损坏。处理：每次渲染后调用 `Quit`，失败时只结束自己启动的 POWERPNT 进程（建委自己打开的那个不动），再重试。
