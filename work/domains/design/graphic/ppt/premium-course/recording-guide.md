# 精品课逐页录制操作稿

适用：录课课件与逐字稿对齐，帮助操作者知道何时翻页、点击动画、播放视频和切换网页。依据：2026-09-26《角的再认识》配套HTML与PPT备注制作；老师完整录课尚未验收。先读[制作流程](workflow.md)。

## 从最终文件建立对应表

以最终页序和最新版逐字稿为源，按教学动作划分连续稿段。逐页核对开头、结尾及相邻页衔接，避免漏句、重句或沿用调整前的页码。不要凭页标题编写老师台词。文稿与画面冲突时记录原句、实际演示和建议改句；未获确认的建议不能伪装成客户原文。

先读取实际动画，再写操作，不把“计划做”写成“已实现”。进入页时的可见内容必须与真实初始状态相符。预览若展示动画完成状态，应明确标注，不能让操作者误以为所有内容一开始就显示。

## 每页可复制模板

| 字段 | 填写内容 |
|---|---|
| 页码与标题 | 最终PPT页码、完整标题；有稳定页标识时同时记录 |
| 对应原稿 | 起句、止句、该页完整稿段，注明使用的稿件版本 |
| 初始画面 | 开页可见对象、尚未显示的答案或归纳 |
| 操作1至N | 操作方式、准确触发句、说之前还是说完之后、出现或运动的对象 |
| 自动后续 | 与上一动画同时或之后、持续时间、无需额外点击的部分 |
| 等待与停顿 | 等学生回答、等视频结束、等旋转完成等真实条件 |
| 翻页口令 | 讲完哪一句、完成哪项操作后翻到哪页 |
| 特别说明 | 重点文字角色、已确认改词、预览状态和媒体路径 |

每个操作一行。例如：“老师说完『静态的角』→按一次右方向键→显示归纳文字→老师继续解释”。不要写模糊的“适时点击”，不要把颜色当触发时机。学生回答应标注等待回答后揭示，不能将学生台词写成教师必读稿。

无动画页写“本页无动画，讲解期间无需点击”，另列翻页句。一次点击带出多个自动效果时写一条人工操作并列明后续链，不按底层效果数拆成多次点击。

## 视频与网页必须单列操作

区分点击媒体、点击超链接、推进动画和翻页。网页入口用鼠标点击链接；进入浏览器后的拖动、角度预设、隐藏名称、揭示答案与重置是网页操作，不是PPT点击序号。示例数值应符合当前教学范围；周角示例不把180°到360°之间一概称为钝角。

演示结束切回原PPT页，确认焦点在放映窗口后再翻页。记录返回方式和下一页，不默认网页会自动关闭或课件自动前进。更换电脑时实际测试媒体和链接，不把本机可用等同于可移交。

## 录制剪辑工作台

精品课录课时老师（或建委）边看边录用的 HTML，作用只有一个：**一眼看清这一页说什么、什么时候点、点完画面变成什么、说完哪句翻页**。来源：2026-10-13 建委对比两个商单的工作台。《揠苗助长》版（左目录、中预览、右单列稿件）直接可用；另一单《条纹乖乖》生成的版本塞进了状态回填、备注框、导入导出等制作管理功能，建委判定为错误版本。

它不是[微课交互式制作工作台](../../../video/education/interactive-production-workbench.md)。那份是给 AI 生图生视频管理分镜、提示词、返工状态用的；精品课录课工作台不套用它的状态、回填、版本记录和提示词模块。

### 页面只保留这些（红线）

| 区域 | 内容 |
|---|---|
| 顶栏 | 课题、所用PPT文件名；页数、点击总数、出镜页、嵌入视频数、后期补声音数各一个小格 |
| 左栏 | P01—P22 目录，按逐字稿环节分组，出镜页标“出镜”，可勾“已录制” |
| 中栏 | 当前页预览大图；下面一排缩略图“开页、点击1……点击N”，点哪张大图换成哪张 |
| 右栏 | 逐字稿原句与操作排成**一列**：老师句、学生句、点击、说明、翻页按发生顺序排，点击插在触发它的那句话后面；末尾一个简短的“本页注意”，再加上一页／下一页 |

用颜色和标签区分行：老师（白底）、学生（蓝底，带 S01 编号，写“录制时停顿，后期插入”）、点击（黄底，写“点击N：显示什么”，需要时加一行小字说准确时机）、翻页（绿底，写“说完哪句翻页 → 下一页”）。每行一句话，不在行里堆解释。

如果有后期要补的声音（学生音频、课文录音），可以另加“剪辑清单”“学生音频台词”两个标签页，列编号、页、内容、插在老师哪句之后，可复制、可下载 TXT。没有就不加。

### 不要放进去的东西（红线）

反例（《条纹乖乖》版）出现过，建委明确说没用、干扰录制：

- “进入本页”“切到下一页”这类与翻页行重复的块；
- “本页剪辑已核对”“本页剪辑已交付”等状态勾选，备注输入框；
- “保存可转发HTML”“备份标记”“导入标记”；
- “载入教师实拍／标记真实时间码”这类文件载入；
- 页面搜索、切换总览、原始逐字稿全文另开一页、“动画核对记录”折叠区；
- 开页说明、片头计时、技术说明（“实际PPT导出”“完成态预览”）铺在预览下方。

判断标准：录制那一刻用不到的，都不放。“本页注意”只写会影响录制的事（某句要改读、某次点击稿中没有台词、画面和稿子冲突待确认），一页最多三四条，每条一句话。

### 一屏看完，键盘操作（红线）

- 按 1440×900 左右的屏幕检查：一页的稿件、预览和点击缩略图在一屏内看全，内容特别长的页才需要滚动；预览区固定在左侧，滚动时不跑掉。
- **← → 换上一页／下一页；↑ ↓（和空格）在本页逐句移动**，当前句高亮并自动滚到屏幕中间。走到点击行时，中栏预览同步切到“点击N之后”的画面；走过本页最后一行再按 ↓ 进入下一页。网址带页号（#P05），刷新还在这页。
- 字号分层：老师句最大（约17px），学生句、点击说明次之，小字只用于时机提示。不出现大段说明文字。

### 画面从正式PPT导出（默认）

用 PowerPoint COM 逐页读出每次点击带出的对象和文字，按“开页、点击1……点击N”逐个隐藏对象导出预览图。点击数以导出结果为准，工作台每页写的点击条数必须和它一致；不一致，说明稿件映射或PPT有一方错了，先查清再交付。

### 单文件离线，发给谁都能用（红线）

2026-10-13 建委把《揠苗助长》工作台发到别的电脑，画面全部不显示：预览图放在旁边的素材文件夹里，只发了 HTML。

- 预览图以 base64 直接写进 HTML（同一张图在数据里只存一次，缩略图和大图引用同一份），不依赖任何旁边的文件、网络字体或在线脚本。22 页、66 张 960×540 的 JPG 约 5MB。
- 视频不嵌入网页（几十上百 MB），也不要用相对路径引用：别的电脑没有这个文件就是一个黑框。视频已经嵌在PPT里，工作台写“本页视频《文件名》已嵌入PPT，放映时点击播放”，用点击后的预览图显示它的位置。
- 验收：把 HTML 单独复制到一个空文件夹，用浏览器打开，检查每页每张图都加载出来、没有任何外部请求、没有脚本报错。

### 内容核对（默认）

- **学生的话单独编号。** 学生音频后期生成时，把学生台词按出现顺序编成 S01、S02……，剪辑清单写明插在老师哪句话之后；PPT 外的声音（如课文录音）也进清单。学生的一段话对应两次点击时，提醒在点击处断开，分两段生成。
- **用程序核对稿子覆盖。** 把逐字稿每句切成短片段，到工作台数据里查找，列出没有去处的句子，再逐条判断是有意处理（如视频已替老师说出引语）还是漏了。
- **画面和稿子冲突，标出来，不擅自改。** 《揠苗助长》第19页点亮4颗星，老师却说“三颗星”；第22页显示作业，稿中没有布置作业的话。都写进该页“本页注意”，请建委决定。
- **浏览器实测。** 用浏览器自动化检查：每页预览图能加载、按键走完一页会进入下一页、复制按钮有反馈、窄屏没有横向滚动、控制台无报错。

## 输出与同步范围

PPT备注适合现场查看；录制剪辑工作台（上一节）按页浏览，内嵌预览与稿段，单文件离线使用。两者使用同一份操作映射生成时，核对页面数、序号、触发句和点击数一致。HTML须区分完成态预览与初始画面说明。

用户要求冻结录制稿时，只修改授权的PPT，不自动同步HTML或覆盖其稿段。记录冻结范围：画面预览可能反映上一版本，并不意味着重新录制了当前画面。后续若用户要求更新，重新对齐实际动画与页序，不能默认旧映射始终有效。

验收抽查每类操作：无动画、问答揭示、多步总结、旋转、视频、网页进入与返回。逐条模拟口令，核对是否早泄露答案或需要未标明的额外点击；没有完成全课录制就明确仅通过局部操作核验。
