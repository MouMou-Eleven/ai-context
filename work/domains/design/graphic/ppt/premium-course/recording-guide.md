# 精品课逐页录制操作稿

适用：录课课件与逐字稿对齐，帮助操作者知道何时翻页、点击动画、播放视频和切换网页。依据：2026-09-26《角的再认识》配套HTML与PPT备注制作；老师完整录课尚未验收。先读[制作流程](workflow.md)。

## 从最终文件建立对应表

以最终页序和最新版逐字稿为源，按教学动作划分连续稿段。逐页核对开头、结尾及相邻页衔接，避免漏句、重句或沿用调整前的页码。不要凭页标题编写老师台词。文稿与画面冲突时记录原句、实际演示和建议改句；未获确认的建议不能伪装成客户原文。

先读取实际动画，再写操作，不把“计划做”写成“已实现”。进入页时的可见内容必须与真实初始状态相符。预览若展示动画完成状态，应明确标注，不能让操作者误以为所有内容一开始就显示。

## 每页可复制模板

| 字段 | 填写内容 |
|---|---|
| 页码与标题 | 最终PPT页码、完整标题；有稳定页标识时同时记录 |
| 对应原稿 | 起句、止句、该页完整稿段，注明使用的稿件版本 |
| 初始画面 | 开页可见对象、尚未显示的答案或归纳 |
| 操作1至N | 操作方式、准确触发句、说之前还是说完之后、出现或运动的对象 |
| 自动后续 | 与上一动画同时或之后、持续时间、无需额外点击的部分 |
| 等待与停顿 | 等学生回答、等视频结束、等旋转完成等真实条件 |
| 翻页口令 | 讲完哪一句、完成哪项操作后翻到哪页 |
| 特别说明 | 重点文字角色、已确认改词、预览状态和媒体路径 |

每个操作一行。例如：“老师说完『静态的角』→按一次右方向键→显示归纳文字→老师继续解释”。不要写模糊的“适时点击”，不要把颜色当触发时机。学生回答应标注等待回答后揭示，不能将学生台词写成教师必读稿。

无动画页写“本页无动画，讲解期间无需点击”，另列翻页句。一次点击带出多个自动效果时写一条人工操作并列明后续链，不按底层效果数拆成多次点击。

## 视频与网页必须单列操作

区分点击媒体、点击超链接、推进动画和翻页。网页入口用鼠标点击链接；进入浏览器后的拖动、角度预设、隐藏名称、揭示答案与重置是网页操作，不是PPT点击序号。示例数值应符合当前教学范围；周角示例不把180°到360°之间一概称为钝角。

演示结束切回原PPT页，确认焦点在放映窗口后再翻页。记录返回方式和下一页，不默认网页会自动关闭或课件自动前进。更换电脑时实际测试媒体和链接，不把本机可用等同于可移交。

## 录制剪辑工作台（默认）

来源：2026-10-13《揠苗助长》，建委要求一份录课和剪辑都能用的 HTML。逐页模板的字段不变，下面是做成网页时这次验证有效的做法。

- **画面从正式PPT导出，不从记忆写。** 用 PowerPoint COM 逐页读出每次点击带出的对象和文字，按“开页、点击1……点击N”逐个隐藏对象导出预览图。点击数以导出结果为准，页面数据里写的点击条数必须和它逐页一致，不一致就是稿或PPT有一方错了。
- **逐字稿原句和点击穿插排成一列。** 老师句、学生句、点击、翻页按发生顺序排在同一列，点击插在触发它的那句话后面，不另列“操作表”。录制时按空格往下走，经过点击行时，左侧预览切到点完后的画面。
- **学生的话单独编号。** 学生音频后期再生成时，把学生台词按出现顺序编成 S01、S02……，同时生成“剪辑清单”，写明插在老师哪句话之后；PPT 外的声音（如课文录音）也进这张清单。学生的一段话如果对应两次点击，提醒在点击处断开，分两段生成。
- **用程序核对稿子覆盖。** 把逐字稿每句切成短片段，到工作台数据里查找，列出没有去处的句子，再逐条判断是有意处理（如视频已替老师说出引语）还是漏了。
- **发现画面和稿子冲突，标出来，不擅自改。** 本例第19页点亮4颗星，老师却说“三颗星”；第22页显示作业，稿中没有布置作业的话。都写在该页的“本页注意”里，请建委决定。
- **交付形式。** 单个 HTML 加同目录的预览图文件夹，相对路径，双击即可打开；视频页直接引用文件夹里的原视频供核对。用浏览器自动化实际测试：每页预览图能加载、按键走完一页会翻到下一页、视频能读到时长、复制按钮有反馈、窄屏没有横向滚动。

## 输出与同步范围

PPT备注适合现场查看；独立HTML可按页浏览，内嵌预览与稿段，离线查阅。两者使用同一份操作映射生成时，核对页面数、序号、触发句和点击数一致。HTML须区分完成态预览与初始画面说明。

用户要求冻结录制稿时，只修改授权的PPT，不自动同步HTML或覆盖其稿段。记录冻结范围：画面预览可能反映上一版本，并不意味着重新录制了当前画面。后续若用户要求更新，重新对齐实际动画与页序，不能默认旧映射始终有效。

验收抽查每类操作：无动画、问答揭示、多步总结、旋转、视频、网页进入与返回。逐条模拟口令，核对是否早泄露答案或需要未标明的额外点击；没有完成全课录制就明确仅通过局部操作核验。
