# 精品课动画时机与几何校验

适用：精品课分步出现、射线旋转、箭头接缝与圆心偏移修复。依据：2026-09-26《角的再认识》放映导出、结构检查及用户截图。先读[制作流程](workflow.md)，操作口令写入[逐页录制稿](recording-guide.md)。

## 先确定教学作用

每组内容标明角色：观察材料、教师提问、学生回答、教师归纳或操作提示。观察材料可初始显示；答案和归纳通常在相应问答后揭示；常驻操作说明不必强加动画。重点色不自动意味着要动画，更不意味着是学生回答。

本案例第4页“一个顶点、两条射线”是教师回顾知识的归纳，不是新增学生台词。在教师说到“静态的角”之后点击揭示，再接“从一个点引出两条射线，就组成角。”这是本稿的具体口令，其他课程必须从实际逐字稿定位。排序页的完整答案应等学生回答后出现，不能开页就泄露答案。

**点击节奏跟着逐字稿走，多数情况一次点击出一项（默认，建委2026-10-12明确）。** 精品课要按讲课节奏录制，老师说到哪一句、点一下出哪一项。一次点击后又自动带出下一项内容、进页后内容自动依次出现，录制时就控制不了节奏，所以列表逐条、问题逐个、答案和结论通常各占一次点击；同一项的配套元素（卡片底框和它的文字、标签和底色）跟着这一项一起出现，不先露出空底框。视频设为单击播放。

**可以嵌套的情况：** 一个画面效果本身就是连续过程时，点一次触发，后面自动播完，不拆成多次点击。例如板书课题“一幅名扬中外的画”按字逐个写出（点一次，约2秒写完，体现板书感），射线旋转后接着出现角弧和名称，生字笔顺逐笔写出。判断标准：后面自动出现的部分是不是同一个教学动作的一部分；如果是老师要停下来讲、等学生答的新内容，就要单独一次点击。

**顺序怎么定：** 客户通常不会标顺序，按逐字稿规划：先出老师的提问，学生回答后再出答案，教师归纳后再出结论，板书在稿中写“（板书）”的那句出现。客户在截图或逐字稿上标了序号时，按序号排。反例：《一幅名扬中外的画》第一版，“你想知道什么？”在讲解“名扬中外”之前就显示了；第14页省略号的提问、含义、“画上还可能有什么人”、结论只做了两次点击，对不上逐字稿的四个停顿。

记录每一步触发对象、时长和对应稿句。72个效果不等于72次点击；无动画页也要明确标为无需点击、讲完翻页。

## 转轴固定在数学顶点

旋转动画通常围绕对象或组的边界中心运行。线段端点画在顶点上，不代表旋转中心就在该点。若需要用不可见对称边界固定轴心，应以数学顶点为中心构造组边界；箭头尖端、装饰和新对象不能再次扩张组框而改变中心。

保留对象ID与动画绑定，检查组坐标、子对象坐标及缩放。分别核对初始、途中、结束状态；顶点标记不能跟着移动。编辑视图的初始水平线和放映后的最终角度可以不同，应在录制稿说明。

实际放映或导出抽帧，观察射线轴是否一直穿过同一顶点。可将线轴延长计算与顶点的距离作为辅助证据；需注明分辨率和采样时点。单帧正确、动画数量一致或XML合法，都不能替代运动过程检查。

## 箭头检查不能只缩短线段

先确认是原生箭头还是线段加三角形。没有既有动画约束时优先原生箭头；局部返修有动画的拼接对象时，不盲目替换整个组。

1. 将顶点、线段中心轴和三角形中轴换算到同一坐标系。水平箭头的线段两端与三角形中轴必须同高，斜线则沿同一向量。
2. 核对自定义路径的尺寸声明、端点和对象变换。路径端点超出声明宽高会使显示长度偏离预期；不能只修改屏幕上的外框宽度。
3. 线段末端进入三角形内部，既不露出尖端，也不在底边前断开。进入深度按线宽、箭头尺寸和实际渲染决定，没有通用固定百分比。
4. 重叠的两条射线分别检查。上层箭头可能遮住下层错误；修一条不代表另一条正常。圆弧箭头还需检查末端切向。
5. 对比修改前后尖端位置、数学长度意义、动画目标及组框；以放大渲染复核接合，旋转对象再查动态。

本次第7页的根因是路径端点超出自身尺寸、尖端轴线未与顶点对齐。修复保留尖端横坐标，重设水平轴和路径尺寸，使线段终止于头部内部。此前批量收缩接缝的次数不能证明全部箭头正确，这次证据取代“只缩端点即可解决”的简化理解。

## 擦除方向要用视频抽帧核对（红线）

擦除、轮子这类带方向的动画，**方向只有动起来才看得出**。按点击逐步隐藏对象导出的静态截图、动画数量、XML 合法性都证明不了方向对不对。《揠苗助长》第一轮的生字笔顺动画全部方向反了，静态检查全部“通过”，是建委放映时才发现的。

- 用程序写擦除动画时，`presetSubtype` 与 `animEffect filter` 的方向词必须写成同一边：从左 = 8 + `wipe(left)`，从右 = 2 + `wipe(right)`，从上 = 1 + `wipe(up)`，从下 = 4 + `wipe(down)`。反例：8 配 `wipe(right)`，属性面板显示“自左侧”，实际却从右往左擦。
- 新写一种方向效果前，先做一页测试：四个色块分别用四个方向，用 PowerPoint 导出 MP4（COM 的 `CreateVideo`，点击动画会按顺序自动播放），抽取播放到一半时的帧，看每块先露出哪一边，确认后再批量用。
- 交付前把有方向动画的页单独导出视频，按 0.1 秒抽帧，逐个对象看起笔端是否先出现。

## 生字书写：笔顺擦除动画（默认）

适用：精品课生字教学的“学一学 / 跟老师写”环节，逐字稿写“播放书写视频”，但客户样片是“左边范字、右边逐笔写出”的效果，需要在 PPT 里直接演示笔顺。

1. **笔画来源要真实。** 用开源笔顺数据（hanzi-writer-data，每字含笔画轮廓与中线，中线首点是起笔），每笔做成一个可编辑的自由曲线，不凭字形手绘、不猜笔顺。用之前把每一笔单独标色渲染一遍，核对笔数和笔顺，例如“助”7画、“坏”7画、“死”6画。
2. **底字与写字分层。** 浅灰描红底字常显，黑色书写层逐笔进入；关键笔画（本课“且”“土”末笔的提、“坏”的点、“死”的首横和竖弯钩）在书写层直接用红色，与“看一看”页的标红一致。
3. **方向沿书写方向。** 直笔按起笔到收笔的主要方向选擦除方向：横从左、竖从上、提从左、撇按主方向。**折笔按转角切段**：中线简化后，转向超过约50°处用转角平分线把笔画切开，每段按自己的方向擦，比如横折钩切成“横从左—折从上—钩从下”，竖弯钩切成“竖从上—弯从左—钩从下”。整笔只用一个方向，转折处一定是反的。切口两侧各留几个单位的重叠，避免接缝露白。
4. **节奏。** 一次点击写完一个字，同一笔的各段之间不留停顿，笔与笔之间停约0.15秒，每段时长按长度算（本课约160～800毫秒）。
5. **验收。** 按上一节导出视频抽帧，逐笔检查起笔端先出现、折笔不倒写、红色笔画位置对。

这种做法替代不了真人书写视频的握笔示范；后期如果要插真人视频，删掉对应字的书写层即可。

## 修改范围与验收边界

先读用户最新保存文件并记录哈希，覆盖前再次比对。用户明确只修一处时，按对象和页限定变更，不顺便重排其手工改页。解包比对可以证明未涉及的PPT条目未变；它与放映检查分别证明结构保护和视觉行为。报告实际检查的范围，不宣称未检查页面或完整录课已验收。
