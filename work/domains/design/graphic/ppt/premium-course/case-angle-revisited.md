# 《角的再认识》精品课制作与修订案例

记录日期：2026-09-26。归属：教师委托的数学精品课制作，不属于建委授课培训。来源：本次连续协作对话、客户文稿与截图、用户保存的PPT及本机渲染检查。

## 输入和交付

输入包括教学设计、括号1与括号6逐字稿及后续截图修订、2026学科课程精品课PPT模板、导入视频和排版对照截图。最终保留21页PPT、配套活动角HTML及AI透明素材。封面身份字段在后续已由用户填写并保留；完整录制、剪辑合成与客户最终验收尚未完成。

本机正式文件：`F:/桌面文件/精品课-数学-角的再认识/v1版本/角的再认识_精品课_21页_最终视觉优化版.pptx`。网页为同目录的 `angle-interactive.html`。二进制课件和客户资料未上传仓库。

费用：最初报价参考26页，现稿21页，最终结算未确认。40元/页、合成400元、网页500元来自本单用户说明，不属于通用价目表（价格口径见[报价方法](../../../../other/commercial/quotations/method.md)）。

## 问题、根因与方法

| 问题（建委或用户指出） | 根因 | 改法与证据 | 方法 |
|---|---|---|---|
| 写稿老师稿与客户修订稿不一致，要比对后拆页报价 | 逐字稿编号不等于版本优先级 | 以最新确认范围为准，删除旧练习；封面未知字段保留可编辑项；页数不为报价凑数 | [制作与验收方法第1、2节](workflow.md#1-先建立文稿版本关系) |
| 课堂操作重复：网页截图又在PPT里演示一遍 | 没按“PPT入口—浏览器演示—返回PPT”的使用习惯设计 | 交互页改成完整入口封面，整图链接到网页 | [制作与验收方法第4节](workflow.md#4-ppt视频与交互各司其职) |
| 导入素材背景不统一、圆规结构错、物体越界、蓝色抠像侵蚀主体、阴影残留 | 多物体一段生成、抠像色选错；文生视频对刚体结构不稳 | 后续导入视频由用户生成提供；不据此声称提示词问题已普遍解决 | [制作与验收方法第5节](workflow.md#5-ai素材制作与合成) |
| 第3页素材底色没去掉 | 用视频提帧当透明素材 | 生成圆规、书本、水龙头、风车并做成透明PNG，经实际alpha和底色合成检查后替换；中文精确排入 | [AI 全流程协作第5阶段](../ai-assisted-design/workflow.md#5-交给codex重建分层素材和原生文字默认) |
| 先说丰富度不足；补了卡片、总结板、人物、手持铅笔和重点色后，又说设计感不足 | 把“加装饰”当成排版完成，素材与文字的比例、间距、中心关系没处理 | 结论居中、收紧卡片、改善底边留白，比较页去掉不必要底框 | [图文设计方法](visual-design.md#先匹配内容再加装饰) |
| 短句放在过高的便利贴里 | 按装饰选框，不按实际行数、行宽 | 重新适配文本框，生成统一的浅木边框 | [图文设计方法](visual-design.md#先匹配内容再加装饰) |
| 用户亲手改了第7页（去掉比较页两张底框、放大中央人物）和第19页（图文位置、卡片大小、底部居中） | — | 以用户保存的文件为源，两页设为保护页；保护的第7页原有约2.3pt宽度超出提示，渲染未截字，原样保留；第7、19页XML逐字节一致 | [用户改稿保护](../ai-assisted-design/workflow.md#开工先定位当前阶段默认) |
| 线段穿过三角箭头的尖端 | 线段终点没收进三角形内部 | 其余页面57处接缝局部收缩路径，保留对象ID、旋转组框和动画时序；保护页不动 | [箭头检查](animation-and-geometry.md#箭头检查不能只缩短线段) |
| 第6、8、10页射线不绕顶点旋转 | 旋转围绕组边界中心，不是数学顶点 | 修正旋转中心；720p三个采样帧射线轴到顶点约0.36、0.92、0.66像素（只说明这些采样） | [转轴固定在数学顶点](animation-and-geometry.md#转轴固定在数学顶点) |
| 答案出示缺少讲稿口令；第16、17页顺序与原稿不符 | 动画按对象排，没按教师问答节奏定位稿句 | 按问答节奏安排揭示、调换两页；新增逐页录制操作稿HTML和备注（初始可见内容、触发句、自动后续、翻页、网页返回）。用户之后要求不再改HTML | [先确定教学作用](animation-and-geometry.md#先确定教学作用)、[逐页录制操作稿](recording-guide.md) |
| 用户再次保存手改版，只授权修第7页箭头 | 重合的初始与运动射线路径端点超出路径尺寸，箭头中轴不与顶点同高 | 重设4个对象的水平轴、路径尺寸和接合位置，保持尖端横坐标和动画绑定；解包比对仅 `ppt/slides/slide7.xml` 改变，覆盖前源文件哈希未变，录制HTML哈希未变。之前批量收缩接缝的次数不作为正确性证据 | [箭头检查](animation-and-geometry.md#箭头检查不能只缩短线段)、[用户改稿保护](../ai-assisted-design/workflow.md#开工先定位当前阶段默认) |

最后一页改为“门、书本、时钟插画组—观察问题—告别语”的纵向层级，用户明确认可比例、间距和整体效果；认可只限这一页，见[最后一页如何收束](visual-design.md#最后一页如何收束)。

## 检查记录与未验收范围

- 早期返修阶段：21页、1个嵌入视频、1个网页入口、39个动画效果，修改页没有文本框溢出提示。
- 动画与录制稿阶段：72个动画效果（不是人工点击数），自动溢出和低字号检查未报问题；PowerPoint 实际导出抽查了旋转途中与分步出示。录制稿预览是动画完成态，不等于开页状态。
- 本轮内置生图工具未提供，采用启动器回退通道生成素材；不据此声称内置通道已实测。
- 以上是课件结构与静态、抽样动态检查，不代表老师完整录课、所有动画中间帧和最终剪辑合成已经验收。
