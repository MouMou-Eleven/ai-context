# 精品课制作

适用于教师委托、须遵守指定模板、配合真人录制及后期合成的精品课 PPT。确认日期：2026-09-26。来源是建委在《角的再认识》商单中的多轮要求、实际课件与人工修订。

## 从任务进入

收到教学设计、多个逐字稿或课件修改任务时，先读[制作与验收方法](workflow.md)。涉及动画、箭头、卡片排版及用户改稿时，重点执行其中的保护范围和视觉检查。只有需要AI视频与网页实现时，再进入[微课与教育交互](../../../video/education/README.md)。
