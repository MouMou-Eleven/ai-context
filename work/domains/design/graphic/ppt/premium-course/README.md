# 精品课制作

适用于教师委托、须遵守指定模板、配合真人录制及后期合成的精品课 PPT。维护从文稿、页面规划与客户确认，到设计、动画及合成交接的完整业务流程。来源是《角的再认识》制作反馈，以及建委2026-10-03在《一幅名扬中外的画》合并任务中确认的判断与SOP。

## 从任务进入

收到有本类模板/录制约束的教学设计、多个逐字稿或课件修改任务时，先读[制作与验收方法](workflow.md)。按问题继续读取下列专题，不把全部规则机械套入每次返修。只有需要AI视频与网页实现时，再进入[微课与教育交互](../../../video/education/README.md)。

| 文件 | 用途 |
|---|---|
| [制作与验收方法](workflow.md) | 文稿核对、拆页与合并、页数确认、模板设计、AI素材、动画及交付 |
| [图文适配与收尾页](visual-design.md) | 配图、文本框、比例、间距、重点色及最后一页设计 |
| [动画时机与几何校验](animation-and-geometry.md) | 问答揭示、固定转轴、箭头路径和动态验收 |
| [逐页录制操作稿](recording-guide.md) | 稿段对应、准确点击句、自动效果、媒体及网页切换 |
| [动画与录制修订](revisions/2026-09-26-animation-recording-and-arrow-axis.md) | 后续反馈纠正早期口径，说明实际验证边界 |
| [《一幅名扬中外的画》合并案例](case-famous-painting-page-merge.md) | 从动画换屏误判改为真实共页，明确27页范围与三个合并组 |
| [《角的再认识》案例](case-angle-revisited.md) | 真实输入、反馈、失败原因、修改结果与证据边界 |
| [2026-09-26 修订](revisions/2026-09-26-layout-and-arrow-review.md) | 从增加装饰转向比例、对齐、留白和箭头接合的验收要求 |

没有强制模板的PPT美化、首页定调及设计图重建，进入[自由视觉PPT](../ai-assisted-design/README.md)。不适用于直接套做商务汇报、路演或全屏自由设计；具体模板、字号、人物区域和费用必须按当前项目确定。方法与案例分别记录已执行、已确认和待验证范围；不能把页数方案获认可写成完整录课验收。
