# 书籍设计

## 负责范围

- 书籍封面、内页版式、图文编排和视觉体系。
- 印刷阅读、图片清晰度、题注、图号和版面一致性。
- 设计端的 Word/PDF 交付检查。

## 边界

本目录负责书籍视觉设计。具体书稿、作者分工、编辑反馈和出版进度属于项目；当前已有[《飞书高效办公》](../../../../projects/feishu-efficient-office/README.md)。主题是否涉及AI不改变这种分工。

## 当前状态

版心、边距比例、网格、字体与行距等通用规则见[设计原则与规范](../design-principles/README.md)，其中[版面骨架](../design-principles/layout-skeleton.md)有书籍的边距比例和基线网格。仓库尚未沉淀独立书籍设计方法文件。后续应从真实书籍设计项目中提炼，不把飞书书稿的全部编辑历史复制到这里。
