# 设计原则与规范

海报、折页、书籍、PPT、KV 等所有平面和演示设计共用的底层规则。好的版面看起来天马行空，背后都有规律：信息有主次、元素有秩序、空间有呼吸。AI 做任何排版、配色、出设计图、写生图提示词之前，先按这里的顺序做判断，再动手。

## 设计一个版面的顺序（默认）

1. **先理信息，再碰画面。** 把文案分成主要、次要、辅助三层，确定这一页唯一的主角。见[信息层级](information-hierarchy.md)。
2. **定气质。** 高级、有力量、纤细、热闹还是安静，决定版面率、字体和配色的方向。见[情感与氛围](mood.md)。
3. **搭骨架。** 定版心和边距、分栏或网格，选一种构图（上下、左右、居中、包围、满版……）。见[版面骨架](layout-skeleton.md)和[构图](page-composition.md)。
4. **放主角，再放配角。** 主要信息和主图先占位，次要信息围绕它保持平衡，辅助信息放进剩下的空间。
5. **建立秩序，再做一处变化。** 用对齐、重复、统一间距建立规则；只在想强调的地方打破一次。见[构成法则](composition.md)。
6. **配字体和颜色。** 字体一到两款；先保证文字和背景的明度差，再谈好看。见[字体与文字](typography.md)和[配色](color.md)。
7. **管留白。** 留白是元素，不是剩下的空地。见[留白](whitespace.md)。
8. **对照下面的检查表过一遍。**

## 用在 AI 生图和设计图上（默认）

让 AI 生成整页设计图或素材时，把上面的判断写进提示词，而不是只写“高级、好看”：

- 写清层级：谁是第一视觉重点，谁是支持信息，谁是辅助信息。
- 写清构图：用哪种构图，主体放哪，文字区在哪，留白在哪一侧。
- 写清秩序：哪些元素对齐、等距、同样大小；只允许哪一处不同。
- 写清颜色：主色、辅助色、点缀色各是什么，背景是深是浅，文字要和背景拉开明度。
- 写清气质对应的手段：要高级就写元素少、留白多、低饱和、居中；要力量就写粗字、撑满、强对比。

拿到生成结果，也按下面的检查表看，不只看“漂不漂亮”。

## 交付前检查表

评判一个设计，看四件事：信息传达有没有受阻、氛围对不对、画面是否美观、有没有解决这次的具体问题。逐项检查：

- [ ] 缩小到缩略图，第一眼看到的是这一页的主角。
- [ ] 层级不超过实际需要；同一层级的文字字号、字重、颜色一致。
- [ ] 所有元素都能说出和谁对齐；没有“差一点没对上”的边。
- [ ] 相关的东西靠得近，不相关的拉得开；组内间距小于组间间距。
- [ ] 版面里有清楚的秩序，变化只出现在要强调的地方。
- [ ] 字体不超过两款；中文和西文气质一致。
- [ ] 文字和背景的明度差足够，远看也能读。
- [ ] 颜色有主有次，不是几种颜色平均分。
- [ ] 留白是有意安排的，文字没有压在图片主体上。
- [ ] 气质和内容相符：该高级的没有塞满，该有力量的没有做得纤细。

## 这些规则的级别

都是**默认**：没有特别理由就照做。客户有品牌规范、指定模板或明确要求时，以客户的为准。打破规则可以，但要先建立规则，并说得出为什么在这里打破。

## 来源与状态

- 建委 2026-10-10 提供的设计教程书照片 30 张（信息层级、规则与秩序、留白、构图、色彩明度与色调、高级感、力量与纤细、图形与图表等章节）。
- 建委的飞书笔记《版式设计》（造型要素点线面、关系要素、十二种构成法则、对比的十个维度）。
- 《版面设计的原理》（伊达千代、内藤孝彦）、《版式设计实用手册》（SUN I 视觉设计）、《PPT基础技能手册2.0版》。
- 建委口述列出的要点：中西文搭配、色环配色、各类构图、网格与边距比例等。其中照片没有拍到的部分（色环角度、范德格拉夫和威廉·莫里斯的具体比例），按通用设计理论写成，建委可对照原书校正。

规范写成后还没有在实际订单里验证；每次设计返修中发现的新判断，回写到对应专题。
