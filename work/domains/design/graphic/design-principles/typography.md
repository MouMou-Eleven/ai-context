# 字体与文字

## 字体数量（默认）

一个版面用一到两款字体，然后重复使用。字体种类一多，版面立刻显乱。一款字体如果有多个字重，标题用粗的、正文用细的，只用这一款就够。

反例：标题用书法体、副题用圆体、正文用宋体、数字再换一款。正确做法：标题一款有性格的，其余全部用同一个字体家族。

## 中文和西文怎么配（默认）

中西文同时出现时，选笔画结构相近的一对，气质才统一：

| 中文 | 配西文 | 气质 |
|---|---|---|
| 宋体（笔画有粗细变化、有装饰角） | 衬线体 | 文化、典雅、正式 |
| 黑体（笔画粗细均匀） | 无衬线体 | 现代、简洁、科技 |

- 不要宋体配无衬线、黑体配衬线，除非是有意做对比。
- 中西文并排时，西文的字重、大小要调到和中文看起来一样重：同样的字号，西文通常显小、显细，需要略放大或选粗一档。
- 西文作装饰时（大号英文垫在中文标题后面），可以放开对比，但全篇只用这一种装饰方式。

## 字号和层级（默认）

- **先定正文字号，再定其他。** 正文定了，才能按比例推出小标题、大标题和注释的字号。
- 字号按层级定，不按“放得下”定。层级的划分见[信息层级](information-hierarchy.md)。
- 相邻层级的字号要有看得出的差距；差一点点等于没差，读的人会以为是没对齐的失误。
- 同一层级全篇同一字号。一页放不下时，先调断行、文字区域和拆页，最后才考虑缩字，而且要同级一起缩。
- 具体字号按成品尺寸和观看距离定：投影的 PPT 要让最后一排看清，海报按远看的距离，书和折页按手持阅读。

## 行距、字距和行长（默认）

- 间距有固定的大小顺序：**字里面的空白 < 字和字之间 < 行和行之间 < 段和段之间 < 栏和栏之间**。顺序一乱，文字就难读。例：行距比字距还小，横排的字会被看成竖排。
- 正文的行高（上一行基线到下一行基线）大约是字号的两倍，也就是行与行之间空出将近一个字高。笔画细、字面小的宋体类行高可以略大，黑体类略小。字越小、行越长，行距越要放宽。
- 标题字大，行距和字距可以收紧，显得紧凑有力；正文字小，适当放松，增加呼吸感。
- 一行不要太长也不要太短：太长，换行时找不到下一行的开头；太短，读起来断断续续。合适的行长是眼睛不用转头就能读完一行。读得快的内容（新闻、说明）行短一些，需要沉下心读的长文行可以长一些。
- 行长靠分栏来控制。各栏宽度保持一致。
- 同样的字号，不同字体看起来大小不一样：字面大的黑体显大，可以用小半号；字面小的宋体显小，要用大半号。英文同字号比中文显小。
- 中文正文优先左对齐或两端对齐；居中只用于标题和短句，长段居中每行开头参差，很难读。
- 断行按意思断：不把人名、专名、数字和单位、一个词拆在两行；标点不放在行首。

## 灰度和粗细（默认）

把一段文字眯眼看成一块灰色。粗字、紧排的文字块颜色深，细字、松排的文字块颜色浅。

- 用灰度的深浅拉开层级：标题深、正文中、注释浅。
- 一组里字号不同的文字，调整字重让整组深浅匀称（见[信息层级 · 同层统一，灰度匀称](information-hierarchy.md#同层统一灰度匀称默认)）。

## 字体的气质（可灵活）

| 想要的感觉 | 字体选择 |
|---|---|
| 高级、经典 | 衬线体、宋体，或简洁的黑体；字重偏细到中等 |
| 力量、冲击 | 笔画粗壮、外形硬朗的黑体，放大到撑满版面 |
| 纤细、优雅 | 字重轻、笔画细的字体，配更大的留白 |
| 柔和、亲切 | 圆角、轮廓圆润的字体 |
| 传统、国风 | 宋体、楷体、书法体；书法体只用在标题 |

带棱角的外形让人想到坚硬，圆的轮廓让人想到柔软轻盈。选字体就是选这种联想。详见[情感与氛围](mood.md)。

## 怎么检查

- 数字体：超过两款就删。
- 数字号：是否和层级数一致。
- 最小的字在实际尺寸和观看距离下能否读清。
- 有没有孤字成行、标点在行首、专名被拆开。
