# 构图：图和字怎么摆

图片最容易抓住视线，所以图片的位置和大小基本决定了构图。先数这一版有几张图，再选构图。

## 只有一张图时（默认）

图通常放大处理。七种常用构图：

| 构图 | 怎么摆 | 什么时候用，注意什么 |
|---|---|---|
| 上下 | 图在上文在下，或反过来 | 最简单、最稳。文字面积可以和图一样大，也可以分主次；文字区小一些更好排 |
| 左右 | 图和文各占一边 | 竖版里文字被挤进又窄又高的区域，难排，常要竖排文字；横版更合适 |
| 上中下 | 分三段，图居中或占两段 | 第三段可以是另一块文字，也可以是留白；留白通常放在文字组和图片之间 |
| 左中右 | 横向分三段 | 竖版少用，对编排要求高；多用在横向更宽的版面，比如横版 PPT、展板 |
| 半包围 | 图放在版面一角，文字在剩下的两侧围着它 | 版面更有个性、有趣 |
| 全包围 | 图居中，文字围在四周 | 留白也是元素，四周不必填满 |
| 满版 | 图铺满整个版面，文字压在图上 | 文字位置由图的内容决定：图里有主体，文字必须避开主体，放在图的“留白”处 |

选择的依据：

- 版面比例：竖版优先上下、上中下、满版；横版（PPT、展板、横幅）优先左右、左中右。
- 图的质量：图够好、主体明确，用满版或大比例；图一般，缩小并靠留白撑气质。
- 文字多少：文字多用上下或左右分区；文字少可以满版或全包围。

## 有多张图时（默认）

先分主次：一张主图加几张辅图，不要几张图一样大地平铺，除非它们本来就是并列关系。

| 构图 | 怎么摆 | 适合 |
|---|---|---|
| 上中下 | 图和文交替成三段 | 步骤、前后变化、几组并列内容 |
| 对角线 | 两张或几张图沿对角方向摆，文字在另一条对角 | 版面有动感，又能保持平衡 |
| 错位 | 图片上下或左右错开，不在一条线上 | 打破呆板，适合时尚、活动类 |
| 模块 | 用网格把版面分成若干格，每格放一张图或一段字 | 图多、信息多：产品合集、作品集、团队介绍 |

并列的图：裁成同样的比例和大小，等距排列，视角和色调尽量统一。要突出其中一张，就只放大这一张。

## 平衡和重心（默认）

- 主体不一定居中，但整体重量要平衡：一侧放了大图，另一侧用标题、色块或足够的留白呼应。
- 版面的一头信息明显过少，会显得往一边倒。把一部分文字挪到空的那一侧。例：标题和说明全挤在上方，下方只有图，就把副题和说明移到底部。
- 四个角是稳定版面的位置：把次要信息压在四角或底边，中间留给主体。

## 一套作品里的构图（默认）

一份 PPT、一本画册、一组海报，统一的是版心、字体、颜色和间距，**不是每页同一种构图**。按内容换构图：封面和章节页可以满版或居中，内容页按图文多少在上下、左右、模块之间切换。连续好几页都是左文右图，会让人疲劳。

## 怎么检查

- 把图和文字块各涂成一个色块，看色块的摆法是否属于上面某一种构图，而不是随手放的。
- 满版图上的文字有没有压到主体。
- 遮住版面的一半，另一半是否明显更重。
