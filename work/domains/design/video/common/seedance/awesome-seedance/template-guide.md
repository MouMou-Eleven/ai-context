## 查一个真实案例，不读全库

能运行Python时，从本目录使用（仓库根目录调用时补完整相对路径）：

```text
python lookup.py --template product-commercial-shotlist
python lookup.py --case seedance-25-diner-frozen-time-rewind
```

第一个命令输出指定模板的结构、适用条件、注意事项和最多两个上游锚点；第二个输出指定案例的原Prompt、作者、原帖、模型和全部复测记录。它只读本地快照，不访问网站、下载视频、调用模型或写文件。参数必须是下表链接中的模板ID或案例链接末尾的slug；未找到必须报告，不能替换为随便一个案例。纯网页AI按模板里的案例链接查看原帖或本仓画廊；打不开就保留未核验状态。

模板的exampleCases是取材锚点，不一定已经跨模型复测。查看retests时区分reproduced、degraded、failed；空列表表示快照未提供复测，finalScore为空不能按0分或高分填补。优先采用与本次输入和镜头最相近、有可核对产物的案例；不按热度替代场景匹配。

## 采用前的冲突判断

1. **画面素材还是最终成片**：需要后期剪辑时保留建委“只生成环境与动作音效、不生成BGM”的规则；音乐卡点模板只在确实制作MV且工具支持时使用。
2. **分镜网格还是逐镜参考**：已有复杂故事板不直接整张上传。明确需要网格方案才读专项Skill，先试少量清晰面板；失败退回主体图＋场景图＋简洁逐镜文字。
3. **时长与分辨率**：模板中的8秒、30秒、4K等来自示例，不是当前模型规格；按当前平台限制拆段，实际看片和检查文件再验收。
4. **视觉风格与事实**：示例中的品牌、人物、产品性能、销量与名人都不是建委项目事实。迁移结构并替换为本次素材，不能靠“电影级”或复制长文堆出结果。
5. **未指定模型**：可先借鉴镜头结构，但不静默指定Seedance或宣称跨模型稳定。需要平台专用语法时核对实际所用工具。

最终至少检查：主体和参考图是否对应、每镜是否只有清楚可执行的主要动作、时长总和与顺序是否自洽、镜头和声音约束是否冲突、生成产物是否满足本次片型要求。暂未生成时只能完成提示词检查。
