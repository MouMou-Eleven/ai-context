# Seedance（即梦）AI 视频提示词

写 AI 视频提示词、做 AI 生成镜头、让参考图动起来时，读这里。所有 Seedance 相关内容都在这个目录：先读建委自己的实战，再按需要查第三方模板库。

**什么时候不用**：纯 AE 合成、Remotion 图形动画、只写口播文案、写介绍 Seedance 的文章、只查资料。只说"做视频"但还没决定哪些镜头要 AI 生成时，先按片型（[宣传片](../../promo/README.md)、[微课](../../education/README.md)、[故事片](../../story/README.md)）决定，需要生成时再来这里。

## 读取顺序

1. **[建委实战工作流](./practical-workflow.md)**（必读）：四段式提示词（主体、场景、声音、镜头）、主体和场景参考怎么用、为什么不要 BGM、清晰度。**这里的规则优先**，和第三方模板冲突时以这里为准。
2. **[建委的三个模板](./prompt-templates.md)**：通用创意导演、战斗动作导演、15 秒视觉叙事。需要 AI 帮你从创意生成整套提示词时用。
3. **[建委的实测案例](./prompt-cases.md)**：一条效果好的提示词的完整拆解，以及哪些写法能复用、哪些有风险。
4. **[第三方模板库](./awesome-seedance/README.md)**（按需）：LearnPrompt/awesome-seedance，25 类镜头模板、497 条案例。当前镜头类型（产品广告、宠物、恐怖、分镜网格转视频……）需要更具体的结构时，先看[模板选择](./awesome-seedance/template-guide.md)，只打开最接近的那一个模板和一个锚点案例，不要全部加载。

## 几条红线

- **声音**：默认只要环境音和动作音，**不生成 BGM**，音乐在后期加。只有做音乐 MV 或建委明确要原生配乐时例外。
- **精确文字、Logo、数字**不要靠提示词保证，后期用 AE 或剪辑软件加。
- **主体和场景参考已经交代的内容，文字里不要再复述**，文字只写这一镜新发生的动作、景别、事件。
- **提示词里的"4K""60 帧""完美口型同步"只是目标**，不代表模型能做到，也不能当作成片验收。
- 模型版本、时长、清晰度、参考图数量上限都会变，执行前在即梦里核对当前情况。

片型方法决定这一段要讲什么、节奏怎样；这里只负责"这个镜头的提示词怎么写"。

- 宣传片、创赛片：[宣传片方法](../../promo/README.md)、[创赛片制作](../../promo/competition-promo-production.md)（带字图片做参考、照片人物动态化、多轮调校）
- 教师微课：[AI 微课画面方法](../../education/ai-generated-microcourse-video-workflow.md)
- 故事片、漫剧：[故事片方法](../../story/README.md)
- 合成、字幕、包装：[AE 制作](../ae-production.md)
