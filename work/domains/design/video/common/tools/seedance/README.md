## 使用规则

- 先确认主交付物与片型，再调用 Seedance。片型方法从 [类型索引](../../../README.md) 进入；教师微课以 [微课设计](../../../education/README.md) 为主入口，可直接组合本工具经验，不必另建 AI 视频片型或混入培训课程。
- 实测经验只对记录时的平台版本和环境负责。
- 时间戳、参数、分辨率和模型能力在执行前必须重新验证。
- 案例不能自动升级为通用平台规则。
