# 三维场景与运镜

程序化搭建三维场景，设计镜头路线，逐帧渲染成片。通用流程（定调、脚本表、渲染管线、迭代）见[通用流程与渲染](../workflow.md)，本页只写三维特有的部分。

## 什么时候用，什么时候不用（默认）

**适合：**

- 科技、工业、城市、设备这类可以用几何体搭出来的场景，比如工厂、数据中心、产线、园区；默认做成全息、线框风格，写实建筑见下面的门槛。
- 需要空间感和运镜的镜头：俯冲进厂房、沿产线穿行、拉升环绕出全景。
- 原理和流程动画：设备怎么工作、信号怎么传、多个站点怎么协同。
- 数字孪生、全息、线框这类“看起来就是数据”的风格。

**不适合：** 真人、写实人物表情、照片级材质特写（布料、皮肤、液体），走 Seedance 或实拍。

### 写实建筑当主角：门槛很高，默认留在全息风格里（默认）

代码擅长的是全息、线框、光带、数据流这类“本来就抽象”的东西；用几何体程序化搭**写实**厂房、写字楼当画面主角，很容易一看就是积木，比全息版还廉价。

- **默认**：要“更真实、更高级”的感觉时，先在全息风格里深化：结构线更密、内部设备看得见、扫描和数据流有层次、局部用实体材质点缀。
- **确实要写实时**，达到下面几条才上屏，做不到就导入现成的建筑模型，或者这一段改用 Seedance、实拍素材：
  - 轮廓有工业特征，不是长方体：锯齿形或坡屋顶、雨棚、管廊、烟囱、冷却塔、装卸月台、屋顶设备，高低错落，每栋都不一样。
  - 立面分层：勒脚、墙身、檐口，竖向分隔；窗按真实比例做成竖长条或横向带窗，不是一格格的正方形。
  - 材质有变化：金属板、玻璃、混凝土各自不同，有脏旧、反射和明暗渐变。
- **风格转换前后要比细节密度**：转换前、转换后各抽一帧并排看，转换后那一侧的细节和精致程度不能低于转换前。转换后反而更简单，观众看到的就是“降级”，想法再好也白费。
- 反例：工厂动画 v3 让光波扫过后线框变成真实厂房。思路建委认可，变化也一眼看得出，但厂房是方盒子、窗户是一格格正方形，建委评价“像积木、很廉价，不如 v2 的全息炫酷”。
- 为什么：观众不会因为“变真实”就买账，只会比较前后哪个更好看。程序化的简单体块只在抽象风格里成立，一旦当成写实，缺的细节全部暴露出来。

## 不同片型怎么用

| 片型 | 常见用法 | 注意 | 状态 |
|---|---|---|---|
| 宣传片（创赛、企业、产品） | 文稿里一句“整体方案”“业务布局”没有素材时，用一段 7—8 秒的三维动画讲清结构；也可做片头的空间展示 | 动画和前后实拍镜头衔接：主色、亮度和前后段协调；字在剪辑里加 | 已验证（创赛） |
| 微课、原理讲解 | 设备结构、工作原理、多站协同的分步演示 | 节奏放慢，每一步停留够看清；镜头少动，重点是讲清楚 | 暂无实战 |
| 故事片 | 不建议，人物和情绪不是代码的长项 | — | — |

## 搭场景（默认）

- **用真实尺寸。** 单位按米，厂房、设备、通道宽度按现实比例搭。比例对了，镜头贴着飞时才有真实的速度感；比例乱了，运镜怎么调都像玩具。
- **实体和发光分开。** 实体（墙、设备）用有光照的材质，发光（线框、光柱、光带）用不受光照、叠加混合的材质；泛光只从发光层吃亮度。
- **先搭主角，再加配角。** 例：智慧工厂先做主车间和产线，再做仓库、数据中枢、远景城市。
- **镜头要经过的地方不放实体。** 通道正上方、镜头高度附近、门洞处要留空，见[运镜 · 路线避开实体](./camera-motion.md#路线避开实体默认)。

## WebGL 技术坑（默认）

| 坑 | 表现 | 原因 | 做法 |
|---|---|---|---|
| 大块黑色方块 | 画面里出现大小不一的黑色矩形，关掉泛光就消失 | 着色器里 `pow(负数, 2.)` 等未定义运算产生 NaN，泛光逐级缩放把它扩散成方块 | 平方写成 `x*x`；`smoothstep` 的两个边界不要反着写；泛光前加一道把 NaN、无穷大清零的处理 |
| 颜色发灰或过饱和 | 和预览颜色不一样 | 自己写的全屏输出又做了一次色彩空间转换 | 最后输出用不做转换的着色器 |
| 加反射后整体发白 | 白色设备冲成一片，地面发灰 | 环境反射、玻璃边缘光、泛光层层叠加 | 先降环境反射，再降曝光，最后提高泛光阈值；查最亮的主体，不只看平均亮度 |
| 细线在 4K 下看不见 | 1080p 正常，4K 线又细又淡 | WebGL 的线固定 1 像素宽 | 要被看到的路径做成有宽度的光带；线框只当肌理 |
| 4K 大面积渐变有色带 | 天空、地面出现一圈圈台阶 | 8 位输出精度不够 | 最后加极细的颗粒 |

## 读取顺序

1. [运镜与流畅度](./camera-motion.md)：镜头路线怎么设计，怎么做到丝滑。
2. [科技感手法库](./visual-toolkit.md)：可选的元素和效果，按内容挑，不是默认样式。

## 检查项

- 镜头路线上没有穿过实体造成的大片黑影或白团。
- 高速段的主角在运动模糊下仍认得出；转向段没有旋转拖影。
- 最亮的主体没有冲白，最暗的画面没有压成一片黑。
