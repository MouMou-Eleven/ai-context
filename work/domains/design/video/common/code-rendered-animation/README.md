# 代码生成动画

用代码把画面或效果做出来：在成片上逐帧画包装、程序化搭三维场景、用图形做 MG 动画等等。它和 [Seedance](../seedance/README.md)（AI 生成镜头）、[AE](../ae-production.md)（模板级包装与合成）并列，是第三种出画面的方式。最大的特点是**可控**：每个元素、每段运镜、每一帧都能指定，改一处就重渲一次，其他地方不变。

本目录管“画面和效果怎么用代码做出来”，按效果类型分门类，每个门类里再写不同片型怎么用。画面上的字号、间距、出场节奏和验收，照常读[代码式视频设计经验](../../../common/code-driven-video/README.md)，两边都要读。

## 什么时候用代码生成，什么时候用别的（默认）

| | 代码生成动画 | Seedance（AI 生成） | AE 模板 |
|---|---|---|---|
| 可控性 | 最高：每个元素、每段运镜、每一帧都能指定 | 低：靠提示词引导，结果要抽卡 | 中：模板结构固定，可换字换素材 |
| 改一处的成本 | 改代码后重渲，其他地方前后完全一致 | 重新生成，整段都可能变 | 改图层后重渲 |
| 擅长 | 结构准确、精确运镜、清晰文字和标注、原理演示、数据感 | 写实质感、人物、自然场景、氛围 | 证书墙、粒子插件光效、现成模板能直接套的内容 |
| 短板 | 写实质感、有机形体、真人 | 结构准确、精确文字、指定运镜 | 没有现成模板的内容；改一轮要重开 AE |

- **画面上要有清楚的文字、数字、标注时，用代码。** 例：飞机总装实拍上的坐标包装，先用 AI 视频模型生成过一版，文字是糊的，改用代码逐帧绘制才清楚。
- **结构必须讲对、运镜必须指定时，用代码。** 例：“智慧工厂整体解决方案”要讲清产线、仓储、数据中枢的关系，Seedance 生成的工厂结构不可控，改用代码搭三维场景。
- **要写实、要人物、要情绪时，用 Seedance 或实拍。**
- 一条片子可以混用：写实镜头用 Seedance 或实拍，结构和原理镜头用代码生成，文字包装按[人机分工](../../promo/competition/ai-production-workflow.md#两种分工模式默认)走。

为什么这样分：建委看重可控，代码生成的每个地方都能说清楚、改得动，适合“这一句必须讲清楚”的镜头；AI 生成适合“这一镜要好看、要真”的镜头。

## 交付前检查表

在[代码式视频检查表](../../../common/code-driven-video/README.md#交付前检查表)之外，再查：

- [ ] 从成片按每 0.25 秒抽帧拼一张总览：没有黑块、黑帧、定格，也没有整屏发白。
- [ ] 每个元素都说得出它在讲什么；同一时刻只有一个主角在发光。
- [ ] 分辨率、帧率和全片一致；交付的是干净版（标题字幕在剪辑里加），除非这单明确要字。
- [ ] 再查本次门类自己的检查项。
