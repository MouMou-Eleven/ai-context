# 代码生成动画：通用流程与渲染

所有门类都适用的做法：从拿到一句旁白或一段素材，到交出成片。各门类自己的做法见对应目录：[三维场景与运镜](./3d-scene/README.md)、[成片上叠加包装](./footage-overlay/README.md)。

## 一、定调和镜头脚本（默认）

1. **先读这一段要讲什么、几秒。** 以真实配音的时长为准，文稿秒数只是预算（见[人机分工 · 前置](../../promo/competition/ai-production-workflow.md#两种模式共同的前置默认)）。用户给了时长范围（例：7—8 秒），按上限做，剪辑时好裁。
2. **一句话定调，告诉用户再做。** 按[审美词库](../../../common/design-principles/aesthetic-vocabulary.md#接到做好看点时怎么做默认)写成“气质 + 主色 + 手段”。例：“深蓝夜景下的数字孪生工厂，青蓝发光线为主、少量暖橙点缀；网格扫描点亮、厂房从地面升起，镜头俯冲进车间沿产线低飞，再拉升出全景。”
3. **写镜头脚本表**：时间段、画面里发生什么、镜头或元素怎么动。每段只讲一件事，按“空间 → 对象 → 关系”的顺序出场（见[出场节奏](../../../common/code-driven-video/motion-and-verification.md#出场节奏默认)）。

| 时间 | 画面 | 镜头 / 元素 |
|---|---|---|
| 0—1.5 秒 | 网格扫描点亮，主厂房从地下升起 | 高空侧移 |
| 1.5—3 秒 | 其余建筑和远景升起，光柱亮起 | 弧线俯冲进门 |
| …… | …… | …… |

为什么先写表：动作和元素出场要对上，先定表再写代码，改动只在表上改，不在代码里试错。

## 二、写代码的规矩

- **所有动画只由时间 t 决定（红线）。** 任何位置、角度、透明度都写成 t 的函数，不用“上一帧的状态 + 增量”，不用不带种子的随机数。为什么：要能单独重渲某一秒、分段并行渲染、用子帧做运动模糊，这三件事都要求同一个 t 永远得到同一帧。
- **程序化生成，不手摆（默认）。** 重复的东西（机械臂、货架、定位点、标签）写成函数批量生成；随机用固定种子。
- **先做主角，再加配角（默认）。** 主角没立住之前加元素只会更乱。
- **字和画分层（默认）。** 要读的文字在最上层单独绘制，不参与发光、模糊、调色；见[代码实现的常见坑](../../../common/code-driven-video/motion-and-verification.md#代码实现的常见坑默认)。

## 三、渲染管线（可灵活）

两条已经跑通的管线，按门类选：

| 管线 | 适合 | 做法要点 |
|---|---|---|
| Python 逐帧绘制（OpenCV + PIL，ffmpeg 编码） | 成片上叠加包装：要读原视频的每一帧 | 读一帧原画面 → 画叠加层 → 合成 → 写入 ffmpeg 管道 |
| 浏览器 + WebGL（three.js，Playwright 驱动 Chrome 截图，ffmpeg 编码） | 三维场景；需要大量发光、粒子、景深的画面 | 网页提供 `renderAt(t)`，脚本逐帧调用并截图，图片直接管道送进 ffmpeg，不落地成几千张图片；启动后先确认用上了显卡 |

两条管线共同的要求：

- **输出**：分辨率和帧率与全片一致，H.264 高码率（crf 14 左右）。默认交**干净无字版**：标题、字幕在剪辑里统一加，要改字时不用重渲。用户明确要标题时另出一版。
- **运动模糊用子帧平均**：每帧在快门时间内渲染多个子帧再平均。累加时权重只乘一次（反例：既乘权重又用带透明度的叠加，亮度被乘两次，全片变暗发灰）。

## 四、迭代节奏（默认）

1. **关键静帧**：每个阶段的关键时刻各出一张，拼成总览看。几秒出一批，用来调构图、曝光、元素。
2. **低清全片预览**：从成片按每 0.25 秒抽一帧拼总览，查运动、遮挡、穿模；有问题的时刻再出静帧细看。
3. **终版**：确认无误再出，从成片里再抽帧复查一遍，并统计每帧平均亮度，最小值太低说明有黑帧。

耗时参考（一台 RTX 4060 Ti 台式机，8 秒三维动画）：1080p、8 子帧约 4 分钟；4K、8 子帧约 15 分钟。4K 约是 1080p 的 4 倍，子帧数翻倍耗时也翻倍。返修时只改被指出的那一类，改完在同一时间点出静帧对比。

代码生成动画还没有确认过的单独报价；创赛片按[报价基线](../../../../other/commercial/quotations/price-baselines.md)的创赛档位整体报。
