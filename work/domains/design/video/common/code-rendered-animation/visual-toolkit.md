# 代码生成动画：科技感手法库（可灵活）

做科技、工业、数字孪生类画面时可以挑的元素和效果。**这是手法库，不是样式**：每条片子按内容挑几样，配色、形状、节奏按主题重新定（见[复用的是手法，不是样式](../../../common/code-driven-video/README.md#复用的是手法不是样式红线)）。下一条片子如果和上一条长得一样，说明挑法错了。

## 挑元素的三条规矩（默认）

1. **每个元素要讲得出在说什么。** 光柱讲“数据从设备上传”，链路弧线讲“各厂房连到中枢”，焊花讲“产线在作业”。说不出意思的元素不加，宁可画面干净。
2. **按时间分批出现，一屏一个主角。** 先空间（地面、网格），再对象（建筑、设备），最后关系（链路、光柱）。同一时刻只让当前主角最亮，其余压低。
3. **加完先查曝光。** 反射、玻璃边缘光、泛光会层层叠加，最亮的白色物体最先冲白。反例：第二版草稿加了环境反射后，立体仓库和机械臂冲成一片白，地面发灰；降反射、降曝光、提高泛光阈值后才恢复层次。

## 元素清单

| 手法 | 讲什么 | 做法要点 | 分寸 |
|---|---|---|---|
| 网格地面扫描点亮 | 空间被数字化 | 地面着色器画大小两级网格，一圈扫描波从中心向外推，波过之处网格亮起 | 开场用；常驻网格要淡，离镜头远的逐渐隐入雾里 |
| 建筑从地下升起 | 工厂被“建”出来 | 用地面裁切平面，建筑从地下整体升起，不压扁变形；升起时底部亮一圈轮廓框 | 按离中心的距离依次升起，跟着扫描波走 |
| 数字孪生扫描光幕 | 全厂被扫描建模 | 一面竖直的半透明光幕从一侧扫到另一侧，底边最亮，带细网格 | 只扫一次，扫完就消失 |
| 玻璃幕墙 | 厂房是透明的数字模型 | 掠射角越大越亮（菲涅尔），加一道慢慢上行的扫描线；屋顶不封，俯视能看到内部 | 正对镜头时几乎透明，不挡内部 |
| 线框描边 | 数字模型感 | 建筑、设备边缘加细线 | 线框是肌理，要被看清的路径改用有宽度的光带 |
| 设备动作 | 产线在运转 | 机械臂按关节层级转动，传送带工件和表面条纹同速流动，堆垛机上下左右移动 | 动作周期错开，不要整齐划一 |
| 焊接火花与焊光 | 正在作业 | 粒子从焊枪尖端喷出，受重力下落，橙白色；焊光随机闪烁 | 只给一部分机械臂，并且一段时间焊一段时间停 |
| 地面流动光带 | 物流路线、AGV 在跑 | 沿路径生成有宽度的带子，光脉冲沿行进方向流动 | 主路线用暖色，辅助线用主色，最多两种 |
| 数据光柱 | 设备数据上传 | 竖直半透明圆柱，光段往上走，越高越淡 | 只放在关键设备和建筑上，不铺满 |
| 链路弧线 | 各单元连到中枢 | 从各建筑顶部画弧线汇到中枢，先逐条“画出来”，再有光包沿线流动 | 光头容易过曝，亮度宁低勿高 |
| 中枢全息环与冲天光柱 | 整体方案的大脑 | 多层旋转环、旋转的菱形核心、向天空延伸的细光柱 | 全片只有一个中枢 |
| 悬浮全息面板 | 数据在实时监控 | 半透明面板上画柱状图、折线、环形仪表，数值随时间变化 | **不放文字**：字在三维里会变形、读不清，标题在剪辑里加 |
| 巡检无人机 | 智能化、有生气 | 小机体带闪烁灯，沿平滑曲线绕飞 | 远景里只是几个闪点，数量少 |
| 远景城市 | 规模和场景感 | 大量低细节楼块加淡线框，放进雾里 | 只当背景，比主体暗一档 |
| 浮尘粒子 | 空气感、景深 | 少量缓慢上升的小光点 | 很淡，不抢主体 |
| 泛光 | 发光物体的光晕 | 阈值调高，只让真正的光源泛光 | 白色实体不能泛光 |
| 速度色散与细颗粒 | 高速感；打散色带 | 色散强度跟镜头速度挂钩，慢下来就没有；颗粒极细 | 收尾静止时看不出色散 |

## 颜色（可灵活）

主色一种、点缀色一种。例：精尺匠造用深蓝底、青蓝发光、少量暖橙（安全线、AGV 顶灯、焊花）。这是那条片子的选择，不是默认；医疗、能源、国风主题要另选。
