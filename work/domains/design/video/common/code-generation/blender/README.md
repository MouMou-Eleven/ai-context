# Blender 建模动画

让 AI（Codex、Claude Code 等）写 Python 脚本驱动 Blender：建模、上材质、布光、设相机、打关键帧、渲染。人不用会 Blender，只负责说清要求、给参考、看渲染图挑错。它是[代码生成](../README.md)的一个门类：模型的形状、材质、灯光、相机、动画都存在 Blender 工程里，AI 不是凭空生成画面，而是替人操作这个三维软件。在浏览器里用 three.js 搭场景是另一个门类，见[三维场景与运镜](../3d-scene/README.md)。

## 两种用法

| 用法 | 做出来的是什么 | 什么时候用 | 方法 |
|---|---|---|---|
| 建模解说视频 | 模型本身就是成片：结构拆开、构件依次出现、高亮、箭头，配旁白和字幕 | 讲清一个结构或原理，要能推近看、能拆开讲、能换主题量产（课件只实践过桥梁） | [modeled-explainer.md](./modeled-explainer.md) |
| 白模预演控 AI 视频 | 灰白粗模的“会动的分镜”，再交给视频模型出写实画面 | 用 AI 生成视频，但镜头轨迹、人物走位、动作时间点、遮挡必须可控，或同一镜头要反复改、批量复用 | [previs-for-ai-video.md](./previs-for-ai-video.md) |

两种用法的开工方式见本页“开工前”；定调、镜头脚本、迭代节奏见[代码生成 · 通用流程](../workflow.md)；成片怎么查见[出片检查](../../video-craft/verification.md)。

## 开工前（默认）

- **让 AI 真的动手做，不要只给操作建议。** 开工先让它查本机 Blender、Python、FFmpeg 的路径和版本，然后写脚本实际执行，保存可编辑的 `.blend` 工程和脚本；收到的是一段“第一步、第二步”的教程，说明它还没开始干活。
- **不预设插件和配置。** 模型、材质都可以全用脚本生成，不装插件；换一台电脑让 AI 自己检测版本、路径和渲染设备，不照抄上一台的配置。
- **一个项目一个文件夹，新版本另开子文件夹，保留上一版。** 参考照片、参考视频放进项目文件夹，工程放 `project`、输出放 `renders` 这类子文件夹。
- **每台电脑的权限、显卡、Blender 版本不一样**，第一次先做几秒到十几秒的低清小样，把流程跑通再加长、提画质（为什么见[第一版粗糙不算失败](./modeled-explainer.md#第一版粗糙不算失败默认)）。

开工指令可以这样写（路径、主题换成自己的）：

```text
请检查当前项目目录和本机工具，确认 Blender、Python、FFmpeg 的实际路径与版本。我要用 Blender 制作一条＿＿视频。请通过编写并执行脚本实际制作，保存可编辑的 .blend 工程和脚本，不要只给操作建议。先列出已有工具与缺少的条件。能完成的步骤继续执行；涉及新的付费服务或缺少账号授权时，准确告诉我缺什么。所有新文件放在当前项目的独立子文件夹中，保留原有文件。
```
