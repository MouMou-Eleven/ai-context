# 代码生成动画

用代码把画面或效果做出来：在成片上逐帧画包装、程序化搭三维场景、用图形做 MG 动画等等。它是 AI 出视频的四种做法之一，另三种是 [AI 生成](../ai-generation/README.md)（扩散模型直接出镜头，目前是 Seedance）、[AI 操作 Blender](../blender/README.md)（驱动三维软件建模渲染）和 [AI 接入 AE](../ae/README.md)；四种怎么选见[视频共用方法 · 四种做法怎么选](../README.md#四种做法怎么选默认)。写入和触发见[视频共用方法 · 写入与触发](../README.md#写入与触发默认)。代码最大的特点是**可控**：每个元素、每段运镜、每一帧都能指定，改一处就重渲一次，其他地方不变。

本目录管“画面和效果怎么用代码做出来”，按效果类型分门类，每个门类里再写不同片型怎么用。画面上的字号、间距、出场节奏和验收，照常读[视频通用设计与验收](../video-craft/README.md)，两边都要读。

## 门类

| 门类 | 是什么 | 例 | 目前状态 |
|---|---|---|---|
| [三维场景与运镜](./3d-scene/README.md) | 程序化搭建三维场景，设计镜头路线，渲染成片 | 智慧工厂、产线、园区、设备原理动画 | 有实战经验 |
| [成片上叠加包装](./footage-overlay/README.md) | 已经有拍好或生成好的视频，在上面逐帧画标注、面板、坐标、扫描线、标题条 | 实拍厂房上标设备位置和空间坐标，镜头上加装备名条 | 有实战经验 |
| MG 图形动画 | 用图形、图标、文字和数据做讲解动画 | 流程图、数据增长、概念讲解 | 暂无实战经验；可编辑参数化动画先看 [Remotion Skill](../../../../other/skills/jianwei-ai-community-remotion-video/README.md) |
| 手绘效果 | 线条逐笔画出、手绘质感的插画动画 | 手绘白板讲解、笔画生长 | 暂无实战经验 |

暂无经验的门类，做第一单时先按本页的通用流程做，做完先问建委要不要新建门类（按[写入规范](../../../../../../system/repository/ingestion-workflow.md)给出放进已有位置和新建两个方案），同意后再建，把学到的写进去。不提前建空目录。

## 什么时候用代码生成（默认）

四种做法的对比和选法统一写在[视频共用方法 · 四种做法怎么选](../README.md#四种做法怎么选默认)。一句话：画面上要有清楚的文字、数字、标注，或结构必须讲对、运镜必须指定时，用代码。

## 读取顺序

1. [通用流程与渲染](./workflow.md)：所有门类都适用的定调、镜头脚本、确定性、渲染管线、迭代节奏。
2. 再读本次对应的门类目录。
3. 排版和验收读[视频通用设计与验收](../video-craft/README.md)。

## 交付前检查表

在[出片检查 · 通用验收表](../video-craft/verification.md#通用验收表默认)之外，再查：

- [ ] 从成片按每 0.25 秒抽帧拼一张总览：没有黑块、黑帧、定格，也没有整屏发白。
- [ ] 每个元素都说得出它在讲什么；同一时刻只有一个主角在发光。
- [ ] 分辨率、帧率和全片一致；交付的是干净版（标题字幕在剪辑里加），除非这单明确要字。
- [ ] 返修版和上一版同一时刻并排：一眼看得出变化，而且新的主画面不比旧的简陋（见[迭代节奏](./workflow.md#四迭代节奏默认)）。
- [ ] 再查本次门类自己的检查项。

本目录管判断，不绑定工具。片型正好对上时，可以调用下面的成套能力，再用[出片检查](../video-craft/verification.md)验收：

| 要做什么 | Skill | 注意 |
|---|---|---|
| 网站、软件、App 的产品宣传片（真实页面截图＋镜头卡＋音效） | [video-shotcraft](../../../../other/skills/video-shotcraft/README.md) | Apache 2.0，可商用 |
| 把一个知识主题做成黑底 MG 科普讲解片（配音、字幕、章节进度条） | [anything2explainer](../../../../other/skills/anything2explainer/README.md) | 非商业许可：客户商单要先取得作者授权 |

它们自带的风格（Ink Press 模板、黑底紫光）是它们的样式，不是建委的默认风格；借它们的流程、组件和质检方法，外观按本次内容定。
