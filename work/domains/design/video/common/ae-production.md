# AE制作与工程交付

## 负责范围

After Effects信息包装、字幕与数据展示、品牌动态视觉、镜头合成、转场和成片交付。本文件保存技术边界，具体项目在work/projects；AI生成镜头不另复制项目。

## 按制作环节调用

| 需要解决的问题 | 入口 |
|---|---|
| AI 动手操作 AE：连 AE、两个 AE MCP 怎么挑、操作和渲染检查 | [AI 与 AE 协作](./ai-ae-collaboration.md) |
| 商单拆解、脚本/分镜、素材、后期与复盘 | [联合制作流程](../../common/production-workflow.md) |
| 企业片信息结构与通用验收 | [企业片工作流](../promo/enterprise/workflow.md) |
| AI 生成镜头、提示词和模型经验 | [AI 视频](../README.md)，再选片型与工具 |
| 企业片的数据、荣誉、卡片镜头怎么做，科技蓝金风格的动效 | [按信息类型拆镜头](../promo/enterprise/info-shots.md) 与 [科技蓝金风格](../promo/enterprise/style-tech-blue-gold.md) |
| 可编辑参数化动画、文字数据动画、参考图动效 | [Remotion Skill 能力入口](../../../other/skills/jianwei-ai-community-remotion-video/README.md)；具体实施读取其 Skill 与当前版本要求 |
| 教育动画与微课 | [微课与 MG 动画](../education/README.md) |
| 查类似商单或沉淀本次经验 | [宣传片案例](../promo/README.md) 与 [案例模板](../../../../../system/repository/templates/case.md) |

AI 按任务所需自动联动上述依赖，不要求建委主动列出跨目录组合。“AE 风格”的生成视频提示词不证明存在可编辑 AE 工程；本次若要求 AE 工程，必须实际交付并验收工程。

## 当前积累与维护

当前 AE 工程实证来自创赛片（精尺匠造、驰热固芯，见[创赛片 AI 代码与 AE 自动化流程](../promo/competition/ai-code-ae-pipeline.md)），其中换哪种片子都成立的操作方法已整理进[AI 与 AE 协作](./ai-ae-collaboration.md)；企业片、MG 动画还没有 AE 工程案例，不把提示词样例当成工程实证。新项目进入项目与案例，AE通用方法就近维护；相关入口按统一更新流程同步。
