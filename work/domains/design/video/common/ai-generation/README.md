# AI 生成视频

用扩散模型直接生成镜头：文生视频、图生视频（让参考图动起来）、参考视频（按一条已有视频的镜头和动作生成）、图加音频（按配音生成口型和动作）。它是 AI 出视频的三种做法之一，另两种是[代码生成](../code-generation/README.md)和 [AI 接入 AE](../ae/README.md)；三种怎么选见[视频共用方法](../README.md#三种做法怎么选默认)。

最大的特点是写实、有氛围、出得快；短板是不可控：结构、精确文字、指定运镜靠提示词保证不了，每次生成都不一样。所以先判断这一镜该不该交给它，再写提示词。

| 内容 | 入口 | 什么时候用 |
|---|---|---|
| Seedance（即梦）提示词：建委实战、模板、案例、第三方模板库 | [seedance/](./seedance/README.md) | 要写视频提示词、生成镜头、让参考图动起来 |
| 设计里用 AI 生成的通用原则：精确信息交给后期、一张参考图只负责一件事、只引用真实素材 | [设计中用 AI 生成的原则](../../../common/ai-generation-principles.md) | 生图、生视频都适用 |
| 镜头和走位必须可控时：先用 Blender 白模定镜头，再用参考视频模式出画面 | [白模预演控 AI 视频](../code-generation/blender/previs-for-ai-video.md) | 复杂运镜、多人走位、要反复改或复用的镜头 |

生成出来的镜头进成片时，和其他做法一样按[视频通用设计与验收](../video-craft/README.md)排字、剪辑、验收（闪、黑帧、停留、转场）。

以后用到即梦以外的模型（可灵等），在本目录下按模型另建文件夹，和 seedance/ 并列；四种输入方式的通用写法再上移到本页。目前只有 Seedance 的实战。
