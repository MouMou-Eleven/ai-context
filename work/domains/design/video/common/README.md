# 视频共用方法

不管做宣传片、微课、故事片、MG 动画还是自媒体短视频都能用的视频方法和工具。整体制作流程（需求 → 素材 → 分工 → 小样 → 交付）见[设计共用流程](../../common/production-workflow.md)，这里不重复。

本目录分两层：**通用层**是所有视频都成立的设计判断和出片检查；**做法层**是 AI 出视频的三种做法各自的经验。片型、比赛自己的要求在片型目录（如[创赛片](../promo/competition/README.md)）。一条经验放哪一层，按[写入规范 · 视频经验写到哪一层](../../../../../system/repository/ingestion-workflow.md#视频经验写到哪一层默认)判断。

## 通用层：不管怎么做都要读

| 内容 | 入口 | 什么时候用 |
|---|---|---|
| 视频通用设计与验收：字号、间距、对齐、版面舒展；出场节奏、转场与闪、停留、跟着配音走；出片检查和通用验收表 | [video-craft/](video-craft/README.md) | AI 自己动手出任何视频（生成、代码、AE、剪辑），开工前读 |

画面本身的排版和审美（层级、留白、对齐、配色）用[设计原则与审美](../../common/design-principles/README.md)，视频画面也是版面。

| 做法 | 文件夹 | 里面有什么 | 什么时候用 |
|---|---|---|---|

“AE 风格”的生成视频提示词不证明存在可编辑 AE 工程；这单要求交 AE 工程时，必须实际交付并验收工程。

## 三种做法怎么选（默认）

| | 代码生成 | AI 生成（Seedance） | AE 模板 |
|---|---|---|---|
| 可控性 | 最高：每个元素、每段运镜、每一帧都能指定 | 低：靠提示词引导，结果要抽卡 | 中：模板结构固定，可换字换素材、改排版 |
| 改一处的成本 | 改代码后重渲，其他地方前后完全一致 | 重新生成，整段都可能变 | 改图层后重渲；用 MCP 改正在打开的工程，改一处看一帧只要几秒 |
| 擅长 | 结构准确、精确运镜、清晰文字和标注、原理演示、数据感 | 写实质感、人物、自然场景、氛围 | 证书墙、粒子、插件光效、三维相机这类现成模板能直接用的效果 |
| 短板 | 写实质感、有机形体、真人 | 结构准确、精确文字、指定运镜 | 没有现成模板的内容；第三方插件本机没装就缺效果 |

- **画面上要有清楚的文字、数字、标注时，用代码。** 例：飞机总装实拍上的坐标包装，先用 AI 视频模型生成过一版，文字是糊的，改用代码逐帧绘制才清楚。
- **结构必须讲对、运镜必须指定时，用代码。** 例：“智慧工厂整体解决方案”要讲清产线、仓储、数据中枢的关系，Seedance 生成的工厂结构不可控，改用代码搭三维场景。要真实建模（产品拆解、设备结构、三维解说）用 Python 驱动 [Blender](./code-generation/blender/README.md)。
- **用 AI 生成、但镜头和走位必须可控时，先用 Blender 搭白模定镜头，再交给视频模型**（[白模预演控 AI 视频](./code-generation/blender/previs-for-ai-video.md)）。3—5 秒、没有复杂动作的氛围镜头，直接生成可能更划算。
- **要写实、要人物、要情绪时，用 Seedance 或实拍。**
- **用户已经挑好 AE 模板、或要模板级的插件效果时，用 AE。** 平面文字包装用代码往往比改模板快（创赛片的实测对比见[两种分工模式](../promo/competition/ai-code-ae-pipeline.md#两种分工模式默认)）。
- 一条片子可以混用：写实镜头用 Seedance 或实拍，结构和原理镜头用代码，模板镜头用 AE，最后统一按配音合成。不管哪种做出来的镜头，都按[出片检查](video-craft/verification.md)验收。

为什么这样分：建委看重可控，代码生成的每个地方都能说清楚、改得动，适合“这一句必须讲清楚”的镜头；AI 生成适合“这一镜要好看、要真”的镜头；AE 模板适合借现成的高完成度效果。

MG 是一种动态图形表达方式，企业、产品、教育都能用。先定信息结构、图形层级、转场和阅读停留时间，再按交付要求选 AE、代码或 Remotion。目前还没有独立验收过的通用 MG 案例。

中文脚本、旁白和字幕，先读[口语样稿](../../../../../system/expression/voice-samples.md)（需要口语时）和[表达短卡](../../../../../system/expression/README.md)。
