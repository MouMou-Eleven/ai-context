# 微课与教育交互

> 长期工作领域：为教师制作微课、精品课和教育交互作品，用于教学、参赛或展示。边界更新：2026-09-18，制作工作台已归入本目录且仅限微课。

## 先按对象区分

本方向负责教师或学校委托的教育设计作品；建委作为讲师备课、授课、培训复盘进入 [AI 培训](../../../training/README.md)。使用 AI 不改变归属，名称中有“课”也不代表会员社群课程。只说“课程/课件”且已有语境不足时，确认对象与交付物，不猜归属。
