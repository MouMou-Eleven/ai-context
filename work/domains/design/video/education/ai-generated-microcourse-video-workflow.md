# AI 教师微课画面生成与多镜头制作方法

- ID：`education-ai-generated-video-workflow`
- 主归属：微课与教育交互
- 状态：当前采用
- 确认依据：2026-09-13，建委根据《小树叶》教师音乐微课的连续修订，明确要求后续同类微课按本方法组织画面、素材和镜头。
- 验证程度：方法已经过一次完整方案迭代、提示词修订和交互页面检查；尚不能据此宣称适用于所有模型或已经通过最终成片、客户与教学效果验收。

## 什么时候使用

适用于以歌曲、旁白、故事或知识讲解音频为主线，需要用 AI 生成插画、MG 动画或叙事镜头，再通过后期剪辑形成完整教师微课的任务。尤其适合以下情况：

- 音频已经确定，画面要逐段贴合歌词、旁白或知识点。
- 同一角色会反复出现，需要保持形象、情绪和动作连续。
- 一个生成片段中需要两到四个机位或镜头变化。
- 需要同时准备场景图提示词和视频提示词。
- 生成结果容易因参考图、人物表情、季节状态或空间关系错误而返工。

以下任务不能只用本方法解决：需要准确展示实操步骤、数据、菜单、公式或规定动作时，应优先使用实拍、录屏、AE、Remotion或后期合成保证事实与文字准确；没有教学目标、脚本或音频依据时，不能先生成一批好看的画面再倒推内容。

## 核心结论

微课画面不是按一句歌词生成一张图，也不是把少量角色图和场景图重复上传到所有片段。稳定的制作单元应当是：

> 一段有完整叙事作用的音频 + 一张状态正确的场景关键图 + 必要的角色资产 + 一次包含合理多镜头的视频生成 + 后期按原音频精确对齐。

音频分镜表与模型提示词承担不同职责。分镜表保留准确时间码，帮助人判断节奏、剪辑和验收；模型提示词用“镜头01、镜头02……”说明事件顺序，不把逐秒时间戳当作模型一定会执行的时钟。

## 一、先把音频变成可执行的画面结构

### 1. 音频是主时间线

先读取完整音频和文案，确认总时长、前奏、演唱或旁白、间奏、尾音与结尾。不能只按文字行数拆分，因为前奏和间奏没有歌词，也仍然需要画面叙事。

为每个音频段记录：

| 字段 | 作用 |
|---|---|
| 全曲起止时间 | 后期定位和检查是否漏段 |
| 对应歌词、旁白或纯音乐 | 说明画面依据 |
| 本段叙事作用 | 建立环境、发生动作、情绪变化、转场或收束 |
| 内部镜头 | 同一次生成里需要哪些景别与事件 |
| 起始状态与结束状态 | 检查与前后片段能否衔接 |
| 所需资产 | 角色图、场景图、上一段合格末帧或音频 |

### 2. 先按叙事段合并，再在段内切镜

一段十几秒的前奏不应只停留在一个静止画面，也不必拆成多个过短的独立生成任务。先确定这段音乐要完成什么，再在同一次生成中安排全景、角色亮相、关系建立和标题等镜头。

在《小树叶》采用的即梦 / Seedance 工作流中，每个独立生成任务不短于 5 秒，最终将约 68 秒音频整理为 9 个生成段，最短段为 5.67 秒。这个数值是本次项目约束，不是所有模型的永久规则；下次制作应先核验平台支持的时长档位，再用相同原则避免大量无意义的碎片。

### 3. 每段只保留一个主叙事作用

同一次生成可以有多个镜头，但这些镜头必须服务同一件事。例如“持续飘动并逐渐害怕”可以先远景跟随、再中近景寻找方向、最后推进到表情特写；“秋风、离枝、落地、春天发芽”属于不同状态变化，不应硬塞进一个片段。

## 二、建立角色、风格、场景三层资产

### 1. 角色资产可以复用

角色图负责锁定身份，包括轮廓、配色、服装或纹理、五官比例和不可变化的特征。重复角色可以建立主体或角色参考图，但角色图不负责决定每一段的背景、机位和情绪。

角色约束应写成可检查的规则，例如：普通背景角色不得长脸，主角不得增生手脚，同一角色的轮廓和五官位置不能漂移。不要只写“保持一致”。

### 2. 风格锚点负责统一世界观

选一到三张已经确认的画面作为风格锚点，定义比例、构图密度、线条、色彩、光影和材质。例如“16:9、二维扁平儿童插画、MG动画、大色块、圆润轮廓、少量平面阴影”。风格锚点只提供视觉语言，不要求所有场景重复同一棵树、同一地形或同一机位。

### 3. 场景关键图要随剧情重新设计

当地点、景别、角色位置、情绪或季节状态发生变化时，应为当前生成段准备新的场景关键图。不能因为已经有五张参考图，就让所有提示词围绕这五张图反复生成。

新的场景图可以继续引用角色资产和风格锚点，但必须重新解决本段的空间与动作需求。例如空中漂流只显示天空和主角，不需要把树妈妈强行放进画面；害怕时需要能推进到脸部特写的构图；生长动画需要完整、固定的整棵光秃树作为起始状态。

### 4. 每张参考图只承担一种明确职责

在提示词开头写清每张图负责什么，也写清它不负责什么：

- `@图片1`：本段起始构图和空间关系。
- `@图片2`：主角形象，不复制其背景。
- `@图片3`：最终季节或色彩目标，不把图中所有对象同时搬入画面。
- 上一段末帧：只在它已经通过角色、表情、构图和状态验收时用于衔接。

参考图是元素、构图、首帧、末帧或某个镜头的依据，不等于整段视频只能在原图上轻微运动。

## 三、决定文生视频、图生视频还是先改关键图

| 情况 | 推荐方式 | 原因 |
|---|---|---|
| 一次性气氛镜头，没有重复角色和精确空间要求 | 文生视频 | 资产一致性要求较低，可以让模型自由构图 |
| 重复角色、明确场景、需要前后衔接或指定开场构图 | 场景关键图 + 全能参考 / 图生视频 | 先锁定主体比例、位置和视觉状态，再安排段内镜头 |
| 参考图的表情、角色数量、季节或物体状态已经错误 | 先图生图或图片编辑，再生成视频 | 视频模型通常会继续继承错误参考，补一句文字很难稳定覆盖 |
| 需要从明确起点连续变化到明确终点 | 起始关键图，必要时补目标状态图 | 适合发芽、生长、变色、满树到光秃等连续变化 |
| 需要复刻上一段空间与动作 | 使用上一段合格末帧 | 只有末帧无变形、状态正确时才可传递 |

表情、连接关系和数量变化是高风险状态。角色是否微笑、叶柄是否仍连在枝头、最终是否所有叶片都离开，这些内容必须先在关键图或硬约束中变成可见状态，不能只依赖“伤心”“离开”这类抽象词。

## 四、场景图提示词的写法

场景图提示词负责生成一张可以直接进入视频阶段的关键图。它应按“参考职责—保持—改变—构图—情绪动作—禁止—验收”编写。

```text
任务：生成[段号/场景用途]的正式关键图，画幅为[比例]。

参考职责：
@图片1只负责[构图、环境或空间关系]；
@图片2只锁定[角色轮廓、服装、五官或材质]；
@图片3只提供[色彩、季节或目标状态]。

保持：[必须保持不变的角色、地形、机位、比例和风格]。
改变：[本图相对参考图必须发生的状态变化]。
构图：[景别、主体位置、运动空间、前后景关系]。
情绪与动作：[眉眼、嘴角、视线、朝向和动作预备]。
禁止：[不该出现的角色、文字、水印、错误状态、变形或多余元素]。
验收：[一眼必须看见的正确状态，以及不能出现的错误状态]。
```

写表情时用眉毛、眼睛、眼睑、嘴角、视线和姿态描述可见变化。例如“不舍”可以落实为眉毛内侧抬起、眼神追随离开的角色、嘴角清楚下弯、不露齿。若参考图仍在微笑，应先编辑成正确关键图；视频阶段不要再上传旧微笑版角色图，否则旧表情可能重新覆盖新状态。

## 五、整段视频提示词的写法

视频提示词负责一次生成中的镜头顺序和状态变化。它应简洁说明主体、场景、音频、镜头、声音和硬约束，不重复长篇描述参考图已经表达的信息。

```text
生成一段[时长]、[比例]的[风格]视频。

参考职责：
@图片1是本段开场关键图，负责[场景、空间和起始情绪]；
@图片2只锁定[主角形象]；
@音频1用于歌曲、旁白或节奏参考。

镜头01｜对应[歌词/旁白/音乐作用]：
[景别与机位]，[主体动作]，[画面事件]，[本镜头结束状态]。

镜头02｜对应[歌词/旁白/音乐作用]：
[切镜或运镜]，[主体动作]，[状态变化]，[与下一镜头的衔接]。

镜头03｜对应[歌词/旁白/音乐作用]：
[需要时增加；不要为了数量强行拆镜]。

声音：只生成[必要环境音与动作音]，不生成新的歌曲、对白或BGM。

硬约束：[角色数量、不可变形特征、起始状态、最终状态、禁止元素和必须完成的动作]。
```

提示词中的“对应歌词或旁白”负责语义顺序，精确时间码留在分镜表和后期剪辑中。模型生成后，将离枝、落地、转头、发芽、表情变化等关键动作剪到对应音频节点，不宣称模型能稳定执行逐秒时间戳。

## 六、四种高频画面怎样设计

### 1. 前奏或无歌词段

先定义它在故事中的作用，再设计两到四个镜头。前奏可以建立世界、介绍角色关系、展示主题标题；间奏应承担转场、视角变化或情绪停顿，不能简单重复开头全景。

### 2. 情绪从环境推进到特写

将远景中的运动和近景中的情绪放在同一次生成内：先跟随主体移动，再切到中近景确认方向，最后推进到眉眼和嘴角特写。需要稳定情绪时，先生成表情正确的关键图。

### 3. 大范围数量或状态变化

“满树叶片全部离开”必须写清开场数量、变化顺序和终态：满树开始、叶片成片离枝、主要枝条显露、结尾完全光秃。只写“树叶离开”容易生成成一片主角叶子离开，其余叶子仍留在树上。

### 4. 连续生长或季节变化

使用固定机位和同一主体完成连续变化：光秃枝条—芽点出现—嫩芽舒展—叶片变绿—树冠丰满。生长必须从枝条上的芽发生，不让地面旧叶倒飞回去。下一段若负责重逢或收尾，应直接从已经长满绿叶的状态开始，不重复上一段生长过程。

## 七、连续性不是重复画面

连续性由角色身份、动作方向、空间关系、起止状态、色彩和前后因果共同建立，不等于重复使用同一张背景。

- 上一段在天空中持续飘动，下一段可以用俯视叶影匹配切到地面，再落地。
- 前一段已经完成生长，下一段展示完整绿树和角色关系，不再长一次叶子。
- 剧情没有树妈妈时不显示树妈妈，避免参考图中的无关元素强行进入画面。
- 新场景沿用角色与风格资产，重新设计机位和环境，既保持世界观又增加画面变化。

## 八、生成、复测与后期

1. 先试做三个高风险段：核心动作、核心表情和最大状态变化。
2. 检查失败属于场景锚点错误、参考图过多、表情错误、动作不清、镜头过碎还是模型随机性。
3. 参考图本身错误时先改图；镜头职责不清时改结构；不要只在原提示词末尾不断堆“必须”。
4. 只把通过验收的末帧传给下一段，变形或错误状态不能继续传播。
5. 最终剪辑以原始音频为唯一主时间线；生成视频的歌曲或BGM静音，必要环境音单独保留。
6. 字幕、准确标题、数据和教学文字由后期可靠工具完成。模型可尝试生成简单标题，但必须逐字验收，不能把提示词中的文字当作正确成片证据。

## 九、逐段验收表

| 检查项 | 通过标准 |
|---|---|
| 内容对应 | 每个镜头能说明它对应哪句歌词、旁白、知识点或纯音乐作用 |
| 起止状态 | 开场承接上一段，结尾给下一段留下正确位置、方向和情绪 |
| 角色一致 | 轮廓、配色、五官、数量稳定，无增生肢体或角色替换 |
| 情绪可见 | 通过眉眼、嘴角、视线和姿态识别，不只靠提示词写了情绪词 |
| 动作完成 | 离开、落地、发芽、说话等核心动作确实发生，不能只有氛围 |
| 场景合理 | 只出现剧情需要的角色和环境，空间能支持本段动作 |
| 镜头节奏 | 一个生成段内镜头数量与时长匹配，没有静止过久或碎切过密 |
| 风格统一 | 画幅、线条、色彩、材质和角色比例属于同一视觉世界 |
| 声音与文字 | 原音频位置正确；无多余BGM、对白、乱码、水印或错误字幕 |
| 终态硬约束 | 数量、季节、表情和物体连接关系达到本段明确终态 |

## 十、交付文件建议

为后续人工制作与 AI 接力，至少保留：

```text
项目/
├── 原始音频与文案/
├── 角色与风格资产/
├── 分段音频/
├── 场景关键图/
├── 场景图提示词/
├── 整段视频提示词/
├── 分镜时间表.csv
├── 交互式分镜页面.html
└── 生成视频与验收记录/
```

多段项目优先按[视频与微课交互式制作工作台](../common/interactive-production-workbench.md)组织页面：一段一卡，按段播放音频、查看参考图职责、复制图片与视频提示词，并回填本段状态、失败修正和验收结果。工作台负责执行和检查，本方法正文负责长期规则，两者不能互相替代。

若浏览器从本地 `file://` 打开时音频或剪贴板失效，应通过本地 HTTP 服务预览，并实际点击播放、复制、图片放大和段落跳转。页面成功打开不等于交互已经可用。
