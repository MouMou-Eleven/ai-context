# 产品宣传片

介绍一个具体产品（硬件、软件、网站、App、智能体）的宣传视频：观众要看懂这个产品是什么、解决什么问题、怎么用、凭什么可信。介绍整个企业的片子放[企业宣传片](../enterprise/README.md)；创赛项目即使主角是产品，也走[创赛宣传片](../competition/README.md)。

本目录还没有建委自己的产品片案例。接到第一单时按下面的做法组合已有方法，做完把案例和新经验写回这里。

## 怎么做（默认）

1. **先定产品片要回答的三件事**：解决谁的什么问题、产品怎么解决（核心功能或结构）、有什么证据（真实界面、实测数据、客户、证书）。每个镜头对应其中一件，答不上就删。
2. **结构和验收借企业片流程**：需求、素材核验、分镜、制作与验收按[企业宣传片通用制作与验收流程](../enterprise/workflow.md)走，把“企业事实”换成“产品事实”。
3. **软件、网站、App 类产品**：用真实页面截图做镜头，可以调用 [video-shotcraft](../../../../other/skills/video-shotcraft/README.md) 的流程和镜头卡；外观按本次产品重新定，不套它自带的模板风格。
4. **硬件产品**：真实产品照片或视频优先；结构说明用可控的三维或 AE 动画，AI 生成的产品画面不能当成实物证据。
5. **AI 自己动手出片**时，叠加[代码式视频设计经验](../../../common/code-driven-video/README.md)；包装完成度参照[创赛视频 · AE 级包装的标准](../competition/ai-production-workflow.md#ae-级包装的标准红线)。

## 写入
