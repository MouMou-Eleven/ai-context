# 创赛片改模板的专属要求与验收

创赛片用 AE 模板出画面时，除了所有视频都要守的通用要求，还有几条只在创赛片里成立的：底部给剪映字幕留一行、签名证书用真实素材、证书框收拢、同一组画面统一字体颜色、全片只用主色。本文件只写这些，并给出创赛片专属的验收表。

不是创赛专属的都不在这里，按层去读：

| 要判断什么 | 读哪里 |
|---|---|
| 排版好不好看：层级、对齐、留白、平衡、两种排法比、外沿共线、就近归属、图要填满框 | [设计原则与审美](../../../common/design-principles/README.md) |
| 视频画面的字号、安全区、版面舒展；动效节奏、闪、转场、停留、片尾 | [视频通用设计与验收](../../common/video-craft/README.md) |
| 用 AE 模板时怎么判断：先设计版面、模板文字组件要用上、只用对应一段、光效对位、新加层做进模板 | [改 AE 模板的设计判断](../../common/ae/ae-template-design.md) |
| 在 AE 里怎么动手：MCP、操作要点、渲染、频闪定位 | [AI 与 AE 协作](../../common/ae/ai-ae-collaboration.md) |
| 创赛片怎么做到：分工模式、按画面用模板、配音对位、包装完成度、思源黑体 | [AI 代码与 AE 自动化流程](./ai-code-ae-pipeline.md) |

## 怎么用本文件（默认）

规则越积越多，靠“读过、记得”一定会漏，所以靠表：

1. **开工时**：把三张表复制成这一单的检查单（每个画面一列）：[出片检查 · 通用验收表](../../common/video-craft/verification.md#通用验收表默认)、[改模板验收](../../common/ae/ae-template-design.md#改模板验收默认)、本文件的[创赛专属验收](#创赛专属验收默认)。先过“模板对应”“版式对照预览”“主色”几行再动手。
2. **交付前**：每一行都填实测值（像素、亮度差、字体名、色差），不能只写“已查”。填不出数值或没出图看过的，按没查处理，回去查。先用眼睛审、再用数字量，做法见[出片检查](../../common/video-craft/verification.md#先用眼睛审再用数字量默认)。
3. **交付说明**里附上填好的表的摘要；没过的行写清原因，并说明是否已和建委确认。

## 创赛片的版面要求（默认）

- **底部给字幕留一行，不留一大片（默认）。** 建委会在剪映里给每条创赛片加一行底部字幕，1080 画面里字幕大约在 y 960—1040。要读的文字、标签、标识不要放进 y 约 950 以下；字幕区以上的空间要用满，不要为了留字幕把整组内容提到画面中上部、底下空出一大片。禁区以上内容放多高，按上下平衡定（见[设计原则 · 留白和平衡](../../../common/design-principles/whitespace.md)），不要把“底边压到某个 y”当目标去凑。反例一：精尺匠造第 5 幕公司段第二版把客户标识条放在 y≈995，压到字幕；反例二：第 7 幕第一版为了“留出底部 18%”把模板的相框整体上移，相框离开了模板设计好的地面，标签被挤到图片上，底下又空着一大块；整组上移后模板的倒影（VC Reflect）跟着上来，文字倒影出现在字幕区，读起来像倒着的乱字，要关掉文字层的倒影、只留图片倒影。反例三：第 14 幕画面二 v2 内容最低点只到 y≈830，建委说“字幕保护区留得太大了”，v3 整组下移 79 像素到 y≈910。
- **签名、证书、标识用客户给的真实素材，不用字体模拟（红线）。** 建委给了签名图，就用签名图；还没给时先用书法字体占位，并在交付时说明是占位。真实签名常是白色细线、四周大片透明：先裁掉透明边，线条按显示尺寸适当加粗（精尺匠造原图线宽约 8 像素、缩到 8% 后不到 1 像素，先在原图上扩 4 像素），同组签名限制在同一个框（约 230×88 像素）里等比缩放，水平居中在卡片下方、同一高度，不出卡片边、不贴上面的文字。反例：第 15 幕 v9 一直是书法字体模拟的签名，建委要求换成真实电子签名。
- **签名、职称、姓名竖排：姓名在上，职称居中，签名在下（默认）。** 签名不要压在姓名上；三者都居中对齐在人像正下方。
- **黑色背景的模板，背景改成主色（默认）。** 人物颁奖、科技类模板常是纯黑底，全片蓝色调里接一段黑底很突兀。在最底层加一层主色径向渐变（精尺匠造：中心 [0.11, 0.39, 0.82]、四周 [0.02, 0.12, 0.36]），网格、地面这类装饰降低不透明度压在上面。

### 证书、文件、人物和同组画面（默认）

下面几条来自精尺匠造第 14—15 幕 v2 建委的逐张意见（2026-11-07）。

- **证书和边框严丝合缝：框按证书比例自动收拢，不留衬底空白（默认）。** 证书模板的相框是按样例图比例做的，竖版、横版、细长的证书放进去后，四周露出一大圈白底或色底，像没做完。证书不能裁（字和章会被切掉），所以改框：
  1. 证书按“完整放进框的窗口”缩放（取宽高比例里小的那个）。
  2. 框是一整张带光效的视频或图片，不能直接拉伸（边会变粗变细）。把框层复制 4 份，每份加一个矩形遮罩只留一个角（以窗口中心为界分成左上、右上、左下、右下），四个角分别向中心平移 sx、sy，sx = (原窗口宽 − 证书宽 + 8) ÷ 2，sy 同理。这样边宽不变，窗口正好比证书小 4 像素一圈，压住证书边缘。
  3. 关掉原整框层和证书背后的衬底层，图层命名写清“边框切片N（随证书比例收拢）”，原框层改名注明“已由切片替代”，建委换证书后重跑脚本即可。
  - 例：精尺匠造第 15 幕奖项模板 7 张证书，脚本 fitframe.jsx 一次处理完；有一张横版证书被存成竖图，先按旋转后的宽高算。
- **同一组画面统一字体和颜色（默认）。** 一个画面用几个模板分别做同一类内容时（论文、专利、奖项），每个模板自带的字体、颜色不同，拼起来像三个片子。统一成一套：建委指定的大字（如“论文”“专利”“奖项”）用同一种书法体，数字行用思源黑体 Heavy，说明行用思源黑体 Bold，金属字统一成同一组蓝色色调（深端约 [0, 0.08, 0.38]、亮端约 [0.16, 0.46, 0.95]），阴影统一。改完把三段的关键帧并排看一眼。反例：第 15 幕 v2 论文的字是浅灰蓝、专利是深蓝，论文的数字行还因为缺字体回退成了衬线体。缺字体的查法见[AI 与 AE 协作 · 字体与文字](../../common/ae/ai-ae-collaboration.md#字体与文字)；字效不一致时直接把兄弟页的文字预合成换进来，做法见文末来源里 2026-11-08 那条。
- **证书、文件图自带的黑边、阴影、透明投影，先裁掉再进框（默认）。** 客户给的扫描件、截图常带一圈黑底、圆角阴影，或 PNG 里带半透明投影；直接放进白色卡框，就是框里又套了一圈深色边，建委说“图片没有和边框适配”。做法：用 Python 找纸面区域裁掉外圈（亮度阈值找白纸；有透明通道的按 alpha 找；浅蓝底的证书按“非白”找），再往里收 1% 左右去掉软阴影；裁完和框窗口比例差在约 9% 以内就按窗口比例铺满（A4 文件、证书只会裁掉一点白边），差得更多的（网页截图、横版页）用纸色补边，不裁内容。例：驰热固芯 4.1 五张检测报告、5.1 十四张论文专利软著卡片都这样重做，脚本 fit41.py、cards51b.py。和上面的“四角切片收拢框”是两种情况：框是带光效的整张素材时改框，框是纯色卡片时改图。
