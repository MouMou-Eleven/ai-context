# 创赛宣传片

大学生创新创业比赛（创赛、大创、科创项目）的介绍和路演宣传视频。其他比赛的宣传片不套这里的结构，见[视频入口](../../README.md)的比赛分流。

## 总览：一部创赛片怎么做

```text
收到文稿和素材 → 定交付范围和规格 → 原句→画面→素材对应 → 每个画面选做法（原素材 / AE 模板 / AI 生成 / 代码）
   → 片头与正文分工 → 提示词与工作台交接 → 多轮调校 → AI 实际出片（模式 A 改模板 / 模式 B 代码复刻）→ 交付检查
```

前半段（到工作台交接为止）是“想清楚、交接清楚”，后半段是“AI 动手做出来”，分别在两份方法里：

| 阶段 | 读哪个 | 里面有什么 |
|---|---|---|
| 想清楚：文稿分析、分镜、选做法、提示词、工作台、多轮调校 | [创赛宣传片制作](./competition-promo-production.md) | 接单规格、原句→画面→素材、叙事结构、指向性选做法、工作台、AI 片头接 AE 标题、参考图、照片动态化、多轮调校、交付检查 |
| 做出来：AI 实际出片，和建委怎么分工 | [人机分工与制作流程](./ai-production-workflow.md) | 配音定时长、模式 A／B 怎么做和怎么选、用 AE MCP 实时改模板、改模板时的设计判断（换字后的字号、依次出现、箭头）、AE 级包装标准、画面文字包装好坏对照 |

AI 自己动手出片时，画面排版、字号、动效验收照常叠加[代码式视频设计经验](../../../common/code-driven-video/README.md)；要做三维动画或在成片上加包装，读[代码生成动画](../../common/code-rendered-animation/README.md)。
