# 创赛宣传片

大学生创新创业比赛（创赛、大创、科创项目）的介绍和路演宣传视频。其他比赛的宣传片不套这里的结构，见[视频入口](../../README.md)的比赛分流。

## 这个板块分三块，按要做的事读

| 要做的事 | 读哪个 | 里面有什么 |
|---|---|---|
| 弄清创赛片是什么、要交什么；读文稿和素材，拆画面，决定每个画面用哪种做法 | [创赛宣传片基础](./competition-promo-basics.md) | 接单规格、交付范围、原句 → 画面 → 素材、叙事结构、按指向性选做法、内容交付检查 |
| 用 AI 视频生成片头、片尾、背景、过渡或缺口画面，写 Seedance 提示词 | [AI 生视频方法](./ai-video-generation.md) | 提示词交接和工作台、AI 片头接 AE 标题、参考图、照片动态化、多轮调校 |
| AI 实际出片：代码预览、改 AE 模板、包装、按配音合成 | [AI 代码与 AE 自动化流程](./ai-code-ae-pipeline.md) + [改模板的排版与验收](./ae-template-layout.md) | 一单怎么走、代码和 AE 两种做法、AE MCP 改模板、AE 级包装标准、经验回流；改模板时的排版判断和交付前排版验收 |

**接到创赛单都先读基础**，再按这一单要做的事读对应的一块；同一单既要 AI 视频又要 AE 出片，两块都读。只要 AI 动手改 AE 模板，[改模板的排版与验收](./ae-template-layout.md)必读：开工时把其中的验收表复制成本单检查单，开工前、静帧、动态三段逐行填实测值，全部通过才交付。两篇的分工：排版与验收写“成片要达到什么”（含所有验收行），流程写“怎么做到、怎么排查”，同一条要求只在一处有正文。

## 一部创赛片怎么做

```text
收到文稿、配音和素材（基础）
  → 原句 → 画面 → 素材，每个画面选做法（基础）
  → 片头片尾背景：写提示词、生成、调校（AI 生视频）
  → 正文：代码预览定版面 → 建委挑 AE 模板 → AI 用 AE MCP 改成预览的版面 → 排版验收 → 建委反馈返修（AI 代码与 AE 自动化 + 排版与验收）
  → 按配音合成，逐幕验收，经验写回仓库
```

AI 自己动手出片时，画面排版、字号、动效验收照常叠加[代码式视频设计经验](../../../common/code-driven-video/README.md)；要做三维动画或在成片上加包装，读[代码生成动画](../../common/code-rendered-animation/README.md)。

## 写入

每轮反馈后，按[经验怎么回流](./ai-code-ae-pipeline.md#经验怎么回流默认)判断要不要写：只收新的判断，写进它所属的那一块；能在画面上核对的，同时在[排版验收](./ae-template-layout.md#排版验收红线)表里加一行；已经写过还犯的，把那一行改成要填数的标准。不新建按片子命名的案例文件；报价改[报价基线](../../../../other/commercial/quotations/price-baselines.md)。规则见[写入规范 · 新的工作怎么沉淀](../../../../../../system/repository/ingestion-workflow.md#新的工作怎么沉淀)。
