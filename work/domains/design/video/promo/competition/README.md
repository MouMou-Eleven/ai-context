# 创赛宣传片

大学生创新创业比赛（创赛、大创、科创项目）的介绍和路演宣传视频。其他比赛的宣传片不套这里的结构，见[视频入口](../../README.md)的比赛分流。

## 按问题读取

| 任务 | 文件 | 说明 |
|---|---|---|
| 收到文稿：分析叙事、拆分画面、选真实素材／AI／AE 模板，写提示词，做工作台 | [创赛宣传片制作](./competition-promo-production.md) | 接单规格、原句→画面→素材对应、片头与 AE 标题、参考图、照片动态化、多轮调校 |
| AI 实际出片：改 AE 模板或用代码做 AE 式包装，剪辑合成；建委和 AI 怎么分工；AE 级包装标准 | [创赛视频人机分工与制作流程](./ai-production-workflow.md) | 两种分工模式、配音定时长、模式 A／B 步骤、经验回流 |
| 一分钟横屏、人机分工、工作台及 AI 片头多轮反馈 | [再净先锋制作规划](./case-zaijing-production-planning.md) | 案例 |
| 标题片头与正文分段、动态停留及群体穿梭 | [聚禾为宝工作台修订](./case-juhe-title-workbench.md) | 案例 |
| AI 代码包装从“简约”改到“AE 式”的对照 | [精尺匠造前 33 秒预览](./case-jingchi-ae-packaging.md) | 案例 |

AI 自己动手出片时，画面排版、字号、动效验收照常叠加[代码式视频设计经验](../../../common/code-driven-video/README.md)。
