# 宣传片制作入口与适用边界

宣传片按片型分三类，先判断这次是哪一类，再进对应目录。AE、AI 生成、实拍、平面动效、代码包装按本次需求组合。

| 片型 | 目录 | 怎么判断 |
|---|---|---|
| 创赛宣传片 | [创赛宣传片](./competition/README.md) | 大学生创新创业比赛（创赛、大创、科创项目）的介绍和路演视频；其他比赛见[视频入口](../README.md)的比赛分流 |
| 企业宣传片 | [企业宣传片](./enterprise/README.md) | 介绍整个企业：形象、业务、实力 |
| 产品宣传片 | [产品宣传片](./product/README.md) | 介绍一个具体产品：硬件、软件、网站、App、智能体 |

三类共用的工具方法：

| 任务 | 文件 | 使用边界 |
|---|---|---|
| AE 工程、排版、合成，或可编辑参数化动画 | [AE 设计能力入口](../common/ae-production.md) | 按工程交付要求选择工具 |
| 写 AI 视频提示词（Seedance / 即梦） | [Seedance](../common/seedance/README.md) | 先读建委实战，再按需查第三方模板；平台能力须重新核验 |
| AI 自己动手剪辑、加包装、出成片 | [代码式视频设计经验](../../common/code-driven-video/README.md) | 片型目录定内容和结构，它管排版、字号、动效和验收 |

## 写入

新单做完，按[写入规范 · 新的工作怎么沉淀](../../../../../system/repository/ingestion-workflow.md#新的工作怎么沉淀)拆成事实、案例、方法三样，放进对应片型目录：案例 `case-*.md` 放该目录，通用做法改该目录的方法文件；提示词经验写进 [Seedance](../common/seedance/README.md)。本 README 只做路由。
