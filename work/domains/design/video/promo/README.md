# 宣传片制作入口与适用边界

> 原实战积累始于 2026-05-25；入口与分层规则更新：2026-09-21。

企业片先确保企业事实、传播目标、信息结构与画面证据一致，再选视觉和工具。AE、AI 生成、实拍、平面动效按本次需求组合；蓝金、HUD、粒子、数字孪生、五大业态与党建都不是通用必选项。

## 按问题读取

| 任务 | 文件 | 使用边界 |
|---|---|---|
| 大学生创新创业比赛（创赛）宣传片：文稿分析、画面拆分、AI／AE 分工与提示词返工 | [创赛宣传片制作](./competition-promo-production.md) | 只用于创赛；其他比赛的宣传片按本目录通用流程走，见[视频入口](../README.md)的比赛分流。按文稿判断结构，选择真实素材、AI 与 AE 模板；含标题／正文分工、动态落版、单参考图和照片动态化；按场景借鉴，不适用于教师微课 |
| 需求、脚本/分镜、素材、制作与验收 | [workflow.md](./workflow.md) | 企业片通用流程；先读 |
