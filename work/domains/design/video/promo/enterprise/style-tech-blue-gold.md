# 企业片风格：科技蓝金

客户选了城市、产业、科技方向，并认可蓝金、通透科技质感时用。这是企业片的**一种**风格，不是默认审美：自然纪实、温暖人物、简洁平面等风格按客户需求另定（见 [README](./README.md#风格按客户定)）。各类信息的镜头怎么拆见[按信息类型拆镜头](./info-shots.md)，提示词写法见[提示词写法与返修](./prompt-iteration.md)。

## 色彩与质感（默认）

- 用：通透科技蓝、冰蓝、银白，少量金色高光；明亮、清透、大气。
- 不用：脏蓝、灰暗、发闷、压抑的画面。

## 包装语言（可灵活）

按信息挑一两种，不是全部上：三维空间穿梭、数字孪生城市、全息沙盘、数据节点、粒子流、蓝色能量光轨、克制的 HUD 圆环、电影级光影。

提示词里写的“AE 高级特效”“OC 渲染质感”“4K”只是告诉模型要什么观感，不代表真的用了 AE、OC 或输出了 4K；需要 AE 工程就实际交 AE 工程。

## 不要什么（默认）

廉价蓝色科技模板、杂乱 UI、低级发光字、无意义的粒子乱飞、过度赛博朋克、与企业业务无关的机器人、芯片、风机等泛素材。

## 动效：哪些显廉价，换成什么（默认）

在这个风格里，下面左列的动效被客户认为不够稳重，右列是替换写法。左列在别的风格（教育动画、活泼品牌）里仍然可以用。

| 不用 | 换成 |
|---|---|
| 回弹、弹性、Bounce | 扫光显影：一道金色扫光掠过，扫到的位置元素逐个显影 |
| 上下滑入、横向滑入、简单飞入 | 遮罩擦除；或带粒子拖尾的飞入 |
| 文字淡入、数字直接淡入 | 文字被一道细光线横向扫描后变清楚；数字按下面的成型链生成 |
| 卡片直接出现 | 竖向光线向两侧扩散成半透明玻璃面板，由暗到亮；边框被金色线条快速描边；图标由粒子点阵凝聚 |
| 一闪一晃、频闪、忽明忽暗 | 稳定后只留体积光扫光缓慢移动、边框轻微呼吸光 |
| 文字跳动、卡片晃动 | 落位后完全不动，只有表面光在走 |

### 数字、文字、徽章的成型链

> **粒子汇聚 → 三维描边 → 向内填充、挤出厚度 → 金属高光与扫光定住**

数据、年份、资质、Logo 节点都可以用这条链写，例子见[企业数据](./info-shots.md#企业数据)。

## 来源与状态

来自 2026-05 济南城市产业类国资企业片（客户认可蓝金科技方向），动效对照是该片反复生成后总结的。只在这一个客户上用过，换客户时先确认对方是否认可这个方向。
