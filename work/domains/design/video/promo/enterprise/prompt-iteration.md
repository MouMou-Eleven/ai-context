# 企业片生成镜头：提示词写法与返修

企业片里要 AI 生成的镜头（数据、荣誉、卡片、开篇、战略）怎么写提示词，生成结果不对时怎么改。各类信息拍什么见[按信息类型拆镜头](./info-shots.md)；提示词的基本结构（主体、场景、声音、镜头）和模型的当前限制见 [Seedance](../../common/seedance/README.md)，本页只写企业信息镜头额外要注意的。

## 一、写法

### 1. 写看得见的画面，不写评价（默认）

- 少写：“表达时代向前、城市向上的开场势能。”
- 改写：“清晨泉水翻涌，水纹扩散后转入城市航拍，建筑群由近及远层层展开，镜头缓慢升起并前推。”

“表达某某精神”“体现某某价值”模型没法执行，只会随便出一张大气的图。

### 2. 写成镜头动作链（默认）

只写“城市航拍、晨光、时间轴、2012 年”这类元素，结果容易是一张静态城市图：没有运动、没有纵深、文字也没有出场过程。要按这个顺序写：

1. **片型和风格**：几秒、什么比例、什么片子、什么色调。
2. **前中后景**：前景（云雾、光粒、建筑边缘）、中景（道路、水系、企业建筑）、远景（天际线、山体），模型才会出空间层次。
3. **按阶段写动作**：场景开启 → 线条和节点被激活 → 镜头推进或穿梭 → 核心信息生成 → 环绕、拉开、稳定。
4. **写生成过程，不只写结果**：不写“出现 2012 年”，写“粒子汇聚、线条描边、数字实体化、轻微发光后稳定”。
5. **写速度变化**：先缓推，中段加速穿梭，接近节点减速锁定，最后轻微环绕或拉远。

反例：

> 生成一支 5 秒城市航拍镜头，清晨济南城市天际线，出现三维时间轴，最终停在 2012 年，整体科技蓝、银白、淡金高光。

正例（同一镜头改写后的核心段）：

> 镜头从高空俯视城市开始，日出从城市天际线后方升起……前景有轻微半透明云雾和光粒掠过，中景是城市道路、水系和建筑群，远景是日出、山体和城市天际线。镜头缓慢向前俯冲推进，城市道路、水系、建筑边缘逐渐出现细腻蓝白光线……随后道路光轨、水系线条和建筑轮廓汇聚成一条银白色三维时间轴……镜头沿时间轴加速推进到一个发光关键节点，随后减速锁定。粒子和光线向节点中心汇聚，线条先描边，再实体化，最终生成清晰、稳重、立体的文字“2012 年”……最后镜头轻微环绕半圈，画面稳定。

可复用骨架：

```text
生成一支 [时长]、[比例]、[片型] [镜头类型]。整体风格为：[本次风格的色调、材质、光影]。

开始：[场景开启]。写清前景、中景、远景和地域特征。
接着：[结构生成]。写清道路、水系、建筑、节点怎样被激活，汇聚成时间轴、沙盘、徽章或数据容器。
然后：[镜头运动]。写清推进、俯冲、环绕、回拉，以及在哪里加速、哪里减速锁定。
核心：[核心信息生成]。写清粒子汇聚、线条描边、实体化、材质，和完整出现的时间点。
结尾：[稳定落点]。写清核心信息和城市、企业、项目怎样同框，稳定段允许哪些轻微运动。

避免：[只写上一版实际出现的失败现象]，以及静态画面、文字乱码、文字不可读。
```

### 3. 引用只写当前工具支持的（红线）

当前平台不能参考视频，就不写 `@视频1 的运镜`、`动作复刻 @视频2`。只上传了一张图，就只写 `@图片1`。每张图写明用途：首帧参考、项目建筑参考、证书或 Logo 参考。工具能力以执行当天在平台上核对的为准。

### 4. 精确内容的约束要写全（默认）

文稿里要出现的名称、数字、顺序，在正文写一遍，在负面词里再写一遍：“不要把‘750 万 m²’改错，不要改变‘管理面积超’的文案，不要让卡片顺序错误。”即便如此，最终的字仍以后期叠加的为准。

## 二、节奏：主画面早出、停够（默认）

信息镜头的目的是让观众读清，所以要写清“**第几秒前完成什么，哪一段持续展示**”。

- 反例：“大约 5 秒时进入主画面，最后定格。”原项目里主画面被压到最后 1 秒，几乎没有停留。
- 正例：“第 2.5 秒前必须完成奖项画面生成，2.5 秒到 9 秒持续停留。”

原项目的目标比例可以参考：9 秒荣誉镜头 2.5 秒前出主画面；6 秒数据镜头约 3 秒前出主要元素，5 秒最终构图落定；5 秒卡片镜头 2.6 秒前出齐。按本次文字量、配音和读完所需时间调整。

时间码是写给模型的目标，模型不保证逐秒执行（Seedance 的实测见[实战误区 4](../../common/seedance/practical-workflow.md#4-给每个镜头写时间戳)）。生成后用实际视频核对；还不准就剪辑掉前段，或者把这段改成确定性的 AE、代码动画。

### 给稳定展示段规定允许的运动（默认）

只写“停留”，模型仍会加特效、换场景。稳定段要写清：

- 不再切换场景，不再新增卡片、数据、文字，不再大转场、不再穿梭。
- 镜头只做非常轻微的推进或呼吸感。
- 保留哪些细节：粒子漂浮、边框流光、细扫光掠过。

先问清客户说的“定格”“停留”是什么：稳定阅读、动作放慢、循环延长还是整幅冻结，分别写相机、主体、背景特效和文字怎么动。稳定段的慢速只管展示阶段，不能把客户认可的高速前段也改慢。

节奏修复句（改时间码就能用）：

> 重要节奏要求：[主体元素]必须在第 [X] 秒前全部出现完成，第 [X] 秒到第 [总时长] 秒保持完整画面停留展示。不要让[主体元素]到结尾才全部出现。后半段不要再切换场景，不要再新增内容，只保留[轻微推进 / 粒子漂浮 / 边框流光 / 细扫光掠过]。

## 三、返修

### 1. 负面词只写上一版真出现的问题（默认）

- 上一版卡片回弹 → “不要回弹，不要弹跳，不要上下慢慢滑入”。
- 上一版主画面最后一秒才出现 → “不要让最终画面只在最后一瞬间出现”。
- 上一版文字闪烁 → “不要频闪，不要忽明忽暗，不要一闪一晃”。

下一版对照看有没有改善；没出现过的问题不预先堆进去。

### 2. 同一个问题反复出现，加一段补充词（可灵活）

主提示词已经很长、模型还是把主画面压到结尾时，在末尾单独加一段 50—150 字的补充词，只处理这一个问题：

> 特别强调：最终奖项主画面不要晚出现，不要只在最后一秒定格。必须在第 2.5 秒前就已经出现完整金色奖项画面，之后持续停留到视频结束。后半段不要再进行大转场，不要再穿梭，不要再切换场景，只保留金色粒子漂浮、轻微扫光、金属反射和稳定的荣誉画面。

### 3. 按需要给几个版本（可灵活）

| 版本 | 内容 | 什么时候给 |
|---|---|---|
| 完整版 | 分阶段动作、前中后景、动效顺序、落点 | 第一遍生成；给客户或剪辑师看画面说明 |
| 精简版（约 300—500 字） | 只留节奏、元素清单、关键动效、顺序约束 | 长版重点被漏掉时换用 |
| 补充词（50—150 字） | 只处理当前反复出现的一个问题 | 加在主提示词末尾再生成 |
| 画面解说版 | 去掉工具用语，只写画面 | 客户审稿、配音稿、镜头脚本 |

只有在用户要比较或当前问题需要时才同时给多版。

### 4. 记录每一版，不无限叠加（默认）

记下每版的失败现象、改了什么、结果有没有变好。改了两三轮还不行，回到上一个相对好的版本换思路，或者把这段交给 AE、代码动画做，不在失败版本上一直加负面词。

## 来源与状态

来自 2026-05 济南城市产业类国资企业片的提示词迭代复盘（主画面压尾、卡片回弹、文字闪烁三类问题）。时间码比例只在那一单的即梦生成上用过，配套成片和版本对照没有归档；换模型、换平台要重新实测。
