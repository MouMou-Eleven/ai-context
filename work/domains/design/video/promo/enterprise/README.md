# 企业宣传片

介绍整个企业的形象片、业务介绍片。先保证企业事实、传播目标和画面证据一致，再选风格和工具。

## 总览：一部企业片怎么做

```text
接单定目标 → 定章节 → 按信息类型拆镜头 → 每镜选做法（实拍 / AE / 代码 / AI 生成）→ 试关键镜头 → 批量制作 → 合成验收
                         │                        │
                  按信息类型拆镜头           生成镜头的提示词与返修
                                                   │
                                      外观按客户选的风格
```

| 要解决什么 | 读哪个 | 里面有什么 |
|---|---|---|
| 从接单到交付的整体步骤 | [制作流程](./workflow.md) | 目标与可信资料、常见章节、分镜字段、素材索取清单、验收表（先读） |
| 某一类信息的镜头怎么拍 | [按信息类型拆镜头](./info-shots.md) | 地域与开篇、企业数据、荣誉与资质、文化与价值观、战略布局、业务板块与产业链、结尾落版，各有做法和例子 |
| 要 AI 生成的镜头怎么写提示词，结果不对怎么改 | [提示词写法与返修](./prompt-iteration.md) | 动作链写法、引用规则、主画面早出停够、稳定段约束、负面词和补充词、多版本 |
| 画面长什么样 | 下面“风格按客户定” | 每种风格一个文件 |

## 风格按客户定

风格由客户的品牌、行业和认可的参考决定，不是做企业片就默认科技风。

| 风格 | 什么时候用 | 文件 |
|---|---|---|
| 科技蓝金 | 城市、产业、科技类企业，客户认可蓝金通透质感 | [科技蓝金](./style-tech-blue-gold.md) |
| 自然纪实、温暖人物、简洁平面等 | 服务型、民生类、注重人和温度的企业 | 暂无实战，做到时新建 `style-*.md` 登记在这里 |

## 不在这里的

- 创赛片走[创赛宣传片](../competition/README.md)；介绍单个产品走[产品宣传片](../product/README.md)。
- 提示词的基本结构和模型当前限制：[Seedance](../../common/seedance/README.md)。
- AE 工程、合成、字幕：[AE 制作](../../common/ae-production.md)；AI 自己动手做包装和出片：[代码式视频设计经验](../../../common/code-driven-video/README.md)。

## 写入

新企业片做完：按[制作流程第 6 节](./workflow.md#6-把本次结果变成下次可用经验)把经验放进对应的那一类，不新建按客户命名的案例文件。

## 来源与状态

目前的方法来自一部企业片：2026-05 给万融集团做的五分钟 AI 宣传片。本目录写的是所有企业片通用的经验，万融只是第一个来源，后面的企业片做完继续往对应的那一类里加；提示词迭代定稿，成片和客户验收没有归档。别的风格、别的行业还没有实战。
