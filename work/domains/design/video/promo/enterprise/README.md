# 企业宣传片

企业形象片、业务介绍片。先确保企业事实、传播目标、信息结构与画面证据一致，再选视觉和工具；蓝金、HUD、粒子、数字孪生、五大业态与党建都不是通用必选项。

## 按问题读取

| 任务 | 文件 | 使用边界 |
|---|---|---|
| 需求、脚本／分镜、素材、制作与验收 | [企业宣传片通用制作与验收流程](./workflow.md) | 企业片先读 |
| 主画面出场太晚、信息停留不足、生成结果偏离 | [企业片提示词节奏与迭代经验](./prompt-iteration.md) | 以失败对照迭代，时间码不是模型执行保证 |
| 客户已选城市／产业科技风，需要具体动效参考 | [科技企业片可选视觉配方](./visual-recipes.md) | 可选配方，不强制所有企业片采用 |
| 找荣誉、数据、卡片镜头的原提示词与项目语境 | [2026 年 5 月企业片提示词实战记录](./case-2026-05-enterprise-prompt-record.md) | 保留原示例，素材与成片验收仍待补 |
