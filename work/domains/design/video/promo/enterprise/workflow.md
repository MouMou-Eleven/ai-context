# 企业宣传片制作流程

从接单到交付的总流程。每类信息的镜头怎么拆见[按信息类型拆镜头](./info-shots.md)，生成镜头的提示词和返修见[提示词写法与返修](./prompt-iteration.md)，外观风格见 [README](./README.md#风格按客户定)。

## 1. 确认目标与可信资料

提取受众、传播场景、片长、比例、品牌规范、交付格式、源工程要求与验收人。配音已经确定且本次未要求修改时，以实际配音时长拆分；需要短版时明确重新剪稿和配音范围，不凭推测改变时长。

有旧片时抽关键帧并对照客户修改意见，标出保留、删除、压缩与强化内容；没有旧片则从素材清单开始。素材已经按段落分类、文稿用颜色或括号标注时，先核对这些对应关系；已有匹配素材以原素材为主，通过剪辑、照片动效与AE包装改善变化，AI补缺或增强。失配、低清与证据不足要说明，用户明确指定创意重做的段落按本次范围执行。创赛细则见[素材优先与工作台交接](../competition/competition-promo-basics.md#先定这次交付什么红线)。企业、建筑、项目、员工、业务、数据、奖项和证书使用已核验材料，AI 生成的示意画面不能代替企业实绩证据。

## 2. 从信息点拆分镜

先定章节，再在章节里按信息类型拆镜头。企业片常见章节如下，按本次传播目标和文稿增减，不是每家都要全有：

| 章节 | 作用 | 对应信息类型 |
|---|---|---|
| 开篇 | 建立地域、企业、气质 | 地域与开篇、企业数据 |
| 理念与文化 | 价值观和温度 | 文化与价值观 |
| 组织属性（国企、党建等，有才做） | 身份与背书 | 荣誉与资质，配真实资料 |
| 战略 | 发展格局 | 战略布局 |
| 各项业务 | 做什么、做到什么程度 | 业务板块与产业链、企业数据 |
| 实力与荣誉 | 凭什么可信 | 荣誉与资质 |
| 结尾 | 品牌收束 | 结尾落版 |

例：2026-05 万融集团的五分钟 AI 宣传片用的是“开篇 → 理念 → 党建 → 战略 → 建设、运营、新兴产业三块业务 → 结尾”。

一个镜头服务一个主要信息，复杂段落拆为可执行镜头组，不把成立年份、多个财务数据和评级挤进一个大提示词（正反例见[按信息类型拆镜头](./info-shots.md#先把一段话拆成一类一镜红线)）。

| 分镜字段 | 应说明的内容 |
|---|---|
| 编号 / 时间 | 镜头起止或预计时长、对应配音 |
| 信息与事实来源 | 口播/字幕、数据依据、参考素材 |
| 画面与运动 | 主体、前中后景（需要时）、动作起止、镜头路径与节奏 |
| 制作方式 | 实拍剪辑、人工设计、AE/代码动画、AI 生成，或组合 |
| 交接 | 与前后镜头的连接、声音、字幕/Logo 叠加位置 |
| 生成镜头附加项 | 所选工具可用的引用方式、单镜头提示词、针对约束与失败的限制 |
| 检查点 | 核心信息何时完整、需要展示多久、文字可读与素材保真要求 |

脚本与旁白调用 [表达短卡](../../../../../../system/expression/README.md)。分镜需要生成镜头或 AE 合成时，按 [联合流程](../../../common/production-workflow.md) 自动补依赖。

## 3. 先试关键镜头，再批量制作

- 先验证最难的主体、动作、文字/数值或衔接，记录模型与实际版本、提示词和结果。
- 提示词描述可见画面和动作链，避免只说“体现精神、展示势能”等抽象评价。
- 引用方式服从当前工具能力；支持图像不等于支持视频，不能未经核验使用 `@视频`。
- 精确数据、中文、Logo、证书优先使用可核验素材或可靠后期叠加；生成模型出现乱码时采用设计/合成修正。
- 信息过晚或运动偏离时，按 [节奏迭代](./prompt-iteration.md) 只修当前问题。时间码需用实际输出验证，必要时用剪辑或确定性动画控制。
- 包装形式服从品牌和目标。简洁平面、实拍纪实或科技视觉均可成立，不以特效数量评判质量。

## 4. 按分镜索取素材

不要只说“给项目素材”，按分镜一项项要：

| 类别 | 要什么 |
|---|---|
| 品牌 | Logo、VI、标准色、字体、落版规范 |
| 企业本身 | 办公楼、门头、员工、会议、沙盘、项目现场 |
| 地域 | 城市地标航拍、项目航拍和夜景 |
| 数据与资质 | 数据的出处和统计口径；资质证书、评级、获奖证明原件 |
| 各业务板块 | 每个板块的真实项目和服务现场（文稿提到几块就要几块） |
| 组织属性（有才要） | 党建阵地、活动、荣誉等真实资料 |
| 旧片与工程 | 旧版宣传片原片、原始素材、可复用工程 |
| 授权 | 音乐、字体、素材的授权 |

## 5. 合成、交付与验收

| 必检事项 | 验收方式 |
|---|---|
| 信息正确 | 对照已批准口播、字幕、数据、Logo 与证明材料，避免生成画面伪造业务或资质 |
| 完整可读 | 核心信息有足够稳定展示时间；实际观看文字、数字、字幕、裁切和遮挡 |
| 连续与节奏 | 检查镜头连接、画面运动、声音、口播同步，不以“最终定格”代替充分阅读时间 |
| 风格适合 | 对照本次品牌和批准参考检查，无无关科技素材或装饰，具体风格不作跨项目强制要求 |
| 技术交付 | 核对约定比例、时长、尺寸、编码、声音、源工程/可编辑参数与素材完整性 |
| 证据与状态 | 保存成片/工程位置、客户反馈与验收状态；未验收就写未验收 |

需要 AE 工程时必须交付实际工程；提示词里出现“AE 风格”不能满足此要求。需要参数可改动画时可从 [Remotion 能力说明](../../../../other/skills/jianwei-ai-community-remotion-video/README.md) 进入，按其当前执行与验收契约开展。

## 6. 把本次结果变成下次可用经验

按[写入规范 · 新的工作怎么沉淀](../../../../../../system/repository/ingestion-workflow.md#新的工作怎么沉淀)：新学到的某类信息的做法改 [info-shots.md](./info-shots.md) 对应那一类；提示词和返修经验改 [prompt-iteration.md](./prompt-iteration.md)；新风格写一个 `style-*.md` 并登记到 [README](./README.md#风格按客户定)；客户、价格、进度写进项目或案例。只有文案或提示词、没有成片时标明状态，不把“定稿”当成“已生成合格成片”。
