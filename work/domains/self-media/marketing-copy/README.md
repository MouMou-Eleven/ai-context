# 营销文案与推广文章

## 负责范围

- 不绑定单一平台的营销文章、活动推广文案、产品介绍和转化页面文字。
- 把人群、问题、证据、产品价值和下一步行动组织成完整的推广表达。
- 跨平台可复用的营销结构和复盘经验；具体渠道文案优先归入对应渠道目录。

## 当前方法

| 文件 | 何时读 |
|---|---|
| [读者问题驱动的宣传](./reader-question-led-promotion.md) | 产品介绍、社群宣传、报名详情页与购买顾虑解释；含真实改稿差异、问题顺序和成品验收 |

用户只指定本文件夹时，先判断读者与用途，再实际读取上表命中的方法；不能只阅读本索引。通用中文与实际版本验收分别由[表达短卡](../../../../system/expression/README.md)和[执行流程](../../../../system/repository/execution-checks.md)承担。

## 分类边界

- 公众号知识文章和长图文进入 [`../articles`](../articles)。
- 朋友圈短文案进入 [`../moments-copy`](../moments-copy)。
- 社群内部文案进入 [`../community-copy`](../community-copy)。
- 直播销售和实时承接进入 [`../live-sales`](../live-sales)。

## 写入要求

- 先说明面向谁、解决什么问题、凭什么相信，再写产品或行动，不用空泛承诺代替证据。
- 明确区分已验证结果、创作者判断和待测试假设。
- 语言基础统一读取 [`../../../../system/expression/README.md`](../../../../system/expression/README.md)；口语化文本再读取 [`../../../../system/expression/oral.md`](../../../../system/expression/oral.md)。本目录只维护营销目标、证据组织和行动设计。

已收录建委认可的宣传组织方法与来源；完整成品留原项目或飞书。后续新增内容注明渠道、目标、版本和验证状态，同一方法补充证据而不重复建文件。
