# 自媒体标题与选题

## 负责范围

- 标题结构、选题来源、目标人群和场景翻译。
- 开头钩子与标题承诺的一致性。
- 已发布内容的标题测试与复盘。

## 当前有效原则

- 优先使用“人群 + 具体场景/问题 + 可见结果”，少用只有技术名词的标题。
- 标题必须与正文和交付一致，不能用无法兑现的结果吸引点击。
- 一条内容通常只解决一个主要问题。
- 没有真实案例和数据时，不使用“翻倍、必火、人人都能”等效果承诺。

## 可直接使用的Skill

[Title Matrix 标题矩阵](./title-matrix/README.md)：第三方 [zhouwei713/title-matrix](https://github.com/zhouwei713/title-matrix)，包含完整原版、MIT许可及固定版本。2026-09-24建委反馈试用效果可以并要求收录；非自研。

明确要起题、改题、评审时使用；写自媒体文章需要拟标题时也自主使用，不要求建委再次点名。先读能力卡，再实际读其SKILL和平台参考。保留原标题、只改正文、查询资料时不另拟题；正式书稿与课堂标题不默认套用。标题与文章正文、读者问题宣传的分工及上游经验边界，以能力卡为准。

当前尚未形成独立的建委账号标题案例库；上游示例不是本人发布记录。新增案例必须来自真实发布或明确测试，注明证据与适用范围。
