# 落点细则与字数核验

本文件给的是写作建议和观察值，不把未经证实的展示经验写成平台算法。平台字段和界面会改版，临近硬上限或准备发布时以当前官方编辑器和官方规则为准。

## 先判断产物，平台名不够用

| 落点 | 交付的到底是什么 | 首要任务 |
|---|---|---|
| 微信公众号 | 文章标题 | 前段说清对象和看点，同时扛住打开和转发两个场景 |
| 小红书 | 笔记标题 | 保住用户会搜的主题词，同时给出具体结果或场景 |
| X 短帖 | 正文第一行，没有标题字段 | 第一行独立成立，直接落在事实、动作或判断上 |
| X 长文 | 长文标题字段 | 脱离账号上下文也能看懂，适合卡片展示 |
| 抖音 / 视频号 | 视频标题或描述首行 | 与前三秒画面和视频实际内容互相兑现 |

同一平台可能有多个入口、终端和卡片样式。不要把某一张截图里的折叠位置写成永久固定值。

## 微信公众号

标题要同时过两关，**我想点**和**我转出去不丢人**。第二关是公众号独有的。一个太 low 的标题用户会点但不会转，而转发是这里的主要增量来源。这也是三档在公众号的真实上限，顶得过了用户会点但不会转。

长标题（30 到 40 字）在这儿是主流且有效，但前段必须独立传达内容，不能把核心结果藏在末尾。

主题实体、冲突或交付物优先放前段。「一文讲透」「完整教程」「附模板」这类承诺必须由正文结构和真实交付物支撑。

## 小红书

字数空间紧，先保住主题词、使用对象和结果，减掉背景铺垫。这点空间要同时干两件事，被搜到，以及在信息流里勾住人。

写完先自问一句，用户会在搜索框里打什么，那句话在不在前半段。搜索词要自然出现，不能为堆词破坏可读性。

封面图承担第一点击力，标题负责补搜索词和结果。语气像朋友安利，不像品牌文案。

关于「前 N 个字是搜索权重区」这类说法，**属于运营经验不是平台规则**，没有当前可追溯的官方依据就不要写成规则。可以说「主题词放前半段更容易被搜索命中」，别说「前 10 字是权重区」。

## X 短帖

短帖没有独立标题字段，交付的是正文第一行。

- 删掉「先说结论」「有件事很有意思」「最上头的一点」这类预告句，它们只宣布后面有信息，本身不带信息。
- 一句话优先表达一个信息点，短到能一口气念完。
- 不要写成总起、展开、收口的三段式，那是公众号节奏贴到 X 上，读者划过去的速度不给你铺垫的机会。
- 黑话和内部名词要么不用，要么当场解释，读者没读过你的原文。

## X 长文

长文有真正的标题字段，逻辑更接近公众号，但卡片比公众号列表窄，要写得更紧凑。

标题会被当成链接转发，脱离你的账号也要能独立成立。

短帖第一行可以拿最有画面的细节，长文标题可以拿最能代表全文的判断。两者不强制不同，但撑同一个点就是浪费一次曝光。

## 抖音与视频号

标题本身通常不直接进推荐判定，但它决定前三秒留不留人，而完播率才是分发的命门。所以抖音标题的真实任务是给前三秒画面配一个钩子，不是概括视频。

标题必须与前三秒画面、口播或字幕一致。不用正文没有回答的悬念换停留。

视频号偏熟人和私域，同样的内容要收着写，降低空泛夸张，增加具体对象和结果。

不断言标题是否直接参与推荐排序，除非有当前的官方依据。

## 字数和折叠位怎么核验

需要精确校验时按这个顺序走。

1. 先确认发布形态和当前编辑器。
2. 记录平台如何计算中文、英文、数字、空格、标点和 emoji，口径可能跟你的计数不同。
3. 用编辑器实测硬上限。
4. 折叠位按目标入口和设备截图验证，结果写成观察值，标明是在哪个入口、哪个终端看到的。
5. 没实测过就用「建议控制在」或「约」，不标成官方上限。
