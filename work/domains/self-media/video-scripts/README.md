## 使用顺序

1. 明确目标人群、具体场景和这一条内容的唯一目标。
2. 选择 PREP、SCQA、故事或步骤结构。
3. 填入真实依据、案例和结果。
4. 检查信息密度、自然口语和承诺边界。
5. 结尾完成内容目标；需要报名、领取、练习或购买时确定一个主行动，纯观点和记录可以自然收束。

脚本方法不自动带入任何培训或社群事实。
