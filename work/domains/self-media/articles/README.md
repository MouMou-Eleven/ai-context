# 自媒体文章与图文

## 负责范围

- 公众号、图文平台、长文章和知识型内容。
- 文章结构、信息密度、案例、图片位置和读者行动。
- 同一主题从短视频扩展为文章的方法。

## 当前原则

- 先说明读者为什么需要，再展开知识和步骤。
- 用真实场景、案例和结果支撑判断，不把口播稿直接拉长成文章。
- 文章可以完整，但不能靠重复和概念堆砌制造长度。
- 需要写操作教程时，明确受众、前置条件、步骤和验收。

公众号和知识型长文归入本目录；以推广、转化或产品行动为主要目的且不绑定公众号渠道的文章，归入 [`../marketing-copy`](../marketing-copy)。朋友圈、社群和直播文字按渠道分别归入对应目录，不在这里重复保存。

当前尚未形成独立文章模板库；后续只保存经过真实发布或项目验证的经验。
