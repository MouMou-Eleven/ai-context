# 朋友圈文案

## 负责范围

- 朋友圈短文案、连续多条朋友圈组合和配图说明。
- 个人动态、项目进展、案例展示、观点表达和活动预告。
- 朋友圈中的自然互动与行动引导，不承担直播间实时销售流程。

## 分类边界

- 社群内部通知和群内话术进入 [`../community-copy`](../community-copy)。
- 直播销售和评论区承接进入 [`../live-sales`](../live-sales)。
- 公众号或长篇知识文章进入 [`../articles`](../articles)。
- 跨平台营销结构进入 [`../marketing-copy`](../marketing-copy)。

## 写入要求

- 一条动态只承担一个主要目的：展示结果、表达观点、记录过程或引导一个行动。
- 个人经历、项目事实和待验证判断分开写，不编造数据、客户和效果。
- 语言基础统一读取 [`../../../../system/expression/oral.md`](../../../../system/expression/oral.md)；本目录只维护朋友圈的长度、节奏和上下文呈现。

当前尚未收录独立朋友圈案例库；后续新增内容必须注明发布时间、场景和反馈。
