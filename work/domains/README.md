# 领域知识

按业务、技能和行业属性进入总类，再逐层进入交付物、子类和具体方法。每个领域承接本业务从接洽到交付的SOP；归属怎么判断见[写入规范 · 先按业务确定归属](../../system/repository/ingestion-workflow.md#先按业务确定归属默认)。

| 领域 | 范围 |
|---|---|
| [设计制作](./design/README.md) | 平面与演示、视频动画、教育作品及共用制作方法 |
| [应用开发与自动化](./development/README.md) | 开发方法、平台工具、排错与自动化 |
| [培训与教学](./training/README.md) | 建委作为讲师的需求接洽、方案大纲、课程设计、授课与复盘 |
| [自媒体与个人IP经营](./self-media/README.md) | 选题、内容、朋友圈、直播和运营经验，不限AI主题 |
| [其他领域](./other/README.md) | 跨行业商业方法及未来有明确职责的新业务 |

具体客户、书稿、课程产品和开发产品统一从[项目与案例](../projects/README.md)进入。领域页提供相关项目链接，不复制项目当前状态。新增方法只在最适用的位置维护，必要依赖通过链接组合。
