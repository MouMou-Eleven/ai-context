# 行业应用案例

按实际行业保存应用开发、自动化和智能体的可复用方法及实践记录。开发过程、领域判断和运行证据放在对应行业；通用编程规则仍回[开发经验](../experience/README.md)，具体工具操作仍回[工具知识包](../tools/README.md)。

| 行业 | 内容 |
|---|---|
| [教育行业](./education/README.md) | 教育智能体与课堂任务的融合、工作流和教学数据设计、参考案例提炼及实际验证 |

新行业有真实需求和独立方法时再按仓库写入规则建立，不预建空行业。每个行业至少维护一个方法正文，案例提供输入、决策与结果，参考材料提供来源及采用边界。
