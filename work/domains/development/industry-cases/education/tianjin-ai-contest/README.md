# 天津市 AI 教育大赛（赛道二）

给客户准备天津市 AI 教育应用场景、智能体设计应用和课程案例大赛**赛道二（教育智能体设计应用）**的作品和参赛材料。目前客户参加的是 2026 年这一届；以后几届先拿新通知对照[提交材料](./submission-package.md)第一节，变化直接改那一节。

## 做一个新的参赛作品，按这个顺序读

| 步骤 | 读 |
|---|---|
| 1. 定课堂场景和学科融合方式 | [学科融合方法](../subject-integration/classroom-agent-design.md) |
| 2. 在指定平台搭建 | [平台能力体系](../tianjin-platform/capabilities.md) + [搭建流程](../tianjin-platform/build-sop.md) |
| 3. 整理提交文件夹和复现材料 | [提交材料与文件夹](./submission-package.md) |
| 4. 写申报书、技术说明与验证报告 | [Word 文档规范](./document-format.md) |
| 5. 写逐字稿、录屏、剪辑 | [演示视频](./demo-video.md) |

只做其中一项（比如"重写数学的技术报告"）时，读这一项对应的文件，再加读[文档规范](./document-format.md)第一至三节，那三节是所有评审材料共用的红线。

## 换一个比赛、换一个客户时（默认）

天津这套是第一次全包做下来的完整流程：读通知 → 选题 → 平台搭建 → 提交文件夹 → 申报书和技术报告 → 逐字稿 → 录屏剪辑 → 交付自查。别的智能体比赛、教育应用比赛，流程骨架和大部分判断可以直接用；要换的只是"这个比赛自己规定的东西"。

| 环节 | 直接沿用 | 按新比赛重定 |
|---|---|---|
| 读通知 | 把通知拆成一张要求表（格式照[提交材料](./submission-package.md)第一节），每条要求对应一份材料或一个章节；评分标准逐条对应作品的亮点 | 表里每一行的内容 |
| 选题与学科融合 | [学科融合方法](../subject-integration/classroom-agent-design.md)全部 | — |
| 搭建 | 学科融合方法里的组件职责、核验和留证 | 平台：[天津平台](../tianjin-platform/README.md)的能力和步骤只对这个平台成立；换平台先在[开发入口](../../../README.md)找有没有该平台的经验，没有就边做边记 |
| 提交文件夹 | 三个文件夹的分法：评审提交、单位材料、内部工作资料；工作提示不进评审包（红线） | 具体文件清单、命名和格式限制 |
| 申报书、技术报告 | [文档规范](./document-format.md)第一至三节：写给评委、扬长避短、团队表只空姓名（红线）；第五节字体写到底层 | 第四节的版式参数、章节顺序和模板处理，按新比赛的模板和通知 |
| 逐字稿与视频 | [演示视频](./demo-video.md)第二节逐字稿；[录屏讲解视频](../../../../design/common/code-driven-video/screen-recording.md)的录制、运镜、标注和自检 | 时长、格式、大小限制；片段结构按评分重点重排 |
| 链接与交付检查 | 平台生成的链接原样复制到一个核对文件，所有材料从它取，交付前用脚本逐字比对（见[成品自查 · 链接](../../../../../../system/repository/execution-checks.md#链接要整条复制红线)） | 平台特有的链接参数（如天津的 appid） |

新比赛的第一单做完：比赛专属的事实（通知要点、模板、提交清单）问建委后建这个比赛的目录（按 [AGENTS](../../../../../../AGENTS.md) 写入规则第 7 条给出两个方案）；通用判断改回上表左列那些方法文件，不复制一份天津的。

## 新经验写到哪

| 新经验是关于 | 写进 |
|---|---|
| 比赛要求、提交文件、文件夹、复现材料 | [submission-package.md](./submission-package.md) |
| 申报书、技术报告的版式、字体、措辞、团队表 | [document-format.md](./document-format.md) |
| 逐字稿、本赛录制、视频结构 | [demo-video.md](./demo-video.md) 对应环节；零散反馈先进第六节积累区 |
| 剪辑、运镜、画面标注、版式、转场、配音对齐 | [代码式视频设计经验](../../../../design/common/code-driven-video/README.md)对应文件，别的片子也要用 |
| 平台功能、节点、导入导出、坑 | [平台能力体系](../tianjin-platform/capabilities.md) 或 [搭建流程](../tianjin-platform/build-sop.md) |
| 学科怎么融合、课堂怎么用 | [学科融合方法](../subject-integration/classroom-agent-design.md) |
| 某个作品的 ID、链接、路径、进度、当次问题 | 该作品的案例文件 |
| 新客户的新作品 | 新建 `case-<作品英文短名>.md`，并在上面"已做的作品"表加一行 |

规则：先在对应文件里找同一件事，有就改那一条（补反例、改具体），没有才加；不为一次视频、一份报告新建方法文件。
