# 天津指定智能体平台

天津市 AI 教育大赛赛道二指定的智能体创作平台（`aiagent.tjtc.edu.cn`），结构与开源扣子（Coze Studio）相近。凡是在这个平台上给客户搭智能体，不管是不是为了比赛，都从这里开始。

| 要做什么 | 读 |
|---|---|
| 了解平台有哪些资源和节点、怎么组合、哪些坑踩过 | [能力体系](./capabilities.md) |
| 实际动手：登录、导入骨架、修改、验收、发布、评审链接、清理、导出 | [搭建流程](./build-sop.md) |
| 智能体怎么和学科、课堂结合（与平台无关） | [学科融合](../subject-integration/README.md) |
| 比赛要交什么、文档和视频怎么做 | [天津 AI 教育大赛](../tianjin-ai-contest/README.md) |

平台本身的新发现（新节点、新限制、新坑、新的导出方式）写进上面两个文件对应的小节，不新建文件；某个客户作品的 ID、链接、进度写进它的案例。
