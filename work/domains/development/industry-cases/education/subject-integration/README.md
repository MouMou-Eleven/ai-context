## 新案例怎么加

建委给来新的参考课例或分析材料时：

1. 一批材料建一个 `case-external-<学科>-<短名>.md`，按"当时的难题、学习动作、AI 分工、技术依赖、课堂产物、教师反馈、可借鉴、不照搬"写；获奖、人数、效果数字标"未核验"。
2. 在上表加一行，"机制"一列写一句话。
3. 案例里出现方法里没有的新机制、新融合手段或新场景，补进[学科融合方法](./classroom-agent-design.md)对应的表；已有的就在那一行补例子，不新起一节。
4. 建委自己做的作品写在作品所在位置（天津大赛的在[大赛目录](../tianjin-ai-contest/README.md)），这里只加一行链接。
