## 文档已确认的能力

| 能力 | 文档口径与开发含义 |
|---|---|
| 工作流调用 | 可视化组合模型、代码、插件等；智能体中的工作流配置类似插件，可设置调用方式，且可直接输出结果，避免外层模型再次总结 |
| 开始与结束 | 开始节点接收输入并定义变量，结束节点返回变量或文本；开始参数可受外部模型提取影响，重要字段还需确认和校验 |
| 大模型节点 | 接收前置变量，输出文本、Markdown或JSON；结构化格式不代替业务校验 |
| 条件与循环 | 条件支持等于、大小、包含、正则、空值等判断；循环支持数组、次数及无限模式，课堂活动优先有限退出 |
| 知识库 | 支持本地文档、自定义文本与QA；检索有混合、语义、全文及召回限制。工作流结果包括rawText与output，关键引文优先核对原文 |
| 变量 | 可新增输入控件或变量；工作流变量节点可获取或设置值。具体跨会话、跨用户作用域须实测，不能仅因文档称全局就当成安全隔离 |
| 数据表 | 支持字段定义、唯一值、必填、数据导入和增删改查，也可引用至智能体；文档未充分证明课堂所需行级权限 |
| 问答与过程输出 | 问答节点可补充输入，过程输出可反馈阶段结果；不因此保证可恢复任意中断任务 |
| 异常 | 节点可设置超时、重试、特定返回和异常流程；流式输出开始后不能再按同样方式重试或跳异常分支 |
| 调试 | 可查看调用组件的输入输出；这为逐节点验证提供入口，不等同于流程已通过 |
| 工作空间 | 个人与团队空间的数据资源相互隔离；团队空间支持所有者、开发者、观察者协作，文档描述支持转让空间所有权 |
| 导出 | 大赛教程称智能体为.agent、工作流为.workflow；能否携带知识库、插件和数据表等依赖需重导入核验。教程中的数据表导出后缀可能有表述问题，以实物为准 |

## 正式账号建议

正式作品由每位客户的参赛负责人或其学校可控制的团队空间持有，建委通过适当的开发角色协作。两位客户各用独立空间，调研账号保留无客户数据的原型。该建议基于可维护与隔离需求，不宣称赛事强制账号注册人必须等同负责人。

客户先完成注册登录和团队创建，再邀请协作者。转让、迁移、公开发布和正式提交分别核实权限、资源点、依赖和链接变化；不先假定个人空间的一切资产可无损转交。当前没有用两个客户的真实账号完成这些步骤。

平台“输入老师模式”只属于业务选项，不是身份认证。需要学生自助使用与教师汇总时，先验证跨账号访问与数据隔离；验证前采用教师控制账号、投屏组织和匿名小组记录的方式。

## 导入与更新的实测约束

原生导出提示知识库文档和数据表数据不随配置导出。导入含依赖的流程会另建空库、表和插件副本，恢复时需重新绑定实际全文库、核对表，再上传资料。不能只看到节点连线完整就判断恢复成功。

HTTP插件支持默认固定Header与Body参数、自动解析出参；认证在导出时可能替换为占位符，导入后需在插件与流程节点核对。固定认证配置不能当作已验证的加密凭据库，公开配置和备份先脱敏。

智能体中绑定的工作流包含组件配置快照。本次发现单独发布新流程后，旧绑定仍可保留旧认证或旧预设；解除并重新绑定最新组件后，再分别保存“自动调用”和“直接输出”，才能使学生入口采用新版。每个设置页先保存再切换；最后用真实学生入口与后台记录核对。

多条件TableDataQuery需显式配置conditionType为AND；只增加条件数组仍可能校验失败。普通字符串字段容量为255字符，本轮课堂卡片实际超限；fieldType7提供长文本（界面标注0—16M），还要同步代码出参、写表引用、查询children/subArgs，最后用超过255字符的实际记录验证。平台将课文和教师QA一起召回时，需同时读取rawText、question和output。

智能体配置更新时，开场正文使用openingChatMsg，快捷问题实际由guidQuestionDtos序列化到openingGuidQuestions；只更新后者可能保留旧按钮。保存发布后以真实新会话页面确认。

当前会话上下文可供代码解析本任务学习记录，完整业务指令避免依赖历史窗口永久保留；明确换课文后可以清空旧回答；作用域、防篡改和跨账号隔离并未因这个机制自动成立。正式发布在教师个人空间的智能体，可由其空间广场“开始使用”进入，评审访问仍单独测试。侧栏默认个人空间路由可能与作品所属空间不同，使用作品实际spaceId核对。
