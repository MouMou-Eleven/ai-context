# 移动端 UI：纠正“记录了规则但成品仍遗漏”

来源：杨建委 2026-09-15 网站第二轮纠错，共 9 张截图与文字说明。截图未复制进公开仓库，避免把个人页面、素材和二维码作为通用训练资料散存。

旧口径只有层级、多端、参考站等原则；路由仅绑定 ai-design，普通编程与百度秒哒任务可能读不到；来源曾写“R26 实际验收”，但本地只找到构建等静态检查，没有完整移动端验收证据，因此撤回该表述。

新口径在[唯一方法正文](../frontend-ui-quality-standards.md)补充标题操作同排、导航动作分离、标签坐标与溢出、页眉安全间距、两列底部导航、画布等比适配。补充具体资源 URL、采用方式、候选/采用门槛、可迁移示例和反例。开发总入口与方法路由同步，普通网站和秒哒任务也能获得建议。

网站 R27 本地浏览器检查覆盖 360/390/430/768/1440 的公共列表及登录页，另查 1024/1920、暗色模式、详情、分页、分享与管理员推荐开关；SQL 临时数据库验证首页排序、公开数据和写入权限。测试使用受控数据；不能据此声称正式秒哒环境已经部署、网络故障完全消失、外部飞书响应速度得到保证，或用户已认可新的视觉设计。

增量包必须保留路径，携带文件清单与哈希，并从确定的旧基线覆盖后构建。源码检查、模拟接口测试、真实平台验收、用户审美确认分别记录；有一层缺失就明确边界。

## 同日第三轮纠错：R28

建委继续提供 11 张截图，指出手机菜单子入口层级错误、教育长分类溢出、关于页工具条断字、作品分享独占行、两列页脚过疏、悬浮色块、教育首页留白、桌面二级分类只占半宽，以及后台导航结构难理解。

这次不是只改规则措辞：用“万彩微课动画（含AI技术）”等长名称复现390px视口下639px文档宽度，确认旧测试内容过短；作品二级分类被旧CSS限制为第一列；页脚44px行高叠加8px间隔；“文档原色”文字沿用32px图标按钮。先针对这些原因修复，再检查各控件边界和交互状态。

方法正文补充真实内容长度与数量、父子联动管理、文字链接间距和图标/文字按钮的差异。网站导航与内容分类保持不同数据语义；后台排序应原子保存，失败不能声称成功。本轮临时数据库验证同级排序、异常列表和管理员权限，浏览器验证后台增删改排、刷新和窄屏交互。

修订依据是用户反馈和本地复现，不能说正式站已部署或用户认可。关于页面仅修改本站外框与工具条，不声称通过跨域CSS改变飞书正文的标题或段落换行。

## 2026-09-16 第四轮：R29 配置与联动

来源为建委最新 8 张截图及说明，均实际查看：桌面作品分享位置、素材系列分享缺失、重复折叠按钮、一二级目标手填、三级分类脱离导航上下文、“通用分类”语义不明、SEO 是否生效，以及分享二维码随访问域名变化。

旧后台虽然已有父子两栏，分类却仍置于独立全局区。R29 改为左选一级、右选二级、左下编辑当前入口分类，使用路径提示；底层数据含义不合并。站内页面下拉与站外 HTTP(S) 输入用于所有导航级别，前台链接同步支持。原 scope=all 是历史跨类型分类，单独折叠说明而不删除或猜测迁移。方法正文合并已有父子条目，不新增同义方法。

2026-09-16 北京时间只读检查正式站：发布标识为 R28，首页渲染后 description 与 keywords 各有两份，HTML 中有 noindex/nofollow；未修改线上设置。R29 让后台保存值进入页面 meta 并消除重复，保留已有禁收录策略。“已保存”“标签生效”“允许收录”是不同事实，不能宣称已收录或保证排名。客户端渲染仍有无 JavaScript 时初始默认 HTML 的边界。

全部分享卡片按当前访问 origin 生成网址与二维码。两本地 origin 的主站/教育作品/素材共 8 张 PNG 已实际生成和解码，另验证查询参数及锚点。测试不等于真实新域名已经绑定，已下载旧图片也不会自行更新。

验收使用受控接口：9 个宽度与公共行为共 33 项、后台 8 项、分享 10 项；路径契约、类型检查、变更 lint 和 R28 基线增量覆盖构建另外记录。云端接口只读验证和本地模拟分开，正式部署仍需上线复核。截图不复制进公开仓库；本轮实现未得到建委新的审美确认。配置消费链路的跨项目推导标为候选，附迁移小样和反例，不默认升级为已验证方法。
