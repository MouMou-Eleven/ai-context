# 商业化与对外交付

维护跨业务、跨行业通用的商业判断与对外交付标准。2026-10-03建委明确：业务SOP按行业归属保存，不能因为要接单、谈预算或给客户交付，就全部放进商业化。

## 先判断归属

| 具体工作 | 主入口 | 本板块提供什么 |
|---|---|---|
| 培训接洽、选择课题、方案大纲、课程开发及授课复盘 | [培训与教学](../../training/README.md) | 通用内外稿语言、Word格式和报价标准 |
| 精品课文稿拆页、页数协商、页面合并、模板设计、动画及合成交接 | [精品课制作](../../design/graphic/ppt/premium-course/README.md) | 通用报价口径、价格状态与修改范围标准 |
| 视频、开发、自媒体等具体业务流程 | [领域入口](../../README.md)中的对应业务 | 按实际需要引用标准，不接管业务流程 |
| 商业计划书、融资、路演、合同及跨领域通用报价与正式表达 | 本板块 | 通用方法本身；仍须读取当前项目事实 |

## 通用标准按子类查找

报价与正式文书各有独立入口；对外表达、路演及商业判断的完整文件目录见[通用经验与方法](experience/README.md)。

| 子类 | 入口与用途 |
|---|---|
| 报价 | [报价方法与基准](quotations/README.md)：数量、单价、范围、修改、价格状态；业务案例回各领域 |
| 正式文书格式 | [交付格式](delivery-formats/README.md)：已确认的政企Word视觉标准；合同、法定公文和客户指定格式分别核对，不虚构模板 |
| 对外表达与提案 | [内外稿边界](experience/external-deliverable-language.md)：按接收者需要保留内容、真实状态与责任条件；培训大纲细则回培训 |
| 商业计划、路演与融资 | [赛事和投资人材料](experience/competition-and-investor-materials.md)、[案例结果叙事](experience/case-result-narrative.md)：价值、证据及外部可访问性 |
| 商业判断与增长 | [增长闭环](experience/business-growth-loop.md)、[分析卡](experience/business-analysis-cards.md)、[内容需求与承接](experience/content-demand-and-conversion.md)：跨行业分析工具，不代替各业务SOP |

## 对外成品的底线（红线）

已确认事实直接表达，内部推敲留工作稿；影响决策、交付、履约和责任的未定事项必须客观保留。不要把讲师操作、研发讨论、制作过程或不可访问的本地证据直接交给外部读者。合同需要真实主体、条款和责任，不能照搬宣传文案的删词规则。详细边界只维护在上表对应文件。

## 写入与组合（默认）

先找业务归属，一单事实和案例放项目或证明其方法的领域旁；跨业务可复用的报价、格式与表达标准才改本目录原文。通用价格基准只在报价表维护一处，不复制到每个领域。不同受众影响表达和格式选择，不构成接管整个专业流程的理由。

没有实际来源的合同模板、谈单话术和行业流程不批量补造；新经验按[写入规范](../../../../system/repository/ingestion-workflow.md)登记。历史来源见[修订记录](revisions/README.md)，历史记录不作为当前归属规则。
