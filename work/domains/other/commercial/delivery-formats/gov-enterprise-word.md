# 政府与企业商业Word方案排版

状态：用户明确采用的视觉方向，确认于2026-09-17。来源：[用户图二](references/gov-enterprise-word-reference.png)，说明见[参考索引](references/README.md)。这是商业方案样式，不称为党政机关公文国家标准，也不替代组织方指定模板。

## 视觉特征与实现起点

| 元素 | 参考图确认的样式 | 实现起点，可按篇幅调整 |
|---|---|---|
| 页面 | 白底，正式文档比例，留白清楚 | A4纵向；左右2.5cm，上2.2cm、下2.0cm |
| 主标题 | 居中、深蓝、突出于正文 | Word原生Title样式；24—28pt；微软雅黑或黑体 |
| 副标题及对象行 | 居中；副标题浅灰，层级低于主标题 | 副标题16—18pt；对象或文档类型14—16pt |
| 题头与正文之间 | 细线分隔，留出自然间距 | 深蓝0.5pt左右的段落下边线；不叠加大色块 |
| 页眉 | 居中、浅灰、简洁的项目和文档名称 | 9—10pt；不出现内部版本和核验说明 |
| 章节标题 | 左对齐，深蓝，中文“一、二、三”层级 | 一级16—18pt，二级14—15pt；标题随下段 |
| 正文 | 黑色宋体，正式书面表达，首行缩进 | 13—14pt；首行2个汉字；1.4—1.5倍行距 |
| 基本信息 | 标签与值逐行展示，标签加粗 | 左对齐不首行缩进；不用默认双列表格承载所有信息 |
| 页脚 | 参考未给出完整页脚，不臆测 | 本次采用居中页码；不强制制作日期 |

截图不能精确反推出字号、边距、字体版本和行距。第三列是为了复用建立的参数起点，不能标成建委逐项确认的数值。

## 内容与分页

- 标题先说清文档是什么；只有用户确认的主题标题才作为创意题头。主标题及副标题居中，章节标题仍靠左，不能把“标题居中”误解为全篇居中。
- 正文以段落和自然层级为主。表格仅用于真正需要横向比较的课程表、费用或方案对比，不把长解释挤进格子；无必要不使用深色表头、斑马纹和彩色提示框。
- 主标题、副标题、对象行和分隔线作为一个完整题头。章节标题不孤立在页底；段落不因不必要的手工分页留下大块空白；讲师简介尽可能连贯。
- 交付使用可编辑DOCX；中间PDF与页面图默认留工作区。无需把来源链接、内部验收表或用户纠错过程附在成品末尾。

## 验收

对实际DOCX检查Title段落居中及外链情况；渲染全部页面，与原参考比较题头、正文密度、中文字体、章节编号和留白。检查孤行、溢出、跨页表格、页码、异常空白和最后一页。自动检查只覆盖部分结构，颜色、字号、阅读效果仍需看图。

内容检查回[对外方案设计](../experience/external-proposal-design.md)。格式符合不能弥补受众错位；内容正确也不能替代用户选定排版。
