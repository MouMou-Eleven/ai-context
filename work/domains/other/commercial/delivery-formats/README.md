# 商业文件交付格式

先判断用途，再选格式。内容边界由[对外方案](../experience/external-proposal-design.md)与[内外稿规则](../experience/external-deliverable-language.md)负责；本目录只维护版式，不复制教学方法或项目事实。

| 格式 | 适用场景 | 不直接套用 |
|---|---|---|
| [政企商业Word方案](gov-enterprise-word.md) | 政府、企业培训方案，课程纲要及正式商业项目方案 | 法定机关公文、合同、标书指定模板、品牌画册与学员课件 |

## 新格式的加入方式

新增格式须有用户明确偏好、认可参考或真实交付反馈，记录适用对象、标题体系、正文、页眉页脚、表格和验收动作。优先保留可重看的参考，注明只采用视觉还是也采用内容。没有来源不批量建立空模板。后续出现不同场景的新样式，在此并列登记，保留现有样式的范围。

本次首项是建委2026-09-17选定的政企Word视觉方向；实现字号等是可调起点，不是截图测量结果，也不是所有商业文件的唯一标准。

[参考资料](references/README.md)保存已获授权沉淀的排版截图；项目姓名、日期和课程安排不能从参考图直接带入新项目。
