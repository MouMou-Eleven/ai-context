## 读取

- 只查事实/进度：项目入口→该事实的权威记录；不强制加载表达或培训创作经验。
- 创作：表达短卡+主领域方法+实际需要的能力/项目证据。无“最多两个文件”限制，也不默认读取所有细节。
- AE/MG与AI生成互通，见[设计制作协作](./design/production-workflow.md)。纯教学案例不加载招生销售框架，正式对外材料按目的加载[商业边界](./other/commercial/README.md)。
- 多个独立任务分别路由；同一任务的跨域依赖不需要建委额外确认。

## 写入

项目保存事实和原始案例；领域经验保存适用条件明确的可复用方法。单次案例可以提出候选方法，经实际验证或建委明确确认才进入默认使用层。

新增内容前读[写入流程](../repository/ingestion-workflow.md)，用[模板](../repository/templates/README.md)记录来源、结果和验收。最近README索引、跨域引用、项目状态、路由与完整结构由AI自动检查更新。
