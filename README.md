# AI Context · 杨建委的长期协作知识库

这里是建委的数字分身：他是谁、怎么想、会做什么、在做什么，以及实战里沉淀下来的经验。任何 AI 来读，先读 [AGENTS.md](./AGENTS.md)。

## 四个板块

| 板块 | 放什么 | 例子 |
|---|---|---|
| [个人信息](./personal/README.md) | 建委这个人：身份、经历、荣誉、业务概要 | 写个人简介、讲师介绍、简历 |
| [建委大脑](./brain/README.md) | 建委怎么想：做事与表达偏好、商业判断、思考与决策习惯（只放总原则，不放具体项目） | 做任何成品前定方向 |
| [工作领域与项目](./work/README.md) | 领域知识（会做什么）＋长期项目（在做什么） | 写课件、做设计、用秒哒开发、推进社群 |
| [AI 协作与维护](./system/README.md) | 表达标准（含口语样稿）、仓库读写规则、电脑环境 | 让 AI 写得像建委、往仓库写东西 |
