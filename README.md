## 从任务出发

“做一条企业宣传片”“继续改飞书书稿”“把这次微课的经验沉淀到设计”都可以作为入口。AI负责查已有事实和方法、组合必要能力、完成更新与验收，无需建委指定每个文件。

工作知识按交付业务组织，AI、AE等作为制作手段。项目只保存一份事实，相关领域提供入口；价格、课程、章节与进度回到项目权威记录核对。

AI开始任务读[启动规则](./AGENTS.md)；完整读取和写入要求由[仓库运行](./system/repository/README.md)统一维护。
