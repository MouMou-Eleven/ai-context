# 付费社群课程研发

> 建委正在研发的付费社群课程项目，首期聚焦 AI 编程方向。（状态：进行中）

## 项目概述

这是建委正在推进的付费社群与课程研发项目。当前产品形态为 **399 元 / 3 个月** 的付费社群，交付内容包括直播、课程、教程文档、社群答疑、社群知识库、团队自研工具 3 个月会员权益和围绕真实问题的实战案例。

首期课程方向为 **AI 编程**。2026-06-24 后当前建议课程名为：**AI 编程新范式实战营**。对外主张是：**别只把 AI 当聊天框，用它把真实问题做成网页、工具、自动化和获客入口。**

本项目在仓库中的定位是：记录课程产品、研发方向、内容体系、交付节奏和自媒体流量入口等长期上下文。**具体教程正文优先写入飞书文档，不把单篇教程全文堆到本仓库里。**

## 使用指南

### 给 AI

- 处理“付费社群、课程研发、AI 编程课程、自媒体流量入口、口播稿、课程内容体系”相关任务时，先读本 README。
- 如果任务是设计课程结构、判断某个内容是否适合社群成员学习，继续读 `course-development.md` 和 `curriculum-design.md`。
- 如果任务是写直播方案、私聊转化、社群运营或 30 天执行计划，继续读 `operations-playbook.md`。
- 如果任务是写短视频脚本、账号定位、内容选题、流量转化路径，继续读 `media-growth.md`。
- 如果任务涉及爆款脚本结构、完播率、故事性、信息密度、推力结构，继续读 `script-patterns.md`。
- 如果任务涉及评论区引导、领取资料、进群交流、从短视频导向社群或课程，继续读 `conversion-path.md`。
- 如果用户提供某篇具体教程内容，并要求写到飞书，教程正文应进入飞书文档；仓库只记录项目层面的结构、原则和长期资料索引。
- 写“课程资料 / 分享资料 / 课件 / 教程”前，必须先确认观看身份是讲师还是学员。讲师资料可以出现备课提示、逐字稿、讲课顺序；学员资料禁止出现这些内部提示，只写学员能直接阅读和使用的内容。

### 给建委

- 后续新增课程主题、直播安排、用户问题、教程选题时，优先更新 `course-development.md`。
- 后续收集自媒体账号打法、爆款脚本结构、口播模板、选题库时，先更新 `media-growth.md`；内容变多后继续拆到 `script-patterns.md`、`conversion-path.md` 等子文件。
- 如果社群定位、价格、周期、目标人群或首期方向发生明显变化，应在 `revisions/` 下新增一篇日期化修订记录。
