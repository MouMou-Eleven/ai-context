# AI 编程实战营课程结构设计

> 版本日期：2026-06-23
> 状态：已按建委反馈返工，当前以“可招生、可交付、可落地”为主线。
> 适用范围：设计课程大纲、拆直播课、写课程介绍、制作海报和对外招生材料时读取。

## 课程名称

**AI 编程实战营：把想法做成作品**

对外主标题：

**不会代码，也能把想法做成能打开、能分享、能获客的作品。**

副标题：

**3 个月，每周直播带你跑通 AI 编程新工作流：网页、工具、自动化、作品集、资料页、个人知识库。**

## 产品定位

这不是传统程序员课，也不是泛泛的 AI 工具课。

这是一套面向普通人的 AI 编程实战课程：用 3 个月时间，让学员从“听说过 AI 编程”走到“能做出自己的网页、工具、自动化和可展示作品”。

课程交付的核心不是“讲了多少工具”，而是让学员拿到 4 类结果：

| 结果 | 对学员的意义 |
|---|---|
| 能展示 | 做出个人主页、作品集、资料页、业务展示页 |
| 能提效 | 做出整理资料、生成文案、处理表格、辅助办公的小工具 |
| 能获客 | 做出自媒体资料领取页、报名页、客户登记页 |
| 能沉淀 | 建立自己的项目文件夹、知识库、经验库，让 AI 后续更懂自己 |

## 价格与权益

主产品为 **399 元 / 3 个月**。

权益包括：

- 每周 1 场直播课，单场 1.5-2 小时。
- 直播回放。
- 课程资料与操作清单。
- 社群答疑。
- 社群知识库。
- 团队自研 **HTML 静态网页托管平台** 3 个月会员权益。

这里的团队自研工具应明确表述为 HTML 静态网页托管平台，用于帮助学员把网页作品部署成别人能打开的链接。

## 目标人群

课程默认面向非程序员设计。

| 人群 | 需求 | 成交抓手 |
|---|---|---|
| 大学生 | 简历需要真实作品，不能只写“会 AI” | 做一个能发给 HR 的个人作品集主页 |
| 职场打工人 | 想把重复整理、复制、改格式、写材料的工作变简单 | 做一个自己的效率小工具 |
| 自媒体 / 知识博主 | 有内容但缺少资料承接和获客页面 | 做资料领取页、课程介绍页、案例展示页 |
| 个体创业者 / 小团队 | 想低成本做官网、报名页、预约页 | 做客户登记 / 活动报名 / 预约咨询页面 |
| AI 学习者 | 想系统进入 AI 编程，不知道从哪里开始 | 按 12 节课路线跑通第一遍 |

## 课程主线

课程不是工具堆叠，而是从浅到深跑通一条完整路径：

**认知工具 → 搭建环境 → 做出网页 → 部署成链接 → 写 PRD → 做小工具 → 修 Bug → 接工作流 → 做自动化 → 上线网站 → 做 SEO 和反馈 → 建立个人知识库。**

## 12 节课程安排

### 第 1 节：AI 编程全景课

主题：先把地图看懂：AI 编程到底是什么，普通人应该从哪开始。

这一节不做安装，不讲 API 细节，重点解决新手的认知混乱。

必须讲清楚 5 类 AI 编程工具：

| 类型 | 怎么理解 | 代表工具 | 适合谁 |
|---|---|---|---|
| 对话式 AI | 打开网页直接聊天，让 AI 生成代码或解释问题 | DeepSeek、豆包、ChatGPT、Kimi、Claude、Gemini | 完全零基础，先体验“用说话生成代码”的人 |
| AI 代码编辑器 | 自带 AI 能力的完整代码编辑软件，能理解项目文件 | Cursor、Windsurf、Trae、Qoder、Kiro、Zed | 想认真做项目、愿意安装软件的人 |
| IDE 插件/扩展 | 给传统编辑器装 AI 插件，相当于给原有开发环境加外挂 | GitHub Copilot、Cline、Continue.dev、Augment、Tabnine、Amazon Q Developer | 已经使用 VS Code、JetBrains 等开发工具的人 |
| 网页版 AI 编程 | 打开浏览器描述需求，直接生成项目、预览甚至部署 | 秒哒、豆包 AI 编程、Coze 编程、Bolt.new、v0.dev、Lovable、Replit | 想最快看到成果、不想先装环境的人 |
| 命令行工具 | 在终端里让 AI 读文件、改代码、跑测试、修 Bug | Claude Code、Codex CLI、Gemini CLI、Aider、Droid | 有一定基础，想追求效率和自动化的人 |

关键认知：

- AI 编程不是背语法，而是“把需求说清楚，让 AI 执行，再验证结果”。
- 工具不是越多越好，而是不同阶段用不同工具。
- 代码不是目的，作品和问题解决才是目的。
- 环境、GitHub、Node.js、Python、终端不是为了吓人，而是让作品真正跑起来的基础设施。

课后动作：

- 选择一个 3 个月内想做出的结果：个人主页、作品集、资料领取页、工作小工具、客户登记页、自动化任务。
- 在群里按模板发出来：我是谁、我想做什么、这个东西解决什么问题。

### 第 2 节：环境搭建课

主题：把电脑变成能和 AI 一起工作的工作台。

讲解顺序：

1. 浏览器与本地文件：为什么 HTML 能直接打开，复杂项目却不能双击运行。
2. VS Code：怎么看文件夹、怎么看 HTML/CSS/JS、怎么看项目结构。
3. Node.js：为什么现代网页项目需要它。
4. Python：为什么自动化、脚本、数据处理经常会用到它。
5. Git：为什么 AI 改代码前一定要会保存版本。
6. GitHub：怎么注册、搜索项目、看 README、下载项目。
7. Codex / Claude Code / 龙虾 / cc-switch / Codex++：先知道它们解决什么，再安装。

课后动作：

- 发环境安装截图。
- 在 GitHub 搜一个自己感兴趣的项目，读 README，写一句“这个项目是干什么的”。

### 第 3 节：AI 协作规则课

主题：不是提示词越长越好，而是上下文越准越好。

重点：

- Prompt 只是入口，Workflow 才是关键。
- 让 AI 先理解项目结构，再规划步骤，再动手修改，再测试验证。
- Skill 是给 AI 的可复用工作说明书。
- MCP 是让 AI 连接外部工具和数据的接口。
- CLI 是很多平台的自动化入口，适合被 AI 调用。
- 用飞书 CLI 讲“AI 如何把资料写进文档”。
- 用 UI 组件库 MCP 讲“AI 如何调用外部组件，而不是凭空乱写界面”。

课后动作：

- 写一个自己的第一个 Skill：比如“帮我写短视频脚本前，先确认目标人群、痛点、案例、结尾引导”。

### 第 4 节：第一个网页作品

主题：用 AI 写一个网页，并让别人真的能打开。

流程：

1. 用 DeepSeek / 豆包生成一个单文件 HTML 页面。
2. 本地打开，看效果。
3. 讲清楚 HTML、CSS、JavaScript 分别负责什么。
4. 解释为什么本地能打开，不代表别人能打开。
5. 使用团队自研 HTML 静态网页托管平台上传页面。
6. 生成公开链接。
7. 发到群里展示。

可选案例：

- 个人主页。
- 简历作品页。
- 课程资料页。
- 小游戏。
- PPT 风格展示页。

课后动作：

- 每个人交付一个可访问链接。

### 第 5 节：静态网页进阶与部署认知

主题：从一个 HTML 到一个真正像样的网页项目。

重点：

- 单文件 HTML 和多文件项目的区别。
- 图片为什么要用图床。
- 什么是服务器、域名、DNS 解析、SSL、备案。
- 为什么简单页面没必要一上来买服务器。
- HTML 静态网页托管平台适合哪些场景，不适合哪些场景。

课后动作：

- 把第 4 节作品升级成多文件版本，或加上图片、按钮、交互。

### 第 6 节：秒哒基础课

主题：从展示页进入小工具：用秒哒做一个带数据能力的产品。

重点：

- 秒哒介于“静态网页”和“完整全栈开发”之间。
- 秒哒能让普通人更快做出带表单、数据、后台能力的小工具。
- PRD 的普通人模板：用户是谁、痛点是什么、页面有哪些、每页能做什么、要保存什么数据、什么结果算完成。
- 前端和后端是什么。
- 做一个资料领取页 / 报名登记页 / 客户预约页。

课后动作：

- 写一份自己的小工具 PRD。

### 第 7 节：秒哒进阶与 Bug 修复

主题：不怕报错：学会把问题描述到 AI 能修。

重点：

- 控制台是什么，怎么打开。
- 红色报错怎么看。
- 怎么截图、录屏、复制报错。
- 怎么把问题描述给 AI。
- 用 Gemini 等多模态模型分析录屏，弥补非程序员表达不精准的问题。
- 什么时候继续让秒哒改，什么时候换 Codex / Claude Code 介入。

课后动作：

按模板提交一个 Bug 或修改需求：

```text
我想实现：
现在现象：
我点了哪里：
控制台报错：
我已经试过：
我希望改成：
```

### 第 8 节：主流 AI 编程工具协作

主题：Codex、Claude Code、龙虾怎么选，怎么配合。

重点：

- Codex 适合：读项目、改文件、写文档、跑命令、沉淀仓库上下文。
- Claude Code 适合：终端内快速修改、排错、自动化和代码协作。
- 龙虾适合：配置模型、接入微信 / 飞书等日常入口，形成更贴近工作流的使用方式。
- README、AGENTS.md、需求文档、资料目录怎么影响 AI 输出质量。

课后动作：

- 给自己的项目建一个文件夹，写 README。

### 第 9 节：浏览器插件与工作流工具化

主题：把 AI 编程能力放进日常工作场景。

重点：

- 浏览器插件是什么。
- 用 Codex 做一个简单插件：网页信息提取、复制格式化、页面标记、资料收集。
- 微信 / 飞书入口为什么重要。
- 什么样的重复动作值得工具化。

课后动作：

- 写一个自己的工作流工具化需求：每天重复做什么、输入是什么、输出是什么、现在耗时多久。

### 第 10 节：自动化与 API

主题：让工具自己跑起来：定时任务、接口调用、素材提取。

API 不放到第一节讲，而是在学员已经理解网页、工具、工作流后再讲。

重点：

- API 是系统之间互相调用能力。
- 自动化任务是定时、批量、触发、输出。
- 用 Codex 设计一个自动任务。
- 案例：公众号视频信息提取、抖音视频信息整理、素材文案抓取。
- 规则边界：版权、平台规则、隐私、接口限制。

课后动作：

- 写一个自动化任务说明，不要求所有人都跑通代码，但要能把流程说清楚。

### 第 11 节：标准网站开发链路

主题：从小工具到正式网站：GitHub + Supabase + Vercel。

重点：

- GitHub 管代码。
- Supabase 管数据。
- Vercel 做部署。
- 邮箱登录、手机号登录、验证码服务分别意味着什么。
- 数据库里的表、字段、权限是什么。
- 域名、SSL、DNS 解析怎么接上。
- 用一个真实案例带大家跑：个人网站 / 公司官网 / 课程资料站。

课后动作：

- 建一个 GitHub 仓库，写 README，准备部署。

### 第 12 节：上线、获客与个人知识库

主题：作品上线后，怎么让它被看见、被使用、被继续迭代。

重点：

- SEO 是什么。
- 标题、描述、页面结构、加载速度为什么影响搜索。
- 分享卡片和 Open Graph 为什么影响点击。
- 数据统计为什么重要。
- 用户反馈怎么收集。
- 为什么要把经验沉淀到 GitHub / GitLab / 飞书知识库。
- 建立个人 AI 协作上下文：README 做入口，项目资料分类，重要变化写修订记录。

课后动作：

- 每个人做一次成果复盘：我做出了什么、链接是什么、解决什么问题、下一步怎么迭代。

## 交付节奏

每周直播建议固定结构：

| 时间 | 内容 |
|---|---|
| 0-10 分钟 | 回顾上周作业，展示 1-2 个学员结果 |
| 10-25 分钟 | 讲本节课为什么重要，解决什么现实问题 |
| 25-75 分钟 | 主体教学和演示 |
| 75-95 分钟 | 现场答疑和常见问题拆解 |
| 95-110 分钟 | 布置最低作业和进阶作业 |
| 110-120 分钟 | 提醒资料位置、回放、下节课主题 |

每节课只设置一个最低作业，避免学员被任务压垮。
