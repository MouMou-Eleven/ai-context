# 2026-06-23：AI 编程实战营方案返工与运营口径修正

## 修订原因

建委指出 2026-06-22 版方案存在几个问题：

- AI 编程工具分类写成了 4 类，实际应按参考文档写成 5 类。
- Cursor 被错误放到 IDE 型 / 插件类表达中，实际应归入 AI 代码编辑器。
- 运营方案里出现了“当前确认口径”“不主推”“参考资料”等内部澄清内容，不适合作为建委要看的正式运营方案。
- 直播话术如“今天这场不讲玄的”不够自然，不像建委会真实表达的话。
- 团队自研工具应明确写成 HTML 静态网页托管平台。
- 方案需要更能用于招生、直播、转化和落地变现，而不是浅层罗列。

## 修订后的关键口径

课程名称建议改为：

**AI 编程实战营：把想法做成作品**

海报主标题：

**不会代码，也能把想法做成能打开、能分享、能获客的作品。**

课程主线：

**认知工具 → 搭建环境 → 做出网页 → 部署成链接 → 写 PRD → 做小工具 → 修 Bug → 接工作流 → 做自动化 → 上线网站 → 做 SEO 和反馈 → 建立个人知识库。**

工具分类修正为 5 类：

1. 对话式 AI。
2. AI 代码编辑器。
3. IDE 插件 / 扩展。
4. 网页版 AI 编程。
5. 命令行工具。

其中 Cursor、Windsurf、Trae、Qoder、Kiro、Zed 应归入 AI 代码编辑器；GitHub Copilot、Cline、Continue.dev、Augment、Tabnine、Amazon Q Developer 应归入 IDE 插件 / 扩展。
