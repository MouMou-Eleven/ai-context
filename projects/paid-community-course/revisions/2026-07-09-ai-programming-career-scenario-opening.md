# 2026-07-09：第一节课先讲职业场景，再讲工具地图

## 背景

建委在准备第一节课时形成新的判断：普通人听到“AI 编程”时，最大的阻力不是不会安装工具，也不是听不懂代码，而是第一秒就把这件事判断成“程序员的事”。如果一个人是财务、文员、设计师、剪辑师、老师、医生、导游，他很容易觉得 AI 编程和自己的工作没有强相关。

这属于更底层的认知偏差：用户不会自动完成“AI 编程可以服务我的职业”的联想。课程和营销必须替用户完成这一步。

## 最新原则

第一节课开场顺序调整为：

1. 先讲普通人的认知偏差：AI 编程不等于程序员写代码。
2. 再讲 AI 带来的范式变化：从“先学代码再做工具”变成“先描述问题，再让 AI 生成工具雏形”。
3. 接着讲职业场景：不同职业分别能做什么工具、页面和自动化流程。
4. 再讲真实边界：不需要先手敲代码，但要学会描述需求、判断结果、修正问题、保护数据、沉淀经验。
5. 最后进入五类工具地图和环境概念。

核心表达：

**AI 编程不是让普通人转行当程序员，而是让每个职业的人都多一种把问题做成工具的能力。**

## 职业场景示例

| 人群 | AI 编程可以服务的具体结果 |
|---|---|
| 老师 / 培训者 | 互动课件、问答游戏、知识点巩固小测验、点名小程序、排座位工具、作文批改辅助页 |
| 设计师 | 灵感收集工具、素材标签管理器、个人作品集网站、提案展示页、图片尺寸批处理工具 |
| 文员 / 行政 | 文档批量改名、表格字段整理、模板生成、文件归档、数据脱敏、批量格式转换 |
| 财务 | 发票批量重命名与分类、报销材料检查清单、发票台账辅助录入、费用分类看板、财务数据脱敏工具 |
| 写作者 / 编辑 | 选题库、稿件版本管理、标题测试器、资料摘录卡片、投稿记录管理页 |
| 自媒体 / 知识博主 | 资料领取页、选题库、爆款标题库、评论区关键词整理、粉丝需求收集页、课程报名页 |
| 剪辑师 / 视频创作者 | 素材整理器、口播稿分镜表、字幕文案清洗工具、镜头清单管理、客户反馈收集页 |
| 个体创业者 / 小团队 | 客户登记页、预约咨询页、活动报名页、产品介绍页、报价计算器、简单 CRM |
| 医生 / 健康从业者 | 科普资料页、随访问卷、患者教育材料整理、排班 / 耗材登记、脱敏后的教学案例资料库；诊断和隐私数据必须遵守专业与合规边界 |
| 导游 / 文旅从业者 | 行程生成器、景点讲解页、客户报名表、费用估算器、路线地图资料页、游客反馈收集页 |
