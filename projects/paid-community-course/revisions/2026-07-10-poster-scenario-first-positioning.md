# 2026-07-10：海报从技术主题改为场景结果

> 当前有效，覆盖此前将“AI 编程系统实战”直接作为海报第一期主题的做法。

## 触发原因

现有海报已经能说明社群的陪跑、直播、答疑和知识库价值，但第一期主题区仍以“AI 编程系统实战”为标题，并优先展示看懂工具、搭环境、部署、修错等技术链路。

这会再次触发认知偏差：设计师、大学生、教师、文案、财务和自媒体看到“AI 编程”后，容易先判断“这是程序员课程”，而不是继续推断它能帮助自己做什么。

## 最新决定

内部课程研发名称继续使用：

**AI 编程系统实战**

第一期海报、直播招生和短视频承接统一优先使用：

**用 AI 做出你的专属小工具**

对外副说明：

**无需先学代码，把教育、办公、设计、自媒体里的真实问题做成可用应用。**

两套名称不冲突：内部名称负责课程体系，外部名称负责让普通人快速理解价值。

主题区工具标签不再写“涵盖 Codex、秒哒等主流工具”，改为“无需编程基础 · 覆盖多种职业场景”。工具名进入课程详情，不占第一视觉层。

## 海报信息顺序

1. 先说能得到什么：做自己的实用工具。
2. 再说和谁有关：大学生、教师、设计师、财务 / 办公、文案 / 自媒体、创业者。
3. 再给具体产物：作品集、课题辅助、互动课件、灵感库、文档批处理、资料领取页、客户登记等。
4. 最后用工具、环境、部署、修错和自动化证明课程系统性。

## 版式落点

保留海报现有六个图标位，但把技术流程改成人群结果：

| 人群 | 海报短句 |
|---|---|
| 大学生 | 作品集 / 课题辅助 |
| 教师 | 互动课件 / 课堂工具 |
| 设计师 | 灵感库 / 作品集网站 |
| 财务办公 | 文档批处理 / 数据脱敏 |
| 文案自媒体 | 选题库 / 资料领取页 |
| 创业者 | 客户登记 / 报价预约 |

收束表达：

**学的不是代码，而是把你工作里的真实问题做成能反复使用的工具。**

“六大理由”中将“不止编程”改为“多场景”，将“出结果”具体化为工具、作品集、互动课件、资料页和自动化流程。“适合谁”改为大学生、教师、设计师、职场人、自媒体、创业者；“零基础”放在补充说明中，不再与职业标签并列。

- `course-development.md`：增加内外命名边界和海报场景优先原则。
- `curriculum-design.md`：明确课程目录与招生表达使用不同名称。
