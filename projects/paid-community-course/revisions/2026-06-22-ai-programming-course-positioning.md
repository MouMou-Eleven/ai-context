# 2026-06-22：AI 编程课程定位、课程结构与运营口径修订

## 修订背景

建委进一步明确了 AI 编程付费社群的课程内容、权益、目标人群、直播获客和社群运营边界。此前存在一些过宽或过重的建议，例如高客单陪跑、重运营栏目、每日技巧 KPI、现场直播完整做作品等，并不完全符合当前阶段。

本次修订以建委最新口述为主，沉淀为长期项目上下文，方便后续 AI 继续参与课程研发时直接读取。

## 最新确认口径

- 主产品仍是 **399 元 / 3 个月** 的 AI 编程付费社群。
- 已确认权益：社群答疑、社群知识库、团队自研工具 3 个月会员权益、每周直播课、回放、课程资料。
- 目标人群不是专业程序员，默认服务大学生、职场打工人、自媒体 / 知识博主、个体创业者、AI 学习者等非程序员或弱技术背景用户。
- 课程不应被定位成“3 个月做一个小网站”，也不应被包装成传统编程课。
- 更适合的定位是“AI 编程新范式实战社群”：系统掌握工具认知、环境搭建、网页部署、秒哒开发、Codex / Claude Code / 龙虾、自动化、标准网站链路和个人知识库沉淀。

## 课程结构修订

建议按 12 节课编排，每节 1.5-2 小时：

1. AI 编程全景与新范式。
2. AI 编程环境与工具安装实战。
3. Skills、MCP、CLI：给 AI 装能力。
4. 第一个可公开访问的网页：从 HTML 到一键部署。
5. 秒哒基础：从 PRD 到带数据能力的小工具。
6. 秒哒进阶：Bug 修复、控制台、多模态辅助。
7. Codex、Claude Code、龙虾：主流 AI 编程工具协作。
8. 浏览器插件、微信 / 飞书入口与工作流工具化。
9. 自动化任务与 API 调用。
10. 标准网站开发链路：Codex + Supabase + GitHub + Vercel。
11. 上线后的 SEO、安全与运维。
12. AI 时代个人知识库与成果复盘。

第一节必须足够基础和全景，重点讲 AI 编程类型、主流工具、运行环境概念和渐进式披露，不讲 API 细节。API 放到后面需要它的时候再讲。

## 运营口径修订

当前阶段运营重点：

- 先通过自媒体和直播建立信任。
- 用 4 个强案例吸引不同人群：大学生作品集、职场效率工具、自媒体资料领取页、个体创业客户登记 / 预约系统。
- 直播不必每场都现场做完整作品，重点是聊天、解惑、讲路径、讲案例、建立信任、引导提问。
- 需要准备冷场、资料领取、课程转化、私聊咨询、支付后引导等话术。
- 社群早期使用轻运营：直播、回放、资料、答疑、知识库和最小作业。

当前不写成正式承诺：

- 高客单定制陪跑。
- 固定每日技巧栏目。
- 固定急诊室栏目。
- 过重的周一 / 周三 / 周五 / 周日任务制。
- 高强度一对一作业精修。
- 包变现或包赚钱。
