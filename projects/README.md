## 📋 新增项目流程

1. 在 `projects/` 下创建目录（kebab-case，如 `my-new-project`）
2. 在目录中创建 `README.md`，必须包含：概述、文件索引表、使用指南
3. 在上方的项目索引表中添加新条目
4. 按需创建其他文件，并在项目 README.md 的文件索引表中登记

**详细规范见 [`STRUCTURE.md`](../STRUCTURE.md) 的「写入规范」章节。**
