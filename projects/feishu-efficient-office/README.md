# 飞书高效办公：AI时代职场人的效率翻倍实战指南

> 建委著 | 状态：🔄 进行中

## 概述

一本面向普通职场人的 AI 办公实战书，核心定位：**大道至简——用最接地气的话，讲最不简单的事。**

- **目标读者**：非技术背景的职场人，日常工作中涉及文档、表格、PPT、数据汇报
- **差异化**：设计师视角（不是程序员教AI）、真实培训验证（线下讲过）、变现闭环（市面上极少）
- **进度**：素材收集与分析阶段

## 文件索引

| 文件 | 内容 | 何时读取 |
|-----|------|---------|
| `writing-style-analysis.md` | 建委写作风格说明书（给AI的风格Prompt） | **生成任何书稿内容前必读**，确保风格一致 |
| `all-docs.md` | AIGC培训原始文档合集（9篇，~20万字） | 需要参考原始培训素材时读取 |

## 使用指南

**对于 AI 工具**：
1. 先读本 README 了解项目背景
2. 生成内容前，务必先读 `writing-style-analysis.md` 获取写作风格规范
3. 需要原始素材时再读 `all-docs.md`，不要默认加载（节省上下文）

**对于建委**：
- 书稿正文写在本书名目录下的新文件中，按章节拆分
- `writing-style-analysis.md` 是给其他 AI 工具的「风格说明书」，喂给它就能按你的风格写
