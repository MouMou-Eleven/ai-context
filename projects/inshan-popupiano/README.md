## 一句话介绍

**广告公司性质的代运营项目**：拿到音乐密码（北京）旗下 POPUPIANO 智能钢琴键盘的海外**经销权**，通过自建独立站 [inshan.cc](https://www.inshan.cc) + 自建 Amazon 店铺 双线销售，**2-3 个月内做出销售成果或明确反馈**。

## 视觉与网站要求（硬性指标）

> 来自建委 2026-05-24 强调："主要是网站要漂亮，点在哪"

1. **整体审美必须符合海外用户预期**——不是"勉强能用"而是"看着精致漂亮"
2. **三大硬件卖点必须有精准视觉落位**：
   - **磁吸拆装**：首屏 hero 区或紧随其后，需拆装 GIF/短视频
   - **Logic / GarageBand 连接**：编曲人受众落地页核心位，需实拍 Mac/笔记本工作流截图
   - **亮灯学琴**：儿童/初学者受众落地页核心位，需亮灯演奏 GIF + APP 互动截图
3. **建议页面分受众入口**：首页"For Producers" / "For Beginners" 双入口，避免一屏想说全部
