# Inshan POPUPIANO — 海外电商冷启动项目

> 状态：🔄 进行中（Phase 0：合作边界澄清中）
> 类型：长期项目，持续迭代

## 一句话介绍

与 PopuMusic 合作的智能钢琴键盘海外销售项目，独立站 [inshan.cc](https://www.inshan.cc) + Amazon 双线运营，定位"AI + 智能乐器"垂直生活方式品牌。

## 项目背景

- **品牌方**：PopuMusic Global INC（深圳，2022 Indiegogo 起家，Red Dot 设计奖）
- **核心产品**：POPUPIANO 智能模块化钢琴键盘（59键，主键盘29键 + 扩展24键 + 和弦Pad）
- **建委角色**：合伙方 / 海外冷启动方案设计与运营牵头
- **合作性质**：分销关系（非独家代理），需考虑流量被品牌方虹吸的风险
- **关键资产**：
  - 独立站：[inshan.cc](https://www.inshan.cc)（Shopify，已建好但内容空）
  - Amazon listing：[B0CNCP8P1W](https://www.amazon.com/gp/product/B0CNCP8P1W)（3.6★ / 54 评论）
  - 社媒：YouTube / Instagram 已注册（无内容）

## 核心策略（B 路线）

**"AI + 智能乐器"垂直生活方式品牌**——脱离单纯卖货逻辑，用内容+AI 玩法做增量价值。

- 核心叙事：`"3 chords + AI = a song in 60 seconds"`
- 海外用 ChatGPT/Suno/Udio 替代豆包（豆包是字节产品，海外用户不认识）
- 与 PartyKeys/Amazon 形成差异化（他们卖产品，我们卖"用产品做出来的东西"）
