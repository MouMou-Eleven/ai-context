# VideoAI 成本分析文档

> 更新日期：2026-05-11
> 版本：v1.0

## 一、成本来源概览

VideoAI 工作流涉及 **两个独立平台** 的 API 调用：

| 平台 | 用途 | 充值比例 | 单积分价值 |
|------|------|---------|-----------|
| 内容抓取平台 | 热门短视频内容采集 | 100元 = 10,000积分 | 1积分 = 0.01元 |
| 数字人平台 | 克隆/语音/视频合成 | 10元 = 15,000积分 | 1500积分 = 1元 |

另有 AI 改写环节，成本约 0.1元/次。

## 三、实际消耗验证

### 3.1 数字人视频合成（实测数据）

| 视频时长 | 实际消耗积分 | 折算积分/秒 | 与官方标准对比 |
|---------|------------|-----------|-------------|
| 1分17秒（77秒） | 4,937 | 64.1 | 官方62.5/秒 ✓ |
| 40秒 | 2,625 | 65.6 | 官方62.5/秒 ✓ |
| 2分53秒（173秒） | 10,875 | 62.9 | 官方62.5/秒 ✓ |

**结论：** 实际消耗与官方标准（3750积分/分钟 = 62.5积分/秒）一致，存在微小浮动属正常。

### 3.2 语音合成（实测数据）

| 音频时长 | 实际消耗积分 | 备注 |
|---------|------------|------|
| 1分17秒 | 2 | 可能为会员优惠/特殊渠道 |
| 22秒 | 25 | 可能为不同计费渠道 |

**说明：** 两次消耗差异较大，推测为调用了不同渠道或计费规则不同，待进一步确认。

## 四、完整工作流成本汇总

### 4.1 含克隆的完整成本（新形象首次制作）

以 **1分钟视频** 为例，使用专家级克隆：

| 环节 | 成本 |
|------|------|
| 内容抓取 | 0.05元 |
| AI 改写 | 0.10元 |
| 专家声音克隆 | 4.00元 |
| 专家形象克隆 | 4.00元 |
| 语音合成 | ≈0.02-0.06元 |
| 专家数字人视频合成（1分钟） | 2.50元 |
| **合计** | **≈10.67元** |

## 五、成本结构分析

- **视频合成** 是最大成本项，占比约 85-94%（已克隆后）
- **克隆费用** 每换一个新形象/声音需重新投入 8元
- **内容抓取 + AI改写** 成本极低，合计仅 0.15元/条
- **语音合成** 成本几乎可忽略
