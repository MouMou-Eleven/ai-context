# VideoAI — AI 驱动的营销视频自动化平台

> 当前核心项目 | 状态：✅ 已上线，持续迭代中

## 一句话介绍

整合内容抓取→AI改写→语音克隆→数字人克隆→视频合成的完整工作流，让中小企业和个人创作者低成本批量生产营销短视频。

- 线上地址：https://app-aebf74n8o16p.appmiaoda.com/

## 核心能力

1. **内容抓取**：自动采集热门短视频素材
2. **AI 改写**：智能改写文案，规避重复
3. **语音克隆**：克隆用户声线，批量配音
4. **数字人克隆**：虚拟形象出镜
5. **视频合成**：一键成片

## 商业模式

- **积分消费制**：10 元 = 1000 积分，按量付费
- **年度套餐制**：面向高频用户的订阅方案
