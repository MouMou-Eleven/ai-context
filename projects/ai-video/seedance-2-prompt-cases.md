## 案例 001：暗黑国风仙侠女子

### 案例定位

- **主体**：参考图中的黑衣、银饰、广袖古风女子。
- **场景**：荒芜云雾悬崖。
- **视觉主线**：银蓝粒子从虚空汇聚成人物，人物苏醒后释放深渊法术能量。
- **节奏结构**：3 秒建立世界与轮廓，3 秒完成人物显形，4 秒完成动作高潮。
- **验证状态**：建委观察到该 Prompt 的画面效果和生成稳定性较好。

### 整理后的原提示词

> 仅修复明显错字、大小写和断行，保留原有参数、时间轴、运镜与画面结构。

```text
生成视频：帮我生成一个 10 秒视频。

整体参数：10 秒，4K、60 帧，16:9 横屏，AI 电影级运镜系统驱动。

整体风格：写实暗黑国风仙侠，史诗级光影，物理级粒子灵光特效，真实布料动力学，动态能量气场，冷暗史诗色调，玄幻压迫氛围感，浅景深，极致面部与服饰细节。严格沿用参考图中的黑衣、银饰、广袖古风女子形象。

负向提示词：卡通、Q版、低幼、现代、模糊、畸形、水印、文字、杂物、塑料质感、多余人物、杂乱特效。

00:00-00:03（3 秒）

运镜：AI 电影级航拍俯冲推镜，大景深全景缓慢下沉式推近，低角度仰拍，保持 16:9 稳定横向构图。

画面：荒芜云雾悬崖之巅，虚无空间中迸发细碎银蓝灵光粒子。万千光点流动缠绕、层层汇聚，从模糊光影逐步勾勒出人体轮廓；粒子明暗跟随运镜和光影变化，形成史诗级开场氛围。

00:03-00:06（3 秒）

运镜：AI 电影级环绕跟拍，镜头以人物为圆心平滑弧形环绕，侧逆光轮廓光精准跟焦，运镜丝滑、无抖动。

画面：灵光彻底凝聚成型，完整呈现参考图中的黑衣、银饰、广袖古风女子。银饰流苏、黑色纱质长袍和精致发型同步显现，灵光缓缓消散。女子缓缓睁眼，眼神清冷疏离，形成强烈压迫气场。

00:06-00:10（4 秒）

运镜：AI 电影级后拉仰拍配合轻微摇镜，使用升格慢镜头，镜头同步跟随法术能量爆发轨迹，形成动态张力。

画面：女子抬手结印施展法术，黑色深渊法术能量爆发，周身环绕流光符文与狂暴粒子气场。黑袍广袖被法术劲风剧烈吹动，长发肆意飘散，能量向天地间扩散，以大电影级玄幻画面震撼收尾，保持 16:9 横屏构图。
```

### 为什么这条 Prompt 容易产生好画面

1. **人物锚点明确**
   - 全片只围绕一个参考图人物。
   - 黑衣、银饰、广袖、纱质长袍构成稳定且容易识别的材质组合。

2. **视觉变化只有一条主线**
   - 不是同时讲多个故事，而是围绕“粒子凝成人形 → 人物苏醒 → 法术爆发”持续升级。
   - 三个阶段前后存在清晰因果关系。

3. **每一阶段有独立功能**
   - 第一阶段建立环境和神秘感。
   - 第二阶段展示人物细节和气场。
   - 第三阶段用动作与能量完成高潮。

4. **运镜与画面事件绑定**
   - 俯冲推镜用于进入世界。
   - 环绕跟拍用于展示完整人物。
   - 后拉仰拍用于放大法术能量和人物压迫感。

5. **材质与物理反馈具体**
   - 银饰流苏、纱质长袍、长发、粒子和法术劲风都能产生可见运动。
   - 动态细节不是独立装饰，而是服务人物显形和能量爆发。

6. **负向约束集中**
   - 明确排除卡通、现代、塑料质感、多余人物和杂乱特效，减少风格跑偏。

## 与通用经验的校正关系

### 时间轴可以组织叙事，但不是精确时钟

这个案例使用 `0-3 秒 / 3-6 秒 / 6-10 秒` 后获得了较稳定结果，说明时间段可以帮助 Prompt 建立清楚的三阶段结构。但不能据此断言模型一定严格在第 3 秒或第 6 秒完成切换。

复用时应把时间轴理解为“阶段比例和事件顺序”，真正影响稳定性的仍包括：镜头数量少、事件因果清楚、每阶段只有一个主要任务。

### 长 Prompt 不一定无效，冗余才是问题

这条 Prompt 篇幅较长，但人物、场景、材质、运镜和动作都围绕同一条视觉主线。它与网络上无效的“华丽小作文”区别在于：大部分描述可以映射到具体画面或物理反馈。

判断一条长 Prompt 是否值得保留，不看字数，而看每句话是否承担以下至少一种功能：锁定主体、限定场景、规定动作、建立因果、描述材质反馈、约束运镜或排除错误。

### `4K、60 帧` 是目标表达，不是验收证据

Prompt 中写入 `4K、60 帧`，只能说明创作者希望得到的规格和观感，不能证明平台原生输出文件一定达到对应分辨率与帧率。验收时应检查实际文件元数据。

如果高分辨率模式降低动作响应或稳定性，仍可按 [`seedance-2-practical-workflow.md`](./seedance-2-practical-workflow.md) 的方案，先用响应更好的分辨率生成并定稿，再使用 Topaz 放大。

## 复用风险

- 第一阶段同时出现“航拍俯冲”和“低角度仰拍”，镜头要求较密；如果生成不稳定，应只保留一个主运镜。
- “史诗级、电影级、震撼”等评价词不能替代画面动作，复用时必须保留粒子汇聚、人物睁眼、抬手结印和布料受风等可执行事件。
- 法术粒子、符文、长发和广袖同时运动，可能造成局部穿模或主体变形；失败时优先减少一种动态元素，而不是继续增加负向词。
- 原 Prompt 没有声音约束。需要进入正式剪辑时，建议追加“只生成环境和法术音效，不生成 BGM”。
