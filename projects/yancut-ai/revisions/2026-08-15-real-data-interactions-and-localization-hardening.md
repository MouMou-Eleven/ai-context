# 真实数据交互与中文化加固

> 日期：2026-08-15
> 状态：已落地本地开发环境并完成构建、浏览器回归

## 问题来源

上一轮界面已经形成言剪 AI 的独立结构，但 Studio 仍混入演示素材、虚构统计和不可操作的卡片；项目删除、网格/列表切换等关键动作缺少真实状态闭环。剪辑台深层面板还残留上游英文，时间线书签存在嵌套按钮导致的 React hydration 报错。项目时长还错误地把 OpenCut 的媒体时间刻度当成秒显示。

这些问题会直接削弱比赛演示可信度，因此本轮原则改为：没有真实数据就显示明确空状态；能展示的按钮必须有实际行为；尚未接入云端的能力必须清楚标注本地边界。

## 本轮落地

### 素材库

- 删除 Studio 演示素材和虚构的 `1,248` 条、`12.6 GB / 100 GB` 等统计。
- 复用 OpenCut 的媒体处理与存储服务，建立言剪 Studio 本地素材库。
- 支持真实图片、视频和音频上传、持久化、搜索、类型筛选、网格/列表切换、预览和删除。
- 无素材时显示真实空状态，不再用公开图片冒充用户上传内容。
- 当前数据保存在本浏览器的 IndexedDB / OPFS 边界内；尚未描述为云对象存储。

### 模板中心

- 模板定义为“内置起始方案”，不是已经上线的云模板市场。
- 支持搜索、分类筛选、收藏、最近使用和“使用此模板”。
- 使用模板会创建真实项目，并写入对应画布比例与背景设置后进入编辑器。
- 删除虚构使用量、虚构协作动态和无行为的推荐按钮。

### 项目管理

- 项目页只读取 OpenCut 项目管理器中的真实项目，不再用演示项目填充空列表。
- 支持真实搜索、网格/列表切换、项目进入和带确认弹窗的删除。
- 统计改为真实项目数、近 7 天编辑数、项目总时长和本地数据位置。
- 修复项目时长口径：项目元数据使用媒体时间刻度，展示前必须通过 `mediaTimeToSeconds` / `formatTimecode` 转换；不能按普通秒数直接格式化。
- 侧栏删除虚构的每日 AI 次数，改为“本地工作模式”和真实存储边界说明。

### 剪辑台中文化与稳定性

- 补齐贴纸搜索与分类、文字属性、变换、混合、速度、音频、字幕、项目设置、快捷键、存储提示和删除项目等深层中文文案。
- 新增文字在中文模式下使用“默认文字”，新轨道使用视频、文字、音频、图形、特效中文名称。
- 编辑器删除项目弹窗改为中文，并真正要求输入“确认删除”后才能执行，移除原先只有提示文案但没有校验的假确认。
- 时间线书签轨道移除嵌套 `<button>`，解决 React hydration 报错；播放头、缩放手柄和关键帧辅助标签同步中文化。
- Studio 素材类型筛选使用稳定的原生分段按钮，消除 Radix 标签 ID 在开发环境中的 hydration 不一致。

## 验证结果

- 素材上传、筛选、网格/列表切换、预览和删除已用真实图片文件完成浏览器回归。
- 模板收藏与模板创建项目已完成浏览器回归，测试项目可通过项目页删除。
- 项目网格/列表切换、中文日期、删除确认弹窗和真实项目计数已验证。
- 新建文字显示“默认文字”，文字属性面板内容、字体样式、间距和背景均显示中文。
- 修复后 5 秒项目在项目页显示为 `00:05`，不再错误显示为 `166:40:00`。
- TypeScript `--noEmit` 通过，涉及文件的 Biome 检查通过。
- Next.js 16.1.3 生产构建通过，26 个页面/接口路由完成生成。
- 最终素材页和剪辑台浏览器控制台没有新增 error。

## 当前边界

- 内置模板是真实可用的项目起始配置，但不是云端模板商城；模板素材、许可证和在线分发仍需后续建设。
- 素材和项目仍是单浏览器本地持久化，跨设备同步、账号隔离和对象存储要在秒哒云端接线后验证。
- 中英切换保留品牌名 `YanCut`、语言入口 `EN`、媒体格式和字体名等必要英文；中文模式下不应再出现上游操作文案。
- 对历史项目中已经保存的英文元素名或轨道名不做无痕批量改写，避免破坏用户数据；新建元素使用当前中文口径。
