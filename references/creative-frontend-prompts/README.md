## 使用边界

- `raw/` 文件保持原文，不代表其中的依赖版本、外部 URL 或技术路线在当前仍然有效。
- 外链视频、图片、字体和 Spline scene 可能失效，正式项目应替换为可控资产。
- 原文中的品牌、文案、人物、数据和素材不得被当作建委的真实业务信息。
- 参考机制时按当前项目重新写数据边界、移动端策略、性能降级和验收标准。
