# 本机生图调用规则

来源：建委2026-09-26最新AGENTS.md，替代2026-09-12旧通道规则。适用设备为当前所称“本机”，尚未映射到具体设备档案；新设备须重新确认配置。

## 当前调用顺序

1. 用户要求生图、画图、生成图片或视觉概念时，默认优先Codex内置ImageGen，读取当前相应Skill。此入口不要求配置 `OPENAI_API_KEY` 或 `OPENAI_BASE_URL`，不通过第三方启动器。使用套餐额度是用户指定偏好，不据此保证实际额度或计费状态。
2. 仅在内置工具不可用、调用失败、额度不足，或用户明确要求aiwanwu时，回退 `~/.codex/skills/imagegen/scripts/imagegen.cmd`。启动器默认模型为 `gpt-image-2`，无需另传 `--model`。
3. 回退时禁止直接执行 `python image_gen.py`：用户说明全局鉴权变量已移除，应使用配置凭据的启动器。按用户配置说明，aiwanwu直连且不经过cc-switch。

2026-09-26《角的再认识》返修阶段，内置工具未提供，通过启动器成功生成两张透明素材，并检查实际alpha与合成预览。该证据只证明当时回退通道及素材结果，不证明内置通道、当前余额或其他设备可用。

入口不可用时先确认工具暴露和当前Skill；回退报模型不存在或鉴权失败时，安全检查启动器凭据有效性、密钥轮换和余额，不猜测原因，不靠切换cc-switch或恢复全局密钥试错。不要打印启动器完整内容、API Key或Token，不将凭据写进日志、Git及对话。

更新规则时同步[环境索引](README.md)。查询配置或整理经验不自动触发生图，不擅自更改本机软件和登录配置。
