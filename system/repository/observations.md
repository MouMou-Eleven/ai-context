# 观察记录：建委的原始反馈

建委纠正或认可成品时，先在这里记原话和成品，不当场写成通用规则；同一类判断在两个独立项目都出现后，由 AI 按[晋升条件](./evolution.md#三什么时候把观察升成通用规则ai-自己判断默认)提成规则。怎么记见[第二节](./evolution.md#二建委纠正或认可时先记观察不当场写成通用规则默认)。

- **类别**用一两个词，同一类判断用同一个词，方便归到一起（例：画面饱满、字的取舍、节奏、配色、完成度、交互演示）。
- **项目**用项目 README 里的名字，同一个项目每次写法一致，脚本才数得到一起。
- **状态**：`待定`；`已晋升 → 链接`；`已按建委要求写入 → 链接`；`不晋升：原因`。升级时把处理完的行删掉，Git 历史能找回。
