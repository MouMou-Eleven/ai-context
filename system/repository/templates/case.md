# 实战案例模板

- ID、标题、日期、所属项目/场次与确认来源：
- 检索词、主要交付物、主领域与关联领域：
- 记录状态：需求中 / 制作中 / 已交付待验收 / 已验收 / 仅展示记录；最近核验日期：
- 公开范围：可公开 / 已去识别化 / 仅记方法；客户或素材使用权限依据：
- 任务、受众、交付物、输入与限制：
- 真实过程：关键选择、采用/否决理由、人工与AI/工具分工。
- 环境与版本：
- 失败与修正：发生了什么、证据、怎么改、是否复测。
- 结果：产物入口、版本/哈希、可观察结果；不虚构节省时间或收入。
- 验收：检查了什么、实际结果、仍未验证的部分。
- 可复用方法：链接现有方法或候选，注明适用/排除条件。
- 不应推广的个案条件：客户数据、业务数量、风格、资源与阶段。
- 后续复用记录：应用到哪个任务、是否有效、是否需要修订。
- 更新责任：最近README、项目/案例登记及domainEntries、相关领域入口、必要修订和派生结构。

设计商单补充必要的原稿与素材来源、时长/比例、预算工期、工具参数、工程与最终导出位置。按镜头/页面/步骤记录人工和AI各自产出；关键修正记录修改前后证据。字段按真实任务填写，未知写待补，不靠占位句暗示成功。

商单资产可以留在源码仓库、飞书或素材存储；此处登记可定位的版本、访问条件和恢复位置，不上传无关大文件。
