# 案例模板（一单设计、一个视频、一次开发、一场培训都用这个）

**什么时候建案例**：事情已经真实发生，而且至少写得出"交付了什么、中间做过什么决定或改过什么、结果怎样"。只有名称、设想或宣传文案，不建案例。

**放哪**：文件名 `case-简短英文名.md`，直接放在它证明的那个方法所在的目录里（例如宣传片案例放 `work/domains/design/video/promo/`）。长期项目的一次交付，写进项目自己的目录，不建案例文件。不另建"案例"文件夹。

## 要求和限制

## 过程

按时间写关键的几步：做了什么选择、为什么；哪些是人做的、哪些是 AI 或工具做的，用了什么工具和版本。
