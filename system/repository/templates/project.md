# 项目模板（一件有目标、持续推进的事）

**什么时候建项目**：要持续推进几周以上、有自己的目标和进度，比如会员社群、言剪 AI、写书。一次性的设计单、一个小工具都不是项目，按[案例模板](./case.md)写。一场培训不单独建项目，作为子目录放进 [AI 培训项目](../../../work/projects/ai-training/README.md)。

**放哪**：`work/projects/<英文短名>/README.md`。建之前先问建委。
