**这个目录会自动触发**：AI 根据你的任务类型自动判断要不要读这里的规则，你不用单独说"去看表达标准"。

## 一、底线卡（所有中文成品必须遵守）

写任何中文内容，交付前对照这张卡自查：

1. **事实有依据**：数字、人名、功能、结论必须来自实际材料，不能编。
2. **读者能看懂**：直接回答读者的问题，指代清楚，承接自然。
3. **搭配正确**：动词和宾语要搭配（"查看文档"不是"浏览文档"，"下载文件"不是"获取文件"）。
4. **不假大空**：具体场景、具体动作、具体例子；不堆砌抽象概念。
5. **符合体裁**：课件是学员视角、方案是对外正式语气、朋友圈是个人口吻，不混。

## 三、中文纠错自查

交付前，AI 用 [corrections.md](./corrections.md) 自查：
- 高频搭配错误（"浏览"不是"查看"、"获取"不是"下载"）
- 指代不清（"它""这"指向不明确）
- 表头和表格内容连读不通顺
- 无意义铺垫（"首先需要明确的是……"）

---

## 四、冲突时怎么办

1. **用户当次要求** > 领域专业规则 > 表达标准
2. **已确认的项目事实**（价格、权益、截止时间）> 任何模板
3. **体裁要求**（课件、书稿、方案、合同）各不相同，不能用一套规则套所有成品
