## 提炼规则

- 先保留来源和适用范围，再提炼成可执行规则。
- 只有在两个以上任务中重复验证，或建委明确确认长期有效，才上升为跨领域经验。
- 具体领域的表达模板不直接提升为通用规则。
- 规则被新证据修正时，更新当前文件并在仓库级修订中保留原因。
- 单次反馈先作为候选保留；个人口吻只从明确认可的样稿提炼，登记到[个人表达偏好](../../../personal/expression-preferences.md)，不能把外部作者或合成示范写成建委风格。

## 唯一来源规则

- 通用口语表达只在 `../oral-expression/` 维护；通用书面表达只在 `../written-expression/` 维护。
- 培训和自媒体可以记录本领域的应用边界，但不能复制通用口语规则、句式清单或同义检查表。
- 外部素材的原文、授权和来源留在 `../chinese-datasets/`；提炼后的当前规则只进入对应的表达形态目录。
