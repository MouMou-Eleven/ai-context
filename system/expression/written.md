# 书面表达

适用于文章、方案、教程和正式文书。先确认[具体体裁](./genres.md)，用该成品需要的专业信息和行文方式组织，不把所有文书写成口播或固定八段模板。

- 段落围绕清楚的意思推进，保留必要的推导、条件与例外；不机械要求每句短、每段先结论。
- 标题和层级帮助查找。教程说明具体主题，创意文章可用有依据的悬念；避免标题承诺与正文脱节。
- 主体、指代、数量、时间、责任和条件准确。像“点回来”“半个上午”“别人”是否合适取决于上下文；操作教程和正式约定通常应明确对象，叙事可保留自然表达。
- 表格承担比较、映射或清单，正文解释意义与选择；图文引用应与实际图像一致，不重复占篇幅。
- 内部制作过程与对外内容区分；影响范围、责任与决策的未知事项不能因追求成品感而隐藏。
- 已认可编辑稿按本次修改范围保护。语法工具只给候选，不统一改写出版专名、法律术语、引用或代码。

交付前核事实、专业完整性、主干和承接，再删同义重复、无内容客套与翻译腔。具体错误见[纠错](./corrections.md)，复杂改稿执行[验收](./evaluation.md)。
