# 参考图背景保真契约

背景不是可以随意“氛围化”的空白区域。参考图任务中，背景的基础色、亮度、渐变方向、纹理密度、暗角和留白共同决定前景对比与整体气质；默认与文字、Logo 一样属于受保护视觉事实。

## 1. 先测量，再命名颜色

不要仅凭“深蓝”“科技蓝”“高级灰”等词猜背景。实施前必须：

1. 选取至少三个没有文字、图标、强光和边框的安全区域；复杂渐变使用 5–8 个区域。
2. 记录每个区域的归一化边界框、平均 RGB 和相对亮度。
3. 判断背景是纯色、渐变、纹理、图片、透明还是混合，并记录渐变中心/方向、暗角和网格等结构。
4. 将参数化 `bgColor` 默认值设为参考图的代表采样值，不得从前景高光或主题色反推背景。

安全区域必须来自真实空白；标题内部、播放键辉光、描边和播放器黑边都不是背景样本。

## 2. 默认值必须保持原色域

- `layout-locked` 的最终稳定区必须回到采样得到的背景色域与亮度范围。
- 禁止把基础背景直接与白色大比例混合，例如用 `shade(bgColor, 0.52)` 生成覆盖全画面的径向中心。这会把深海军蓝洗成灰白。
- 局部扫光、爆闪和辉光可以短暂改变背景，但必须有明确动作触发、范围受控，并在最终稳定区前完全退出。
- 参考图没有大面积雾化、白色径向光或灰色幕布时，不得为“电影感”自动添加。
- 若参考图背景包含真实渐变，按采样点重建渐变；若只是近似纯色，不要强行增加大跨度明暗变化。
- 参数化改色后的派生渐变可以通过相对明暗生成，但默认参数下仍必须通过背景区域对比。

## 3. 背景与动效分工

观赏性优先来自主体动作、因果反应、空间层级和相机路径，不靠把背景提亮。背景动态只允许承担：

- 为主动作提供方向，例如一次受控扫描；
- 为冲击点提供短促反应，例如局部亮度脉冲；
- 提供极轻的深度连续性，例如纹理或网格缓移；
- 在结果区回到参考图外观，不改变主体对比度。

如果删掉背景光效后主动作不成立，应重写动作逻辑，而不是继续增加亮度。

## 4. 可执行验收

在最终静帧与参考图上使用同一组安全区域，运行：

```bash
python scripts/compare_background_regions.py <reference.png> <final.png> \
  --region 0.02,0.02,0.20,0.12 \
  --region 0.40,0.02,0.20,0.12 \
  --region 0.02,0.65,0.12,0.20
```

默认硬门槛：每个区域归一化 RGB MAE 不超过 `0.06`，相对亮度差不超过 `0.05`。含颗粒或压缩噪声时可以调整像素级差异门槛，但平均色和亮度不得明显漂移。若必须改变背景，先把区域、幅度和原因加入已批准差异清单。

实施报告记录采样区域、参考值、最终值、脚本结论和任何获批差异。不要只写“看起来差不多”。
