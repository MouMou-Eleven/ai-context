# Personal — 个人信息总入口

> 这里保存“杨建委是谁、现在做什么、具备什么能力、有哪些已确认事实”。个人信息先从本页路由，不再把身份、荣誉、工具和待确认事项散放在仓库根目录。

## 文件索引

| 文件 | 内容 | 何时读取 |
|---|---|---|
| [`identity.md`](./identity.md) | 稳定身份、教育背景、核心经历和性格 | 写个人介绍、讲师简介、合作资料时 |
| [`current-focus.md`](./current-focus.md) | 当前项目、业务方向、近期关注和社会角色 | 判断建委现在主要在做什么时 |
| [`achievements.md`](./achievements.md) | 比赛荣誉、学术成果、讲师聘任、客户和影响力数据 | 对外使用荣誉、案例和数字时 |
| [`capabilities.md`](./capabilities.md) | 设计、AI、编程和咨询能力边界 | 判断建委适合承担什么工作时 |
| [`interests.md`](./interests.md) | 长期关注、持续探索和不关注领域 | 规划学习、选题和长期方向时 |
| [`toolbox.md`](./toolbox.md) | 当前常用 AI、设计、课件、协作和运维工具 | 了解常用工具或选择工作环境时 |
| [`open-questions.md`](./open-questions.md) | 会影响多个文件或对外表达的事实冲突 | 使用荣誉、数字或有争议口径前 |

## 读取原则

- 只需要身份时，不读取全部项目和知识库。
- 需要对外数字时，必须同时检查 `open-questions.md`。
- 当前状态与稳定身份冲突时，以 `current-focus.md` 和用户最近确认的信息为准。
- 沟通方式、语言表达和写作习惯不放在这里，统一进入 [`../expression/`](../expression/README.md)。

## 时间与工作环境

- 时区：Asia/Shanghai。
- 日常操作系统：Windows。
- 通常白天工作；深夜 23:00 至次日 08:00 不处理工作，除非紧急。
